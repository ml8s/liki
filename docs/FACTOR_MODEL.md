# 因子模型（实现结果）

本文件记录当前生产因子清单、值域、定义、数量结果和被因子引用的常量闭集。代码不读取本文件；实现权威是 Python 代码与 CSV 真值表。

实现文件结构：

```text
paipan.py         排盘层：RPC 编排，返回完整 pan
pan_schema.py     pan 契约层：拒绝快照、裁剪盘和半截盘
factors.py        因子门面：snap 编排（本命/流年）
operators_natal.py 本命算子 + pan 基础上下文聚合
operators_liunian.py 流年算子 + 目标星解析
factor_context.py FactorContext/NatalContext 显式生命周期
factor_constants.py constants.json 懒加载
factor_tables.py  因子长表加载：OR group + AND term
domain_snapshot.py 领域快照层：reserved domain facts 只读投影
yearly_eval.py    流年范围/年度断语共用编排
assertion_store.py 断语长表索引
duanyu.py         断语层：完整 pan 校验、snap + 断语表 → 断语
yearly helper     duanyu 内部年度流程，供 yearly_range/calibrate 复用
```
