# 因子模型契约

本文件是 `factors.csv` 与 `factors_liunian.csv` 的当前契约快照；因子表变更时同步更新。

## 模块分层

```
paipan.py        排盘 RPC 适配
factor_context.py 只读求值上下文
factor_tables.py 长表加载与 OR/AND 分组
operators_natal.py 本命机械算子
operators_liunian.py 流年机械算子
factors.py        因子门面：snap 编排（本命/流年）
duanyu.py        断言门面：因子快照 × 断言条件组
```
