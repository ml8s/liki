# Liki 用户指南

本指南保留完整使用说明。README 只负责快速安装和最小示例；这里解释每次提问背后的流程、边界和常见问题。

## 开始前准备

不同领域需要的输入不同，但通用原则相同：只提供当前问题所需的信息，缺项时等待 Skill 追问。

| 领域 | 建议准备 |
| --- | --- |
| 命理 | 出生日期、尽量精确的时间、出生城市、性别 |
| 起名 | 姓氏、性别、偏好；有准确出生时间时再提供出生信息 |
| 问卦 | 一个具体问题、事件或决策目标 |
| 风水 | 房屋坐向、宅运日期；八宅还需要出生年份和性别 |

## 第一次提问

可以直接把背景和问题写在一句话里：

> 帮我看看婚姻，女，1992-03-15 14:30 广州出生

信息不全也没关系。只知道“上午”“大概几点”或完全不知道时辰时，Skill 会追问，或进入考时流程。

## 对话方式

Skill 按命理师的专业习惯组织对话：一次处理一个主题，结论先行，再解释依据。

| 目标 | 这样问 |
| --- | --- |
| 追问依据 | `为什么？` / `这个结论的依据是什么？` |
| 看具体年份 | `2026 年呢？` / `未来三年怎么样？` |
| 换主题 | `那财运呢？` / `健康方面呢？` |
| 看对方 | `我们俩合不合？` |
| 要完整报告 | `帮我出一份命书` |

同一命盘会复用；切换主题时不需要重新提供出生信息。

## 命理与紫微

命理域会同时排八字和紫微，再按问题读取对应领域断语。

可覆盖的问题包括：

- 婚姻：什么时候结婚？婚姻质量如何？
- 事业：适合什么方向？创业还是打工？起伏在哪几年？
- 财运：财源类型？哪年得财、哪年破财？
- 健康：哪些脏腑或流年需要关注？
- 学业：学历能力、考试运、深造机会。
- 性格、父母、兄弟、子女、迁移等六亲与宫位问题。

输出遵循统一结构：

1. 首句给结论或明确说明证据不足。
2. 列出关键命理依据。
3. 展开解释和建议。
4. 应期只作为条件性窗口，不写成必然结果。

## 起名与改名

起名流程是：

1. 确认单字名 / 双字名、风格、避讳、必含字、叠字偏好。
2. 有完整出生时间时排八字并确定用神。
3. 从引擎字池中选择符合五行的候选字。
4. 组名并做字库、音韵、五行校验。
5. 输出候选、优点、可商榷点和代表性不推荐项。

示例：

> 宝宝起名，2024-06-10 广州出生，男，姓陈

外国人起中文名时，先从音近候选中确认中文姓；无可靠音近姓时，Skill 会说明 fallback，而不会编造音译姓。

无出生时间时，Skill 不会默认时辰，会改用期望五行策略，并明确标注“未评估用神”。

## 问卦

问卦先按目标选择方法，默认单法，不自动双盘合参。

| 目标 | 默认方法 | 示例 |
| --- | --- | --- |
| 事情能不能成 / 何时有结果 | 六爻 | `这个项目能成吗？` |
| 该不该行动 / 往哪个方向 / 怎么推进 | 奇门 | `现在该不该签？` |
| 哪天搬家、签约、开业 | 黄历 | `哪天搬家好？` |

如果同时问“能不能成”和“该怎么推进”，Skill 会先让你选择本次主问题。明确要求双法互证时，六爻独立看结果，奇门独立看策略，不混算吉凶。

奇门普通问法不需要选择排盘方法；默认使用时家奇门、转盘法和拆补定局。只有用户明确要求时才使用置闰、飞盘、刻家或其他高级口径。

| 想用的口径 | 这样说 |
| --- | --- |
| 置闰定局 | `用置闰盘看现在` |
| 洛书飞盘 | `用洛书飞盘看这件事` |
| 十分钟刻家 | `用十分钟刻家看看` |
| 十二分钟十分局 | `用十二分钟十分局看看` |
| 金函玉镜 | `用金函玉镜看今天` |

起卦 / 起局后会保留 immutable snapshot 和证据引用；追问继续复用同一 snapshot，不重排。

## 风水

风水域覆盖八宅和玄空：

| 体系 | 主要用途 |
|---|---|
| 八宅 | 命卦、四吉四凶、门主灶配合 |
| 玄空 | 宅运、山向星、元运和流年飞星 |

八宅需要出生年份和性别，不需要出生时辰。玄空需要宅运起盘日期和房屋坐向，不需要命主出生日期。

阳台、大门、主要采光面的朝向可能不同；排盘前会先确认以哪一项作为坐向依据。坐山和向山必须相对 180°。

## 常见问题

### 不知道出生时辰怎么办？

命理分析会先追问，或使用真实事件做考时校准。建议提供 2-3 个候选时辰和 3-5 件已发生大事及年份；技能会核验候选并标注置信度。证据不足时会输出“考时证据不足”。起名域不会默认时辰，会改用期望五行策略。

宝宝和青少年跳过考时，直接以提供的时辰排盘。

### 需要联网吗？

默认需要访问 JSON-RPC 引擎；排盘和规则查询都由引擎完成。高级用户也可以自建 engine，并用 `LIKI_RPC_URL` 指向本地或私有服务。

### 我的出生数据会被存储吗？

不会。Skill 约定不在对话之外存储出生信息，不索要真实姓名；出生数据只在当前会话上下文中使用。

### 结果该怎么理解？

结论是传统文化视角下的条件性解读。涉及健康、法律、财务、重大决策或安全问题时，Skill 会提示咨询现实领域专业人员。

### 怎么更新？

Skill 启动时会检查版本。提示更新后重新执行：

```bash
npx skills add ml8s/liki -y
```

### 自建引擎怎么升级？

保持 skill `VERSION.txt` 和 engine discover 返回的 `info.version` 兼容。engine 低于 skill 要求时，工具层会 fail closed，不会降级调用旧 RPC。

## 输出原则

- 首句给明确结论，或明确说明证据不足。
- 关键结论引用 engine 事实、断语 ID、因子或 RPC 依据。
- 缺失字段输出「不可用」，不猜测。
- 不把应期写成必然结果。
- 医疗、法律、金融、安全等现实问题附专业咨询提示。
