## 二、目标设计

### 流年命理域 rule 全集（yearly_range rules 参数）
- **八字流年**：`年十神 年旺衰 年用神 年大运 年合会 年神煞 年五行 年六亲`（对应本命八字层次）
- **紫微流年**：`年命宫 年官禄 年财帛 年疾厄 年夫妻 年子女 年迁移 年田宅 年父母 年兄弟 年仆役 年福德`
- 保留 `yingqi` 作为**跨命理域应期汇总**（特殊聚合，不拆散——应期断语强多宫协同）

### 关键消费模型决策
本命拆成单域后，`query(rule=十神)` 一次一个命理域。但**流年是"生活场景型"查询优先**（app 婚姻卡要"流年婚姻"）。激进全拆会让 LLM 查"流年婚姻"需拼 `年六亲+年神煞+年合会+年用神`，**易漏且反直觉**。

**推荐方案（保留场景入口 + 命理域双视图）**：
- 物理 csv 按命理域拆分（满足"命理域对齐"）
- **yearly_range 的 rules 增加"生活场景别名"**：`yearly_marriage→[年六亲,年神煞,年合会,年用神]` 等映射表，LLM 仍可用 `yearly_marriage` 便捷查"流年婚姻"，也可用命理域精确查
- 即：**不破坏现有场景入口，新增命理域并列**（非替换）

### 八字流年断语→命理层的归位规则
按**该断语命理主导目标**（`流年配偶星/财星/神煞/干忌神/日主长生…`）归入对应层：
- `流年配偶星/母星/子女星` → 六亲
- `流年财星/财坏印` → 十神
- `流年神煞X` → 神煞
- `流年干/支忌神` → 用神
- `流年日主长生` → 旺衰
- `三刑/冲/合/岁运并临/天克地冲` → 合会
- `流年官杀换运首年` → 大运
