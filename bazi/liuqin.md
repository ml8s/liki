# 六亲判断必查清单
## 📋 必查清单：父母/配偶/子女

用于分析父亲、母亲、配偶、子女问题时逐项检查。

**核心原则**：偏财为父星，年柱为父之宫位。

## 必查清单

□ 偏财明现还是暗藏？ （____）
  - 偏财透干 → 父星明显，父亲在命主人生中影响大
  - 偏财藏支 → 父星隐晦，父亲缘薄或影响小
  - 偏财不现 → 看年柱及正财（有时正财代父）

□ 年柱是否被冲刑？ （____）
  - 年柱被冲 → 祖上/父亲有重大变动
  - 年柱被刑 → 与父亲关系不睦
  - 年柱伏吟 → 父亲事重复出现

□ 偏财状态如何？ （____）
  - 偏财有根 → 父亲有能力/长寿
  - 偏财无根 → 父亲能力弱
  - 偏财被合 → 父亲被牵制（被合走=缘分薄）
  - 偏财被克 → 父亲有灾

□ 大运对偏财的影响 （____）
  - 大运生扶偏财 → 该运父亲状况好
  - 大运克制偏财 → 该运父亲有忧
  - 大运合走偏财 → 该运父亲缘薄

## 父亲应期判断

**走 Step 2.5 排队列流程：**
- 目标星 = 偏财星
- 目标宫位 = 年支
- 引动方式：偏财被冲/被合/入墓之年
- 月柱被冲刑也关联父母

□ 正印明现还是暗藏？（____）
  - 正印透干 → 母亲在命主人生中影响大
  - 正印藏支 → 母亲隐忍，影响内在
  - 正印不现 → 看偏印或年支

□ 正印状态：（____）
  - 正印有根 → 母亲身体好/长寿
  - 正印被财克 → 母亲因财务/家庭事务受累
  - 正印被合 → 母亲被牵制
  - 正印被冲 → 母亲有重大变动

## 【子女判断分支】

女命以食神伤官为子女。
时柱为子女宫。

□ 子女星（男：正官/七杀 / 女：食神/伤官）：（____）
  - 透干 → 子女明显，影响大
  - 藏支 → 子女内敛
  - 不现 → 子女缘薄，需大运引出

□ 子女星状态：（____）
  - 有根 → 子女健康/有出息
  - 被冲 → 子女有变故
  - 被合 → 子女性格被牵制
  - 子女星多现 → 多子之象

□ 时柱状态：（____）
  - 时柱空亡 → 子女缘薄
  - 时柱冲刑 → 与子女关系不睦
  - 时柱吉 → 晚年子女相伴

## 【配偶判断分支】

男命以正财偏财为妻（正财为正妻，偏财为偏室/次妻/情人）。
女命以正官七杀为夫（正官为正夫，七杀为偏夫/情人/非正式关系）。
日支为配偶宫。

□ 配偶星（男：正财/偏财 / 女：正官/七杀）：（____）
  - 透干 → 配偶在命主人生中影响大
  - 藏支 → 配偶内敛，影响内在
  - 不现 → 配偶缘薄，需大运引出

□ 配偶星状态：（____）
  - 有根 → 配偶能力好/健康
  - 被冲 → 配偶有变或夫妻分合
  - 被合 → 配偶被牵制或易有外缘
  - 配偶星多现 → 感情复杂或多婚之象

□ 配偶宫（日支）状态：（____）
  - 日支冲刑 → 婚姻不顺，多磨合
  - 日支被合 → 配偶受外界牵制
  - 日支吉 → 配偶得力

## 兄弟姐妹判断（月柱比劫）

月柱为兄弟姐妹宫，比劫为兄弟姐妹星。

□ 月柱比劫状态：（____）
  - 比劫旺 → 兄弟姐妹多或助力大
  - 比劫弱/不现 → 兄弟姐妹少或缘薄
  - 月柱冲刑 → 兄弟姐妹散落或不睦
