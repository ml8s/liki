# 旺衰判断
## 📋 方法论：旺衰与气势
### 天道、地道、人道

- **天道**：看天干之配合，天干主动，主外在表现
- **地道**：看地支之配合，地支主静，主内在根基
- **人道**：看干支之间的配合关系，判断人的行为和选择

## 旺衰三原则

判断身强身弱的三个维度。三者缺一不可，须逐项检查后再综合判断。

### 得地

日干在其他地支中是否有根：

- **强根**：地支为临官或帝旺（如甲木见寅卯）
- **弱根**：地支为余气或墓库（如甲木见辰、甲木见未）
- **无根**：地支无同五行藏干
- 注意区分：天干不通根、仅隔位生助、被贴身地支克制 → 虚浮，不视为真根

### 得势

天干有比劫帮身，或印星生身：

- 有比劫帮身或印星生身 → 得势
- 无比劫印星，或被合克 → 不得势

### 综合判断

三得之中得令最为重要。三者综合后定性判断：

- **得令 + 得地或得势** → 身旺
- **得令但无根无助** → 虚浮无根（旺而不实）
- **失令但有强根且多帮身** → 中和偏强
- **失令但有弱根或一助** → 中和偏弱
- **失令 + 无根 + 不得势** → 身弱
- **三方面大致平衡** → 中和

### 从格判断

从格的判断不依赖精确计数，而是看"势"的纯度：

- **从旺格**：印比满盘，几乎无克泄耗，日主极旺而无制
- **从弱格**：官杀/财/食伤满盘，日主无根无助
- **假从格**：有微根但势极偏，整体仍顺其势
- 从格不论正格，不适用三得法旺衰判断

判断要点：
1. 从格的关键不是"比例多少"，而是"有无对抗力量"
2. 有一点点印比对抗官杀，就不成从弱格
3. 有一点点官杀对抗印比，就不成从旺格
4. 有微根但被合克 → 仍可从；有微根且得生扶 → 不从

## 气势流通

命局喜五行流通，不喜阻滞。

**流通示例**：
- 金生水、水生木、木生火，一路顺生 → 气势流畅，人生顺遂
- 某五行过旺或过弱造成堵塞 → 需通关之物。如金木相战，取水通关

**核心口诀**：
- **旺极宜泄不宜克**：旺到极致反而喜欢被泄（食伤泄秀），克之则犯旺
- **衰极宜扶不宜帮**：弱到极致不能再帮扶（从弱格），帮之则激怒旺神
