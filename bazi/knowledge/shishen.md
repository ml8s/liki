# 十神组合场景化

十神组合不能只说"杀印相生贵格"，须说明在人生中的具体应事方向：

| 组合 | 应事场景 | 不应事场景 |
|------|---------|-----------|
| 杀印相生 | 压力大的环境中反而能学习成长；被挑战时发挥最好 | 轻松安逸的环境中难以发力；不适合自由散漫的岗位 |
| 伤官配印 | 技术/学术领域有天赋；以专业技能立足 | 纯管理岗或纯执行岗（需要创造空间） |
| 财官相生 | 资源换地位；在商业环境中攀升 | 体制内完全按资历排队的岗位（需要市场验证） |
| 食伤生财 | 才华变现；创意/内容/咨询类工作 | 固定流水线或按部就班的工作体制 |
| 比劫争财 | 适合合伙但有分配风险 | 独享型商业模式（需要分钱机制） |

## 📖 判断原则

- 性格/能力看**十神组合**，不以单一十神定论。同是正官，正官+正印与正官+七杀性格完全不同
- 十神被合走后，对应的性格/能力特征大幅减弱或消失

## 📖 女命婚姻——官杀混杂判断

女命以正官为夫、七杀为偏夫/情人。官杀混杂（正官七杀同时出现或均暗藏）时婚姻复杂。

**取清规则**（《子平真诠》"官杀混杂取清为贵"）：
1. **有合则取清**：合杀留官（七杀被合走，只留正官）→ 婚姻由浊转清
2. **有冲则取清**：冲去多余的一颗 → 看被冲走的是正官还是七杀
3. **无合无冲** → 官杀混杂无法取清 → 婚姻复杂，至少两次婚姻或长期情感困扰

**判断流程**：
- 第一步：原局正官几位？七杀几位？
- 第二步：有合化取清吗？（合杀留官 / 合官留杀）
- 第三步：有冲克取清吗？（冲去七杀留正官）
- 第四步：混杂无法取清 → 感情多波折

## 📖 学历判断——印星有效性检查

印星主学历，但印星可能受克而失效。不可仅凭"有印星"判断学历高。

**印星检查链**（《子平真诠》"印逢财则坏"）：
1. 印星在月令得令吗？（月令生印→学业顺）
2. 印星被财星克坏吗？（印被财克→因贫/因利辍学）
3. 印星有根吗？（无根则虚浮，学历名不副实）
4. 伤官透干制印？（伤官制印如果不构成"伤官配印"，则学业受阻）

**学历参考表**：

| 印星状态 | 对应学历 |
|---------|---------|
| 印旺得令+无破 | 硕士以上 |
| 印旺+微破 | 大学 |
| 印弱+无破 | 专科/高中 |
| 印弱+被克 | 中小学 |
| 无印+食伤旺 | 技艺专长，非学历型 |
| 印被财合 | 因利弃学，学历中断 |
