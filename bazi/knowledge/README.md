## 关卡纪律

1. **不填完不得进入下一关** — 每个 `□ ____（填空）` 必须填写，空项视为未完成
2. **每次重新读取** — 进入新 Phase/领域时，必须按上表 📖 重新读取对应章节，不得凭记忆
3. **Gate 1 不通过 → 不得进入 Phase 2**：旺衰、格局、用神、合会冲刑四项填空必须全部完成
4. **Gate 2 不通过 → 不得进入 Phase 3**：对应领域的专题填空必须全部完成
5. **Gate 3 不通过 → 不得输出**：通用复核 + 领域特定复核全部完成才能输出
6. **跳过填空 = 结论无效**：任何空项未填写时，对应结论不可作为最终输出
