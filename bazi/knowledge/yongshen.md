## 用神方法论

取用神以扶抑（日主强弱）为基础，格局定方向，调候做修正。

### 扶抑派（基础）

日主强弱是取用神的第一前提：
- **身弱** → 需要生扶（印星化杀生身、比劫帮身抗杀）
- **身旺** → 需要克泄耗（官杀制身、食伤泄秀、财星耗身）
- **中和** → 泄旺补缺（看命局中哪个五行过旺或过弱）

从格的判断从扶抑出发——日主极旺无制或极弱无援时，不从正格走从格路线。

### 格局派（定方向）

定格：月令支藏干透干（本气→中气→余气第一透干者定格，都不透则月令本气虚格）。
取用：定格后按顺逆取用——顺用（官印财食）生扶保护，逆用（杀伤劫刃）制化克泄。

格局用神在扶抑框架内提供方向参考：
- 扶抑需要克泄，格局指向官杀 → 用官杀
- 扶抑需要克泄，格局指向食伤 → 用食伤
- 扶抑需要生扶，格局指向印星 → 用印星
- 格局与扶抑冲突时 → 以扶抑为准，格局作为补充说明

### 调候派（修正）

月令寒暖 → 调候用神。依月令对照《穷通宝鉴》十天干逐月取调候用神。
冬夏寒暖燥湿明显时权重高，春秋温和时权重低。
调候不宜突破扶抑框架，只在扶抑方向内做微调。

### 从格处理

从格不论正格，不适用上述三派聚合规则：

**格局**：从格不论格，不适用定格→顺逆取用。
**用神**：顺其势而非逆其势。
- 从旺格：顺印比方向，忌克泄耗
- 从弱格（从杀/从财/从儿）：顺官财食伤方向，忌印比帮身
- 假从格：有微根时以假从论。大运破格（根被冲合）时回归正格
**分析逻辑切换**：
- 不看身强身弱，看势的纯度和流通
- 吉凶判断和正格相反——正格喜生扶帮身，从格喜克泄耗

### 聚合规则

三派各自独立分析后聚合：
1. 扶抑定基础方向（身弱→生扶，身旺→克泄）
2. 格局在扶抑方向内做方向选择
3. 调候在扶抑和格局的基础上做微调
4. 仅一派有输出 → 以该派为准
5. 三派皆空（极少见）→ 取命局五行分布中最弱且无克制的五行

### 用神状态分析

取用神之后，须进一步判断用神的状态：

**有根无根** — 用神在地支有藏干同五行为有根。有根则力量持久，无根则虚浮不可依。
**有力无力** — 用神得月令生扶或处于长生/帝旺之地为有力；被月令克制或处于休囚死地为无力。
**处境如何** — 用神是否被克/被合/被冲。被克则减力，被合则牵制，被冲则动摇。重点关注原局和大运对用神的生克制化。

### 清单（分析时逐项检查）

- [ ] 从格：满足从格条件吗？从旺还是从弱？
- [ ] 扶抑：日主强弱需要什么？（生扶/克泄/中和）
- [ ] 格局：月令透什么格？顺用还是逆用？
- [ ] 调候：穷通宝鉴取什么？
- [ ] 聚合：三派如何取舍？冲突怎么处理？
- [ ] 用神状态：有根吗？有力吗？处境如何？
