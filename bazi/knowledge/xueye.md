# 学业判断必查清单

用于分析学历/学业问题时逐项检查。

**核心原则**：印星为学业的第一指标，食伤为辅助。

## 📖 决策表：学历判断

**输入**：印星透干/藏支 + 印星状态（得令/被财克/有根） + 食伤状态
**输出**：学历档

### ① 印星有效性三关

| 检查项 | 通过条件 | 不通过标记 |
|--------|---------|-----------|
| 得月令 | 印星在月令得生扶 | 印星在月令休囚死 |
| 不被财克 | 原局无财星透干克印 | 财星透干克印（坏印） |
| 有根 | 印星在地支有藏干同五行 | 无根（虚浮） |

通过三关 → 印旺有效
通过两关 → 印星中等
通过一关或不通过 → 印弱或无效

### ② 大运辅助

| 大运类型 | 对学业影响 |
|---------|-----------|
| 印星运 | 学业上升期 |
| 官杀运 | 压力中学业 |
| 食伤运 | 轻学重技 |
| 财运 | 不利学业（财坏印） |

### ③ 组合判断

| 组合 | 效果 |
|------|------|
| 食伤配印 | 学以致用，聪明且学历高 |
| 食伤无印 | 聪明但学历不高 |
| 官杀生印 | 文凭带来地位 |
| 财星坏印 | 因钱弃学 |

### ④ 学历等级决策表

| 印星状态 | 食伤/财状态 | 学历倾向 |
|---------|------------|---------|
| 印旺得令+有根+无破 | — | **硕士以上** |
| 印旺+微破（缺一关） | 食伤不克印或无食伤 | **大学** |
| 印弱+无破 | — | **专科/高中** |
| 印弱+被克 | — | **中小学** |
| 无印 | 食伤旺 | **技术技艺型**（非学历） |
| 印被财合 | — | **因利弃学，学历中断** |
