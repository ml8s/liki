# 学业判断必查清单

用于分析学历/学业问题时逐项检查。

**核心原则**：印星为学业的第一指标，食伤为辅助。

## 必查清单

- [ ] 印星透干还是藏支？
  - 透干 → 学历信号强
  - 藏支有根 → 学历信号弱但有
  - 藏支无根 → 学历信号微弱
  - 印星不现 → 学历不高或靠其他途径（食伤/财星）

- [ ] 财星是否坏印？
  - 财星透干克印 → 学业中断风险
  - 大运走财运 → 此运不利学业
  - 流年财星克印 → 该年考试不利

- [ ] 大运是否走印星运？
  - 印星大运 → 学业上升期
  - 官杀大运 → 压力中学业
  - 食伤大运 → 轻学重技

- [ ] 食伤配印还是食伤无印？
  - 食伤配印 → 学以致用，聪明且学历高
  - 食伤无印 → 聪明但学历不高

- [ ] 官印相生还是财坏印？
  - 官杀生印 → 文凭带来地位
  - 财星坏印 → 因钱弃学

## 学历等级参考

| 命局特征 | 学历倾向 |
|---------|---------|
| 正印透干+有根+大运走印 | 大学及以上 |
| 正印透干但无根或财坏印 | 中学/专科 |
| 印星藏支不透+食伤旺 | 技术学校 |
| 印星不现+财官旺 | 中学及以下 |
