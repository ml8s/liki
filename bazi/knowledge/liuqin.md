# 六亲判断必查清单（父母配偶子女）

用于分析父亲、母亲、配偶、子女问题时逐项检查。

**核心原则**：偏财为父星，年柱为父之宫位。

## 必查清单

□ 偏财明现还是暗藏？ （____）
  - 偏财透干 → 父星明显，父亲在命主人生中影响大
  - 偏财藏支 → 父星隐晦，父亲缘薄或影响小
  - 偏财不现 → 看年柱及正财（有时正财代父）

□ 年柱是否被冲刑？ （____）
  - 年柱被冲 → 祖上/父亲有重大变动
  - 年柱被刑 → 与父亲关系不睦
  - 年柱伏吟 → 父亲事重复出现

□ 偏财状态如何？ （____）
  - 偏财有根 → 父亲有能力/长寿
  - 偏财无根 → 父亲能力弱
  - 偏财被合 → 父亲被牵制（被合走=缘分薄）
  - 偏财被克 → 父亲有灾

□ 大运对偏财的影响 （____）
  - 大运生扶偏财 → 该运父亲状况好
  - 大运克制偏财 → 该运父亲有忧
  - 大运合走偏财 → 该运父亲缘薄
