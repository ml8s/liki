# 事业判断必查清单

用于分析事业/职业问题时逐项检查。

**核心原则**：官杀定层次，财星定类型，食伤定才华方向。

## 必查清单

- [ ] 官杀+财星哪个透干？
  - 官杀透 + 财星透 → 管理+赚钱，事业有成
  - 官杀透 + 财星藏 → 有职但财少
  - 财星透 + 官杀藏 → 有钱但无实权
  - 官杀财星均不透 → 普通职员

- [ ] 食伤生财还是官印相生？
  - 食伤生财 → 技术/销售/经商
  - 官印相生 → 体制内/管理/文职
  - 伤官配印 → 技术专家/学术
  - 杀印相生 → 实权人物

- [ ] 大运走哪个领域？
  - 官杀运 → 事业上升/压力期
  - 财星运 → 求财期
  - 印星运 → 稳定/积累期
  - 食伤运 → 才华施展/变动期
  - 比劫运 → 竞争/合伙期

- [ ] 比劫是帮身还是夺财？
  - 身强比劫旺 → 竞争多，不宜合伙
  - 身弱比劫帮 → 合伙得助

## 职业类型参考

| 命局特征 | 职业倾向 |
|---------|---------|
| 正官+正印透 | 公务员/国企/管理 |
| 七杀+偏印透 | 军人/警察/创业 |
| 正财+食神透 | 稳定技能型 |
| 偏财+伤官透 | 经商/投资 |
| 食伤配印 | 技术专家/研发 |
| 正官+正财 | 企业管理 |
