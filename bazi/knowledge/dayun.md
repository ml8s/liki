# 大运分析方法论

## 大运与命局的互动

每步大运须从三个维度分析：

**大运干支与命局的关系**
- 大运天干与四柱天干：生合冲克刑
- 大运地支与四柱地支：六合三合六冲六害
- 重点关注：大运冲合原局哪个柱，该柱对应的宫位和十神

**大运对用神的作用**
- 大运生扶用神 → 得运，该运有利
- 大运克制用神 → 失运，该运不利
- 大运助忌神 → 该运需谨慎

## 十年分治

每步大运不能笼统概括，须细分：

**前五年（天干主导）** — 大运天干的力量在五年中逐步增强，前五年受天干影响更大
**后五年（地支主导）** — 大运地支的力量在后五年显现，地支冲合的影响在后五年更明显
**换运年** — 前后两步大运交接之年（前后各一年），是人生节奏切换的关键节点，工作/感情/健康容易出现重大变化

## 大运与流年的配合

大运定十年基调，流年看当年应事。判断方法不是简单的"生扶=吉/克制=凶"，而是看组合后对原局用神/忌神的影响：

- 流年与大运配合后生扶用神 → 吉
- 流年与大运配合后引发忌神 → 凶
- 流年虽克大运，但克的是大运中的忌神 → 反为吉
- 流年虽生大运，但生的是大运中的忌神 → 反为凶

## 冲合关系

冲与合是两种不同性质的作用，**并行分析，无先后优先级**：

- **冲**：突发、变动、断裂性事件。冲入年柱→祖辈/根基变动，冲入月柱→家庭/事业环境变动，冲入日支→婚姻/自身变动，冲入时柱→子女/晚年变动
- **合**：牵绊、聚合、持续性事件。合绊→被牵制放不开，合化→性质改变，合动→被引动为应期
- 先看是否有冲（冲比合更直观应事），再看是否有合解救（冲被合解则力度降低）
- 注意：天干论合先于论冲（天干合化重于冲克），地支冲与合并行分析

## 天干地支分论

- **天干**：主外显之事、上半年（1-6月）、社会层面、可见变化
- **地支**：主内隐之事、下半年（7-12月）、个人层面、内在变化
- 天干透出的十神决定事件性质，地支的冲合决定事件力度
- 流年对命局的影响：天干先作用于天干，地支先作用于地支

## 应期推断

同一方法适用于六亲、财运、事业、健康、感情等所有领域。

### 第一步：确定目标

| 目标 | 对应 |
|------|------|
| 父亲 | 偏财星 + 年柱 |
| 母亲 | 正印星 + 年柱（正印为生母，偏印不为母） |
| 配偶 | 男命正财/女命正官 + 日支 |
| 子女 | 食伤星 + 时柱 |
| 财运 | 正偏财星 + 财帛宫 |
| 事业 | 官杀星 + 官禄宫 |
| 健康 | 日主 + 忌神 + 疾厄宫 |

### 第二步：大运引动

大运给时间窗口。大运的如下行为打开应期窗口：

- **冲**：冲目标星或目标宫位 → 该运为该领域的窗口
- **合**：合住目标星 → 受牵制；合化 → 性质改变
- **克**：大运干支克制目标星 → 凶应窗口
- **生扶**：大运生扶目标星 → 吉应窗口
- **值**：大运干支与目标星/宫位完全相同 → 最强烈的引动

### 第三步：流年应事

流年定具体时间。如下情况为强应期：

- **双重引动**：大运+流年同时引动同一目标 → 强应年
- **三重引动**：大运+流年+命局自刑冲 → 极强年
- **引动强度分级**：三重>双重>单重。有多重引动的年份优先级高于单重引动
- **换运叠加**：换运年前后一年+流年引动 → 特殊窗口
- **伏吟**：流年与目标宫位相同（年柱伏吟→父母事）

### 应期精度

- 流年定年，流月定事
- 换运年（前一年交运+后一年）= 重点窗口
- 换运年叠加流年冲刑 = 重大变化概率高

### 引动强度分级（排序用）

同一个应期窗口内出现多个候选年份时，按以下规则排序：

**时段优先级：** 换运年（±1年） > 大运首尾年 > 普通年份
★ 换运年本身即重大事件窗口，大于普通流年吉凶

**引动方式强度：** 六冲 > 三合 > 六合 > 六害 > 相刑

**叠加效应：** 三重引动（大运+流年+命局同时引动） > 双重引动 > 单重引动 > 无引动

**宫位 vs 天干：** 流年合冲宫位（地支） > 流年十神透干（天干）
★ 地支引动宫位的应事力度大于天干十神透干。如流年合入日支（婚姻宫）> 流年天干透正官

**特殊组合：** 冲刑并见 > 单一冲 > 单一刑 | 伏吟 + 引动 > 单纯伏吟
