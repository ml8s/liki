# 财运判断规则

## 核心原则

财星定有无，身强定胜负，大运定起伏。

## 财星类型

| 类型 | 特征 | 财源 |
|------|------|------|
| 正财透干 | 稳定收入、工薪、实业 | 工资、做生意 |
| 偏财透干 | 投机收入、投资、偏门 | 股票、投资、副业 |
| 正偏财混杂 | 综合收入型 | 主业+副业 |
| 财星不显 | 靠技艺/印星生财 | 技术、专业服务 |

## 财星量级

| 状态 | 判断条件 | 财级 |
|------|---------|------|
| 财旺 | 财星有根 + 身强任财 + 大运生扶 | 富裕，有积蓄 |
| 财平 | 财星有根但身弱 / 身强但财无根 | 中等，略有盈余 |
| 财弱 | 财星无根 + 身弱 / 财被比劫克 | 温饱，存款少 |
| 比劫夺财 | 比劫旺 + 财星弱 + 无比劫制化 | 财来财去，负债 |

**注**：财星在地支有藏干同五行为"有根"。临官/帝旺位为"强根"，余气/墓库位为"弱根"。

## 大运引动

- 财星大运 → 财运上升期
- 比劫大运 → 破财期（合伙/争斗/开销大）
- 官杀大运 → 压力生财（辛苦得财）
- 食伤大运 → 技术/投资得财

## 正财 vs 偏财

| | 正财 | 偏财 |
|--|------|------|
| 来源 | 固定收入、工资 | 投资、副业、横财 |
| 风险 | 低 | 高 |
| 持续性 | 持续稳定 | 时有时无 |
| 命局特征 | 正财透+无冲 | 偏财透+无克 |
| 大运 | 财星运 | 食伤生财运 |
