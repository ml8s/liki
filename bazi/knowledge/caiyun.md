# 财运判断规则

## 核心原则

财星定有无，身强定胜负，大运定起伏。

## 📖 财星类型

| 类型 | 特征 | 财源 |
|------|------|------|
| 正财透干 | 稳定收入、工薪、实业 | 工资、做生意 |
| 偏财透干 | 投机收入、投资、偏门 | 股票、投资、副业 |
| 正偏财混杂 | 综合收入型 | 主业+副业 |
| 财星不显 | 靠技艺/印星生财 | 技术、专业服务 |

## 财星量级

| 状态 | 判断条件 | 财级 |
|------|---------|------|
| 财旺 | 财星有根 + 身强任财 + 大运生扶 | 富裕，有积蓄 |
| 财平 | 财星有根但身弱 / 身强但财无根 | 中等，略有盈余 |
| 财弱 | 财星无根 + 身弱 / 财被比劫克 | 温饱，存款少 |
| 比劫夺财 | 比劫旺 + 财星弱 + 无比劫制化 | 财来财去，负债 |

**注**：财星在地支有藏干同五行为"有根"。临官/帝旺位为"强根"，余气/墓库位为"弱根"。

## 大运引动

- 财星大运 → 财运上升期
- 比劫大运 → 破财期（合伙/争斗/开销大）
- 官杀大运 → 压力生财（辛苦得财）
- 食伤大运 → 技术/投资得财

## 📖 正财 vs 偏财

| | 正财 | 偏财 |
|--|------|------|
| 来源 | 固定收入、工资 | 投资、副业、横财 |
| 风险 | 低 | 高 |
| 持续性 | 持续稳定 | 时有时无 |
| 命局特征 | 正财透+无冲 | 偏财透+无克 |
| 大运 | 财星运 | 食伤生财运 |

## 📖 决策表：财运判断

**输入**：财星状态 + 身强弱 + 大运类型 + 比劫位置
**输出**：财运档

### ① 财星定有无

| 财星状态 | 含义 |
|---------|------|
| 正财透干 | 固定收入，稳定财源 |
| 偏财透干 | 投资/副业，波动财源 |
| 财星暗藏 | 财运一般，需要大运引出 |
| 财星不现 | 财运较弱，靠食伤生财 |

### ② 身强定胜负

| 身强弱 | 胜财能力 | 风险 |
|--------|---------|------|
| 身旺 | 能担财，财旺则富 | 比劫夺财则破 |
| 中和 | 可担财，适合稳定财源 | — |
| 身弱 | 不胜财，财多身弱反为贫 | 财旺时更穷 |

### ③ 大运定起伏

| 大运 | 财运方向 |
|------|---------|
| 财星运 | 得财（但身弱不胜则破） |
| 食伤运 | 技术/投资得财 |
| 比劫运 | 夺财，不利 |
| 官杀运 | 压力生财，辛苦得财 |

### ④ 比劫夺财检查

| 条件 | 风险 |
|------|------|
| 比劫与财星相邻（如年干劫财克月干偏财） | **夺财风险高** |
| 比劫与财星隔位 | 有竞争但不直接 |
| 无比劫 | 无夺财之忧 |
