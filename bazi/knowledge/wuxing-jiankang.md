# 五行与健康

五行与人体器官的对应关系，用于命理健康分析。

## 五行所属

| 五行 | 对应器官 |
|:---:|:--------|
| 木 | 肝胆、筋骨、眼睛、神经、毛发 |
| 火 | 心脏、血液、血管、小肠、舌头 |
| 土 | 脾胃、肌肉、皮肤、胰腺 |
| 金 | 肺、大肠、皮毛、气管 |
| 水 | 肾、膀胱、生殖系统、耳朵、骨骼、骨髓 |

## 五行失衡的健康倾向

### 某行过旺 → 所克系统易出问题

- 木旺克土 → 脾胃、肌肉系统
- 火旺克金 → 肺、皮毛、大肠系统
- 土旺克水 → 肾、生殖、耳、骨骼系统
- 金旺克木 → 肝胆、筋骨、目系统
- 水旺克火 → 心、血管、小肠系统

### 某行过衰 → 本身系统易出问题

- 木弱 → 肝胆、筋、神经
- 火弱 → 心、血液循环
- 土弱 → 脾胃、肌肉
- 金弱 → 肺、皮肤
- 水弱 → 肾、骨骼、生殖

## 特殊组合的健康应事

特殊组合给出的是健康问题的方向，不预设具体病名：

- **枭神夺食** → 消化/吸收/代谢系统
- **伤官见官** → 手术、外部创伤、炎症
- **杀旺无制** → 慢性消耗、反复不愈
- **金木交战** → 筋骨损伤、意外伤
- **水火相战** → 心脑血管、血压
- **土壅木郁** → 肝胆系统、情绪

## 注意事项

- 五行对应关系给出的是健康**倾向**，非确定性诊断
- 同一五行失衡在不同命局中应事不同，取决于大运流年的具体引动
- 以上仅为命理传统文化视角，不可替代医学诊断
