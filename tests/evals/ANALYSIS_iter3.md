## 3. 根因分类（抽样核验）

### ① 应期粒度错配（主因，约半数错题）
断语表是**本命定性级**（婚可成/婚难成、财丰、身弱——见 `tools/bazi/marriage.csv` 全部 34 条均为"婚姻状态/质量"定性），而题目是**流年事件定位级**：

- pan02题2：A.2005 结婚 vs B.2006 先签纸、2007 摆酒 vs C.2012 旅行签纸——选项粒度到**仪式细节**，流年法无法区分
- pan14题3：1993 vs 1994（agent 自述"1994 伏吟+刑+冲互动更强"仍选错）
- pan11题1（ftb_0051）：何年分手，断语仅 ying_110 命中

→ 断语给不出"哪一年"，agent 用流年干支冲合刑害 + 四化自由推断，精度 ≈ 50%。

### ② 性格断语覆盖缺口（性格 21% 最异常）
11 道性格错题中 **7 道零断语引用**（64%），agent 纯方法论自由发挥：

- ftb_0021（pan05题1）：agent 用七杀/枭神断语判 C"先斩后奏"→ 答案是 A"谨慎小心"——断语方向与真实命例相反
- `tools/bazi/xingge.csv`、`tools/ziwei/xingge.csv` 未覆盖"谨慎/冒险/暴躁/啰嗦"这类表述

### ③ 多域冲突 · 综合裁决错（健康 8/9 有引用仍错）
断语命中多个域，agent 选错主域：

- ftb_0105（pan21题5）：推理整段在分析**财运**（食伤生财/财帛巨门化禄），结论却落到**健康**题选项
- ftb_0005（pan01题5）：ying_112/113/114 应期断语命中，综合裁决仍错

### ④ 已排除：判分器取错
逐盘检查「题N 答案：X」行：298 行中**同题无不同字母**，grade-grouped 取第一个匹配无取错问题。agent 偶有中途输出答案行（pan03 两次"题5 答案：C"），字母一致，无害但建议规范。

## 4. 改进建议（按性价比）

1. **补流年应期断语**（治本）：`make_liunian_factors` + 流年层新增"婚动年/破财年/升职年/病灾年"判定规则（流年干支合冲本命配偶星/财星/官星 + 四化引动 + 神煞），让年份题有断语可依，而非 agent 自由发挥。
2. **性格断语补强**：`xingge` 表增加"谨慎保守 vs 冒险冲动 vs 暴躁 vs 啰嗦"的因子组合（正官/正印主谨慎，七杀/劫财主冒险，偏印/枭神主压抑逃避…）。
3. **SKILL.md 判题流程约束**：
   - 强制"断语命中 → 多域冲突时按题目类别锁定主域（健康题只看健康断语）"
   - 禁止推理中途输出「题N 答案：X」行（统一最后输出）
   - 断语零命中时声明"无断语覆盖，方法论推断"（便于定位覆盖缺口）
4. **评测答案保护**（顺带）：run-qwen.sh 的 stash 目录 `/tmp/liki-answers` 在 /tmp 被清后丢答案（已 git 恢复），改脚本内 `mkdir -p` + 判分前从 git 校验。

## 5. 结论

51.9% 的主因**不是断语表错误，而是粒度错配 + 覆盖缺口**：
- 断语（本命定性）与题目（流年事件 + 细节选项）不匹配 → 约 50% 错题
- 性格断语缺口 → 21% 正确率
- 多域冲突裁决 → 健康/婚姻有引用仍错

治本顺序：**流年应期断语 → 性格断语补强 → SKILL.md 流程约束**，重跑评测验证。

## 7. 年份题根因深挖（12/14 case 证据）

对 14 道年份错题逐候选年算流年因子 + yingqi 断语，发现：
- **答案年几乎从不是"流年信号最强年"**（12/14）：ftb_0018 离婚答案 2013 只命中"婚变"，pred 2018 命中冲+克更多信号；ftb_0028 被骗答案 2021 命中"婚动中"，pred 2019 命中天克地冲+反吟
- **答案年无统一命理模式**：纯合会年（ftb_0051 结婚 2016）/透+合会（ftb_0097）/换运首年（ftb_0063）/冲克年（ftb_0007）都是答案
- **结论**：年份题答案是真实事件年，规则断语只能给候选集合，无法锁定；补断语改善语义（yearly_* 域），但年份题正确率天花板有限

**正确率：60.6%（97/160）**——与 iter4（61.9%）基本持平（-1.3pp，agent 随机波动范围内）。

| 类别 | iter4 | iter5 | 变化 |

**解读**：
- 健康 yearly 确认有效（+18，两次连续高）；家庭/性格回归向好

## 12. 性格题调查（iteration-5 后）

性格题 13 道：7 PASS / 6 FAIL。逐盘因子分析：

- **「枭神主面」假设被否决**：6 个 PASS 盘（pan05/06/07/29/30/32）几乎全部也有偏印旺+枭神夺食，却判对了——加"枭神夺食→内向"断语会误伤 PASS 盘
- FAIL 盘无统一因子规律：pan09（正印+枭神+七杀）/pan12（偏印+枭神+劫财）/pan16（正印+偏印+枭神+七杀）因子各异，答案方向各异（爱抱怨/内向/机灵）
- **根因**：性格断语表已覆盖（多断语多面），agent 每次从多断语中选「主面」的方向不稳定（pan12 取劫财外向、pan06 取对）——agent 裁决随机性，非断语缺口
- **结论**：性格题不补断语（无命理依据的补法会误伤），改进空间在 agent 裁决质量（超出断语层可控范围）

**当前状态**：三轮评测 51.9% → 61.9% → 60.6%，yearly 流年断语（7 域）已落地；性格题确认是 agent 裁决随机性而非断语缺口。
