# 引擎流年神煞改进方案（liki-engine）

> 原则：冲突的不做；不部署（由用户部署）；先测试后实现（TDD）；skill 侧不重复实现。

## 1. 目标

补齐引擎 `bazi.liunian` 返回的流年神煞覆盖，让 skill 断语层能拿到完整信号：
- **E1**：流年神煞从「仅命局年支」扩展为「年支+日支」双查（补覆盖）
- **E2**：新增值年凶煞 4 种（病符/丧门/吊客/大耗）——《协纪辨方书》无争议表

## 2. 现状（代码事实）

- `internal/engine/bazi/bazi_liunian.go:82`：`r.ShenSha = computeDynamicShenSha(yearBranch, bz.Nian.Zhi, riYuan)`
  - 参数1 = 流年支、参数2 = **命局年柱支**、参数3 = 日干
- `internal/engine/bazi/bazi_shensha.go:396 computeDynamicShenSha(b, yearBranch, riYuan)`：
  - 用**年支**查：桃花/驿马/华盖/劫煞/灾煞/红鸾/天喜（map：taohua/yima/huagai/jiesha/zaisha/hongluan/tianxi）
  - 用**日干**查：羊刃/天乙（yangRenLookup/tianYiLookup）
  - 流年支 == 神煞位 → 返回
- 结论：**日/月/时支的神煞位逢流年不返回**（覆盖不全）；**值年凶煞完全缺失**

## 3. 改动项

### E1：年支+日支双查（`bazi_shensha.go:396`）

**改法**：`computeDynamicShenSha` 增加命局**日支**参数，年支查一遍、日支查一遍，合并去重。

**分支细节**：

| # | 分支 | 处理 |
|---|---|---|
| E1.1 | 三合局系神煞（桃花/驿马/华盖/劫煞/灾煞）——年支查 + 日支查 | 两者都支持（map key 是地支，年/日支均可查——《三命通会》日支桃花/驿马） |
| E1.2 | 红鸾/天喜——**仅年支查** | 红鸾/天喜属年支体系（流年红鸾按太岁），日支不查——避免错误取象 |
| E1.3 | 羊刃/天乙——按日干（现状不变） | 与支无关，不受影响 |
| E1.4 | 年支+日支命中**同一神煞**（如年支桃花位=日支桃花位=流年支） | **去重**，只输出一条（结果按 name 去重） |
| E1.5 | 年支/日支命中**不同神煞** | 都输出（多神煞并存，按查表顺序） |
| E1.6 | 无命中 | 返回空 slice（`[]shenShaEntry{}`，保持现状） |
| E1.7 | 四柱重复支（如两子） | 日支只取一次，天然无重复 |

**签名**：`computeDynamicShenSha(b, yearBranch, riBranch, riYuan)`（新增 riBranch=日柱支）

### E2：值年凶煞 4 种（`bazi_shensha.go` 新增）

**改法**：新增 `computeAnnualShenSha(b, bz)`——按流年支（太岁）查表，命局四柱逢煞支即应。

**查表**（《协纪辨方书》值年神煞，无争议）：

| 煞 | 算法 | 分类 | 描述 |
|---|---|---|---|
| 病符 | 太岁后 1 辰（子→亥） | 凶 | 流运病符临命，主病灾 |
| 丧门 | 太岁后 2 辰（子→戌） | 凶 | 流运丧门临命，主孝服/丧事 |
| 吊客 | 太岁前 2 辰（子→寅） | 凶 | 流运吊客临命，主吊丧/孝服 |
| 大耗（岁破） | 太岁对冲（子→午） | 凶 | 流运大耗临命，主破财大耗 |

**分支细节**：

| # | 分支 | 处理 |
|---|---|---|
| E2.1 | 命局四柱（年/月/日/时支）**任一 == 煞支** | 输出该煞（shenShaEntry{Name, catXiong, 描述}） |
| E2.2 | 四柱**多个**含同一煞支（如两子逢病符） | 只输出一条（结果按 name 去重） |
| E2.3 | 两个煞支相同（如病符位=丧门位？） | 查表位互不相同（后1/后2/前2/对冲），天然不冲突 |
| E2.4 | 值与 E1 的年支/日支型神煞**并存**（如同时有"流年红鸾"和"病符临命"） | 都输出（不同体系，不互斥） |
| E2.5 | 四柱无煞支 | 不输出（值年煞不临命） |
| E2.6 | 返回拼接：E1 结果 + E2 结果 | 顺序：E1（年支→日支→日干）后接 E2（值年煞） |

**不做（冲突排除）**：
- ❌ 白虎——查表版本有争议（后四辰 vs 三合后一位），用户定"冲突的不做"
- ❌ 值年红鸾/天喜——引擎已有年支型红鸾/天喜，值年型会与"流运红鸾"重复/混淆（两个方向、同语义），不新增

### E3：调用处（`bazi_liunian.go:82`）

```go
r.ShenSha = computeDynamicShenSha(yearBranch, bz.Nian.Zhi, bz.Ri.Zhi, riYuan)
r.ShenSha = append(r.ShenSha, computeAnnualShenSha(yearBranch, bz)...)
```
