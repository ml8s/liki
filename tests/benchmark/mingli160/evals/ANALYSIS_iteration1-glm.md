## 关键发现

### 1. 婚姻层缺“婚姻阶段状态机”

婚姻错题 26 道，覆盖：

- 初婚应期：`ftb_0002`、`ftb_0051`、`ftb_0063`、`ftb_0092`、`ftb_0101`、`ftb_0143`
- 二婚 / 再婚：`ftb_0077`
- 离婚应期：`ftb_0018`、`ftb_0099`、`ftb_0102`
- 当前婚姻状态：`ftb_0044`、`ftb_0048`、`ftb_0054`、`ftb_0112`、`ftb_0129`
- 对象类型与分手原因：`ftb_0106`、`ftb_0107`、`ftb_0108`
- 婚姻终止原因：`ftb_0100`

现有断语有“婚动 / 婚喜 / 婚变 / 配偶凶”，但缺少稳定的婚姻阶段模型：

1. 未婚；
2. 恋爱；
3. 初婚；
4. 婚姻不稳；
5. 分居；
6. 已离异；
7. 再婚。

因此“配偶星透”“夫妻宫冲”“红鸾”可以被同时解释为恋爱、结婚、婚变。LLM 只能按信号数量猜。

### 2. 同年反向断语仍会并存

对 80 道错题所在命盘的流年输出复核，发现同一年内存在反向信号，例如：

- 婚动 + 婚变：`ymar_120` 与 `ymar_108`；
- 成婚信号 + 婚变：`ymar_103 / 104 / 105 / 107 / 115 / 116 / 120` 与 `ymar_108 / 131`；
- 得财 + 破财：`ycai_103` 与 `ycai_101 / 110`；
- 事业升 + 事业阻：`ys_206 / ys_210` 与 `ys_106`；
- 得子 + 子女凶：`yz_101 / yz_103 / yzz_201` 与 `ystar_101 / yz_102`。

这些不是必须立即删掉的“错误断语”，传统命理中确有“吉凶同动、先吉后凶、机会中藏风险”的取象。但当前输出没有：

- 婚姻状态门槛；
- 用喜忌门槛；
- 事件阶段门槛；
- 信号强度；
- 冲突组。

所以 LLM 会把最多、最醒目的候选误当成唯一答案。

### 3. 职业层粒度不足

事业 / 职业错题 15 道，其中大量是“现职 / 行业 / 受雇或自营 / 高管或普通打工”判断：

- `ftb_0016`：家庭主妇 vs 秘书；
- `ftb_0083`：配偶打工或经商；
- `ftb_0138`：入殓师 vs 牧师；
- `ftb_0141`：私企高管 + 自营 vs 负债老板；
- `ftb_0157`：工厂 / 国企 vs 小生意企业家。

现有 `zy_101~111` 只给十神类象，如偏印、食伤、正财、七杀、官印、比劫伤官，不足以稳定区分：

- 受雇；
- 体制；
- 自营；
- 高管；
- 专业技艺；
- 家庭主妇；
- 宗教 / 殡葬；
- 体育健身；
- 新兴职业。

这不是简单补一条断语，而要建立“职业形态”复合因子：受雇 / 体制 / 自营 / 技艺 / 特殊行业 / 家庭主妇，并叠加官禄宫与当前大限。

### 4. 财富对象没有分离

财运错题里混着：

- 命主当前收入：`ftb_0053`；
- 破财应期：`ftb_0028`；
- 房产：`ftb_0104`；
- 出身家境：`ftb_0117`；
- 父亲身家：`ftb_0120`；
- 原生家庭：`ftb_0036`。

当前财运层主要看“日主财星 / 流年财星 / 财库 / 田宅”，但缺少对象化：

| 财富对象 | 主要依据 |
|---|---|
| 命主当前财 | 日主 + 财星 + 身强弱 + 用喜忌 |
| 出身家境 | 年柱 + 父母宫 + 田宅 + 原局财印 |
| 父亲身家 | 偏财 + 父母宫 + 大限流年 |
| 房产 | 财库 + 田宅宫 + 流年田宅 |
| 投资损益 | 食伤生财 / 比劫夺财 / 财星喜忌 |

同一套“得财 / 破财”无法同时回答这些题。

### 5. 六亲和健康断语过泛

家庭错题包括父亲应期、父母状态、儿时家境、原生家庭；健康错题包括手术器官、抑郁最重年、具体疾病。

当前断语常用“父星受克”“母星受克”“健康凶年”“病灾候选”等粗信号。它们能提供候选，但不足以精确到：

- 哪位六亲；
- 事件阶段；
- 手术部位；
- 疾病名称；
- 现实经济规模。

这类题不应靠强行补断语硬凑，应输出候选和低置信提示。

### 6. 性格 / 学业 / 外貌仍受“多断语同现”影响

性格错题 4 道，学业错题 3 道，外貌错题 3 道。这些领域的断语本身较多，但同一命盘常见多面性格、学历阶段、身材混合象。当前裁决准则已要求月令主面优先、状态题不查流年，但仍需更强的“状态题禁引流年噪声”测试。

## 第二轮表驱动修复

在逐题台账（`error_audit_iteration1.csv`）基础上，新增两组成复合因子与断语：

### 婚姻阶段 / 稳定性

- `男命婚姻不稳`：比劫夺财、配偶星混杂、配偶星为忌、夫妻宫破分别构成候选。
- `婚姻基础稳定`：要求配偶星为用、得地，夫妻宫安静，并排除混杂、受克、夺财或伤官克官。
- `婚姻迟滞倾向`：配偶星不现、寡宿临命，或夫妻宫破且配偶星不现。
- `婚姻波折倾向`：男/女命婚姻不稳，或夫妻宫破且配偶星现。
- `再婚倾向`：婚姻波折 + 配偶星混杂，低置信。
- 对应断语：`hun_421` 稳定候选、`hun_422` 波折候选、`hun_423` 迟滞候选、`hun_424` 再婚/多婚倾向。

### 职业形态

- `职业形态受雇`：官印相生、正财透干，或用官有力有印。
- `职业形态自营`：比劫旺、伤官现、财星现。
- `职业形态技艺`：食伤为用透干，或食伤生财而无比劫争。
- `职业形态管理`：官杀为用有力且身强。
- `职业形态特殊行业`：偏印旺、华盖、孤辰寡宿同见。
- `职业形态不稳定`：官杀为忌且食伤旺。
- 对应断语：`shi_115` 到 `shi_120`。

这轮的原则仍然是：**先决条件并入条件组，命理逻辑全部进表；agent 不做自由命理补全。**
