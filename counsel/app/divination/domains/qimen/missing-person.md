# 奇门占走失人口

> 命理依据：《奇门遁甲元灵经·卷十八·占走失》。时干为失主，六合为走失者。

## 流程

1. 用 `qimen_snapshot(matter=missing_person)`；Python 表把事象映射为六合，engine 输出用神落宫。
2. 用 snapshot.special.assertions。
3. 只解释表内候选；候选并列，不排序，不推出必然回归或必然失踪。

## 当前边界

- 仅支持 `scope=hour` + `school=zhuanpan`。
- 内外由阴阳遁表判定：阳遁坎坤震巽为内、离艮兑乾为外；阴遁相反。
- 中宫无内外 / 方向；若用神落中宫，不输出内外远近或方向候选。
- 宫位方向由八宫方向表投影，不得临场另算方位。
- 可输出方向、易寻 / 难寻 / 犹可寻候选，以及六合落宫所临九地、太阴、九天、玄武、螣蛇、朱雀、勾陈的神盘信号。
- 六合落宫星旺 / 相且临景、死、惊、伤四门时，可输出“可得候选”；星态使用 engine 的星宫旺衰标记。
