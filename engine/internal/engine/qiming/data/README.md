# Qiming data tables

Runtime tables are embedded by `data.go`:

- `naming_characters.csv`: the six-field runtime naming character projection generated by `scripts/generate_naming_characters.py`; each row has a curated or radical-inferred naming element.
- `negative_chars.txt`: characters excluded from naming pools.
- `surnames.csv`: classic Baijiaxing surname projection with pinyin, tone, original order, and curated diaspora romanization aliases. The classic source text has 504 entries (`444` single surnames and `60` compound surnames); two historical variants (`郁` and `后`) repeat, so the runtime matcher exposes 502 unique surnames. `baijiaxing_index` is the classic order, not a modern population rank. Aliases are curated, not exhaustive, and each alias is unique within its row; cross-surname alias collisions are valid historical facts and produce multiple candidates. The runtime loader fails closed on broken classic order, duplicate indexes, missing tone marks, and invalid or row-duplicate aliases. Toned pinyin projection is adapted from the MIT-licensed [`flyw/baijiaxin`](https://github.com/flyw/baijiaxin) data.
  Curated diaspora aliases currently include common Cantonese, Hokkien, Teochew, Hakka, and Vietnamese official romanizations. Vietnamese examples include `Nguyễn → 阮`, `Phạm → 范`, and `Trần → 陈`; input diacritics are normalized by the engine before alias matching.
