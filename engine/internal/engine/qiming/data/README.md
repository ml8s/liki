# Qiming data tables

Runtime tables are embedded by `data.go`:

- `naming_characters.csv`: the six-field runtime naming character projection generated by `scripts/generate_naming_characters.py`; each row has a curated or radical-inferred naming element.
- `negative_chars.txt`: characters excluded from naming pools.

Source records that are not embedded:

- `gsc_pinyin_with_tone.csv`: the source naming character table.
  - Upstream: <https://github.com/ben-hua/general_standard_chinese/tree/ec5f981f6402>
  - License: Apache-2.0
  - Local SHA-256: `bec882bc208fdaf50d851e37b045f233bfc234238b96e17c8e154c5485367f6b`
- `radicals.yaml`: the source radical-to-element table used to build the naming projection.
