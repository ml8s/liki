# 断语库 schema v2（三层架构：常量表 + 复合因子定义表 + 断语表）

> 架构原则（决策纪要）：
> 1. **规则只由表定义**——engine 只做机械匹配/求值，命理知识 100% 在表
> 2. **禁止自算兜底**——因子源：A 引擎已给=直接用、B 机械提取=查表、C 真缺=报缺（当前 C=0）
> 3. **回归命理定性**——"旺/重/多/弱" = 该十神**五行**月令旺衰（wang_shuai），**非 count≥N 阈值**（count 只作事实数据，如印星三关数）
> 4. **复合因子计算表驱动**——复合因子 = 因子间逻辑运算，用因子定义表表达
> 5. **factor_gen 封装 RPC**——birth-info 进 → 全量因子快照出（编排权在 python，agent 只解读/综合/考时）
> 6. **流年应期归第 3 层**——需要时单独做（逐年 bazi.liunian）

## 数据流

```
birth-info
  │
  ▼
第一层 factor_gen（表驱动）：
  ├─ 解析出生信息（birth.py）
  ├─ 调 RPC（fullchart/yongshen/ziwei）      ← 封装（client.py）
  ├─ 复合因子求值（constants.yaml + factors.yaml + 算子）
  ▼
因子快照（一份 dict，键=因子名）
  │
  ├─ 第二层：断语匹配（match：因子快照 ↔ 断语表）→ 本命断语
  └─ 第三层：流年应期（factors_liunian.yaml，需要时）→ 候选年
```

## 二、复合因子定义表（factors.yaml）——第一层表驱动核心

每个复合因子 = 一行逻辑（算子 + 参数）。engine 通用求值器逐行执行。

### 算子集（engine 通用求值器提供）

**基础算子（十神/五行）**：
| 算子 | 语义 | 依据 |
|---|---|---|
| `现(十神)` | 该十神出现（count≥1，事实） | 十神存在 |
| `透(十神)` | source=stem（天干透出） | 透干为显 |
| `藏(十神)` | source=main_qi（地支本气） | 藏支为待 |
| `得地(十神)` | 地支有根（藏干同五行） | 得地 |
| `旺(十神/五行)` | 其五行 wang_shuai ∈ {旺,相} | 月令司权（《子平真诠》） |
| `弱(十神/五行)` | 其五行 wang_shuai ∈ {休,囚,死} | 月令失令 |
| `缺(五行)` | wuxing_count=0 | 五行缺失 |
| `克(A,B)` | A 五行克 B 五行（常量表） | 五行相克 |
| `生(A,B)` | A 五行生 B 五行（常量表） | 五行相生 |
| `直读(路径, 值)` | 引擎字段路径=值 | 透传引擎 |
| `含(字段, 值)` | 引擎列表字段含值（如 shen_sha 含"桃花"） | 神煞查询 |
| `宫含(宫位, 星, 唯一?)` | 紫微宫位含星/四化 | 紫微斗数 |
| `大运十神(年, 星类)` | 该年大运 step 的 shi_shen ∈ 星类 | 大运为根 |

**逻辑算子**：`且` / `或` / `非`（组合子句）

### 因子定义行示例

```yaml
因子:
  # ── 十神旺衰（定性，无阈值）──
  - 名: 食伤旺
    判: 或: [旺: [食神, 伤官], 透: [食神, 伤官]]
  - 名: 比劫旺          # 兄弟星旺/比劫重 同源
    判: 旺: [比肩, 劫财]
  - 名: 财旺
    判: 或: [旺: [正财, 偏财], 透: [正财, 偏财]]
```

## 三、断语表（17 域 yaml 升级为域包）——第二层匹配

```yaml
# marriage.yaml 域包
领域: 婚姻
引用因子: [gender, 配偶星透干, 配偶星受克, 宫破, 比劫重, 大运配偶星, 桃花, 天机独坐夫妻宫]
  # ↑ 本域"相关列"声明（必须——engine 校验：断语引用了未声明列=错）
条目:
  - id: hun_101
    事件: 婚姻状态
    强度: 硬
    优先级: 低
    约束: {gender: male, 配偶星透干: 1, 配偶星受克: 0}
    结论: 财星透干且不受克——妻星得地，婚可成（命理表达——评测标签在测试层映射）
    依据: 男命财星透干为妻星得地且不受克（《渊海子平》"财星透干方为妻星得地"）
```

### 匹配语义（保持）

- **行内 = AND**：约束全命中 → 行成立
- **行间 = OR**：多行成立 = 多面性（agent 合成）
- **零行命中** = 经典未覆盖偏型 → agent 综合（标注"无经典断语直接覆盖"）
- **硬断语**（结构定性）→ 规则定案；**软断语**（倾向证据）→ agent 综合
- **优先级**（高/中/低）：同域多行命中时 if-elif 次序（主妇/年柱官杀/从格/紫微交叉优先）

### 值语义

- `1` = 条件须命中；`0` = 条件须排除（排他上下文）；**缺省 = 无关**
- `any_of: {...}` = 任一命中（拆行/特殊结构）
- `>=N` = **仅事实计数**（印星三关数等；"旺/多/重"判断一律用旺衰定性，不用 >=N）

## 五、engine 执行流程（通用求值器）

```
factor_gen(birth_info):
  rpc_data = client.full_panchang(birth_info)          # 封装 RPC
  snapshot = {}
  for 定义 in factors.yaml.因子:                        # 表驱动逐行
    snapshot[定义.名] = 求值(定义.判, rpc_data, constants)
  return snapshot

match(断语表, snapshot):
  for 行 in 断语表.条目:
    if 快照满足(行.约束):  hits.append(行)
  return hits  # 按优先级排序
```

- **engine 零领域知识**：只执行算子 + 查常量表 + 匹配——所有命理知识（五行生克/十神定义/旺衰判断/组合规则/断语）在表
- **换领域复用**：六爻/风水同架构（不同常量表+因子表+断语表）
