# 八字合盘方法论

## 📋 方法论：双人盘事实合参

## 核心理念

合盘只做**可复核的命理事实并列与合参**，不做打分、不定“良配 / 慎配”，也不把单一冲合说成关系成败。所有结论必须回到双方原局、夫妻宫、配偶星、大运流年与现实事实验证。

## 经典依据边界

| 对象 | 传统口径 | engine 输出边界 |
| --- | --- | --- |
| 日主 | 日干为主我，两造日干可见生、克、同气、五合 | 只输出关系事实；不得由日干直接定性格或成败 |
| 夫妻宫 | 日支为配偶宫 | 只输出双方日支的六合 / 半合 / 拱 / 冲 / 刑 / 害 / 破等成对事实 |
| 配偶星 | 男命以正财为主、偏财为辅；女命以正官为主、七杀为辅 | 分别记录透干 / 藏支、柱位与旬空；辅助星不等同主配偶星 |
| 十神 | 以各自日主定对方天干的十神视角 | 输出双向十神事实；不做能量传递定论 |
| 五行 | 双方干支与藏干五行可计数 | 输出各自、合并与扶抑用神在对方盘的出现次数；不评分 |
| 纳音 | 纳音五行属传统辅助口径 | 输出柱对柱生克同异；不以纳音单独定合婚 |
| 神煞 | 天乙、禄、桃花、驿马、空亡等各有取法 | 只记录对应支是否出现在对方四柱；不单独作吉凶结论 |
| 大运流年 | 大运流年按本命逐盘分析，再按应期规则合参 | `compare_birth_charts` 不合成“大运同步”结论；应期走双方各自流年工具 |

## Engine 契约

`compare_birth_charts` 返回八字与紫微两层事实：

- 八字：`day_master`、`spouse_palace`、`zhu_cross`、`shi_shen_cross`、`wuxing_cross`、`nayin_cross`、`spouse_star`、`shensha_cross`。
- 紫微：并排返回双方命宫、夫妻宫、子女宫主星。空宫借对宫是紫微通例，但借星只作观察，不等同本宫坐星。
- 两支关系不得由交叉工具输出完整三合 / 三会；完整成局仍须看单一命盘全盘结构。
- 引擎不输出“良配 / 可配 / 慎配 / 不利”，也不输出“缘分分数”。

## 分析规则

1. 先读双方原局：日主强弱、用喜忌、夫妻宫状态、配偶星透藏与空亡。
2. 再读两柱交叉事实：日干五合 / 生克、日支六合 / 冲刑害、其他柱位重要冲合。
3. 配偶星合参时，主星优先，辅助星只作补充；空亡是结构证据，不是唯一否定。
4. 神煞只作辅助取象；桃花、驿马、贵人等不能替代配偶星与夫妻宫。
5. 应期必须分别看双方大运流年，寻找同一时段的同域引动；不得用“当前大运干支关系”推断关系节奏。
6. 紫微只读双方夫妻宫、子女宫主星与借星，配合八字同域证据；不同体系冲突时并列说明，不得强行合并。

## 输出边界

- 只输出事实、传统取象、优势证据、摩擦证据与需现实确认的问题。
- 必须说明证据层级：主配偶星 / 夫妻宫强于辅助神煞；双体系同向强于单体系单点。
- 缺时辰、性别或完整盘时，明确说明无法评估哪些对象。
