# 风水分析

## 依赖的领域知识

[必读] - 八宅: domains/bazhai/youxing.md（游星吉凶+门主灶）
[必读] - 玄空: domains/xuankong/feixing.md（飞星断语）+ yuanyun.md（元运）

## 用户问法 → 流程分支

| 用户问题 | 分支 |
|---------|------|
| 我家风水怎么样 / 布局问题 | 八宅 |
| 流年风水 / 旺山旺向 | 玄空 |

## 📖 流程

| 步骤 | 类型 | 条件 / 目标 | 动作 | 产物 |
|---|---|---|---|---|
| 1 | 收集参数 | 八宅：出生年份、性别；玄空：宅运日期、坐向 | 流年问题先 `time.now` | 分析参数与年份 |
| 1a | ⛔ 阻塞确认 | 坐向证据 | 区分“阳台 / 主要采光面朝向”和“大门朝向”；确认以哪个为准。能精确到二十四山时先确认山名，再换算 index | 已确认坐向 |
| 1b | 💬 参数收集 | 户型描述 | 门取主要出入口，主卧取主用 / 最大卧室，灶取独立厨房或烹饪区；多间卧室时确认哪间是主用房间 | 门主灶方向或卦位 |
| 2 | 八宅盘 | 已有命卦和门主灶 | `bazhai.chart` → `bazhai.layout` | 命卦、四吉四凶、门主灶 |
| 3 | 八宅断局 | 读取 `domains/bazhai/youxing.md` | 游星吉凶与布局建议 | 八宅侧证据 |
| 4 | 玄空盘 | 已有坐向和宅运 | `xuankong.chart`，按需 `xuankong.liunian` | 山向盘、元运、流年飞星 |
| 5 | 玄空断局 | 读取飞星、元运与裁决文档 | 山空旺衰与体系冲突裁决 | 玄空侧证据与裁决 |
| 5a | ⛔ 阻塞确认 | 展示八宅 + 玄空核心结论摘要 | 编号选项：1.出完整布局建议 2.先看某个方位 | 确认的分析方向 |
| 6 | 输出 | 结论前置 | 先给一句话判断，再列核心依据，最后展开建议 | 判断、方位建议、化解思路 |

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 八宅缺出生年份或性别 | 先问出生年份和性别；不需要出生时辰 |
| 玄空缺宅运日期或坐向 | 先问建成 / 入住 / 改宅日期与坐向；不要用命主出生日期替代 |
| 坐向不是相对 180° | 先纠正坐向；玄空坐山与向山必须相隔 12 山，不能同山或随意组合 |
| 阳台、大门、主要采光面朝向不同 | 不自动替用户选择；列出差异并要求确认作为坐向依据 |
| 八宅与玄空结论冲突 | 按 `domains/fengshui/caijue.md` 分层裁决；不得只引用有利体系 |

## 📖 输出模板

| 输出 | 内容 |
|---|---|
| 结论 | 首句给“可用 / 可用但需调整 / 不宜”方向；冲突时明确说分层可用 |
| 核心依据 | 八宅、玄空各 1-2 条关键事实；冲突必须并列 |
| 八宅 | 命卦、东四命 / 西四命、四吉四凶、门主灶 |
| 玄空 | 元运、山向、流年飞星与旺衰 |
| 建议 | 按房间 / 方位给可行动调整；标注传统文化视角 |
| 现实边界 | 采光、通风、结构、安全、预算等现实约束不得由命理结论替代 |
