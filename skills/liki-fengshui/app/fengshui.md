# 风水分析

## 依赖的领域知识

[必读] - 八宅: domains/bazhai/youxing.md（游星吉凶+门主灶）
[必读] - 玄空: domains/xuankong/feixing.md（飞星断语）+ yuanyun.md（元运）

## 用户问法 → 流程分支

| 用户问题 | 分支 |
|---------|------|
| 我家风水怎么样 / 布局问题 | 八宅 |
| 流年风水 / 旺山旺向 | 玄空 |

## 📖 流程

1. 确定房屋坐向 → 八宅定东西四宅
   输出：□ 坐向____

2. 八宅排盘 → `bazhai.chart`（命卦+四吉四凶方）
   输出：□ 宅卦____ 命卦____ 吉凶位____

3. 断局（八宅）→ domains/bazhai/youxing.md（游星吉凶）
   输出：□ 游星吉凶____

4. 玄空排盘 → `xuankong.chart`（山向盘+元运）→ 按需 `xuankong.liunian`（流年飞星）
   输出：□ 当运飞星____ 旺山旺向____

5. 断局（玄空）→ domains/xuankong/（feixing 飞星断语 + yuanyun 元运）
   输出：□ 飞星吉凶____ 门主灶____

6. 综合结论
   输出：□ 吉凶____ 化解建议____

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 用户没说房屋坐向 | 先问坐向，不知则按八宅命卦论 |
| 用户没给出生年份（定命卦） | 先问出生年份 |

## 📖 输出模板

### 一、命卦判定（八宅）
出生年份 → 命卦 → 东四命/西四命

### 二、八宅方位
四吉方（生气/延年/天医/伏位）、四凶方（祸害/六煞/五鬼/绝命）在各方位分布。

### 三、布局建议
- 大门、主卧、厨房宜在吉方
- 卫生间、储物间宜在凶方
- 命卦与宅卦是否配合

### 四、大运飞星（玄空）
当运飞星、流年飞星、旺山旺向。

### 五、吉凶化解
凶方化解方法（五行制化、屏风/植物/颜色调整）。
