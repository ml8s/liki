# 八宅 / 玄空冲突裁决

> 结论冲突不是“挑吉的写”。八宅和玄空回答的问题不同；冲突时必须并列证据，再按用途裁决。

## 领域分工

| 体系 | 主体 | 判断什么 | 强项 |
|---|---|---|---|
| 八宅 | 人（命卦） | 命卦与宅 / 方位的配合；久居、常坐、安门、设灶的适配 | 宅命配合 |
| 玄空 | 宅（时空盘） | 宅运、山向飞星、旺衰与流年引动 | 时空气场 |

## 裁决顺序

1. **安全与现实优先**：结构、采光、通风、消防、噪音、隐私、动线先行；命理不得推翻现实硬约束。
2. **功能匹配**：先判断房间用途。久坐 / 卧室偏看八宅命卦配合；判断当运旺衰、动土、开门、纳气偏看玄空。
3. **冲突并列**：分别给出八宅星、玄空山向星 / 流年星，不隐藏不利侧。
4. **行动策略**：
   - 两体系同吉：可优先推荐。
   - 两体系同凶：优先调整或另选。
   - 八宅凶、玄空吉：可作次选，必须给出八宅化解和使用限制。
   - 八宅吉、玄空凶：慎用；优先调整纳气、 timing 或另选。
5. **建议措辞**：用“可用但需调整 / 慎用 / 不宜”，不用绝对吉凶承诺。

## 案例

东北卧室在八宅为五鬼，但玄空双九到坐：

- 八宅侧：五鬼不宜脏乱、红色、长期冲突性使用。
- 玄空侧：当元吉气到坐，可利久坐或静态使用。
- 裁决：**可用但需调整**——保持整洁、避免大红大紫、不宜作为争吵 / 病痛话题的主位；床头与纳气布置结合坐山。

## 方向 → 卦位

用户只给八方位时按此映射；若只给“进门区”“靠近客厅”这类描述，必须先确认具体方位或门位。

| 方位 | 卦位 |
|---|---|
| 北 | 坎 |
| 东北 | 艮 |
| 东 | 震 |
| 东南 | 巽 |
| 南 | 离 |
| 西南 | 坤 |
| 西 | 兑 |
| 西北 | 乾 |

二十四山可用中间山定宫：坎含壬子癸，艮含丑艮寅，震含甲卯乙，巽含辰巽巳，离含丙午丁，坤含未坤申，兑含庚酉辛，乾含戌乾亥。边界山仍应让用户确认精确朝向。
