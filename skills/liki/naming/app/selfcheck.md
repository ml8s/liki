# 自选名字评估

> RPC 报文：使用 `naming/RPC.md` §5；查单字时另用 §6。
> 场景：用户已有候选名字。起名/改名 → `naming.md`；外国人起中文名 → `foreign.md`。

## 依赖的领域知识

[必读] - bazi: `naming/domains/bazi/yongshen.md`「用神方法论」（有用神信息时）
[必读] - qiming: `naming/domains/qiming/ziku.md`「字库与选字」

## 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- |
| 1 | 收集名字 | 确认姓、名、用户约束；有出生信息才排盘 | 名字、用神或“未评估五行” |
| 2 | 字库校验 | 发送 `RPC.md §5 qiming.check` 报文；查单字时发送 `§6 qiming.char` | valid / errors / phonetic / wuxing |
| 3 | 结论 | 结合字义、出处等级、音韵、五行与约束评估 | 优点、可商榷点、建议 |

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 无出生信息 | 跳过五行评估，只评字库事实和音韵 |
| 字库未收录 | 显示 invalid，并建议从 `qiming.pick` 重新选字 |
| 评估字段缺失 | 跳过该维度并标注缺失 |

## 输出模板

### 示例

```text
结论：「王浩然」整体可用，五行匹配良好。
五行：浩（水）然（火）——有出生信息时给匹配结论；无排盘时标「未评估五行」。
音韵：wáng hào rán，三字声调 2-4-2，起伏有致，无不良谐音。
建议：可使用；如需更精确五行匹配，补排八字后复核。
```
