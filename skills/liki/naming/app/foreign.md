# 外国人起中文名

> RPC 报文：使用 `naming/RPC.md` §2-§7。
> 场景：外国人罗马字姓起中文名。通用起名/改名 → `naming.md`；自选名字评估 → `selfcheck.md`。

## 依赖的领域知识

[必读] - bazi: `naming/domains/bazi/yongshen.md`「用神方法论」+ `naming/domains/bazi/calibration.md`「时辰判定」
[必读] - qiming: `naming/domains/qiming/ziku.md`「字库与选字」

## 流程

| 步骤 | 类型 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- | --- |
| 0 | 交互 | 罗马字姓 | 发送 `RPC.md §2 qiming.surname` 报文 | 中国姓候选 |
| 0a | ⛔ 阻塞确认 | 用户必须选定一个候选中的中国姓 | 展示 `match_level`、拼音与传统《百家姓》序号；明确说“请选择后我再继续”。禁止暗定后继续取字 | 已确认中国姓 |
| 0b | 💬 参数收集 | 一次列出默认建议 | 单 / 双名、风格、避讳、出生信息或期望五行 | 命名参数 |
| 1 | 排盘 | 有完整日期和时间时 | 先发送 `RPC.md §7 city.coords / tianwen.time / bazi.chart`，再发送 `bazi.fullchart` 报文 | 用神 |
| 1 | 排盘 | 时辰缺失或模糊 | 问一次能否确认；仍不能确认时不排八字，进入期望五行分支 | 未评估用神 |
| 2 | 取字 | 有用神默认「用+用」，不足回退「用+喜」 | 期望五行按该五行取，“不限”合并五池；仅在 `chars` 内过滤语义、出处和跨语言音韵 | first / second 字池 |
| 3 | 组名 | 机械组合 | 发送 `RPC.md §4 qiming.compose` 报文 | 候选名 |
| 4 | 校验 | 引擎事实 | 发送 `RPC.md §5 qiming.check` 报文；姓氏仅用于展示和谐音判断 | 校验事实 |
| 5 | 候选输出 | 展示 5-8 个候选、首选与可商榷点 | 只输出候选与简要理由，不展开全卷 | 候选清单 |
| 5a | ⛔ 阻塞确认 | 用户选定终选名或迭代方向 | 展示首选推荐与编号选项；等用户回复后才能继续 | 终选或迭代方向 |

### 交互模板

0a ⛔ 只输出：根据「{罗马字姓}」找到候选：1.{姓} {拼音}（{match_level}）…。请选择编号或直接写姓。停在这里，等用户回复后继续；不要输出候选名。
0b 💬 只输出：单 / 双名、风格、避讳、出生信息或期望五行；每项给默认值。回复“都用默认”可直接继续。
5a ⛔ 只输出：首选推荐「{名}」({拼音})、一个优点 / 可商榷点、其他候选；选项 1.确认首选 2.看其他候选详情 3.换方向。停在这里，等用户回复后继续。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 原始姓不是拉丁字母 | 要求用户提供官方或惯用罗马字拼写；不自行转写西里尔、阿拉伯、日文或韩文 |
| `strategy=baijiaxing_fallback` | 明确说明没有可靠音近姓；候选只是按传统《百家姓》顺序给出的备选，不得包装成音译 |
| 多个候选同级别 | 并列给用户选择；不按序号伪造唯一答案 |
| 出生时区不明 | 先询问 UTC offset 或出生地；不默认北京时间 |
| 关键候选 | 先确认中国姓，再深入中文名；不合并为一次暗定 |
| 用户要求直接给全名 | 说明中国姓必须先确认；可给出候选与选择建议，但不得替用户暗定 |
