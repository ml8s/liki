# 起名用神选择

`create_birth_chart` 的 `fu_yi` / `tiao_hou` / `ge_ju` 提供扶抑 / 调候用神候选和格局结构候选。起名只做选择与复核，不重新推盘，也不把 `ge_ju.pattern_god` 直接当最终用神。

## 选择顺序

1. **从格复核**：`ge_ju.ge_ju` 含“从”时，检查日主无根或极旺、原局无印比破格；双证成立走顺势用神，方向冲突以复核为准。
2. **冬夏调候**：月令为亥子丑或巳午未时，优先调候候选，扶抑复核；`tiao_hou.secondary_condition` 必须满足。
3. **清透格局**：读 `pattern_god` / `pattern_god_ten_god` 判断命局主题与表达方向；最终补益五行仍由扶抑、调候和盘面力量复核。
4. **普通命局**：取扶抑候选，格局作辅助说明。
5. **合并冲突**：扶抑与调候方向相同则合并；冲突按 1-4 裁决，输出“以某源为准”的理由。

## 候选冲突处理

| 候选关系 | 处理 |
| --- | --- |
| 扶抑与调候同五行 | 合并输出 |
| 格局格神为印比，扶抑需克泄 | 格局只作主题辅助；补益仍以扶抑复核为准 |
| 格局格神为官杀 / 食伤 / 财，扶抑需生扶 | 格局只作主题辅助；不得因格神方向硬取补益 |
| 仅扶抑或调候有候选 | 采用该源 |
| 两源皆空 | 取命局最弱且无克制五行 |

## 喜神与忌神

- 最终用神取自扶抑时，喜神 / 忌神先取 `fu_yi.xi / fu_yi.ji`。
- 最终用神取自调候时，可用 `tiao_hou.secondary_wuxing`，但 `secondary_condition` 必须满足；不得机械反推调候忌神，忌神回到扶抑和整体组合。
- `ge_ju` 不提供 `xi / ji`；格神方向不能直接作喜忌。
- 两源皆空时，取命局最弱且无克制五行为用神；喜神为生扶该五行者，忌神为克泄该五行者。
- 从格喜顺势同党，忌逆势异党。

## 输出

最终只输出一组 `yong / xi / ji`、主要依据来源、取舍理由和从格复核结果；engine 字段缺失时标注“用神未评估”。
