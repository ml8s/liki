# 起名用神选择

`bazi.fullchart` 的 `yong_shen` 已给出扶抑、格局、调候三派候选。起名只做选择与复核，不重新推盘。

## 选择顺序

1. **从格复核**：`ge_ju` 含“从”时，检查日主无根或极旺、原局无印比破格；双证成立走顺势用神，方向冲突以复核为准。
2. **冬夏调候**：月令为亥子丑或巳午未时，优先调候候选，扶抑复核。
3. **清透格局**：月令本气透干成格时，取格局候选，扶抑验证力度。
4. **普通命局**：取扶抑候选，格局作辅助说明。
5. **合并冲突**：候选五行相同则合并；冲突按 1-4 裁决，输出“以某派为准”的理由。

## 候选冲突处理

| 候选关系 | 处理 |
|---|---|
| 三派同五行 | 合并输出 |
| 格局印比，扶抑需克泄 | 取格局方向，但输出用量需克制 |
| 格局官杀 / 食伤 / 财，扶抑需生扶 | 取格局方向，但输出用量需减弱 |
| 仅一派有候选 | 采用该派 |
| 三派皆空 | 取命局最弱且无克制五行 |

## 喜神与忌神

喜神、忌神直接取所选学派的 `xi` / `ji`。三派皆空时，取命局最弱且无克制的五行为用神；喜神为生扶该五行者，忌神为克泄该五行者。从格喜顺势同党，忌逆势异党。

## 输出

最终只输出一组 `yong / xi / ji`、所选学派、取舍理由和从格复核结果； engine 字段缺失时标注“用神未评估”。
