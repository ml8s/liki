# 出生时辰判定（起名精简版）

起名只在获得完整出生日期和时间时排八字定用神。时辰缺失或模糊时，不得默认补时；改用期望五行策略继续起名。

## 决策表：时辰确认

| 用户情况 | 处理方式 |
|---------|---------|
| 提供了具体出生时间 | 直接采用；海外出生先取经度并做真太阳时校正 |
| 时间不确定（如"下午 / 晚上"） | 问一次能否确认时辰；确认后排盘，仍不能确认则不排八字 |
| 只给日期、无时间 | 问一次是否可补时辰；不能补则不排八字 |
| 用户明确说"不知道时辰" | 不排八字，改用期望五行策略 |

## 未确认时辰的起名路径

1. 询问期望五行；用户选“不限”时合并五个字池。
2. 输出明确标注「未评估用神」。
3. 不得使用午时、平均时、默认时或推测时补排八字。
4. 不追问真实出生时辰之外的信息，不引导编造。

## 边界

| 异常场景 | 处理方式 |
|---------|---------|
| 用户只知年月日 | 问一次是否能补时辰；不能补则不排八字 |
| 用户说"时辰不重要，随便" | 不排八字，改走期望五行策略 |
| 海外出生且时辰完整 | 必须传出生地经度校正真太阳时；经度缺失先询问 |
