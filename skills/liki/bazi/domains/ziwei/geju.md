# 特殊格局

## 📖 翻译表：格局识别

| 格局 | 组成 | 含义 |
|------|------|------|
| 杀破狼 | 七杀+破军+贪狼 | 动格，一生变动大成大事者多 |
| 紫府同宫 | 紫微+天府 | 贵格，领导才能 |
| 紫微朝垣 | 命宫紫微，三方四正有左辅右弼/天魁天钺/文昌文曲/禄存等百官朝拱 | 贵格，有权威（仅紫微坐命无百官不构成） |
| 日月并明 | 太阳在巳/午（庙）+ 太阴在酉/戌/亥（庙），分别居命宫三方 | 光明磊落，名利双收 |
| 日月反背 | 命宫三方四正见日戌月辰或日子月午（《全书》原文结构） | 反背劳碌；勿把任意双落陷概化为本格，昼夜与离宗成家另核 |
| 月朗天门 | 太阴在亥 | 清贵，文采出众 |
| 日丽中天 / 金灿光辉 | 太阳居午为日丽中天；太阳独坐命宫午宫为金灿光辉 | 光明有力；加一主星则不再是金灿光辉的“独坐”边界 |
| 机月同梁 | 天机+太阴+天同+天梁 | 吏人格，公职稳定 |
| 武贪同行 | 武曲+贪狼同宫（丑未），同宫火星或铃星为「武贪火铃」格 | 有火铃少年暴发；无火铃发较迟，仍主富 |
| 廉贪同行 | 廉贞+贪狼 | 桃花犯，才艺格 |
| 雄宿朝元 | 廉贞守命于未申，且无羊陀火铃空劫六煞 | 声名远播；加煞平常 |
| 府相朝垣 | 天相+天府在三方 | 贵格，稳重有成 |
| 巨火羊 | 巨门+火星+擎羊 | 凶格，是非官非 |
| 刑忌夹印 | 命宫天相被化忌与天刑分居两侧夹制 | 凶格，被拖累 |
