# 紫微时辰校验

用于八字考时后交叉验证候选盘。前提：命主为成人、已有候选紫微盘、候选 ≥2、用户已提供 ≥3 件婚姻 / 子女 / 事业等人生事实。

## 工具流程（agent 编排，复用排盘与应期判断）

考时 = 排盘 + 应期判断的组合编排（工具经 `tools/list` 自举），不新增工具：

1. 收集 2-3 个候选出生时间（同一人，时辰临界 ±）。
2. 对每候选：公历 → 农历 → 排本命盘 → `chart`。
3. 取因子快照 → `factors`。
4. 对每件真实事件 `(year, 领域)`：查该年该领域应期断语。
5. 对比各候选的事件断语——哪个候选在对应年份命中与真实事件一致的信号。
6. 输出对比矩阵与最吻合候选 + 依据。

事件年份为年号（紫微农历春节界），不做日期换算。

## 结构性排除

| 人生事实 | 紫微对照 | 处理 |
| --- | --- | --- |
| 婚姻段数 | 夫妻宫主星、吉煞与四化 | 星性与多次婚史不符则排除；凶星叠化忌且事实相符则保留 |
| 有无子女 | 子女宫主星与空宫 | 星性与子女事实明显不符则降置信 |
| 事业层次 | 官禄宫主星、辅煞与四化 | 格局与实际成就明显不符则排除 |

## 事件吻合核对

| 吻合度 | 判断 |
| --- | --- |
| 吻合 | 流年昌曲引动与考试年份、化忌煞星与事件性质匹配 |
| 不吻合 | 流年星曜四化与事件性质冲突 |
| 不相关 | 无法建立领域对应 |

## 校准参考

| 维度 | 强信号 | 反信号 |
| --- | --- | --- |
| 感情 | 夫妻宫红鸾天喜、化禄 | 夫妻宫吉多化禄但实有多次婚史 |
| 学业 | 命 / 福德宫昌曲化科 | 学历事实高而文星全弱 |
| 子女 | 子女宫天同天梁 | 子女宫杀破狼空宫但实有子女 |
| 事业 | 官禄宫紫府左右、化权 | 官禄宫空劫冲破但实有高位 |

## 输出

| 结果 | 含义 |
| --- | --- |
| 保留 | 紫微验证通过，与八字一致 |
| 存疑 | 紫微与八字结论相左，需用户确认 |
| 排除 | 星曜与人生事实明显冲突 |
