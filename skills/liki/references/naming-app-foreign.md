# 外国人起中文名

> 场景：外国人罗马字姓起中文名。通用起名/改名 → `references/naming-app-naming.md`；自选名字评估 → `references/naming-app-selfcheck.md`。

## 依赖的领域知识

[必读] - bazi: `references/naming-bazi-yongshen.md`「用神计划」+ `references/naming-bazi-calibration.md`「出生时辰判定（起名精简版）」
[必读] - qiming: `references/naming-qiming-ziku.md`「字库与选字」

## 流程

| 步骤 | 类型 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- | --- |
| 0 | 交互 | 罗马字姓 | 使用姓氏候选能力 | 中国姓候选 |
| 0a | ⛔ 阻塞确认 | 用户必须选定一个候选中的中国姓 | 展示匹配级别、拼音与传统《百家姓》序号；明确说“请选择后我再继续”。确认前不继续取字 | 已确认中国姓 |
| 0b | 💬 参数收集 | 一次列出默认建议 | 单 / 双名、风格、避讳、出生信息或期望五行 | 命名参数 |
| 1 | 排盘 | 有完整日期和时间时 | 排八字并取 `用神裁决能力`；可用时保留完整 `选定用神` | 用神计划 |
| 1 | 排盘 | 时辰缺失或模糊 | 问一次能否确认；仍不能确认时不排八字，进入期望五行分支 | 无八字计划 |
| 2 | 取字 | 目标五行 | 双字名两个字位均传同一目标五行；“不限”合并五池；仅在返回字池内过滤语义、出处和跨语言音韵 | `第一用神` / `第二用神` 字池 |
| 3 | 组名 | 机械组合 | 使用组名能力 | 候选名 |
| 4 | 校验 | 工具事实 | 使用起名校验能力并传 `选定用神`；姓氏用于展示和谐音判断 | 字库、音韵与目标五行命中事实 |
| 5 | 候选输出 | 展示 5-8 个候选、首选与可商榷点 | 只输出候选与简要理由，不展开全卷 | 候选清单 |
| 5a | ⛔ 阻塞确认 | 用户选定终选名或迭代方向 | 展示首选推荐与编号选项；等用户回复后才能继续 | 终选或迭代方向 |

### 交互模板

0a ⛔ 只输出：根据「{罗马字姓}」找到候选：1.{姓} {拼音}（匹配级别）…。请选择编号或直接写姓。停在这里，等用户回复后继续；不输出候选名。
0b 💬 只输出：单 / 双名、风格、避讳、出生信息或期望五行；每项给默认值。回复“都用默认”可直接继续。
5a ⛔ 只输出：首选推荐「{名}」({拼音})、一个优点 / 可商榷点、其他候选；选项 1.确认首选 2.看其他候选详情 3.换方向。停在这里，等用户回复后继续。

## 输出模板

```text
结论：推荐中文名与姓来源（罗马字姓 → 候选 + 匹配类型）。
候选：5-8 个候选（名 + 拼音 + 五行 + 音近关系）。
理由：逐字五行角色、字义、出处与跨语言音韵。
```

### 示例

```text
结论：推荐「李安楠」。Smith→李（用户确认候选）；安楠（土木，音近 Anne），楠命中目标五行木。
```

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 原始姓不是拉丁字母 | 要求用户提供官方或惯用罗马字拼写；不自行转写西里尔、阿拉伯、日文或韩文 |
| 姓氏策略为传统《百家姓》回退 | 明确说明没有可靠音近姓；候选只是按传统《百家姓》顺序给出的备选，不包装成音译 |
| 多个候选同级别 | 并列给用户选择；不按序号伪造唯一答案 |
| 出生时区不明 | 先询问出生地并解析 IANA 时区；用户只给 UTC offset 时，先确认对应出生地 / IANA 时区，不把 offset 直接当工具参数，也不默认北京时间 |
| 关键候选 | 先确认中国姓，再深入中文名；不合并为一次暗定 |
| 用户要求直接给全名 | 说明中国姓必须先确认；可给出候选与选择建议，但不得替用户暗定 |
