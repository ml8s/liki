## 📖 八宅 / 玄空合参与裁决

结论冲突不是「挑吉的写」——两体系回答的问题不同，冲突时必须并列证据，再按用途裁决。

- **领域分工**：八宅（人 / 命卦）主命卦与宅 / 方位配合，久居、常坐、安门、设灶的适配，强项是宅命配合；玄空（宅 / 时空盘）主宅运、山向飞星、旺衰与流年引动，强项是时空气场。
- **安全与现实优先**：结构、采光、通风、消防、噪音、隐私、动线先行；命理不得推翻现实硬约束。
- **功能匹配**：先判断房间用途——久坐 / 卧室偏八宅命卦配合；当运旺衰、动土、开门、纳气偏玄空。
- **行动策略**：两同吉优先推荐；两同凶优先调整或另选；八宅凶玄空吉可作次选（附八宅化解与使用限制）；八宅吉玄空凶慎用（调纳气 / 时机或另选）。
- **案例**：东北卧室八宅为五鬼、玄空双九到坐 → 八宅侧五鬼不宜脏乱 / 红色 / 长期冲突性使用，玄空侧当元吉气到坐利久坐或静态使用 → 裁决「可用但需调整」：保持整洁、避免大红大紫、不宜作为争吵 / 病痛话题主位。
- **方位归一化**：用户只给八方位时按 北→坎、东北→艮、东→震、东南→巽、南→离、西南→坤、西→兑、西北→乾 映射；只给「进门区」「靠近客厅」这类描述时先确认方位或门位。
- **二十四山定宫**：坎含壬子癸，艮含丑艮寅，震含甲卯乙，巽含辰巽巳，离含丙午丁，坤含未坤申，兑含庚酉辛，乾含戌乾亥；边界山仍让用户确认精确朝向。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 八宅缺出生年份或性别 | 先问出生年份和性别；不需要出生时辰 |
| 玄空缺宅运日期或坐向 | 先问建成 / 入住 / 改宅日期与坐向；不要用命主出生日期替代 |
| 坐向不是相对 180° | 先纠正坐向；玄空坐山与向山必须相隔 12 山，不能同山或随意组合 |
| 阳台、大门、主要采光面朝向不同 | 不自动替用户选择；列出差异并要求确认作为坐向依据 |
| 八宅与玄空结论冲突 | 按「八宅 / 玄空合参与裁决」分层裁决，并明确说分层可用；不得只引用有利体系 |
| 只给八方位 / 只给边界山 | 先按「方位归一化」映射到卦位；边界山让用户确认精确朝向，不替用户选山 |
| 采光、通风、结构、安全、预算等现实约束 | 由相关专业评估，不由本卡判断 |
