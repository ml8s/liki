# 考时（出生时间存疑）

> 场景：出生时间、时辰、日界、交节或历史时制存疑；先归一候选与影响域，再用受影响体系做时敏事实交叉校准，定可用时间或说明不确定边界。

## 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- |
| 1 | 收集候选 | 与用户确认候补时辰（或“只记得上午 / 下午”）、出生地与已知人生大事；存在历史时制歧义（如夏令时）先确认口径 | 候补时间、地点事实与验证事件 |
| 2 | 时间候选归一 | 用地点坐标和时间候选归一能力展开候选；保留每个候选的原因域，不静默选择 | 候选集与影响域 |
| 3 | 影响域分类 | 按候选原因域判断影响八字、紫微还是双侧；交节通常只影响八字 / 大运 | 执行计划 |
| 4 | 受影响侧校准 | 按候选逐侧执行本域时敏事实与应期验证工具 | 逐候选、逐侧证据 |
| 5 | 交叉裁决 | 双侧同指一时辰 → 定案；不同 → 并列候选与各自证据；交节-only 只用八字 / 大运证据 | 校时结论 |
| 6 | 输出 | 按模板给出结论、依据与不确定边界；唯一结论须经用户确认 | 校时报告 |

时间事实明确时，可由用户事实直接组装 schema 要求的排盘主体；时间模糊、跨边界或多候选时，先用时间归一化能力并列原因并等待用户确认。不得编造缺失信息或静默选择候选。

## 边界条件

| 异常场景 | 处理方式 |
| --- | --- |
| 无任何可验证事件 | 不给唯一时辰；给出候补区间与建议补充的事件类型 |
| 两侧结论冲突 | 并列两侧证据与适用层面，不强行合并 |
| 用户无法提供更多信息 | 按已知信息给出条件性结论，标注未校时 |
| 宝宝 / 青少年 | 跳过校验，使用用户输入时辰 |
| 用户已明确时辰 | 以用户确认为准 |
| 候补 < 2 | 请用户确认唯一时辰或补充候补 |
| 人生大事 < 3 | 考时精度不足；按「后续选项」向用户提供降级路径 |
| 候补 > 5 | 先缩小时间范围，再进入结构排除 |
| 输入时间距时辰交界 ≤30 分钟 | 仍先按输入排盘；旁注提示建议校准，不得静默视为确定时辰 |

## 输出模板

> 输出依据时：引用工具返回的断语 ID 和该断语的经典依据简引（`source.classic_basis`），格式为 `断语 ID —— 经典简引`。

```text
结论：可用时辰与证据覆盖说明（或候补区间）。
依据：两侧时辰敏感事实（列断语标识）。
证据覆盖：唯一候选（结构排除后仅剩一盘）/ 优势候选（吻合数明显领先）/ 并列候选（平局后借问题方向分界）/ 证据不足（无充分事件可校验）。
不确定项：未验证事件与对结论的影响。
后续选项：证据不足时可择一继续：
  1. 补充更多人生大事年份后重新校准；
  2. 用最可能时辰看趋势，输出标注「未校时」；
  3. 只看不受时辰影响的分析（五行大方向、大运阶段、紫微命宫主星）。
```

### 示例

```text
用户：我是 1990 年 5 月 20 日早上出生的，但不确定是 5 点还是 7 点，帮忙看看哪个对。

结论：卯时（05:00–07:00 交界处）为优势候选，两个候补中卯时吻合 3 项人生大事（2015 年结婚、2018 年购房、2021 年生子），辰时吻合 1 项（2015 年结婚）。
依据：卯时盘 2015 年流年夫妻宫化禄（断语 ID —— 红鸾星动，嫁娶缘成）；辰时盘 2018 年财帛宫化忌（与购房事实不符）。
证据覆盖：优势候选（吻合数 3:1 明显领先）。
不确定项：2021 年生子事件在两个候补中均未出现对应断语，不影响主要结论。
后续选项：如需进一步确认，可补充 2019–2020 年事业变动年份后重新校准。
```
