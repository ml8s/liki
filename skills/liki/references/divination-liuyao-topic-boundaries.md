# 六爻专题断语边界

> 用途：约束按用神解读时的常见误判。断语来自引擎返回的事实与条件候选，本页只规定“不能怎样断”，不新增断法。

## 通用原则

- 用神旺衰是必要条件之一，不是单一充分条件；必须同时看原神、忌神、仇神、动变与世应关系。
- 条件候选只表示“若条件成立则倾向如此”，不得改写为绝对结果。
- 应期是候选窗口，不是承诺日期。
- 工具不读取用户问题；领域化解释由持有 `question` 的调用方完成，不得把问题文本反灌进 chart / ask 参数。

## 分专题

### 求财 / 交易（`wealth`，用神妻财）

- 兄弟发动不必然破财，须看是否克到用神以及用神旺衰。
- 财爻旺不等于已获利，仍须看世爻能否承受。
- 边界：重大投资、借贷、全仓决策应引导专业财务意见。

### 事业 / 功名（`career`，用神官鬼）

- 官鬼旺不一定升迁，须看世爻能否承官以及文书 / 名位是否有力。
- 子孙动不必然不利，某些去职、转型、避险语境下是解除压力。
- 边界：不构成职业、法律或人事处分建议。

### 学业 / 考试（`study`，用神父母）

- 父母爻旺只是文书 / 名位有气，不等于真实成绩或录取。
- 子孙动未必全凶，宽题、减压、创作类事项须结合目标。
- 边界：不替代学业规划或招生结果。

### 失物（`lost_item`，用神妻财）

- 玄武不必然代表盗窃，不可指认他人。
- 伏神有气只说明可寻候选，不保证寻回。
- 边界：涉嫌犯罪、人身安全或执法事项应引导专业处理。

### 出行（`travel`，用神世爻）

- 驿马类取象只是辅助，不能单凭六神断行程。
- 应爻受伤不一定行程失败，须先确认问的是道路、目的地还是对方。
- 边界：签证、交通、安全事项以现实规则和紧急信息为准。

### 健康（`health`，用神世爻）

- 健康取象按传统六爻语境解释，不替代医疗判断。
- 应期解释状态变化或关注节点，不作为停药、换药或治疗指令。
- 边界：急症、重病、怀孕、心理危机应立即引导医疗或紧急帮助。

### 婚恋（`relationship`，男占女妻财 / 女占男官鬼）

- 不能只按性别推断用神；同性、代占、非二元视角必须显式确认。
- 六合不必然复合或结婚，须看用神与世应是否实际受益。
- 边界：不判断他人私密意愿、忠诚或健康状况。

### 官司 / 诉讼（`legal`，用神官鬼）

- 官鬼旺衰只作事态压力候选，不预测胜诉。
- 世应冲合不能替代证据、程序和法院判断。
- 边界：不构成法律建议；重大争议应咨询律师。

### 自身（`self`，用神世爻）

- 世爻旺不等于身心强健，健康语境须专业医疗。
- 世爻弱不等于无力，须看原神救应。
- 边界：健康、安全与情绪危机以专业帮助为准。

### 对方 / 环境（`other`，用神应爻）

- 应爻只代表所问对象或环境，不自动指特定个人。
- 应爻强弱不能替代对方真实意愿或事实核查。
- 边界：不判断他人私密意愿、忠诚或健康状况。

### 家宅 / 住宅（`home`，用神父母）

- 父母爻旺只说明屋宅文书有气，不等于交易必然成功。
- 搬家、买卖与产权须核实现实流程。
- 边界：产权、贷款、安全与法律事项以专业核查为准。

### 子女 / 晚辈（`children`，用神子孙）

- 子孙爻旺不必然指向生育，可能是解忧、创作或晚辈事务。
- 生育、健康与监护须以医疗和现实条件为准。
- 边界：孕育、子女健康与监护问题须专业医疗或专业帮助。

### 父母 / 长辈（`parents`，用神父母）

- 父母爻代表长辈、文书与庇护，不等于对子女事务的判断。
- 长辈健康与赡养问题须以现实医疗与家庭条件为准。
- 边界：医疗、监护与家庭安全事项应寻求专业帮助。

### 兄弟 / 朋友 / 同辈（`siblings`，用神兄弟）

- 兄弟爻在求财语境常为竞争者或分利者，但在朋友、同辈语境是所问对象本身；先看问题域。
- 兄弟发动不必然破财或胜利，须分清竞争、合作或分利。
- 边界：重大合作与竞争决策应核查合同、资质和风险。
