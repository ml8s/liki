# 财运分析

## 流程

| 步骤 | 条件 / 目标 | 合参所需信息 |
| --- | --- | --- |
| 1 | 财星 | 八字 + 紫微：财运本命（正 / 偏财、透藏、是否为用；财帛宫） |
| 2 | 胜财能力 | 八字 + 紫微：财运本命（能担 / 不能担 / 中和） |
| 3 | 风险与运势 | 八字 + 紫微：财运应期（十年窗口与比劫夺财风险） |
| 4 | 具体细节或流年 | 八字 + 紫微：财运 / 房产本命；八字 + 紫微：财运应期（目标年，含财库与流年财信号） |

## 📖 双盘财运合参

- **受骗 / 合伙**：紫微巨门忌 + 仆役宫凶 → 被熟人所欺 / 合伙受骗；与八字偏印为忌 + 比劫争财同参。
- **置产 vs 理财**：紫微田宅宫吉星只论置产（买房 / 置业），不论理财；断经济状况 / 积蓄看八字财星与比劫。
- **宫位语义**：紫微财帛宫 / 田宅宫主财运与资产，与八字财星同域互证。

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 原局无财星 | 查食伤（食伤生财为隐性财源）|
| 财多身弱 | 标注财难存 / 富屋贫人（`cai_104`），需大运帮身方可担财 |

## 输出模板

```text
结论：一句话财运层次与财源类型。
依据：财星透藏与根气、能否担财、比劫与食伤（列断语 id）。
运势：当前大运性质与得财 / 破财关注年。
建议：一个理财方向与风险提示。
```

### 示例

```text
结论：财运中等偏上，偏财有根，比劫不旺。
依据：偏财得地透干（cai_105）；比劫不旺，夺财压力小。
运势：当前大运食伤运生财（2025-2034），2027 丁未流年财星得令。
建议：适合中长期投资；2026 丙午年比劫现，短期不宜大额投入。
```
