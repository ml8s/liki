# 命书总入口

## 路由

| 用户问题 | 处理 |
| --- | --- |
| 用户明确要完整命书 | 走完整报告流程 |
| 算命 / 看命 / 没说目的 / 未命中具体主题 | 命书开场：先排盘 / 校准，再给命盘核心信号与编号深入入口 |
| 明确问婚姻、学业、健康等 | 直接进入对应 app 卡 |
| 双人关系 | `references/natal-app-compatibility.md` |

## 流程

| 步骤 | 类型 | 条件 / 目标 | 合参所需信息 | 产物 |
| --- | --- | --- | --- | --- |
| 1 | 排盘 | 取得命盘 | 八字 + 紫微：排盘与基础因子 | 命盘与基础因子 |
| 2 | 基础框架 | 基础结论 | 八字 + 紫微：基础本命（身强弱、格局、用神裁决、冲合） | 基础结论 |
| 2a | ⛔ 阻塞确认 | 确认四柱、时辰与校准 | 本域：展示命盘概要与编号选项 | 确认的命盘 |
| 3 | 命书开场 | 无明确问题 / 默认入口 | 八字 + 紫微：婚姻 / 学业 / 健康 / 事业 / 财运 / 性格 / 家庭本命摘要 | 核心信号、领域摘要与编号入口 |
| 4 | 专项模式 | 用户选择领域，或已明确问题 | 本域：切换对应场景卡 | 专项断言 |
| 5 | 双盘验证 | 比较两侧结论 | 本域：按证据强度口径判强 / 中 / 弱 / 并列 | 证据强度 |
| 6 | 历史校准 | 有真实事件 | 八字 + 紫微：历史事件校准（回推 3-5 段） | 校准结果 |
| 6a | ⛔ 阻塞确认 | 确认分析范围 | 本域：展示校准摘要与编号选项 | 确认的分析范围 |
| 7 | 输出 | 按模板组稿 | 本域：结论 + 依据链 | 完整命书 |

### 交互模板

```text
2a ⛔ 只输出：四柱概要、日主、时辰；选项 1.正确，继续 2.时辰可能不准，我要校准。停在这里；不要输出领域分析。
6a ⛔ 只输出：校准摘要、核心命盘概要；选项 1.确认出完整命书 2.先看某个领域。停在这里；不要展开全卷。3 命书开场只输出：2-3 条最显著信号；每条一句；末尾列编号深入入口。不展开完整章节。
```

## 边界条件

| 场景 | 处理 |
| --- | --- |
| 用户深入某个领域 | 切换对应 app 卡，不在本卡展开该领域全卷 |
| 历史事件吻合 | 只作校准参考，与因果证明分开表述 |
| 双盘证据 | 按 `references/natal-dual-system.md` 标注单侧、互证或分歧 |
| 年龄、健康、生育、重大财务或时间窗口 | 结论旁提示结合专业意见与现实条件；不得把应期写成必然结果 |

## 输出模板

> 输出依据时：引用工具返回的断语 ID 和该断语的经典依据简引（`source.classic_basis`），格式为 `断语 ID —— 经典简引`。

单一领域只输出该领域对应章节；命书开场只输出领域摘要（每域 1-2 条核心结论与断语标识）、核心信号与编号深入入口，不展开全卷；否则按下列结构全卷输出。顺序先回应问题——首句给直接方向，再列 2-3 条核心依据，之后展开完整章节。

| 章节 | 必要内容 |
| --- | --- |
| 八字总览 | 四柱与藏干、日主五行、身强弱、格局、宫位对应领域 |
| 五行十神 | 五行分布、十神配置、关键组合与应事方向 |
| 用神喜忌 | 用神裁决结果的最终用喜忌、命中规则、冲突与用神状态 |
| 格局 | 正格 / 从格、顺逆用、成破格、相神与清浊 |
| 大运 | 起运、各运干支、与命局生克、当前运与换运年 |
| 当前流年 | 干支关系、大运互动、应事应人与关注事项 |
| 紫微总览 | 命身宫、主星格局、十二宫要点、四化与三方四正 |
| 紫微限运 | 当前大限主题、流年命宫与引动宫位 |
| 双盘交叉 | 按证据强度口径输出一致、单侧或分歧 |
| 综合建议 | 事业、财运、感情、健康各一句信号与建议；信号不足如实标注 |

### 示例

```text
正印格身强，喜食伤与财星；八字戊土身强，紫微命宫天相（庙）、夫妻宫太阳（旺）；合参事业食伤生财、婚姻中稳。
```
