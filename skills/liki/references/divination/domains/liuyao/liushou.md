# 六爻六神（定色彩/情状）

> 命理依据：《卜筮正宗》六神章。六神描述事情的性质/情状/氛围，**不决定吉凶**，只给吉凶判断"染色"。

## 引擎输出字段说明

- `yong_shen.liu_shou`：用神临的六神（青龙/朱雀/勾陈/螣蛇/白虎/玄武）

## 📖 解读：六神 → 色彩/情状

| 六神 | 主事 | 情状/色彩 |
| ------ | ------ | ---------- |
| 青龙 | 喜庆、酒色、财喜 | 顺遂、喜事 |
| 朱雀 | 口舌、文书、官非 | 争吵、是非、口舌 |
| 勾陈 | 田土、牵缠、迟滞 | 拖延、纠缠、迟滞 |
| 螣蛇 | 虚惊、怪异、缠绕 | 惊吓、虚妄、缠绕 |
| 白虎 | 刑伤、血光、丧服 | 凶伤、急迫、血光 |
| 玄武 | 暗昧、盗贼、隐私 | 隐秘、暗昧、暗昧之事 |

## 📖 解读原则

- **吉凶不变，色彩不同**：六神不改变吉凶判断，只补充"事情的情状氛围"
- 用神旺相 + 生用 = 吉；用神临青龙 = 吉，且喜庆；临朱雀 = 吉，但有口舌
- 用神临白虎 = 吉，但有刑伤/急迫色彩；临玄武 = 吉，但有暗昧/隐私

**解读时**：在吉凶结论上附加六神色彩（如"事可成，但需防口舌是非（朱雀）"）。

### 六神"人事在场与否"的事实义（判是否登场/现身）

六神除色彩外，还有**人事在场与否**的事实义——用于判"人/事是否实际现身"，与吉凶色彩是两个维度：

| 六神 | 在场事实义 |
| --- | --- |
| 玄武 | 藏匿、隐而不现（对应人未登场、事未显形） |
| 青龙 | 公开显现、风光出场 |
| 朱雀 | 显于言、显于文书（口舌/文书层面在场） |
| 白虎 | 凶事显形、急迫显现 |
| 螣蛇 | 虚像、影影绰绰（似在非在） |
| 勾陈 | 牵缠在场、滞留不脱 |

### 玄武未登场的判定边界

“玄武=未登场”的组合判断由工具按 `liuyao_condition_rules.json` 的 `xuanwu-presence-needs-compound-conditions` 输出（并列条件齐备才判未登场，单凭玄武不判）；LLM 只解读工具返回的 `statement / restored / conclusion / forbidden`。

六神不决定吉凶方向，但决定"人/事是否在场"这一事实，两者都要读。
