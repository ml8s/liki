# Divination 工具契约

本文只约定变量绑定、领域边界与黄历参数；其余工具参数以 MCP schema 为准，流程见 app 卡。

## 变量绑定

| 变量 | 绑定 |
| --- | --- |
| `$LIUYAO_SNAPSHOT` | 六爻起卦（快照）工具返回的对象 |
| `$LIUYAO_ANSWER` | 六爻追问工具返回的对象 |
| `$QIMEN_SNAPSHOT` | 奇门排盘（快照）工具返回的对象 |
| `$QIMEN_ANSWER` | 奇门追问工具返回的对象 |
| `$HUANGLI_RESULT` | 黄历择日工具返回的对象 |

## 边界约束

- 起卦 / 排盘创建快照，追问基于快照出断语；追问只接受同法快照，`snapshot` 必须用对应变量原样对象，不得裁剪或重建。
- snapshot 是 immutable 上下文：同一 snapshot 可切换用神或事项从不同角度解读；新事件、新时间、新决策必须新建 snapshot（auto 模式会重新起卦，不得伪装成同一卦）。
- 事项与用神二选一；显式用神仅在用户明确要求时传，优先于事项自动推导。
- `snapshot_digest` 只读，不修改、不伪造。

## 黄历择日

engine MCP 黄历工具：返回连续 N 天的黄历信息；事项给定时按建除事项规则输出适配推荐，只输出日期适配事实，不预测现实结果。

- 问事必填；事项用工具 schema 的 `event` 枚举值（经 `tools/list` 读取），不自行改写。
- 起始日期 `start_date`；查几天用 `count`（默认 3、上限 30）；事项用 `event` 单值限定。
- 日期范围默认（不传范围）不设，按服务端默认返回。

## 专占公共边界

奇门专占（失物 / 捕盗 / 走失 / 捕亡）共用以下口径：

- 排盘取默认时家转盘基础盘，不传事项或用神。
- 断语读 `snapshot.special.assertions`，只解释工具命中的表内候选；候选并列给出，不合并成单一必然结论。
- 方向与内外由八宫方向表、阴阳遁表投影；中宫无方向 / 内外，用神落中宫时不给对应候选。
