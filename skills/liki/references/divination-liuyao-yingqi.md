# 六爻应期（定何时应验）

> 命理依据：《增删卜易》应期章。应期是根据用神旺衰、动静、空破、合冲与墓库状态推出的候选触发条件，不是必然日期。

## 引擎输出字段说明

- `用神.旺衰`：用神旺衰
- `用神.月破`：用神月破
- 用神逢旬空
- `用神.墓库`：用神入墓
- `动爻关系`：动爻关系

## 📖 解读：用神状态 → 应期

| 用神状态 | 候选触发 |
| --------- | ------ |
| 旺相 | 逢值或逢合候选；仍须核动静与是否被绊 |
| 休囚 | 待生扶旺相候选 |
| 月破（假破/真破） | 逢值、逢合、出月候选；真破不作成事主据 |
| 旬空（假空/真空） | 出空、填实或冲空候选；真空不作成事主据 |
| 入墓 | 冲墓、刑开或合起候选 |
| 动爻 | 逢值、逢合或冲开合绊候选 |

## 📖 解读原则

- **旺相逢值逢合应**：用神旺相，逢值日或逢合日应验
- **休囚待旺相应**：用神休囚，待旺相时（逢生扶）应验
- **月破逢合补破应**：月破待逢合补破应验
- **旬空出空填实应**：旬空待出空/填实/冲空应验
- **入墓冲/刑/合开应**：入墓待冲墓、刑开墓库或合起应验

## 📖 取舍规则（动静 × 来源 × 合刑冲）

「逢合」先分动静，再确认来源是否实际命中。《增删卜易·六合章》明确：

> 爻之合者，静而逢合，谓之合起。动而逢合，谓之合绊。……爻静或与日月动爻合者得合而起。即使爻值休囚亦有旺相之意。

| 用神状态 × 逢合 | 含义 |
| ------ | ----------- |
| 旺相发动，逢值逢合 | **合为应**——即应期（动而旺者，合日应验） |
| 旺相安静，逢合 | **合起则动**——合起之日应事 |
| 休囚发动，逢合 | **合为绊**——衰而动者被绊住，待冲开合神之日 |
| 休囚安静，逢合 | **静爻合起**——虽休囚，合起后可列旺相之意；仍须复核真假空破与事体 |
| 变爻与日辰相合 | 变爻本身在标记应期日，按应期论 |

静爻合起必须确认来源是**日支、月支或动爻支**与用神本支六合；只凭抽象六合关系不列候选。引擎中的 `静爻逢合` 遵守该来源边界；旬空、月破已有专门应期路径，不重复生成该候选。动爻逢合的传统口径是**合绊**，其释放规则应单独复核，不与静爻合起混用。

取舍优先级：**先定吉凶与旺衰 → 再定动静与合的来源 → 最后列应期候选**。禁止跳过旺衰直接取「逢合为绊」。

### 用神两现

卦中用神两现，依《增删卜易》取舍（逐条判，禁止凭感觉二选一）：

1. 舍休囚，取旺相者
2. 舍安静，取发动者
3. 舍月破，取不破者
4. 舍旬空，取不空者
5. 舍被伤，取不被伤者
6. 皆同 → 取临世应者（近取）

（「取旺不取衰」优先于「财爻持世」——持世/临应仅作同格时的近取参考。）

### 入墓应期三路

入墓（含世爻入墓）的应期除**逢冲**（冲墓）外另有两路：

- **刑开**：墓库被三刑之支相刑（如戌墓逢丑日，丑戌刑开）
- **合起**：日、月或动爻合起墓中静爻用神（如子丑六合起静爻用神）

三路并察，取先到之日。

### 短应期（日级）

旺相引动可在日辰层面应验（隔日级）：动而旺相之用神，逢值、逢合之日即应，不必待年月；静卦入墓逢刑开亦同。

**应期是吉凶之外的独立维度**——先断吉凶（成/难成），再断应期（何时）。

## 常见误判

- 只断"会成"不落应期（应给时间窗口）
- 应期与吉凶混淆（吉凶定方向，应期定时间）
- 旺相动爻逢合误判为「合绊」（应先看旺衰动静——动而旺者合为应）
- 用神两现时按持世优先或把墓作第一层通用取舍
- 静卦入墓只知待冲（忘刑开、合起两路）
