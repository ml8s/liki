# Liki 宝宝起名取名 — 八字用神 + 五行选字

> 覆盖通用起名、外国人起中文名与自选名评估。八字排盘由引擎计算；字库、音韵与五行匹配由 counsel 起名工具在本地完成，LLM 只在工具返回范围内做语义、出处、音韵与文化适配筛选。

## 工具契约

agent 经 `counsel` MCP 使用姓氏候选、取字、单字校验、组名与起名校验能力；工具与参数由 MCP 自省和 schema 提供。

## 路由

三张场景卡共享「输入 → 排盘 / 五行策略 → 用神裁决 → 取字 → 组名 → 校验 → 输出」领域链，差异见各卡流程表。

| 用户问题 | 入口卡 | 功能 |
| --- | --- | --- |
| 起名 / 改名 | `references/naming/app/naming.md` | 通用起名与改名 |
| 外国人起中文名 | `references/naming/app/foreign.md` | 罗马字姓转受控中文姓候选并起中文名 |
| 评估自选名字 | `references/naming/app/selfcheck.md` | 自选名字评估 |

## 硬边界

- 外国人的中文姓候选只能来自姓氏候选能力；无音近候选时说明 fallback，不自创音译姓。
- 关键候选是阻塞确认：外国人起名必须先让用户从姓氏候选结果中确认中国姓；终选前也必须等用户反馈。
- 生成流候选字仅在取字能力返回的字池内过滤；必含字冲突时报告并请用户选择。
- 组名能力只接收字；校验能力只接收不含姓的名。
- 无出生信息时跳过五行匹配，并明确输出未评估用神。
- 出处分为直接典故、字义联想、现代审美、未确认；直接典故必须给可核书名、篇名与原文。
- 起名的五行依据只取八字用神裁决结果（见 `references/naming/domains/bazi/yongshen.md`）；起名校验回传同一份用神来源。

## 输出契约

- 生成类首轮 5-8 个精选候选；每个候选列优点、可商榷点与五行 / 音韵 / 出处依据，不创建分数或新的吉凶档。
- 附代表性不推荐清单和具体淘汰原因；候选不足时如实说明。
- 有排盘时说明用神依据；无排盘时说明未评估用神。
- 外国用户中文名保留拼音；解释可使用英文。
- 外国人中文名是文化 / 社交用名；不宣称改变法律姓名，不默认按中国出生时间处理。
