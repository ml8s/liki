# 合盘分析

## 依赖的领域知识

[必读] - bazi: `references/natal/domains/bazi/hepan.md`「双人盘事实合参」
[必读] - bazi: `references/natal/domains/bazi/shishen.md`「十神组合」

## 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- |
| 1 | 双方出生信息 | 分别排盘 | 双方命盘 |
| 2 | 原始对照 | 调 engine 合盘（八字合盘 + 紫微合盘，双方命盘原样传入） | 双方日主、夫妻宫、配偶星、干支关系与紫微宫位事实 |
| 3 | 证据整理 | 读取 `references/natal/domains/bazi/hepan.md` | 优势证据、摩擦证据、证据缺口 |
| 4 | 输出 | 按模板列共同点、差异与相处建议 | 参考结论 + 依据链 |

## 📖 双盘合参层级

- 紫微层只读双方命宫、夫妻宫、子女宫主星（空宫借对宫只作观察，见 `references/natal/domains/ziwei/gong12.md`）；八字层读日主、配偶星、日支与交叉关系。
- 证据层级：主配偶星 / 夫妻宫强于辅助神煞；跨体系强弱与冲突处理按 `references/natal/TOOLS.md`「合参与裁决」。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 只提供了一方的八字 | 提示需要双方出生信息才能合盘 |
| 问合盘但只说"帮我看看我俩" | 提示提供双方出生信息 |
| 缺一方时辰或缺性别 | 明示对应对象无法完整评估 |
| 单一冲、合、神煞 | 只作证据，不下关系成败结论 |

## 输出模板

```text
结论：一句话关系格局与相处要点。
八字：日主关系、配偶星与夫妻宫事实（列断语 id）。
紫微：双方命宫、夫妻宫、子女宫主星。
共同点 / 差异：优势证据、摩擦证据、证据缺口。
建议：一个相处或现实确认动作。
```

结论按事实与证据层级给出；缘分分数与“良配 / 慎配”标签不出现。

### 示例

```text
结论：日主互补，合盘中等偏吉。
八字合婚：甲方戊土，乙方壬水，戊土克壬水；甲方配偶星乙木透干得地。
紫微合参：甲方夫妻宫太阳（旺），乙方夫妻宫天同（庙）；双方宫位吉星并见。
建议：互补大于冲突；日主克泄关系在磨合期需关注。
```
