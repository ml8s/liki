# 大运分析方法论

## 大运与命局的互动

每步大运须从三个维度分析：

### 大运干支与命局的关系

- 大运天干与四柱天干：生合冲克刑
- 大运地支与四柱地支：六合三合六冲六害
- 重点关注：大运冲合原局哪个柱，该柱对应的宫位和十神

### 大运对用神的作用

- 大运生扶用神 → 得运，该运有利
- 大运克制用神 → 失运，该运不利
- 大运助忌神 → 该运需谨慎

## 十年分治

每步大运按前五年 / 后五年细分：

**前五年（天干主导）** — 大运天干的力量在五年中逐步增强，前五年受天干影响更大
**后五年（地支主导）** — 大运地支的力量在后五年显现，地支冲合的影响在后五年更明显
**换运年** — 前后两步大运交接之年（前后各一年），是人生节奏切换的关键节点，工作/感情/健康容易出现重大变化

## 大运与流年的配合

大运定十年基调，流年看当年应事。判断方法不是简单的"生扶=吉/克制=凶"，而是看组合后对原局用神/忌神的影响：

- 流年与大运配合后生扶用神 → 吉
- 流年与大运配合后引发忌神 → 凶
- 流年虽克大运，但克的是大运中的忌神 → 反为吉
- 流年虽生大运，但生的是大运中的忌神 → 反为凶

## 冲合关系

冲（突发 / 断裂 / 变动）与合（牵绊 / 聚合 / 性质改变）的语义与宫位应事见 `hehui.md`「📖 六冲」；本卡只用其应期强度：

### 应期强度：冲 > 合

- 冲本身即凶的信号：先按冲定性（有无断裂 / 破坏），再看合是否有解救（冲被合解则力度降低）
- 合为中性：合化用神为吉、合化忌神为凶；合动只作引动，结果取决于引动的星
- 天干论合先于论冲（天干合化重于冲克），地支冲与合并行分析

## 天干地支分论

- **天干**：主外显之事、上半年（1-6月）、社会层面、可见变化
- **地支**：主内隐之事、下半年（7-12月）、个人层面、内在变化
- 天干透出的十神决定事件性质，地支的冲合决定事件力度
- 流年对命局的影响：天干先作用于天干，地支先作用于地支

## 应期推断

同一方法适用于六亲、财运、事业、健康、感情等所有领域。目标星与目标宫位见下方「各领域目标星与目标宫位」表。

实现契约：本表的「目标星」是方法层取象；流年因子层没有隐藏 target。实际查表必须使用显式因子名/显式算子参数（如「流年配偶星透」「流年财星克」），不得回退为泛称目标星因子。

### 大运定窗口

大运给时间窗口。大运的如下行为打开应期窗口：

- **冲**：冲目标星或目标宫位 → 该运为该领域的窗口
- **合**：合住目标星 → 受牵制；合化 → 性质改变
- **克**：大运干支克制目标星 → 凶应窗口
- **生扶**：大运生扶目标星 → 吉应窗口
- **值**：大运干支与目标星/宫位完全相同 → 最强烈的引动

### 流年定年

#### 先读流年盘（分析工具内部编排）

- 对候选年份范围由 应期判断 选择年份区间，内部编排流年排盘（流年 vs 原局四柱、大运交叉、伏吟/反吟、流年神煞）

**流年引动类型**（以下为强应期信号）：

- 值宫/伏吟：流年地支值目标宫位（年柱伏吟→父母事）
- 宫位引动：流年地支对目标宫位的**六合/三合/三会/六冲**均为引动；**三合/三会须三方齐备成局**，两支半合只作辅助信号
- 星动：配偶星透干（男流年干=财、女流年干=官杀）为结婚/婚缘直接信号，须与宫位引动同断（单透干不足定年）
- 换运叠加：换运年前后一年 + 流年引动 → 特殊窗口
- 多层引动：大运、流年、命局分别提供不同层证据时，闭环强于单层重复信号；同源信号不因数量累加而自动升格

**应期精度**：流年定年、流月定事；**精确到年**（禁止只断「有/无」或模糊区间）。应年 = 大运引动（窗口）× 流年强引动取交集。

### 状态题 vs 事件题

- **状态题**（性格 / 婚姻状态 / 财运状况 / 学历层次）→ 以本命因子定案，不查流年引动。
- **事件题**（某年发生何事 / 何年结婚 / 哪年突破）→ 以流年因子 + 大运引动定案。

### 候选取舍

多候选年先按同一问题域逐年列证：

- **锁域内主信号**：候选只在「本问题域有明确支持」的年份内取舍——问婚姻，候选年须有婚姻域结论明确支持的婚动 / 婚喜 / 法律仪式变动；健康、财帛、六亲等他域杂音不改写婚动候选。真实事件年可吉凶并存，不因「年份不纯吉」排除。
- 事类语义：结婚、手续、生育、升迁、迁移、健康等是否同域；
- 星动：目标星透干、合、冲、受克或值宫；
- 宫动：目标宫位合、冲、刑、害、伏吟或流年宫位引动；
- 限运：大运是否给出十年窗口；
- 用忌与吉凶混杂：用神、忌神、神煞是否支持该事类；
- 时间线：候选与已知人生阶段、事件先后是否自洽。

候选取舍看**独立证据覆盖面**，不看同源信号数量。宫动与星动无全局高下：宫为事象场域，星为事象主体，二者同见时闭环更强。换运、三合、六合、神煞均须回到具体事类判断，不设全局硬排序。证据仍并列时输出并列候选与置信度差异，不默认最早年份。验证可推翻结论时须标注理由。

**婚期专项**：取「大运配偶星窗口 × 流年引动交集」为候选年份，只在候选内裁决。首次成婚看成婚引动——配偶星实引动 + 夫妻宫 / 法律仪式变动 + 配偶星大运窗口三者覆盖越完整，成婚解释越强；单纯桃花、合会或异性缘只作恋爱引动，不等同成婚。冲夫妻宫偏手续 / 登记 / 分离或关系状态变动，合会偏感情聚合，按用户已述语义（签纸 / 同居 / 分手 / 办酒）取对应引动。

### 硬性要求

- 禁止单信号直接定案；候选可由单引动进入，定案须有事类闭环或用户事实验证。
- 凶信号≠排除：应期年常伴冲、比劫、官杀攻身，目标星或目标宫位被引动时保留候选。
- 六合合化须验条件；未验证时只论合绊/合动，不论合化出某五行。

### 健康/牢狱/手术专项

- 官非/刑讼候选 = 官杀攻身、三刑或凶煞、印星无救分属不同层证据；不作法律结论
- 手术部位 = 被冲克的五行对应脏腑（火=心/眼/血，木=肝/胆/头，金=肺/肠/皮肤，水=肾/膀胱/骨，土=脾/胃/肉）
- 断部位看流年冲克哪个五行，不是固定「日主五行=某器官」

### 📖 翻译表：流年应期星宫合参

使用前先确定目标星和目标宫位（见上表）。

**① 星动检查**：目标星在天干透出，或被流年天干合、冲、生、克？通过则记录证据。
**② 宫动检查**：目标宫位地支被流年地支合、冲、刑、害、伏吟？通过则记录证据。
**③ 限运检查**：该年是否处于对应大运窗口？通过则记录证据。

星动、宫动、限运不必三者全备才入候选；但定案须覆盖“事类语义 + 至少一类实引动 + 时间线自洽”。星动与宫动同见时证据更完整，单星动或单宫动只作候选，不作定案。

### 额外规则（应期推断必查）

- **三合/三会局夺根**：参与合化的用神地支视为被合走，不得当旺根救身（例：巳被巳酉丑合化 → 巳火不提供日主旺根）。
- **童限（未上运）凶应**：大运未起时仍按“流年合局 × 原局忌神”论凶，不作自动减分。
- **无六冲≠排除突发事故**：交通意外/车祸类改查驿马、灾煞/金舆及流年×大运组合，禁止用“全年无六冲”单项排除。

### 📖 专项引动与吉凶并存

- **六亲入墓**：流年/大运地支为六亲星墓库，且伏吟、冲刑或星受克时，为六亲健康/关系重大变故候选；是否灾亡须宫凶、星损、限运与流年形成独立闭环。
- **迁移/出行类**：驿马伏吟或逢冲、驿马坐支受克、灾煞并见时，优先按迁移/出行事类解释，不用婚恋或事业的排序套用。
- **吉凶并存**：驿马、羊刃、冲刃、刑开财库等凶象成立时，仅在本事类内解释风险；同年吉神/吉象不因数量少而自动失效，须分域列证。
- **多信号分属不同年份**：各引动皆算候选，无全局优先级；比较独立证据覆盖面与时间线。
- **领域取象以目标星与目标宫位被引动的十神/宫位为准**；大运提供十年主题，不直接替代流年取象。
- **六亲灾与自身吉象**：以结论严重程度、宫星闭环和事类语义裁决，不以“六亲必优先”或信号数量硬压。
- **三合局、贵人、禄马**：表该年环境有利或引动增强，不作事件已发生的直接证据；仍须目标星、目标宫位或现实事实闭环。
