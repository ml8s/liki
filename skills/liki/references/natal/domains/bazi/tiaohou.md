# 调候用神

## 📋 方法论：调候

### 核心原则

论命重调候，冬夏极端月份调候优先于格局和扶抑。若命局缺调候之字，即使格局好也难发挥。夏生火旺须用水调候，冬生水旺须用火调候。

### 📥 数据来源（引擎为准，不背诵）

调候主 / 辅神由 engine `bazi_fullchart.tiao_hou` 输出（`primary` / `secondary`），口径为**通行《穷通宝鉴》十天干逐月调候表**（焦顺华、韦千里等常用软件一致的一系）。本卡不复制调候表；凡与引擎字段不一致的名目一律以引擎输出为准。

- 主神缺失时先看辅神；藏而不透、被冲被合只作结构证据，不作铁定喜神。
- 辅神保留经典条件（如「壬多取戊」「无壬用己」）；条件非空时辅神不得当作无条件喜神。
- 原文寒暖燥湿的附加条件仍须按盘面复核。
- 调候辅神是喜神重要候选而非结论：须实际生助或护持已定用神，且不得旺到反制用神；若辅神克用神，只能说明调候需求，不得因入表就直接作喜神。

### 📖 解读法

- 调候优先度：冬夏寒暖燥湿明显时高，春秋温和时低；春秋以格局、扶抑为主，调候只作微调。
- 物候倾向（仅作解释背景，具体用神一律读引擎字段）：初春余寒先取暖，盛夏燥热先取润，金旺月酌情抑金护日主所喜，寒冬先取火。
- 主 / 辅神进一步记录表内天干是否透干、藏支、所在柱，及其宫支参与的合会冲刑；组织断语时据此说明依据，不得直接复述原表数值。

### 📖 使用原则

- 调候用神是命局中最关键的「药」；分析时应先检查其有力无力。
- 若命局中调候用神受克或缺失，即使格局好，人生也多阻碍。
- 忌神判断回到扶抑、格局与整体组合，不得因「克日主」或「泄日主」直接冒充调候表事实。
