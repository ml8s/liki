# 格局论命

## 📋 方法论：格局判定

### 核心原则

格局以月令为提纲，月令本气透干则定格，不透则以月令本气为虚格。格局以清纯为贵，杂浊为贱。

### 📥 数据来源（引擎 + 断言）

- **定格**：engine `bazi_fullchart.ge_ju` 输出 `pattern_god` / `pattern_god_ten_god` / `pattern_god_source`（透干来源：本气/中气/余气/不透），`structure` 给出格神、克格神、生格神的透干柱、藏干根、季节旺相与合会冲刑证据；四柱藏干读各柱 `cang_gan`。LLM 读字段，不自行查藏干表定格。
- **成 / 破格与救应断语**：由 counsel 格局断言（`ge_*` 系列）经 `natal_query` 返回（如"正官格成（官印相生）""官杀混杂破格"等）。LLM 只解读返回的 `conclusion`。

### 📖 理解背景：顺逆用成破条件（结论以 `ge_*` 断言为准）

| 格局类 | 成格方向 | 破格方向 | 说明 |
| ------ | -------- | -------- | ------ |
| 顺用格（官印财食） | 有财官/印/食伤等生扶护卫 | 忌神攻破（伤官克官、财坏印、比劫争财、枭神夺食） | 官喜财印护 |
| 逆用格（杀伤刃劫） | 制化克泄（食神制杀、印化杀、印制伤、七杀制刃等） | 无制失控或制之太过 | 杀宜制、伤宜印化 |
| 建禄格 | 财官成格 | 比劫争财、食伤泄身太过 | — |

顺逆用是理解骨架：顺用格宜生扶、逆用格宜制化；具体成格/破格/救应以工具断言给出的结论为准，不自行逐条组合判成败。

### 格神、用神与相神：术语边界

| 概念 | 定义 | engine 是否输出 |
| ------ | ------ | ------ |
| 格神 | 月令藏干定格之干，如酉月甲日见辛为正官格神 | `pattern_god` / `pattern_god_ten_god` |
| 用神 | 全盘复核后维护格局平衡的关键十神；不必然等于格神 | 不输出，须合参 |
| 相神 | 辅助成格之神，如正官格中的印星或财星 | `structure` 只给克格神 / 生格神证据，不终判相神 |
| 喜神 / 忌神 | 最终喜忌 | 不输出；回到扶抑、调候、格局成败合参 |

### 判断要点

1. **清浊**：格神一位为清，多格神或格神受冲克为浊。
2. **有力无力**：格神在地支有根、得月令生扶为有力。
3. **位置**：格神与日主距离越近，结构作用越直接。
4. **证据读取**：先读 `structure.pattern.transparent_pillars / roots / timely`，再读克格神与生格神状态；三者只说明结构强度与牵制，成破终判以 `ge_*` 断言为准。
