# 事业判断决策表

用于分析事业/职业问题时逐项检查。

**核心原则**：官杀定层次，财星定类型，食伤定才华方向。

## 📖 翻译表：事业职业判断

**输入**：官杀/财星/食伤/印星透干情况 + 身强弱 + 大运类型
**输出**：事业方向 + 职业类型

### 事业档升格与负债映射

**官杀不透 ≠ 锁死安分上班**（食伤生财升格条款）：

- **食伤生财成立**（食伤旺生财、偏财得禄、禄马交驰）→ 虽官杀不透，**升自营/经商**——禁止按 shi_101-109 档位直落"寻常职业/安分上班"
- 判断"创业还是打工"：食伤生财 + 偏财得禄 + 财库冲开 → 经商；官印相生 + 财星藏支 → 安分上班/体制内
- **"老板有负债"类诉求单列映射**：食伤生财 + 偏财得禄 = 经营有成；羊刃冲财 / 劫财夺财 / 财星受冲被劫 = 经营负债并存——两者同现时**并列列证据对比强弱**，禁止单取"食伤生财"或单取"冲刃破财"

### 职业类型取象（禁单星独占）

- 官印相生 + 文昌/印星得地 → 文书/文职类；但**体力/技术组合**（比劫旺、食伤佩羊刃、驿马）并存时须并列裁决（行政 vs 体力/技术），禁止单星独占定"文职秘书"
- 偏印/华盖聚 + 官杀受制 → 阴质偏门类（与"物流/商贸"区分：看驿马/食伤是否主运输流通）——取象以**命局+大运引动的组合**定，禁止单神煞硬套职业

### 📖 用神与格局合参定职业 / 科系

用神十神定才能与资源方向，格局定实现形态，大运定阶段窗口：

- 偏印为用 → 艺术 / 技术 / 偏门；正财为用 → 财务 / 经营；食伤为用 → 表达 / 创作 / 教育；官杀为用 → 管理 / 体制。
- 上列方向均须与官杀、财星、食伤、印星的实际透藏与格局成败合参，禁止只取用神单一符号定职业。
