# 字库与选字

> 经典依据：《说文解字》（东汉·许慎）字形字义、辨汉字五行归属；取名出处《诗经》《楚辞》《论语》《周易》。

## 📖 翻译表：字库过滤细则

在取字返回的 chars 上操作，只删不增：

- 先删用户明确避讳的同字；同音避讳需有 `qiming.char` 拼音或用户显式提供读音，按音节比较（默认不计声调），否则不凭记忆推断
- 机械删除：偏旁含疒/虫/歹/尸、工具器物、化学虚词、负面动作、生僻字
- 语义判断：认识吗？含义积极吗？能举出用这个字的人名吗？任一"否"就删除
- 保留龙/凤/鹤/燕/麟等传统入名吉祥动物字

生僻字（瓤/穰/噍/衢/髂/簟等）、负面义（僵/瘠/瞎/瘿等）、工具器物字（犁/铲/锹等）一律删除。

## 📖 翻译表：选字原则

- 声调平仄：明快悦耳为佳，避免拗口
- 字形结构：协调美观为佳，避免过繁过简或与姓搭配失衡
- 寓意出处：典出《诗经》《楚辞》《论语》等经典为佳
- 五行补益：优先选用神五行，次选喜神五行。避忌神五行

## 📋 方法论：出处证据等级

1. **直接典故**：能确认书名/篇名与原句时使用；输出原文，优先从原句取字重新组合，不整词照搬
2. **字义联想**：只解释字义、气质与组合关系，不冒充经典出处
3. **现代审美组合**：说明音韵、字形与当代使用感受，不伪装典故
4. 记不准、无法核对时降级为「字义联想」或「未确认」；禁止补书名、篇名、作者或原句

## 📋 方法论：选字质量标准（审美自查）

不给示范名——**具体名字会诱导照抄、收敛成重复**。用以下标准自查，好名需同时满足：

1. **雅而不僻**：常用字为主，不用生僻字；认识的人能读会写
2. **通而不俗**：寓意积极，但避免烂大街的用字（梓/轩/涵/萱/浩/宇等高频字慎用，除非字池无更好选择）
3. **音韵顺口**：连读三遍不拗口；与姓氏连读无谐音歧义（如"梦嘉"→"梦假"）
4. **出处可核**：能确认的直接给典故；不能确认就明示字义联想或现代审美，不编造出处

**反重复红线**：
- 不得直接采用任何示范名、明星名、网红名、已知人名
- 每次起名须结合当下姓氏、性别、用神，重新组合——**同一轮候选彼此不重复用字**（用户要求叠字除外）
- 候选名彼此要有差异（不同字根、不同气质），不堆同风格
- 同一会话续起名时不重复完整名字，并尽量不重复已呈现的字；用户明确要求沿用某字或风格时除外
