# 出生时辰判定（起名精简版）

起名需要时辰来排八字定用神。用户给的出生信息可能完整、不确定或缺失，按以下规则处理。

## 决策表：时辰确认

| 用户情况 | 处理方式 |
|---------|---------|
| 提供了具体出生时间 | 直接采用，转为真太阳时排盘（经度未知先调 `city`） |
| 时间不确定（如"下午/晚上"） | 询问确认到时辰；无法确认 → 走默认时辰（见下） |
| 只给日期、无时间 | 按默认时辰处理并标注 |
| 用户明确说"不知道时辰" | 按默认时辰处理并标注 |

## 默认时辰规则（缺省处理）

出生日期确定但时辰缺失/不确定时：

1. **默认取午时（12:00）**排盘——午时日照居中、真太阳时偏差最小，是缺失时辰时的通用默认
2. 排盘结果必须**标注"时辰缺失，按午时排盘"**，用神结论相应降低确定性表述
3. 不向用户追问真实出生时辰之外的信息，不引导编造

## 边界

| 异常场景 | 处理方式 |
|---------|---------|
| 用户只知年月日 | 按午时排盘 + 标注，用神结论用"参考"语气 |
| 用户说"时辰不重要，随便" | 按午时排盘 + 标注，不重复追问 |
| 海外出生 | 必须传出生地经度校正真太阳时（longitude 必传），否则时辰可能错 |
