# 外国人起中文名

> 场景：外国人罗马字姓起中文名。通用起名/改名 → `naming.md`；自选名字评估 → `selfcheck.md`。

## 依赖的领域知识

[必读] - bazi: `domains/bazi/yongshen.md`「用神方法论」+ `domains/bazi/calibration.md`「时辰判定」
[必读] - qiming: `domains/qiming/ziku.md`「字库与选字」

## 📖 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
|---|---|---|---|
| 0 | 罗马字姓与偏好 | `qiming.surname(source_surname)`；在返回候选中确认中国姓。一次确认单 / 双名、风格和避讳 | 中国姓、偏好、避讳 |
| 1 | 出生信息 | 有则先确认出生地 / UTC offset；需真太阳时再查经度，然后 `bazi.chart` → `bazi.fullchart`；无则进入期望五行分支 | 用神或“未评估五行” |
| 2 | 取字 | 有用神默认「用+用」，不足回退「用+喜」；期望五行按该五行取，“不限”合并五池；仅在 `chars` 内过滤语义、出处和跨语言音韵 | first / second 字池 |
| 3 | 组名 | `qiming.compose` | 候选名 |
| 4 | 校验 | `qiming.check(given_names)`；姓氏仅用于展示和谐音判断 | 校验事实 |
| 5 | 输出 | 结合 PhoneticFit 终选 | 推荐名、拼音、寓意、可商榷点 |

## 📖 输出模板

| 输出 | 内容 |
|---|---|
| 选姓 | 罗马字姓、engine 中国姓候选、`match_level`、拼音与传统《百家姓》序号 |
| 选姓解释 | LLM 基于每个候选的 `match_level` 和 `basis` 说明音近关系、罗马字依据或 fallback 边界；语言跟随用户 |
| 用神 | 有排盘时给五行策略；无排盘时说明未评估 |
| 候选 | 5-8 个中文名、拼音、寓意 / 出处、音韵、PhoneticFit（`easy / medium / hard`） |
| 平衡 | 每名一个优点与一个可商榷点 |
| 淘汰 | 代表性不推荐名字与具体原因 |
| 推荐 | 首选名及综合理由 |

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 原始姓不是拉丁字母 | 要求用户提供官方或惯用罗马字拼写；不自行转写西里尔、阿拉伯、日文或韩文 |
| `strategy=baijiaxing_fallback` | 明确说明没有可靠音近姓；候选只是按传统《百家姓》顺序给出的备选，不得包装成音译 |
| 多个候选同级别 | 并列给用户选择；不按序号伪造唯一答案 |
| 出生时区不明 | 先询问 UTC offset 或出生地；不默认北京时间 |
| 关键候选 | 先确认中国姓，再深入中文名；不合并为一次暗定 |
