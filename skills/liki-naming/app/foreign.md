# 外国人起中文名

> 场景：英文起中文名。通用起名/改名 → `naming.md`；自选名字评估 → `selfcheck.md`。

## 依赖的领域知识

[必读] - bazi: `domains/bazi/yongshen.md`「用神方法论」+ `domains/bazi/calibration.md`「时辰判定」
[必读] - qiming: `domains/qiming/ziku.md`「字库与选字」

## 📖 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
|---|---|---|---|
| 0 | 英文姓与偏好 | 选音近中国姓；一次确认参数，缺省同通用起名 | 中国姓、偏好、避讳 |
| 1 | 出生信息 | 有则 `bazi.chart` → `bazi.fullchart`；无则进入期望五行分支 | 用神或“未评估五行” |
| 2 | 取字 | 有用神默认「用+用」，不足回退「用+喜」；期望五行按该五行取，“不限”合并五池；仅在 `chars` 内过滤语义、出处、音韵与英文发音 | first / second 字池 |
| 3 | 组名 | `qiming.compose` | 候选名 |
| 4 | 校验 | `qiming.check(given_names)`；姓氏仅用于展示和谐音判断 | 校验事实 |
| 5 | 输出 | 结合英文发音便利度终选 | 推荐名、拼音、寓意、可商榷点 |

## 📖 输出模板

| 输出 | 内容 |
|---|---|
| 选姓 | 英文姓、音近中国姓、音义依据 |
| 用神 | 有排盘时给五行策略；无排盘时说明未评估 |
| 候选 | 5-8 个中文名、拼音、寓意 / 出处、音韵、英文发音便利度 |
| 平衡 | 每名一个优点与一个可商榷点 |
| 淘汰 | 代表性不推荐名字与具体原因 |
| 推荐 | 首选名及综合理由 |
