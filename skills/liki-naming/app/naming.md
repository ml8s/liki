# 通用起名/改名

> 场景：新生儿起名、成人改名。外国人起中文名 → `foreign.md`；自选名字评估 → `selfcheck.md`。

## 依赖的领域知识

[必读] - bazi: `domains/bazi/yongshen.md`「用神方法论」+ `domains/bazi/calibration.md`「时辰判定」
[必读] - qiming: `domains/qiming/ziku.md`「字库与选字」

## 📖 流程

| 步骤 | 类型 | 条件 / 目标 | 动作 | 产物 |
|---|---|---|---|---|
| 1 | 排盘 | 时辰明确 | `bazi.chart` → `bazi.fullchart` | 用神、喜神、忌神 |
| 1 | 排盘 | 时辰模糊 | 先确认到时辰；无法确认则按午时排盘并标注低确定性 | 参考用神 |
| 1 | 排盘 | 无出生信息 | 询问期望五行；“不限”则合并五个字池 | 五行策略 |
| 2 | 💬 参数收集 | 命名参数 | 一次确认单 / 双名、风格、必含、避讳、叠字、出处偏好；缺省为均衡风格、无必含 / 避讳、不允许叠字、出处优先但不强制 | 参数与默认值 |
| 3 | 取字 | 双字名默认「用+用」，不足回退「用+喜」 | `qiming.pick` 后仅在 `chars` 内过滤 | first / second 字池 |
| 4 | 组名 | 机械组合 | `qiming.compose` | 候选名 |
| 5 | 校验 | 引擎事实 | `qiming.check(given_names)` | 字库、音韵、五行事实 |
| 6 | 候选输出 | 按模板精选 | 推荐、优点、可商榷点、淘汰代表 | 候选清单 |
| 6a | ⛔ 阻塞确认 | 用户选定终选名 | 展示首选与编号选项；等用户回复后才能继续 | 终选名 |

### 交互模板

```text
2 💬 只输出：1.单 / 双名（默认双字名） 2.风格（默认均衡） 3.必含字（默认无） 4.避讳字（默认无） 5.叠字（默认不允许）。回复“都用默认”可直接跳过；不调用 RPC。
6a ⛔ 只输出：首选推荐「{名}」({拼音})、一个优点 / 可商榷点、其他候选；选项 1.确认首选 2.看其他候选详情 3.换方向。停在这里，等用户回复后继续。
```

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 候选不足 5 个 | 放宽语义过滤；仍不足则回退「用+喜」；仍不足则如实少给 |
| 用户不满意 | 放宽风格约束，或回退另一五行策略 |
| 必含字不在字池 | 说明冲突，询问保留五行策略或调整必含字 |
| 长辈同音字无法核对读音 | 请用户提供拼音；未提供时只避 exact 字 |
| `qiming.compose` 报字符错误 | 只能改用 `qiming.pick` 返回池中的字 |
| `qiming.check` 标记 invalid | 丢弃该候选并保留 invalid 原因 |

## 📖 输出模板

| 输出 | 内容 |
|---|---|
| 用神 | 有排盘时给最终五行策略；无排盘时说明未评估 |
| 候选 | 5-8 个名字、拼音、五行、寓意 / 出处、音韵 |
| 平衡 | 每名一个优点与一个可商榷点 |
| 淘汰 | 代表性不推荐名字与具体原因 |
| 推荐 | 首选名及综合理由 |
