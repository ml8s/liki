# 自选名字评估

> 场景：用户已有候选名字。起名/改名 → `naming.md`；外国人起中文名 → `foreign.md`。

## 依赖的领域知识

[必读] - bazi: `domains/bazi/yongshen.md`「用神方法论」（有用神信息时）
[必读] - qiming: `domains/qiming/ziku.md`「字库与选字」

## 📖 流程

第1步：收集名字与可选用神
  确认姓、名（单字名/双字名）；可选出生信息。
  姓氏仅用于最终展示与谐音判断，不传入 qiming.check。
  有出生信息时调用 `bazi.chart` 和 `bazi.fullchart`。
  输出：□ 姓____ 名____ 用神____

第2步：评估
  调用 `qiming.check`；`given_names` 只传 given name。
  读取 `valid/errors/characters/phonetic/wuxing`。
  输出：□ 字库校验____ 五行匹配____ 音韵____

第3步：结论
  LLM 结合字义、出处、音韵和五行匹配给出评价。
  输出：□ 评价____ 建议____

## 红线（强制）

- 自选名字评估不调用 `qiming.pick` 或 `qiming.compose`。
- 不自行推算字符属性；一律以 `qiming.check` 返回为准。
- 字库未收录时保留 `valid=false`，不得补造属性。
- 结论依据只使用字库事实、五行、字义、出处和音韵。

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 无出生信息 | 跳过五行评估，只评字库事实和音韵 |
| 字库未收录 | 显示 invalid，并建议从 `qiming.pick` 重新选字 |
| 评估字段缺失 | 跳过该维度，不臆测 |
