# 自选名字评估

> 场景：用户已有候选名字（自己取的/别人起的），要求评估好坏。起名/改名 → `naming.md`；外国人起中文名 → `foreign.md`。

## 依赖的领域知识

[必读] - bazi: domains/bazi/yongshen.md「用神方法论」（有用神信息时）
[必读] - qiming: domains/qiming/wuge.md（三才五格）+ ziku.md（字库）

## 📖 流程

第1步：收集名字与可选用神
  确认：姓、名（单字名/双字名）；可选：出生信息（有则排用神，无则跳过五行评估）
  有出生信息 → 排八字 `bazi.chart` + `bazi.fullchart` 取用神（不调 ziwei）
  输出：□ 姓____ 名____ 用神（可选）____

第2步：定评估参数
  确认用户是否考虑三才五格（默认考虑）：
  答「考虑」→ wuge=true（check 返回五格数理+三才）
  答「不考虑」→ wuge=false（check 跳过五格三才，仅返回音韵/五行匹配）
  输出：□ 考虑三才五格？____（默认考虑）

第3步：评估
  调用 qiming.check——评估（wuge 按第2步结论）
  读评估结果：五格数理、三才、音韵、五行匹配（用神/喜神/忌神）
  输出：□ 五格____ 三才____ 音韵____ 五行匹配____

第4步：结论
  LLM 按评估结果 + 字义/出处，给出评价：
  - 好在哪里（数理吉、五行补益、音韵佳）
  - 不足与建议（数理凶、五行不合、谐音歧义 → 可建议换字或走 naming.md 重起）
  输出：□ 评价____ 建议____

## 红线（强制）

- **跳过排盘取字**：不调 qiming.pick / qiming.build，直接 qiming.check 评估用户给的现成名字
- **不得自行推算五格数理**，由 qiming.check 返回（wuge=true 时）；wuge=false 时禁止凭空补五格三才数据
- **check 的 names 只传名（given name 不含姓）**，surname 单独传
- **未提供出生信息时**，五行匹配维度跳过，不臆测用神
- **wuge=false 时**评估结论只基于音韵/字义/五行，不得把五格三才当依据

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 无出生信息 | 跳过五行评估，只评音韵（+三才五格，若考虑） |
| 不考虑三才五格 | wuge=false，只评音韵/字义/五行匹配 |
| 名字含生僻字/数据库未收录 | 跳过该字维度，告知用户 |
| 用户想重起 | 引导到 `naming.md` 通用流程 |
| 名字评估字段缺失 | 跳过该维度，不臆测 |

## 📖 输出模板

### 一、评估

| 名字 | 五行 | 五格三才 | 音韵 | 结论 |
|------|------|---------|------|------|
| [名字] | [五行匹配情况] | [数理/三才吉凶；不考虑三才时留空] | [声调] | [优缺点一句话] |

名字行数不限。用户不考虑三才五格时，「五格三才」列留空，不臆造数据。

### 二、建议
一句话给出综合评价与改进方向（保留/换字/重起）。
