# 五行与健康
## 📖 翻译表：五行健康

五行与人体器官的对应关系见 `query(rule=五行)`（脏腑映射/过旺过衰断语）；十神为忌→健康 由 `query(rule=用神)`（jk_* 十神为忌健康断语）承担。本文为健康分析方法（双向映射/特殊组合）。断语 id 前缀 jk_ 现分布于五行/用神/旺衰/合会等命理域 csv。

## 五行失衡的健康倾向

**双向映射（强制）**：过旺五行**先克所胜、再耗泄于所生**，两个方向都要查——
- 例：木旺 → ①克土（肝/脾胃/脚患）②生火耗木（心/目）——不得只查一个方向
- 用户提到多脏腑时，把用户提到的各脏腑逐一映射到命局最弱/受克五行再比对
- **星曜≠单义**：廉贞（火）主心亦主血、破军主血水、天机主肝、太阳主心/头/目——按命局五行主次裁定，禁止星曜标签化定脏腑

## 特殊组合的健康应事

特殊组合给出的是健康问题的方向，不预设具体病名：

- **金木交战** → 筋骨损伤、意外伤
- **水火相战** → 心脑血管、血压
- **土壅木郁** → 肝胆系统、情绪

## 注意事项

- 五行对应关系给出的是健康**倾向**，非确定性诊断
- 同一五行失衡在不同命局中应事不同，取决于大运流年的具体引动
- 以上仅为命理传统文化视角，不可替代医学诊断

## 健康/官非/大运吉凶断法（无规则断语表的题型）

固定年份断事件/大运段吉凶：按**用神喜忌 + 大运流年吉凶**综合——先读 `bazi.fullchart` 的 `yong_shen` 用神（扶抑/调候/格局），断流年/大运干支为喜为忌：
- 喜用神干支临流年 → 吉事（顺遂/进财/升迁）
- 忌神干支临流年 → 凶事（健康/破财/官非）
- 健康事件再结合五行失衡（克泄用神之五行过旺）

### 疾病细节断法（疾厄宫闭环）

断具体疾病/健康应期须三层叠加，缺一层不断细节：
1. **本命疾厄宫**主星 → 定先天薄弱系统（紫微 gong12 疾厄宫）
2. **大限疾厄宫** → 定当限引动的健康主题（调 `ziwei.daxian` 取大限命宫，十二宫逆布定大限疾厄）
3. **流年干支** → 定应期（流年五行冲克本命薄弱五行/疾厄宫位）

只查五行倾向不断具体疾病；用户未反馈应验时，健康结论须标注「倾向推断，未经流年验证」。

## 健康裁决细则

### 健康判定补充规则

- **先查流年地支值日支（伏吟）/冲日支 + 忌神五行攻身**——任一成立即健康关注年；疾厄宫流曜需与上述引动同查
- **好体质判定路径**：命宫天府/天相 + 迁移紫微七杀 + 疾厄宫无煞忌 → 运动健康型；童年流年冲刑只作当年小病，不作"终身暗疾"
- **被大运/流年连年反复引动的失衡方向优先**：如木运连年先查木旺克土（脾胃/脚患/肥胖）；静态五行计数只作辅助

### “六亲灾 vs 自身病”裁决

- 印星（母）受克+合绊 **且** 流年伏吟/冲年柱母宫 → 优先断**母灾**
- 日主自身另受忌神攻身 + 紫微疾厄宫化忌 → 才断**自身病**
- 紫微流年疾厄宫化忌/凶化 = **自己**（一级信号）；健康"谁得病"判准固定为此
- 五行只能作脏腑倾向：火弱直接对应心/血脉/神志偏弱；若火弱不能制金，且金气偏盛，才可间接提示肺/呼吸道受扰，须金旺与疾厄宫佐证。流羊/驿马只推急性意外，且须多重凶象闭环；不作疾病诊断
