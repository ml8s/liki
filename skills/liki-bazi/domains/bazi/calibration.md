# 出生时辰校验

时辰不确定时，用已发生人生事实反向验证候选盘。候选与事件不足时停止考时或降低置信度。

## 前提

| 条件 | 处理 |
|---|---|
| 成人且时辰不确定 | 建议校验 |
| 宝宝 / 青少年 | 跳过校验，使用用户输入时辰 |
| 用户已明确时辰 | 以用户确认为准 |
| 候选 <2 | 请用户确认唯一时辰或补充候选 |
| 人生大事 <3 | 考时精度不足；延后校验或接受低置信度 |
| 候选 >5 | 先缩小时间范围，再进入结构排除 |

## 第一层：结构性排除

| 人生事实 | 八字对照 | 处理 |
|---|---|---|
| 婚姻段数 | 男命正偏财数；女命官杀数 | 数量与事实明显不符则排除 |
| 有无子女 / 子女缘 | 子女星、时柱吉煞、产育应期 | 明显冲突则降置信；性别不作排除依据 |
| 是否离异 | 日支六冲、六害、相刑 | 已离异而日支无冲刑害则排除 |
| 学历层次 | 印星状态与学历档 | 事实偏高而印星全不通过则排除 |

仅剩一盘则直接采用；无候选则回到信息收集；仍有多盘进入事件核对。

## 第二层：事件吻合核对

对每盘逐条核对用户 3-5 件大事：

| 事件 | 年份 | 候选 A | 候选 B |
|---|---:|---|---|
| {事件} | {年份} | 吻合 / 不吻合 / 无法判断 | 同左 |

依据 `yearly_range` 流年结果与 `domains/bazi/dayun.md` 应期规则判断。吻合数明显领先者直接采用。

## 第三层：问题方向分界

仅当吻合数持平或接近时，比较当前关心领域与候选盘特征：

| 关心领域 | 判断点 |
|---|---|
| 事业 | 官杀透干有力 vs 财旺身弱难担 |
| 婚姻 | 夫妻宫冲刑 vs 合化吉 |
| 财运 | 比劫夺财 vs 财星有食伤生 |

## 输出与置信度

| 置信度 | 条件 |
|---|---|
| 高 | 结构排除后仅剩一盘 |
| 中 | 事件吻合数明显领先 |
| 低 | 平局后借问题方向分界 |

输出候选时辰、排除依据、核对详情与置信度。事件年份误差 ≥2 年时降低该事件权重；用户无法补足事件时输出“考时证据不足”；用户指定候选时标注“未经考时确认”。
