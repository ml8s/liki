# 命理裁决准则

> 方法层文档（`domains/bazi/caijue.md`）——agent 在多断语/多域冲突时的命理裁决次序。
> 根 SKILL.md「流程约定」引用本文件；不随临时调整，依据经典命理（《子平真诠》《滴天髓》《三命通会》《紫微斗数全书》）。

## 流年显式目标映射（主域取象——不是泛称因子）

| 主域 | 显式目标 |
|------|--------|
| 婚姻 | 配偶星 |
| 六亲 | 父星 / 母星 / 子女星 |
| 财运 | 财星 |
| 事业 | 官杀 |
| 健康 | 日主 |
| 学业 | 母星（印星） |
| 子女 | 子女星 |

实现契约：流年因子没有隐藏 target，也不存在泛称「流年目标星透 / 流年克目标星」。查询必须落到显式因子，如「流年配偶星透」「流年财星克」「流年母星透」「流年子女星透」；算子参数同样显式写入 target。

**★主域优先**（综合断事看多域——但以用户问题对应域为主——其他域只作佐证，不跨域否决主域）：先识别用户问什么（婚姻/事业/学历/出身/健康/性格/财运/六亲/应期/综合）——主域断语优先定案；其他域断语仅作辅助佐证（如问婚姻以 marriage 为主——personality/health 只佐证不否决婚姻断语——问性格以 personality 判主面）。

**性格主面裁决（月令格神定主面；透干≥2 十神作强辅面——见准则 8）**：问性格（含"此命性格/个性/性情如何"）——**主面 = 月令本气十神断语（xg_m01~m10，表序最前）**：《子平真诠》"月令为提纲，格神主性"——月令本气（月支藏干主气）的十神是性格主面，唯一命中（月令本气互斥）。十神旺衰断语（xg_2xx 劫财/伤官/七杀/正印/食神…）**只作辅面观察，不得反超月令主面**——多十神旺衰断语同时命中属正常（多面），主面以月令本气为准（如月令偏印主内向沉默，虽有劫财旺断语不取外向；月令七杀身弱主胆小压抑）。紫微命宫主星断语同列辅面，不反超月令主面。**紫微命宫双主星**（廉府/紫府/武贪/机月同梁等——命宫同时坐两颗主星）：两条主星断语**都真实，不冲突**——按《紫微斗数》双星组合论综合（两星特征并见：廉贞天府=刚柔并济外柔内刚、紫微天府=大气守成、武曲贪狼=魄力与欲望并见），星曜亮度高者略主（庙>旺>利>陷），但**不覆盖八字月令主面**。

**流年分析域事件隔离（跨域事件杂音不作证据）**：问应期（年份/发生何事）做流年分析时，**按用户主域只采信对应事件断语**——健康/灾劫问只取 yearly_health/yingqi 的「健康/凶事/血光/精神」事件断语；婚姻问只取「婚动/婚变」；财运问只取「得财/破财」；六亲问只取「六亲灾/父母/子女」事件。**非主域事件断语命中也不得作该问题依据**（如健康问里命中的「婚动/姻缘吉/感情」断语、婚姻问里命中的「健康凶年」——跨域事件杂音不作证据）。八字/紫微**同域**事件断语可交叉作候选，异域一律排除。
**多命中一致性（agent 综合——程序不硬选）**：一局多断语多面共存（命理表达各不相同）——agent 按命理次序综合（参考裁决次序），同象互证（如"婚可成"+紫微"天机独坐姻缘淡薄"冲突时按紫微夫妻宫专断信号权衡）——不得程序硬选/归一标签。
**双盘参看（真分开——各自判→对照，非合并）**：八字因子快照（bazi）与紫微因子快照（ziwei）分别计算——八字表纯八字断语、紫微表纯紫微断语（无跨术数条件行）——输出为双盘命理断语（各自表达）——综合评定 agent 做（像命理师八字紫微合参，各自判完再对照；紫微夫妻宫专断信号——贪狼化忌/天机独坐——见紫微断语表 hun_301/302）。

query 工具输出：学历 / 婚姻状态 / 子女 / 事业 / 出身 的断语结论（附命理依据与断语 id）。

- **确定性结论全部走 query 工具**（内部真值表 `tools/assertions/assertions.csv` + `tools/assertions/assertion_conditions.csv`——因子取值行 + 经典原文列；婚姻含紫微交叉）
- **断语规则统一**：query 内部真值表（`tools/assertions/assertions.csv` + `tools/assertions/assertion_conditions.csv` 执行）+ `domains/bazi/*.md`+`domains/ziwei/*.md`（八字/紫微断法细则）+ 其他术数 `domains/*/*.md`（未 csv 化的断语）——**规则就是规则，不存在"参考"弱化**：agent 执行以 query 输出为准，md 细则用于理解规则依据与补充未入表细则（判断链/取象顺序/组合规则），不得与 query 输出矛盾
- **直接采纳输出为最终判断**，禁止自行重算状态/档位（规则编码自真值表 + 经典，重算必错）
- query 输出双盘断语（八字/紫微分别多条命中）→ 按命理次序整合：结构专断（表序最前/紫微专断）定调，其余作佐证
- query 输出与查表冲突 → 以 query 为准，输出中说明冲突
- 紫微结构专断（无子/生死/残疾的紫微宫位断语）与结论验证已发生事件例外，可推翻并标注依据
- 排盘 RPC 失败 → 提示重试（不降级查表——真值表匹配是精度来源，降级会退化精度）
- query 工具是 skill 的一部分（`tools/assertions/` 随 skill 分发），容器/本机均可用

**婚姻应期（何年结婚）**：按决策表取大运配偶星窗口 × 流年引动交集给候选年份，**只在候选内裁决**（禁止选候选外年份；验证可推翻须标注理由）。

**应期多候选裁决（验证语义，通用准则，非单一问题规则）**：
0. **候选锁域内主信号**：问结婚/成婚 → 命中**婚动断语**（ymar_101~111——流年域 yearly_marriage）的年份即候选，候选内**其他信号（凶事/健康/忌神/婚变杂音）不得降级候选**——真实事件年多信号并存（婚动+凶象混杂叠加），非纯吉年。裁决候选：**变动叠加优先**（冲夫妻宫/换运首年/值宫/配偶星大运窗口多信号叠加年 > 单纯配偶星透/合会年——引动多则应事实）。与准则 1 关系：**带凶象/婚变杂音的婚动年（合会+忌神、冲+克等）不按"恋爱引动"排除**（真实事件年常混杂）；纯合会恋爱年仍按准则 1（通常不作结婚答案，除非结论验证时间线自洽支持）。婚变断语（ymar_108~110b）只作离婚/分手问题主信号，不作结婚问题否决（按用户诉求取域内主信号：问结婚取婚动、问离婚取婚变）。
1. **首次成婚**：问"何时结婚/第一段婚姻" → 候选年内取最早**成婚引动**（配偶星透/合会 + 换运/配偶星大运窗口——成婚实据）；**恋爱引动（单纯合会/桃花/异性缘）≠成婚**——不得取为结婚年（《三命通会》合会主感情聚合，成婚看配偶星实引动；如 1999 合会恋爱 vs 2006 换运配偶星透成婚——取后者）
2. **冲主变动**：六冲夫妻宫主**手续/仪式/法律变动**（签纸、登记），合会主感情聚合——用户提到"冲年签纸/合年同居"语义时按用户诉求指认
3. **引动都算（禁虚引动降级）**：流年合/冲/透/换运/配偶星大运窗口——**任何引动都是候选信号，不得以"虚引动/引动强弱/无配偶星大运窗口"降级排除**（《三命通会》合会引动为准，不分实虚）；**换运首年 + 配偶星透干 = 一级成婚候选**（大运交接主变——不得被其他候选年的引动强度否决）
4. **多候选同级**：取最早年份；仍有歧义 → 按用户诉求（首次/再婚/手续/仪式）指认并标注理由

**结论验证补则（命理依据）**：
0. **流年凶信号权重 > 吉信号（仅限问凶）**：用户问**凶事**（欠债/破财/病灾/灾劫/官非/凶年事件）时——流年同现吉信号（财星透/进财/婚动/禄）与凶信号（日犯岁君/伏吟/反吟/三刑/天克地冲/忌神攻身/灾星入宫），**凶信号定调，吉信号不否决**（《渊海子平》伏吟反吟主凶、日犯岁君主凶年：凶年里的"财透/婚动"只是表象，不得取"进财机会"判吉）。用户问**吉事**（结婚/得财/升迁/得子）时——按准则 0 取主域信号，**答案年可为吉凶混杂**（婚动+凶象并存的结婚年是真实事件年），不按凶排除。判定前先分派用户诉求：问凶取凶、问吉取吉，忌混用。
1. **孕产凶险 ≠ 否认定生育**：难产/损胎/堕胎信号（食伤受冲刑/子女宫煞/流羊入子女宫）是"生育年之象"——**不得以此排除生子/生育候选**（得子看子女星/宫引动；如"难产信号"正是该年生子之象）
2. **性向/寿元以本命结构定案**：婚恋异常（性向类）以本命结构定案（官杀全无/宫星陷/神煞三证）——**大运配偶星引动只断恋爱经历，不断性向**（本命结构与流年引动分开）
3. **主断语优先于辅象**：query 的唯一/主断语优先——**辅象（非断语的星曜/五行推断）不得覆盖唯一断语**（如"金旺→皮肤白皙"为主象——巨门唇大/土多敦实等辅象不覆盖）
4. **跨问题互斥禁用含命理修辞**：禁止用"其他问题结论 + 命理推理（如'某年母已应灾→本问题母亡排除''木局生火母有救'）"绕过护栏——**各问题独立看盘**（跨问题互斥=错误：前一问误判会连锁毁掉后续判断）
5. **六亲生死需断语/应期支持**：不得以泛信号（财坏印/财克印/忌神年）臆断六亲生死（如"1984 财克印=母亡"无断语支持=臆断）——六亲亡故须有六亲星受克应期断语命中或命局铁证（财坏印仅主家计/健康——父寿以父星断语为准）
6. **健康应期看疾厄宫+大限**：重病/手术/癌类应期——疾厄大限（疾厄宫主星大限）内 + 流年引动疾厄宫（化忌/权入疾厄）为主信号；八字"官印相生=好年"不否决疾厄引动（疾厄大限内紫微权入疾厄=重病年；疾厄宫武曲忌+流年疾厄宫流陀=重病信号）
7. **子女性别以时柱食伤阴阳为唯一标准**：以时柱干十神（食神/伤官）阴阳定性别（阴→女/阳→男——时柱为子女宫主位）。流年伤官/食神引动、大运食伤变化、紫微子女宫星曜均**不得改变**时柱定的性别判断——时柱食神阴=女婴，时柱伤官阳=男婴，为唯一标准，禁止引入其他信号反超

**综合裁决准则（agent 裁决层的命理次序）**：
1. **专断断语优先于一般反证**：专断断语命中（六亲宫化忌→六亲灾、值宫伏吟/婚动强→婚期、疾厄化忌→健康大事）——**一般性反证（印星当旺/喜用好年/单年杂音）不得否决**——须**同域闭环强反证**（同域双断语冲突）才可翻（《三命通会》宫位引动专断；父母宫忌命中母逝——"印星当旺"不否决；婚动强——杂音不否决）
2. **断语直指即采纳**：断语结论与用户表述**直接对应**（官禄空劫=转工漂泊、父母宫化忌=六亲灾）→ **直接采纳，不得转释/降权/另解**（官禄空劫即"不停转工"——不解读成"经营艰辛"；子女宫化禄=生育吉应——不排除）
3. **孕产分情境**：**问生育应期**——凶险≠否认定生育（难产是生子年之象）；**问事件且用户提到"流产/堕胎"**——伏吟日柱+刑子女宫+疾厄化忌组合 = **断流产**（不转释为剖腹产/其他）（伏吟日柱+刑子女宫+文曲忌=流产——此则只适用问生育应期）
4. **六亲生死闭环**：六亲星入墓+伏吟 **≠ 六亲亡铁证**——须**父母宫凶/六亲星受克叠加闭环**才断亡故（六亲亡故双证：宫凶+星受克——单凭印星入墓+伏吟不足断亡故）
5. **本域主信号优先**：本域主信号（学业偏印/事业官星/六亲星）——**跨域佐证（红鸾婚恋星/武曲忌/他域杂星）不得否决本域主信号**（升学看偏印+考试宫——红鸾/武曲忌不否决；合伙投资看偏财比肩——诈骗类不覆盖）
6. **多证即采纳**：**≥3 同向证据齐备即采纳**（不拘"规则断语"形式——证据充分性优先于断语形式要求）（偏财投机+偏印偏门+比肩合伙+流马冲库四证=合伙投资——不因"无应期断语"排除；子女宫合动+多证=该年应事）
7. **宫位语义不串域**：紫微**官禄宫**化权/化科/化忌——**主事业/职场/掌权**，**禁止**用作学业/婚姻信号（学业应期看印星/文昌/文曲/考试宫；婚姻看夫妻宫/红鸾/配偶星）——同盘冲突时以本域信号为准（问学业时流年官禄化权≠升学证据——勿引为升学；同理官禄化权不作婚动）
8. **主面以月令为纲、全局修正**：性格主面 = **月令本气十神**（《子平真诠》月令为提纲，见上文「性格主面裁决」）；但某十神**透干 ≥2** 时作**强辅面**——叠加修正主面（月令偏印内敛 + 食伤三透付出 → 外冷内热付出型，不按纯偏印孤僻断）。
9. **性格外显 vs 内在**：通用性格题（"此命性格/个性如何"）**默认取月令主面**（rule 8 优先——xg_m*）；仅当选项明确描述行为模式时才按措辞分别取象：选项描述外显行为（"做事风风火火/爱指挥别人/好胜争强"）→ 取透干辅面断语（xg_2xx/xg_5xx）；选项描述内在性格（"内心敏感/多思多虑/沉默寡言"）→ 取月令主面断语（xg_m*）。**禁止通用性格题取辅面覆盖主面**（月令偏印主内向，不得因劫财旺透选"好胜外向"）。双面描述（外冷内热）须合参两层（xg_507）。
10. **状态题 vs 事件题**：状态题（性格/婚姻状态/财运状况/学历层次）→ 以本命因子定案，不查流年引动；事件题（某年发生何事/何年结婚/哪年突破）→ 以流年因子+大运引动定案。状态题禁止引流年断语作答（流年杂音不作证据）；事件题禁止只凭本命断语作答（须有应期引动）。
11. **应期同层级二级排序**：多个候选年同为宫动层级时，按引动方式排强度——值宫/伏吟 > 天克地冲 > 三合/三会 > 六合 > 相刑/六害 > 星动 > 神煞。同级同式取引动最多的年份（多重引动>双重>单重）。禁止凭"感觉"选年——须逐年列出引动方式后排序。
12. **流年事件题六亲优先执行细则（有限度）**："某年发生何事"类题，agent 逐年检查六亲星受克信号（流年母星克/流年父星克/流年配偶星克/流年子女星克）。六亲灾断语 **≥2 条且结论明确**（如"母逝候选""配偶重病"级）时，优先于自身一般吉象作答案。自身吉象 **≥3 条且结论明确**（如"事业突破""得奖""升迁"级）时，六亲候选降为次选——六亲灾弱信号（仅 1 条"候选"级）不得单独压过多条明确吉象。禁止无差别六亲优先。

13. **紫微宫位主星断语同级参看**：紫微十二宫主星庙陷断语（zf_3xx 夫妻宫、zc_3xx 财帛宫、zj_3xx 疾厄宫等）是**主信号级**——与八字断语同级参看，不得因"紫微四化只作佐证"而忽略紫微主星断语。例如：zf_328"配偶有财衣食丰足"应参与婚姻质量判断（配偶是否给家用）；zj_320"慢性病长期服药"应参与健康判断。禁止只看八字而忽略紫微宫位断语。

14. **健康时间线关联**：当多年连续出现健康凶象（天克地冲→手术年 + 空亡填实→确诊年 + 岁运并临→重病年），应关联为"手术→确诊→恶化"的时间线，而非孤立看单年。若三年内出现≥3次健康域凶象断语，应推断存在重大疾病进程。

15. **日主五行底色取象优先**：审美/风格/偏好类问题，日主五行底色取象（如辛金→精致/欧式/金属感）优先于十神取象（如偏印→古董/复古/玄学）。十神取象描述行为倾向，日主五行描述本质特质——本质决定偏好方向。
