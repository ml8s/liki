# 财运判断规则

**命理域断语查询**：本场景断语已按命理域重组——查 `query(rule=十神)`（财星/比劫/食伤取象，cai_* 财运档）、`query(rule=用神)`（财为用/忌）、`query(rule=旺衰)`（身强弱）、`query(rule=大运)`（比劫/食伤运）、`query(rule=神煞)`（羊刃/驿马）。断语 id 前缀 cai_/cy_ 现分布于这些命理域 csv。

## 📖 断语核心

财星定有无，身强定胜负，大运定起伏。

**注**：财星在地支有藏干同五行为"有根"。临官/帝旺位为"强根"，余气/墓库位为"弱根"。

**财多身弱互斥锁（强制）**：
- 身弱 + 财旺 → 强制结论"财多身弱反为贫"，阻断后续"得财"判断
- 身弱 + 财平 → 财可担但有限，不以大财论
- 身强 + 财旺 → 正常得财判断

## 大运引动

- 财星大运 → 财运上升期
- 比劫大运 → 破财期（合伙/争斗/开销大）
- 官杀大运 → 压力生财（辛苦得财）
- 食伤大运 → 技术/投资得财

## 📖 翻译表：财运判断

**输入**：财星状态 + 身强弱 + 大运类型 + 比劫位置
**输出**：财运档

### ④ 比劫夺财检查

| 条件 | 风险 |
|------|------|
| 比劫与财星相邻（如年干劫财克月干偏财） | **夺财风险高** |
| 比劫与财星隔位 | 有竞争但不直接 |
| 无比劫 | 无夺财之忧 |

### ⑤ 食伤生财检查

食伤为财之源。食伤状态直接影响财星健康度。

**判断链**：食伤生财为"因"，比劫夺财为"果"。先判断食伤是否生财，再判断比劫是否夺财。
- 食伤生财且无比劫夺财 → 顺遂得财，财能留存
- 食伤生财但比劫夺财 → 辛苦得财，财来财去
- 无食伤生财且比劫夺财 → 无稳定财源还被劫，财务困境

### ⑥ 财印关系检查

财和印相克（财克印为正克）。财印关系决定财富能否转化为长远根基。

**身弱时财印关系更关键**：身弱不胜财，财星透干反克印→财为压力非财富，得财即损根基。

### ⑦ 财运流年应期排队列

候选年份优先级（参考 domains/bazi/dayun.md「应期决策表」）：

| 优先级 | 条件 |
|-------|------|
| 1st | **换运年（±1年）** > 普通年份 |
| 2nd | **财星透干+食伤生财双重引动** > 单重引动 |
| 3rd | **财星合入命（六合/三合引动财星）** > 财星冲入命（冲则变动不定） |
| 4th | 财星值年（流年干支与财星相同）> 食伤生财年 > 比劫夺财年 |

**用法**：多个候选年份时从第1维开始比，第一个分出高低的维度决定应年。

### ⚠️ 破财引动细分与理财判据【强制】

**破财按引动方式细分（断"何年/如何破财"必查）**：
- **驿马 + 比劫** → 外出合伙破财（合作散财）
- **巨门忌 + 仆役宫凶** → 被熟人所欺/合伙受骗
- **比劫 + 偏财无迁移** → 诈骗/借贷失财
- **身弱财多** → 财多身弱漏财，破财最重段 = **财星忌神旺相段**；比劫运帮身反主得财（勿断破财）
- **冲刃/刑开财库**（见 `dayun.md` 冲刃·刑开财库）→ 破财不作制刃吉论

**理财/积蓄判据**：比劫夺财 + 财无根 → 无蓄财观念（钱来钱去）；田宅宫吉星只论**置产**（买房/置业），**不论理财**（储蓄/投资）——断"经济状况/积蓄"看财星本身与比劫，不看田宅吉星
