# 大运分析方法论
## 📋 方法论：大运应期

## 大运与命局的互动

每步大运须从三个维度分析：

**大运干支与命局的关系**
- 大运天干与四柱天干：生合冲克刑
- 大运地支与四柱地支：六合三合六冲六害
- 重点关注：大运冲合原局哪个柱，该柱对应的宫位和十神

**大运对用神的作用**
- 大运生扶用神 → 得运，该运有利
- 大运克制用神 → 失运，该运不利
- 大运助忌神 → 该运需谨慎

## 十年分治

每步大运不能笼统概括，须细分：

**前五年（天干主导）** — 大运天干的力量在五年中逐步增强，前五年受天干影响更大
**后五年（地支主导）** — 大运地支的力量在后五年显现，地支冲合的影响在后五年更明显
**换运年** — 前后两步大运交接之年（前后各一年），是人生节奏切换的关键节点，工作/感情/健康容易出现重大变化

## 大运与流年的配合

大运定十年基调，流年看当年应事。判断方法不是简单的"生扶=吉/克制=凶"，而是看组合后对原局用神/忌神的影响：

- 流年与大运配合后生扶用神 → 吉
- 流年与大运配合后引发忌神 → 凶
- 流年虽克大运，但克的是大运中的忌神 → 反为吉
- 流年虽生大运，但生的是大运中的忌神 → 反为凶

## 冲合关系

冲与合是两种不同性质的作用：

- **冲**：事件性质为突发/断裂/变动（性质为负），结果走向取决于冲去用神还是忌神。冲入年柱→祖辈/根基变动，冲入月柱→家庭/事业环境变动，冲入日支→婚姻/自身变动，冲入时柱→子女/晚年变动
- **合**：牵绊、聚合、持续性事件。合绊→被牵制放不开，合化→性质改变，合动→被引动为应期

**断凶事时引动方式：冲 > 合（冲主变动最烈）**
- 冲：事件性质为突发/断裂/变动，本身即为凶的信号
- 合：中性，需看合化结果。合化用神为吉，合化忌神为凶
- 合动不等于凶：合动只是"引动"，结果取决于引动的是什么星
- 冲与合同时出现时：先按冲定性（判断有无断裂/破坏），再看合是否有解救作用

**判断常规事时**：先看是否有冲（冲比合更直观应事），再看是否有合解救（冲被合解则力度降低）
- 天干论合先于论冲（天干合化重于冲克），地支冲与合并行分析

## 天干地支分论

- **天干**：主外显之事、上半年（1-6月）、社会层面、可见变化
- **地支**：主内隐之事、下半年（7-12月）、个人层面、内在变化
- 天干透出的十神决定事件性质，地支的冲合决定事件力度
- 流年对命局的影响：天干先作用于天干，地支先作用于地支

## 应期推断

同一方法适用于六亲、财运、事业、健康、感情等所有领域。目标星与目标宫位见下方「各领域目标星与目标宫位」表。

实现契约：本表的「目标星」是方法层取象；流年因子层没有隐藏 target。实际查表必须使用显式因子名/显式算子参数（如「流年配偶星透」「流年财星克」），不得回退为泛称目标星因子。

### 大运定窗口

大运给时间窗口。大运的如下行为打开应期窗口：

- **冲**：冲目标星或目标宫位 → 该运为该领域的窗口
- **合**：合住目标星 → 受牵制；合化 → 性质改变
- **克**：大运干支克制目标星 → 凶应窗口
- **生扶**：大运生扶目标星 → 吉应窗口
- **值**：大运干支与目标星/宫位完全相同 → 最强烈的引动

### 流年定年

**先读流年盘（yearly_range 内部编排）**：
- 对候选年份范围调 `yearly_range(pan, start, end, rules)`，内部编排流年排盘（流年 vs 原局四柱、大运交叉、伏吟/反吟、流年神煞）

**流年引动类型**（以下为强应期信号）：
- 值宫/伏吟：流年地支值目标宫位（年柱伏吟→父母事）
- 宫位引动：流年地支对目标宫位的**六合/三合/三会/六冲**均为引动；**三合/三会须三方齐备成局**，两支半合只作辅助信号，不得单独按完整合会定事。合/会主聚（婚聚、事成），冲主变动（婚宫逢冲=婚动，可主成婚亦可主婚变，需结合配偶星/忌神方向）
- 星动：配偶星透干（男流年干=财、女流年干=官杀）为结婚/婚缘直接信号，须与宫位引动同断（单透干不足定年）
- 换运叠加：换运年前后一年 + 流年引动 → 特殊窗口
- 多重引动：大运+流年同时引动（双重）→ 强应年；大运+流年+命局自刑冲（三重）→ 极强年

**应期精度**：流年定年、流月定事；**精确到年**（禁止只断「有/无」或模糊区间）。应年 = 大运引动（窗口）× 流年强引动取交集。

### 候选取舍

多候选年 → 取**引动最充分者**，同分取最先发生者（先到先应）：
- 值宫/伏吟 → 强引动，一律入候选，不得以「忌神/星未透/强度不足」否决
- 宫位引动（合/冲/刑/害）> 星动（目标星天干透出/合）——宫为根、星为用
- 换运年（±1年）仅在直接引动目标星或目标宫位时视为充分，不得仅因「换运+叠加」压过宫位/值宫引动
- 多重引动（三重 > 双重 > 单重）更应——仅在同一引动方式内比较
- 引动方式（断凶事）：六冲 > 三合 > 六合 > 六害 > 相刑（冲主变动最烈）

**硬性要求（禁止违反）**：
- 禁止单信号定年（只凭红鸾/流马/六合/羊刃一个信号就定年）
- 紫微四化只作佐证——不得因"无化禄/有化忌"排除八字主信号已成立的年份（冲突时以八字用神为纲）
- 凶信号≠排除：应期年常伴冲/比劫/官杀攻身，只要目标星或目标宫位被引动就保留候选
- 六合合化须验条件：未验证不得论"合化出某五行"并据此排除该年（合绊/合动不作合化论）

**健康/牢狱/手术专项**：
- 牢狱官非 = 官杀攻身 + 印星无救（忌神年）
- 手术部位 = 被冲克的五行对应脏腑（火=心/眼/血，木=肝/胆/头，金=肺/肠/皮肤，水=肾/膀胱/骨，土=脾/胃/肉）
- 断部位看流年冲克哪个五行，不是固定「日主五行=某器官」

**额外规则（应期推断必查）**：
- **三合/三会局夺根**：参与合化的用神地支视为被合走，不得当旺根救身（例：巳被巳酉丑合化 → 巳火不提供日主旺根）。
- **童限（未上运）凶应**：大运未起时仍按“流年合局 × 原局忌神”论凶，不作自动减分。
- **无六冲≠排除突发事故**：交通意外/车祸类改查驿马、迁移宫、灾煞/金舆及流年×大运组合，禁止用“全年无六冲”单项排除。

### 📖 附加强引动（命中即应期候选）

- **六亲入墓**：流年/大运地支为六亲星（父=偏财、母=正印）之**墓库且伏吟/引动**（如丑为癸水偏财之墓，大运丑+流年丑）＝父/母大灾**一级应期**，须与"入库得财"取象对比后裁决（六亲优先）
- **紫微宫位应期（主信号级，与①②③并列）**：红鸾坐流年夫妻宫；流年命宫落迁移宫（搬迁/出国）；流年命宫落目标领域宫且吉化（如太阴禄入子女宫=儿童领域）；流年命宫落田宅+太阳化禄=搬迁定居
- **迁移/出行类专用信号**：流年命宫落迁移宫、驿马伏吟/逢冲、换运叠加 → **优先于"六冲>六合"引动方式排序**（原第 5 维仅适用断凶事，迁移应期不得误用）
- **凶象优先于吉化**：驿马+羊刃+迁移化忌（出行意外）、冲刃（身强羊刃逢冲=破财/血光，不作制刃吉论）、刑开财库（受损不作得财）——此类凶象成立时，流禄/流昌/流魁等小吉星**不得反转定案**

### 📖 领域目标锁定与紫微吉化降权【强制——应期裁决护栏】

- **引动目标按领域锁定**：健康=日主+忌神+疾厄宫；婚姻=日支/夫妻宫；子女=时柱/子女宫；父/母=偏财/正印+年支。宫位引动只在本领域目标内比较，**禁止用他领域宫动判他领域事件**（如"冲夫妻宫"不得判健康"谁得病"）
- **八字凶信号 > 紫微吉化**：比劫克食伤/忌神攻身/冲刃成立时，流禄/流鸾/流钺/流昌/流魁/四化只作"应事领域提示"，**禁止作"纯吉定案"**，更不得否决八字主信号已对齐的年份
- **多信号分属不同年份时**：各引动皆算候选，无固定优先级排序——同分取**最先发生者**（先到先应，命理验证准则）
- **领域取象以流年四化所入宫位主星为准**：禁止用大限主星硬套领域（如大限天府≠必房地产；太阴禄入子女宫=儿童领域优先）
- **六亲事件优先于自身吉象【强制】**：流年事件题（该年发生何事）中，**六亲星受克合绊/六亲宫被冲（父星被合、父宫伏吟、印星受制、财星受损）优先于自身吉象**（官星合身、贵人、吉化、升职信号）——先查六亲灾，再查自身吉，禁止用"官合身+吉化"盖过"父星被合+父宫伏吟"
- **三合局/贵人修饰化【强制】**：三合局成形、天乙贵人、禄马交驰**只表该年环境有利，不作事件已发生的直接证据**——须叠加目标星或目标宫位实引动才定事；禁止"见三合局+贵人即断吉事已发生"（事业突破/得子/得财类）
- **凶象优先于吉化仅限出行/迁移专项**：不得压过同年的婚姻/事业主信号；凶象与吉象同年并存时按领域目标分别考量
