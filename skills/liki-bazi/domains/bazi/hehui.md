# 合冲刑害应事逻辑
## 📖 翻译表：合冲刑害

## 📖 六合

子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合。

地支六合的三种应事状态：

- **合绊**：被合住，放不开手。事应于合住的宫位对应领域（如年柱被合绊→受家庭牵制）
- **合化**：两股力量结合产生新五行（子丑合化土、寅亥合化木、卯戌合化火、辰酉合化金、巳申合化水、午未合化土）。新五行对命局生扶则为利、克制则为弊。**合化吉凶分析详见 `domains/bazi/yongshen.md`「合化吉凶判断」**
- **合动**：被合的关系被外部引动（大运/流年冲合该柱时），为应期

**宫位影响**：年柱被合为早运受家庭牵制；月柱被合为环境对个人选择有约束；日支被合为婚姻受外部因素影响；时柱被合为晚年受子女牵制。

> **合与克的应事方向不同**：合主牵绊/聚合/性质变化，不是断裂性事件。克的应事方向是直接攻击/伤害/断裂。判断时应严格区分：合改变的是关系性质（如性格变化、关系重组），克带来的是直接伤害（如生病、破财、离世）。

## 📖 六冲

子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

### 📖 翻译表：冲的判断

**输入**：冲入的宫位 + 被冲对象的类型（用神/忌神/吉星/凶星）
**输出**：事件定性 + 结果走向（两者分开写）

#### ① 宫位应事表

| 冲入宫位 | 事件方向 |
|---------|---------|
| 年柱 | 祖上/父母变动，根基不稳 |
| 月柱 | 家庭/事业环境变动，青年奔波 |
| 日支 | 婚姻波折，自身/配偶变动 |
| 时柱 | 子女事/晚年变动 |
| 三柱以上有冲 | 一生动荡不安 |

#### ② 吉凶决策表

| 场景 | 事件性质 | 结果走向 | 例 |
|------|---------|---------|-----|
| 冲去用神/吉星 | 突发/断裂/破坏 | **凶**—失去依靠，结果不利 | 失业/丧亲/重病 |
| 冲去忌神/凶星 | 突发/断裂/变动 | **先凶后吉**—过程痛苦但长远有利 | 手术治病/离婚解脱 |
| 冲起吉星 | 被动激活 | **转机** | 因祸得福 |
| 冲起凶星 | 潜伏问题爆发 | **凶** | 隐患突然发作 |

**铁律**：冲本身就是凶的（突发/断裂/破坏性事件），差异只在结果走向。输出时先定性"发生了冲"（事件），再判断"结果如何"（吉凶）。

#### ③ 应事强度等级

| 组合 | 强度 |
|------|------|
| 冲+刑并见 | 最强 |
| 单一冲 | 强 |
| 伏吟+冲 | 最强（叠加） |
| 冲被合解 | 力度降低 |

## 三合局

申子辰合水、亥卯未合木、寅午戌合火、巳酉丑合金。

- **完整三合**：三方齐全，力量最强，不受外力轻易破坏
- **半合**（申子、子辰、亥卯、卯未、寅午、午戌、巳酉、酉丑）：力量中等，需要大运或流年引动第三方才能成事
- **拱合**（亥未、寅戌、巳丑、申辰）：力量最弱，待应期触发

## 三会方

寅卯辰会木、巳午未会火、申酉戌会金、亥子丑会水。

力量大于三合，但成局条件苛刻（需三支齐全），频率低。

## 六害

子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害。

- 暗中不和，小事积累，不一次性爆发
- 应事于长期消耗而非急性事件
- 害入年柱为家庭默默付出；害入月柱为同事消耗；害入日支为夫妻之间不说的委屈；害入时柱为晚年子女牵绊

## 相刑

寅巳申互刑、丑未戌互刑、子卯刑、辰午酉亥自刑。

- 口舌是非，纠缠不清，反复发作
- 刑入日支：夫妻关系紧张，但不到破裂
- 刑入年柱：与长辈关系不睦
- 刑入时柱：与子女关系紧张
- 自刑（辰午酉亥）：自我纠结，无事生非

## 📖 流年事件类型推断表

**用法**：拿到流年干支、大运/大限基调、冲合刑害与用忌数据后，逐项匹配。此表是事件方向参考，与 yingqi 断语同源；多条命中时按同域独立证据与时间线综合，程序不硬选第一条，也不设全局优先级。

| 证据组合 | 事件方向 | 确认条件 | 对应领域 |
|---------|---------|---------|---------|
| 换运/大限交接 + 冲刑引动 | 环境、职责或关系状态变动 | 交接窗口须与目标星/宫同域 | 综合 |
| 三合/三会成局且五行成势 | 该五行所克系统失衡倾向 | 结合身强弱、用忌与疾厄宫 | 健康 |
| 偏印 + 七杀组合 | 信息不对称、强制压力、虚假承诺 | 须财帛/官禄/迁移同域引动 | 财运/事业 |
| 财星被合走或合化忌神 | 破财、投资失利、财务纠纷 | 财星受制与求财事类对应 | 财运 |
| 冲入时柱 + 子女星受克 | 子女事务、孕产风险或亲子变动 | 子女星、子女宫、大限同参 | 家庭 |
| 日主被流年干支合克 | 身心压力、受制或重大抉择 | 身弱或用神受制时更明显 | 综合 |

**多条匹配时的取舍规则**：
1. 先按用户问题锁定主域；异域事件只列观察，不改写主域答案。
2. 健康凶象与自身吉象并存时，分别说明健康风险与吉事候选，不以“身体是根本”硬压吉事。
3. 婚姻、事业、财运按对应星/宫引动判断，不用他域宫位替代。
4. 同域多候选看独立证据覆盖面：结构、星、宫、限运、流年、用忌、时间线。
5. 冲与合按事类解释：冲主状态变动，合主联结聚拢；不设全局谁优先。

**用法示例**：
- 流年丙子 + 原局申子辰三合水局 + 身弱 → 水旺转忌克火，提示心脑血管系统倾向；是否成病须疾厄宫与流年凶象同参。
- 流年戊子 + 原局年柱被冲 + 偏财受克入墓 → 父亲事务或健康波动候选；是否重大灾变须父母宫、父星、限运闭环。
