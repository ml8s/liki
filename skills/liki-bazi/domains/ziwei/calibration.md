# 紫微时辰校验
## 📋 方法论：紫微时辰校验

用于出生时辰不确定时，通过紫微12宫星曜反向验证时辰。

## 前置检查（防呆）

- □ 命主为成人（宝宝/青少年跳过此步）
- □ 已对候选时辰排紫微盘（在考时流程中通过 full_paipan 排盘）
- □ 候选时辰 ≥ 2 个
- □ 用户已提供 ≥ 3 件涉及婚姻/子女/事业的人生事实

## 第一层：结构性排除

| # | 人生事实 | 紫微对照宫位+星曜 | 排除规则 |
|---|---------|------------------|---------|
| 1 | 婚姻段数 | 夫妻宫主星（廉贞贪狼=感情复杂/多桃花，天同天梁=晚婚/稳定） | 夫妻宫吉星多+化禄但实有多次婚史 → 排除。夫妻宫凶星多+化忌且实有多次婚史 → ✅ 保留（星与事实吻合） |
| 2 | 有无子女 | 子女宫主星（天同天梁=子女缘厚，七杀破军空宫=子女缘薄） | 子女宫星性与实际子女数明显不符 → 排除 |
| 3 | 事业层次 | 官禄宫主星（紫府+左右=高位，杀破狼=波动创业） | 官禄宫格局与实际成就层次明显不符 → 排除 |

## 第二层：事件吻合度核对

使用本命盘、大限盘星曜对用户已发生重要事件年份做交叉验证。

### 核对规则

| 吻合度 | 核对 | 说明 |
|-------|:----:|------|
| 吻合 |  | 流年文昌/文曲引动与学业/考试年份匹配 |
| 不吻合 |  | 流年化忌+煞星与事件性质冲突 |
| 不相关 | | 无法判断 |

### 📖 决策表：各宫星曜校准参考

| 校准维度 | 强信号（取信） | 反信号（排除） |
|---------|--------------|--------------|
| 感情 | 夫妻宫红鸾天喜+化禄 | 夫妻宫吉星多+化禄但实有多次婚史（星与事实不符） |
| 学业 | 命宫/福德宫文昌文曲+化科 | — |
| 子女 | 子女宫天同天梁 | 子女宫七杀破军空宫但实有子女 |
| 事业 | 官禄宫紫府+左右/化权 | 官禄宫被空劫冲破但实有高位 |

## 输出

- ✅ 保留：紫微验证通过，与八字一致
- ⚠️ 存疑：紫微与八字结论相左，标记需人工确认
- ❌ 排除：紫微星曜与人生事实明显冲突
