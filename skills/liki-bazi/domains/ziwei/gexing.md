# 性格分析方法

## 判断流程

**双盘合参原则**：性格以八字月令/十神定结构主面，以紫微命宫、身宫、福德宫定星情与表达层。两盘冲突时不默认八字压紫微，须分层列证并说明冲突。


```
① 紫微命宫主星 → 性格基调
   读取 `domains/ziwei/zhuxing.md` 星曜性格基调表
   例：命宫天府 → 保守稳重型

② 命宫辅星/煞星 → 修正
   文昌文曲+ → 文采好
   火星铃星+ → 急躁
   擎羊陀罗+ → 刚烈/拖延
   空宫 → 借对宫主星

③ 八字十神 → 性格修正
   七杀有制/无制 → 区分"魄力型"和"莽撞型"
   印旺身强 → 保守内敛
   食伤泄秀 → 聪敏外露
   比劫重重 → 刚强独立
   官杀混杂 → 内心矛盾

④ 综合输出
   "紫微命宫XX星+XX煞 → 性格基调
    八字十神XX → 性格修正
    结论：描述"
```

## 空宫处理

命宫无主星 → 借对宫（迁移宫）主星为断。
对宫也无主星 → 性格受后天环境塑形明显，以八字十神为主要判断依据。
