# 宫位与四化

> 紫微无「用神」概念——以星曜庙旺落陷 + 四化 + 宫位组合论，不套八字用神。

| 交友宫 | 朋友助力，社交圈 |
| 官禄宫 | 事业方向，社会地位 |
| 田宅宫 | 房产运，家庭根基 |

**空宫处理**：命宫无主星时，借对宫（迁移宫）主星为断。

### 📖 翻译表：空宫处理

| 场景 | 操作 | 经典依据 |
|------|------|---------|
| 命宫无主星 | 借迁移宫主星+四化为断。辅星不借。命宫性格基调由迁移宫主星决定 | 《紫微斗数全书》"命宫无主星，借迁移宫主星为断" |
| 其他宫无主星 | 不直接借入。看对宫主星作为参考，标注"参考对宫XX星"而非"该宫有XX星" | 中州派：空宫看对宫但不等于有星 |
| 对宫也无主星（双空宫） | 无星可借，以本宫五行论吉凶。标注"双空宫，以本宫五行断" | 《紫微斗数全书》"空宫无星可借，以宫位五行论" |
| 命宫空+身宫在别宫 | 命宫借入星+身宫方向复合判断 | 《紫微斗数全书》身宫论 |

> 例：命宫在丑无主星，迁移宫在末有武曲化禄+破军→命宫借入武曲化禄+破军
> 例：官禄宫在丑无主星，夫妻宫在末有主星→官禄宫空，参考夫妻宫星曜
> 例：子女宫在巳无主星，田宅宫在亥也无主星→双空宫，以巳宫五行（火）论

## 📖 翻译表：四化含义

| 四化 | 性质 | 影响 |
|------|------|------|
| 化禄 | 财富/机遇/顺利 | 落财帛宫最佳，夫妻宫主感情滋润 |
| 化权 | 权力/掌控/能力 | 落官禄宫最佳，命宫主强势 |
| 化科 | 名声/文化/考试 | 落命宫主名声好，福德宫主修养 |
| 化忌 | 缺失/课题/考验 | 所在宫位为人生命题，须说明 |

## 来因宫（原宫）

来因宫 = 命盘12宫中，天干与生年天干相同的宫位（排除子、丑两个地支）。

| 来因宫所在 | 人生主要课题方向 |
|-----------|----------------|
| 命宫 | 自我实现、个人成长、建立自我 |
| 兄弟宫 | 手足合作、母亲关系、团队协作 |
| 夫妻宫 | 婚姻经营、感情课题、合作关系 |
| 子女宫 | 子女缘分、桃花境界、才华成果 |
| 财帛宫 | 财富格局、赚钱方式、财务课题 |
| 疾厄宫 | 身体健康、生死观、务实扎根 |
| 迁移宫 | 外出发展、人际网络、跨界能力 |
| 交友宫 | 贵人助力、人际圈层、伙伴关系 |
| 官禄宫 | 事业成就、社会地位、使命方向 |
| 田宅宫 | 家业根基、房产运、家族传承 |
| 福德宫 | 精神世界、福气厚度、内在修为 |
| 父母宫 | 父母缘分、祖上荫功、文化底蕴 |
