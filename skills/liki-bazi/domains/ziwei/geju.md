# 特殊格局

## 📖 翻译表：格局识别

| 格局 | 组成 | 含义 |
|------|------|------|
| 杀破狼 | 七杀+破军+贪狼 | 动格，一生变动大成大事者多 |
| 紫府同宫 | 紫微+天府 | 贵格，领导才能 |
| 紫微朝垣 | 命宫紫微，三方四正有左辅右弼/天魁天钺/文昌文曲/禄存等百官朝拱 | 贵格，有权威（仅紫微坐命无百官不构成） |
| 日月并明 | 太阳在巳/午（庙）+ 太阴在酉/戌/亥（庙），分别居命宫三方 | 光明磊落，名利双收 |
| 月朗天门 | 太阴在亥 | 清贵，文采出众 |
| 机月同梁 | 天机+太阴+天同+天梁 | 吏人格，公职稳定 |
| 武贪同行 | 武曲+贪狼同宫（丑未），同宫火星或铃星为「武贪火铃」格 | 有火铃少年暴发；无火铃发较迟，仍主富 |
| 廉贪同行 | 廉贞+贪狼 | 桃花犯，才艺格 |
| 府相朝垣 | 天相+天府在三方 | 贵格，稳重有成 |
| 巨火羊 | 巨门+火星+擎羊 | 凶格，是非官非 |
| 刑忌夹印 | 天相被天梁化忌+天刑夹制 | 凶格，被拖累 |
