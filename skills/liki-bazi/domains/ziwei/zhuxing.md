## 📖 取象升格铁律【强制——禁止单星曜/单十神/单神煞直接升格为具体职业/身份/事件】

- 单星曜（贪狼=僧道、太阴=财务、空劫=极简、破军=分离、天机=聪明）、单十神（偏财格=金融、杀印相生=高管）、单神煞（华盖=宗教、驿马=出国、灾煞=终身病）**一律不得单独定案**
- 职业/身份/事件取象须覆盖八字与紫微至少各一层证据（十神/格局 × 官禄/财帛/迁移宫），并以命局最强基础象与流年引动合参；不以固定数量硬锁结论
- "僧道命/宗教缘/华盖"只作**倾向**（对结论的加分项），不作职业定论
- 判断顺序：先查命局强弱/格局/财官透干 → 再查被制化的十神 → 最后查紫微组合象

### 📖 组合取象表（反标签化——同一星曜在不同组合下取不同象）

| 组合 | 取象 | 勿误取为 |
|------|------|---------|
| 天机 + 空劫 | 古灵精怪、奇巧收藏、智谋型 | 极简/不喜摆设 |
| 太阳 + 火星 + 陀罗 + 天马 | 体能/运动/行动力职业（健身/运动/外勤） | 财务/文书 |
| 太阴化禄入官禄 | 财务/管理；但**须结合命宫主星定象**（命宫火陀天马→健身/体态管理） | 一律=会计财务 |
| 命宫天府/天相 | 保守稳重、重享受 | 闯祸/激进 |
| 紫微+武曲+天府于田宅/官禄 | 管理/资产 | 单凭田宅星=已购房 |
| 贪狼+华盖（辰戌） | 宗教/玄学**倾向**，不作职业定论 | 牧师/僧道职业 |
| 身宫主星 | 后天补充，**不得反压命宫主星**（命宫=第一属性） | 以身宫反断性格 |

### 📖 取象护栏【强制——固定取象只作方向提示，禁止硬否决】

- **反例清单**（固定取象遇此不得直接定案）：空劫≠贫穷/极简（看父母宫禄存/天梁/年柱财星）、桃花/天喜≠出轨（须叠化忌/忌神攻身）、将星≠干部、文曲化科≠获奖（看是否入官禄且被凶星夹）、驿马逢冲≠交通意外（须疾厄/迁移宫凶格）、水旺≠航运/贸易、太阴≠必会计、廉贞≠必音乐、金水伤官≠必瘦（命宫太阳旺/火陀=结实健壮优先）、破军≠必吵闹（庙地+禄存=家底厚）、偏财当令≠家富（看劫财盖头/根空亡）
- **出身/身材基础判据**：骨架/身材查 query(rule=外貌)（八字五行身材）；家境以年柱财星旺衰+父母宫主星庙陷（天梁祖荫/禄存家底）定，田宅空劫仅作"白手起家"辅助信号
- **取象顺序**：先查被制化十神/根空亡/被合走 → 再按组合取象表 → 覆盖八字与紫微各至少一层独立证据才定案；单星曜、单神煞或同源重复信号不直接定案
