# 性格分析

## 依赖的领域知识

[必读] - bazi: domains/bazi/wangshuai.md「身弱五行属性降级表」
[必读] - bazi: domains/bazi/shishen.md「十神组合场景化」

[按需] - ziwei: domains/ziwei/yingqi.md（仅问特定年份状态时读取）
[必读] - ziwei: domains/ziwei/gexing.md「紫微性格分析方法」

## 📖 流程

1. 排盘 → `full_paipan(gregorian, gender, longitude, correct)`
   输出：□ 本命盘已排____

2. 日主五行定基础 → `query(rule=五行)` + `query(rule=旺衰)` + wangshuai.md「身弱五行属性降级表」
   输出：□ 日主____ 身强/弱____ 基础特征____

3. 十神组合修正 → `query(rule=十神)` + shishen.md「十神组合场景化」
   输出：□ 组合类型____ 修正方向____

4. 综合
   输出：□ 正向特征____ 负向特征____ 最终结论____

5. 紫微合参【强制——断「具体细节」时必做，禁止只凭八字粗断】→ 本命以 `query(rule=命宫)` 合参；仅问特定年份状态时用 `yearly_range(pan, year, year, ["yingqi"])`
   输出：□ 命宫主星____ 身宫____ 福德宫____ 命主/身主____ 生年四化____
   综合：命宫定性 + 福德宫定内心状态 + 四化定执念与消耗点——单层主星不得下结论


## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 用户问外貌 | 日主五行+旺衰定体型倾向（木高瘦、土敦实、金方正、水丰腴、火中等）|

### ⚠️ 身材/体型双向校验【强制——禁止单线五行定体型】

- **五行旺衰 + 身强弱双向校验**：断体型须先定身强弱，再定五行旺衰——
  - 身强木旺 → 高瘦；身弱木（被金克）→ **未必瘦**（骨细体弱反显瘦削感弱，可能矮小）
  - 金旺身强 → 骨健方正；**身弱金 → 骨架细、未必高大**
  - 土旺 → 敦实矮胖；火旺 → 中等偏壮；水旺 → 丰腴
- **双盘互证**：八字五行 + 紫微身宫/命宫星曜（天府丰腴、天机纤细、武曲骨感）冲突时**并列列证据对比强弱**，禁止默认八字优先
- 用户提到"矮/胖/壮/瘦"具体描述 → 逐诉求映射后比对，禁止单信号（如"木主高"）直接定档
