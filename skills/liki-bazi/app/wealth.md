# 财运分析

## 依赖的领域知识

[必读] - bazi: domains/bazi/wealth.md「决策表」
[必读] - bazi: domains/bazi/shishen.md「十神」

[必读] - ziwei: domains/ziwei/yingqi.md「财运紫微应期」
## 📖 流程

1. 排盘 → `full_paipan(gregorian, gender, longitude, correct)`
   输出：□ 本命盘已排____

2. 财星有无 → `query(rule=十神)`（财星现/透/藏取象） + `query(rule=用神)`（财为用否）
   输出：□ 财星类型____ 透/藏____ 财为用____

3. 胜财能力 → `query(rule=旺衰)`（身强弱）
   输出：□ 胜财能力____（能担/不能担/中和）——财多身弱互斥锁见 wealth.md「断语核心」

4. 大运/比劫 → `query(rule=大运)` + `query(rule=十神)`（比劫夺财取象）
   输出：□ 当前大运____ 夺财风险____

5. 紫微合参【强制——断「具体细节」时必做，禁止只凭八字粗断】→ `query(rule=财帛)` + `query(rule=田宅)`；流年再调 `yearly_range(pan, start, end, ["yearly_wealth","yingqi"])`
   输出：□ 财帛宫星曜____ 田宅宫星曜____ 化禄/忌____ 流年财运信号____


## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 原局无财星 | 查食伤（食伤生财为隐性财源）|
| 财多身弱 | 标注为"财多身弱反为贫"，需大运帮身方可担财 |

## 📖 输出模板

### 长格式

```
【财运分析】
财星类型：{正财/偏财}，{透干/藏支}
胜财能力：{能担/不能担/中和} → {财旺则富/财多身弱/稳定财源}
大运影响：{财/食伤/比劫/官杀}运 → {得财/技术赚钱/夺财/辛苦得财}
风险提示：{比劫夺财/无}
```

### 短格式

```
财运：{正/偏}财{透/藏}，身{旺/弱/中和}。当前{大运}运{有利/不利}。
```
