## 📖 流程

1. 排盘 → `full_paipan(时间, 性别, 地点, correct)`
   输出：□ 本命盘已排____ 因子快照已写出____

2. 定位配偶星（男看财星、女看官杀）→ shishen.md「女命婚姻——官杀混杂判断」
   输出：□ 配偶星____ 官杀几位____ 有取清？____

3. 夫妻宫（日支）检查 → gongwei.md「日柱」
   输出：□ 日支冲刑____ 日支被合？____ 合化结果（化用神吉/化忌神凶）____

4. 婚姻状态锁定【强制——先锁状态再推应期；未锁定状态时禁止编造"某年结婚+某年离婚"完整叙事】
   输出：□ 状态 = 已婚 / 单身（含独身倾向）/ 离异

   已婚判据（需≥2项，且无否决项）：
     □ 配偶星得地（透干/有根/得月令）
     □ 夫妻宫无大破（非空亡、非双重冲克）
     □ 大运或流年已引动过配偶星且带禄/贵人

   否决项（任一项成立 → 不得锁"已婚"，强制走婚恋异常路径；红鸾/天喜/六合/大运透星一律不得升格"已婚"，只许修正"独身"为"晚婚/有恋情"）：
     □ 大运从未实引动过配偶星（只有原局信号，无应期年份）
     □ 官杀（女）/财星（男）原局极弱且大运无透
     □ 孤辰/寡宿入命宫或夫妻宫、夫妻宫主星落陷/空宫
     □ 配偶星得地但带桃花贵人——仅为"异性缘/恋情"

   升格条款（仅适用"配偶星得地但带桃花贵人"，且在否决项核验之后）：须叠加"大运夫妻宫真动（六合/禄入）"才升格"已婚"；红鸾/天喜不苛求坐实流年夫妻宫，夫宫/妻宫逢合逢冲流年 + 大运财官星交集即可断婚期

   单身/独身倾向判据（需≥2项）：
     □ 配偶星原局不现且大运无透
     □ 比劫重重（比肩+劫财≥3）+ 夫妻宫双重冲克
     □ 孤辰/寡宿入命宫或夫妻宫、命宫无桃花星
     → 判"难成婚/晚婚/独身倾向"后：有引动年份只能断"有感情经历/婚恋机会"，禁止输出"某年结婚+某年离婚"

   婚恋异常检查（强制输出一行判断，禁止写"无异常信号"式未验证否定句）：
     □ 女命官杀极弱或无 / 男命财星极弱或无 + 命宫身宫主星 + 桃花/孤寡组合 → 输出"性取向/婚恋模式倾向"判断（独身主义/同性倾向/晚婚等）
     □ 孤辰寡宿禁断极端：孤辰/寡宿/华盖入命宫或夫妻宫 → 只许断"晚婚/有恋情/婚缘迟"，禁止据此断"同性恋/独身主义"
     □ 同性恋须三证齐备：原局配偶星全无 + 夫妻宫廉贞贪狼组合 + 身宫天相类组合，且大运无配偶星实引动

   对向证据对比（定案前必做）：同时给出"已婚"与"未婚/独身/同性恋"两列证据（原局官杀/财星有无、夫妻宫主星庙陷、孤寡/桃花、大运是否实引动）逐项对比强弱（本命日支/原局配偶星为主，大限夫妻宫/流年桃花为次），同向证据 ≥2 项才锁状态；禁止"无同性信号"一句话绕过

   婚变判定（双证门槛）：
     □ 伤官克官（女）/财星受克（男）年份只记"婚姻矛盾年"，先不判离异
     □ 断离异须双证齐备：① 夫妻宫被冲/刑/穿（流年或大运冲合刑穿日支，伏吟/反吟不作冲开）② 夫妻宫凶格（地空/天哭/流羊/化忌入本命夫妻宫）或忌神攻身（官杀克身、伤官见官、财星受克并见）
     □ 紫微流年夫妻宫化忌只作佐证（助证离异之年），不作必要条件
     → 婚变段数 ≠ 冲忌次数：每段婚变须独立"成婚→离异"闭环

   再婚判据：离异后再见"大运配偶星重新得地（透干/有根）+ 流年夫妻宫复吉（禄入/合动）"即断第二段婚姻；无此则维持"离异后未再婚"；禁止用"同干支机制重演"逆向锁年（头婚年变更时强制重推再婚候选）

5. 应期裁决（应期题）→ dayun.md「应期决策表」：
   婚变流年：女命正官受克之年 = 婚变窗口（官坐绝地/被伤官冲克/被比劫争合优先），男命看正财同理
   排序铁律（优先级从高到低，禁止跨级覆盖）：
     ① 流年地支值夫妻宫/日支 → 一律入候选
     ② 夫妻宫被合/冲/刑/害引动（宫动）优先于配偶星天干透出（星动）
     ③ 大运配偶星得地期内早期合动年优先；换运首年透财官强制入候选
     ④ 换运年仅在直接引动配偶星或夫妻宫时加权
     ⑤ 凶信号≠排除
     ⑥ 大运与流年相冲冲散流年合动 → 不作最高级
     ⑦ 正官/财星合日主 = 最高级婚期信号；妻星/夫星透干降为佐证
   输出：□ 窗口年份____ 引动类型____

6. 紫微佐证【强制——断「具体细节」（何年结婚/离婚/配偶情况）时必做，禁止只凭八字粗断】→ yingqi「婚姻」表 + ziwei.liunian
   输出：□ 夫妻宫星曜____ 四化____ 桃花星____


## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 用户未婚但问离婚 | 先问是否已有稳定对象，有则分析当前关系，无则分析命局倾向 |
| 男命问感情但原局无财星 | 食伤为财源，查食伤状态（食伤生财为隐性妻星） |
| 女命问婚姻但原局无官杀 | 查财星（财生官杀为隐性夫星），或大运引动 |
| 已离婚问再婚 | 查七杀是否清透，大运有无正官/正财出现 |
| 用户只提供了一个人的八字但想看合盘 | 提示需要双方出生信息，引导到 app/compatibility.md |
