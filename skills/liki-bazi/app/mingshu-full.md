# 完整命书

## 依赖的领域知识

[必读] - bazi: `domains/bazi/dayun.md`、`domains/bazi/wangshuai.md`、`domains/bazi/geju.md`、`domains/bazi/yongshen.md`
[必读] - ziwei: `domains/ziwei/yingqi.md`
[按需] - 用户深入某领域时读取对应 app 卡与 domain 文档。

## 路由

| 用户问题 | 处理 |
|---|---|
| 用户明确要完整命书 | 走完整报告流程 |
| 明确问婚姻、学业、健康等 | 直接进入对应 app 卡 |
| 双人关系 | `app/compatibility.md` |

## 📖 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
|---|---|---|---|
| 1 | 取得命盘 | `full_paipan` | `pan` 与基础因子 |
| 2 | 基础框架 | `query`：旺衰、格局、用神、合会冲刑 | 身强弱、格局、用神、冲合 |
| 3 | 陈列模式 | 无明确问题时扫描婚姻、学业、健康、事业、财运、性格、家庭、大运 | 领域摘要与深入入口 |
| 4 | 专项模式 | 有明确问题时读取对应 app 卡 | 专项断言 |
| 5 | 双盘验证 | 比较八字 / 紫微 / 合参断言 | 证据强度 |
| 6 | 历史校准 | 有真实事件时回推 3-5 段已发生时段 | 校准结果或“未验证” |
| 7 | 输出 | 按模板组稿 | 结论 + 依据链 |

## 双盘验证

| 证据形态 | 输出强度 |
|---|---|
| 双体系同向，或有 common 断言 | 强 |
| 一侧明确、另一侧无矛盾 | 中，标单侧主导 |
| 仅一侧有信号 | 弱，标可能 |
| 双侧相反 | 分列证据与适用范围 |

## 📖 输出模板

用户只问单一领域时，仅输出该领域对应章节；无明确问题时按下列结构全卷输出。

| 章节 | 必要内容 |
|---|---|
| 八字总览 | 四柱与藏干、日主五行、身强弱、格局、宫位对应领域 |
| 五行十神 | 五行分布、十神配置、关键组合与应事方向 |
| 用神喜忌 | 三派候选、取舍理由、最终用喜忌、用神状态 |
| 格局 | 正格 / 从格、顺逆用、成破格、相神与清浊 |
| 大运 | 起运、各运干支、与命局生克、当前运与换运年 |
| 当前流年 | 干支关系、大运互动、应事应人与关注事项 |
| 紫微总览 | 命身宫、主星格局、十二宫要点、四化与三方四正 |
| 紫微限运 | 当前大限主题、流年命宫与引动宫位 |
| 双盘交叉 | 按证据强度表输出一致、单侧或分歧 |
| 综合建议 | 事业、财运、感情、健康各一句信号与建议；信号不足如实标注 |
