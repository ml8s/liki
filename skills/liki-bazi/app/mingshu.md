# 命盘快速扫描

## 依赖的领域知识

[必读] - bazi: `domains/bazi/wangshuai.md`「旺衰」+ `domains/bazi/geju.md`「格局」+ `domains/bazi/yongshen.md`「用神」
[按需] - ziwei: `domains/ziwei/yingqi.md`（问当前 / 流年主题时读取）

## 路由

| 用户问题 | 处理 |
|---|---|
| 随便看看 / 看命盘 | 快速扫描核心事实 |
| 明确问婚姻、事业、健康等 | 进入对应 app 卡 |
| 要求完整报告 | `app/mingshu-full.md` |

## 📖 流程

| 步骤 | 类型 | 条件 / 目标 | 动作 | 产物 |
|---|---|---|---|---|
| 1 | 排盘 | 取得命盘 | 使用根流程 `pan` | 基础因子 |
| 2 | 基础框架 | `query`：旺衰、格局、用神 | 身强弱、格局、用喜忌 | 基础结论 |
| 2a | ⛔ 阻塞确认 | 确认四柱和时辰 | 展示四柱、日主、真太阳时与编号选项；等用户确认后再分析 | 确认的命盘 |
| 3 | 领域扫描 | 婚姻、事业、财运、健康、学业、家庭各取核心断言 | 领域摘要 | 领域摘要 |
| 4 | 双盘状态 | 标明八字 / 紫微 / 合参来源 | 证据层级 | 证据层级 |
| 5 | 输出 | 给深入入口，不展开全卷 | 摘要 + 下一步选项 | 摘要 + 下一步选项 |

### 交互模板

```text
2a ⛔ 只输出：年柱 {干支} | 月柱 {干支} | 日柱 {干支} | 时柱 {干支}；日主 {天干}（{五行}）；真太阳时 {时间}。选项 1.正确，继续分析 2.时辰可能不准，我要校准。停在这里；不要输出领域分析。
```

## 📖 输出模板

| 输出 | 内容 |
|---|---|
| 基础 | 四柱、日主强弱、格局、用喜忌 |
| 领域 | 每域 1-2 条核心结论与断语 id |
| 双盘 | 一致 / 单侧 / 分歧 |
| 下一步 | 编号列出可深入领域或完整命书 |
