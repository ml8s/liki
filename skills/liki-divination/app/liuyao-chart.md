# 六爻问卦

## 依赖的领域知识

[必读] - liuyao: `domains/liuyao/yongshen.md`（用神）+ `yuejian.md`（旺衰 / 修饰）+ `jixiong.md`（动爻关系）+ `patterns.md`（格局）+ `liushou.md`（六神）+ `yingqi.md`（应期）

## 📖 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
|---|---|---|---|
| 1 | 时间基准 | `time.now` | 当前时间 |
| 2 | 起卦装卦 | `liuyao.qigua` → `liuyao.chart` | 卦象、用神、动爻、格局、六神 |
| 3 | 解读六因子 | 旺衰、月破、旬空、动爻关系、格局、六神 | 吉凶、助力 / 阻碍、结构、色彩 |
| 4 | 应期 | 读取 `domains/liuyao/yingqi.md`，只解释相关候选 | 时间窗口 |
| 5 | 输出 | 按模板综合 | 结论 + 依据 + 建议 |

卦盘 `lines`、干支与宫位是展示事实；吉凶解读只使用上述六因子。

## 边界条件

| 异常场景 | 处理方式 |
|---|---|
| 用户说“随便算算” | 起卦看当前运势 |
| 时间跨度很大 | 说明六爻偏中长期，重大节点可分段起卦 |

## 📖 输出模板

| 输出 | 内容 |
|---|---|
| 结论 | 一句话吉凶 / 成败 |
| 用神 | 用神六亲、爻位、世应、旺衰修饰 |
| 动爻 | 本卦 → 变卦、生克冲合、助力 / 阻碍 |
| 结构 | 格局与六神色彩 |
| 应期 | 相关候选与时间窗口 |
