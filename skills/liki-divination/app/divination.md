# 占卜分析

## 依赖的领域知识

[必读] - 六爻: domains/liuyao/yongshen.md（用神）+ jixiong.md（吉凶）+ yingqi.md（应期）
[必读] - 奇门: domains/qimen/yongshen.md（用神）+ bamen.md（八门）+ jiuxing.md（九星）+ bashen.md（八神）

## 用户问法 → 流程分支

| 用户问题 | 分支 |
|---------|------|
| 这个事能成吗 / 什么时候有结果 | 六爻 |
| 往哪个方向好 / 现在该不该做 | 奇门 |

## 📖 流程

1. 区分问题类型 → 吉凶类走六爻，方向/时机类走奇门
   输出：□ 问题类型____ 调用领域____

### 六爻（吉凶/应期）
2. 起卦 → `liuyao.qigua(...)`（不强制出生时间，心念/随机起卦；返回 yaos 六爻值：6 老阴 / 7 少阳 / 8 少阴 / 9 老阳，6/9 为动爻）
   输出：□ 卦象已起____
3. 装卦 → `liuyao.chart(...)`
   输出：□ 用神____ 世应____ 动爻____ 旺衰____
4. 断卦 → domains/liuyao/（yongshen 选用神 → jixiong 判定链 → yingqi 应期 → liushou → yuejian）
   输出：□ 吉凶____ 应期____

### 奇门（方向/时机）
2. 排盘 → `qimen.chart(...)`
   输出：□ 用神落宫____
3. 断局 → domains/qimen/（yongshen → bamen 八门 → jiuxing 九星 → bashen 八神）
   输出：□ 方向____ 时机____ 结论____

4. 输出 → 按对应「输出模板」给一句话结论
   输出：□ 结论____

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 用户说"随便算算" | 走六爻，起卦先看当前运势 |
| 用户问时间跨度很大的事 | 奇门主要用于近短期决策，六爻可看中长期 |

## 📖 输出模板（六爻）

### 一、断语（依据链先行）
先列卦象依据（用神/世应/动爻），最后给**一句话明确判断**所求之事吉凶成败。

### 二、用神分析
- 取何爻为用神，世应关系
- 用神旺相/休囚/生克状态
- 动爻对用神的影响（生扶/克制）

### 三、关键动爻
- 动爻所在位置及变化（本卦→变卦）
- 动爻与世应、用神的生克冲合关系

### 四、应期推断
- 根据用神旺衰、冲合、伏现推断应期

## 📖 输出模板（奇门）

### 一、用神
以问事人出生年干或问事方位为用神。

### 二、八门九星
- 八门开/休/生/伤/杜/景/死/惊 分布
- 九星天蓬/芮/冲/辅/禽/心/柱/任/英 分布
- 门星组合

### 三、八神
值符/腾蛇/太阴/六合/勾陈/朱雀/九地/九天 与用神的关系

### 四、结论
- 时干/日干/用神关系
- 门开与否、星旺相与否
- 综合建议
