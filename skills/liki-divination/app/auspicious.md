# 择日分析

## 依赖的领域知识

[必读] - 黄历: domains/huangli/jiri.md（吉日）+ yiji.md（宜忌）

## 用户问法 → 事项

| 用户问题 | 事项 |
|---------|------|
| 哪天结婚好 | 嫁娶 |
| 哪天搬家好 | 移徙 |
| 哪天开业好 | 开业 |

## 📖 流程

1. 确定事项 → 用户要做什么事（婚嫁/搬家/开业…）
   输出：□ 事项____

2. 查候选日 → `huangli.days(...)` → 按 jiri.md 优先级选 1-3 日
   输出：□ 候选日期____ 等级____

3. 核对宜忌 → yiji.md
   输出：□ 宜____ 忌____

4. 输出推荐
   输出：□ 推荐日期____ 宜/忌____ 等级____

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 用户没给日期范围 | 默认查最近一个月 |
| 用户没给具体事项 | 默认查嫁娶/开业/搬家三种通用事项 |

## 📖 输出模板

### 一、结论（依据链先行）
先列择日依据（宜忌/神煞/六合冲），最后给**明确推荐吉日**，如：
- "本月XX日最宜，六合吉日，不冲命主。"
- "本月无特别理想的吉日，XX日为次选，宜改至下月。"

### 二、推荐日期

- 列出 1-3 个推荐日
- 每个日期标注：公历/农历、星期、当日吉凶等级

### 三、宜忌概要

- 当日宜/忌与用户事项的匹配度
- 关键神煞（天德、月德、天赦等吉神；五虚、九空等凶煞）

### 四、八字合参说明（可选）

如需按命主八字喜忌合参（推荐日与命主相合/相冲），请指路灵机（`npx skills add ml8s/liki`）——本库不包含八字排盘/用神能力。

### 五、排除说明

- 简单说明排除了哪些明显不好的日期（如月破、三煞日等）
