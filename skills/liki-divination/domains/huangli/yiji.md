# 宜忌规则

用于判断特定事项适合什么类型的日子。

> **字段契约**：本表只引用 `huangli.days` 实际返回字段（`jian_chu` 建除 / `huangdao` 黄黑道十二神 / `gan_ji`+`zhi_ji` 日忌干支 / `mansion` 二十八宿 / `xi_shen` `cai_shen` `fu_shen`）。天德贵人/月德/三煞/四离/四绝/杨公忌/大耗/鸣吠日等**日神煞不在返回字段中，不得臆造**——涉及此类表述时以黄黑道/建除/日忌干支近似判定。

## 📖 翻译表：黄黑道（`huangdao`，黄道=吉，黑道=凶）

| 黄道十二神 | 吉凶 | 宜 |
|-----------|------|-----|
| 青龙 / 明堂 / 金匮 / 天德 / 玉堂 / 司命（`path=="黄道"`） | 吉 | 嫁娶/开业/搬家/出行等诸事皆宜 |
| 天刑 / 朱雀 / 白虎 / 天牢 / 玄武 / 勾陈（`path=="黑道"`） | 凶 | 忌嫁娶/开业/搬家/安葬等大事，宜静守 |

## 📖 翻译表：建除十二神（`jian_chu`）

| 建除 | 宜 | 忌 |
|------|-----|-----|
| 建日 | 出行/上任/祈福 | 动土/开仓 |
| 除日 | 除旧布新/求医/祭祀 | 嫁娶 |
| 满日 | 祈福/祭祀/开市 | 安葬 |
| 平日 | 修整/平治/小事 | 开市/嫁娶（平稳之日） |
| 定日 | 定盟/签约/安床 | 诉讼/出行 |
| 执日 | 捕捉/搬迁 | 开市/嫁娶 |
| 破日 | 无（破败之日） | 诸事不宜——忌嫁娶/开市/搬家 |
| 危日 | 谨慎行事/小事 | 登高/行船 |
| 成日 | 嫁娶/开市/搬家/入学（成就圆满） | 诉讼 |
| 收日 | 收账/纳财/安葬 | 开市/出行 |
| 开日 | 开业/出行/求财（开始之意） | 安葬 |
| 闭日 | 安葬/筑堤 | 开市/出行 |

## 📖 翻译表：日忌干支（`gan_ji`/`zhi_ji`，彭祖百忌）

- `gan_ji`（日干忌）：如"甲不开仓财物耗散""丙不修灶必见灾殃"——**开仓/修灶等对应事项忌**，其余事项不受限
- `zhi_ji`（日支忌）：如"子不问卜自惹祸殃""卯不穿井水泉不香"——**问卜/穿井等对应事项忌**
- 判定时读当日 `gan_ji`/`zhi_ji` 文案，按文案关键字对号入座（开仓/栽植/修灶/穿井/问卜/冠带…）

## 📖 翻译表：二十八宿（`mansion`）

| 宿 | 吉凶 | 宜忌 |
|----|------|------|
| 吉宿（角/房/尾/箕/斗/室/壁/娄/胃/毕/井/张/轸 等吉星宿） | 吉 | 宜嫁娶/开业/安葬等大事 |
| 凶宿（亢/氐/心/牛/女/虚/危/觜/参/鬼/柳/星/翼 等凶星宿） | 凶 | 忌大事，宜静守 |
| 平日宿 | 平 | 常规事务不受限 |

> 二十八宿吉凶按传统七政择日归类，实际以 `mansion` 字段返回的宿名查表；不确定吉凶归属时降级为"平"。

## 📖 翻译表：事项宜忌（合并判定）

| 事项 | 优先宜 | 忌 |
|------|--------|-----|
| 嫁娶 | 黄道日 + 成日/满日/定日 | 黑道日/破日/闭日；日支忌问卜类除外按文案 |
| 开业 | 黄道日 + 开日/成日/满日 | 黑道日/破日/闭日/收日；`gan_ji` 涉"开"忌（如甲不开仓） |
| 搬家/入宅 | 黄道日 + 成日/定日/执日 | 黑道日/破日/危日 |
| 出行 | 黄道日 + 开日/建日 | 黑道日/收日/闭日；`zhi_ji` 涉"出行"忌 |
| 动土/修造 | 黄道日 + 定日/成日 | 建日/破日；`gan_ji` 涉"修造"忌 |
| 安葬 | 吉宿 + 除日/收日/闭日 | 黑道日/满日/开日 |

## 📖 翻译表：吉凶程度（供 agent 组织输出）

| 组合 | 等级 | 说明 |
|------|------|------|
| 黄道日 + 建除宜项 + 日忌干支无涉 | 上吉 | 百事皆宜 |
| 黄道日或建除宜项居其一 | 中吉 | 所选事项宜 |
| 无吉神亦无凶煞（平/平日宿） | 平 | 可用 |
| 黑道日或破日，或日忌干支涉该事项 | 凶 | 应避开 |

> 判定链（自顶向下）：先取 `huangdao` 定吉凶基调 → 取 `jian_chu` 定事项宜忌 → `gan_ji`/`zhi_ji` 按文案排除 → 大事（嫁娶/安葬）叠加 `mansion` 宿吉凶 → 输出对应等级。任一环节数据缺失（如 `mansion` 无返回）时降级处理，不臆造字段。
