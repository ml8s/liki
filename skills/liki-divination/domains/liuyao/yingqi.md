# 六爻应期（定何时应验）

> 命理依据：《增删卜易》应期章。应期是根据用神状态推断的应验时间。

## 引擎输出字段说明

- `yong_shen.wang_shuai`：用神旺衰
- `yong_shen.yue_po`：用神月破
- `yong_shen.xun_kong`：用神旬空
- `yong_shen.mu_ku`：用神入墓
- `dong_yao_relations`：动爻关系

## 📖 解读：用神状态 → 应期

| 用神状态 | 应期 |
|---------|------|
| 旺相 | 逢值或逢合之年月日 |
| 休囚 | 待旺相之年月日 |
| 月破（假破/真破）| 逢合补破之年月日 |
| 旬空（假空/真空）| 出空、填实或冲空之年月日 |
| 入墓 | 冲墓之年月日 |
| 动爻 | 动爻逢冲逢合之年月日 |

## 📖 解读原则

- **旺相逢值逢合应**：用神旺相，逢值日或逢合日应验
- **休囚待旺相应**：用神休囚，待旺相时（逢生扶）应验
- **月破逢合补破应**：月破待逢合补破应验
- **旬空出空填实应**：旬空待出空/填实/冲空应验
- **入墓冲墓应**：入墓待冲墓应验

**应期是吉凶之外的独立维度**——先断吉凶（成/难成），再断应期（何时）。

## 常见误判

- 只断"会成"不落应期（应给时间窗口）
- 应期与吉凶混淆（吉凶定方向，应期定时间）
