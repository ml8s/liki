# 六爻应期（定何时应验）

> 命理依据：《增删卜易》应期章。应期是根据用神状态推断的应验时间。

## 引擎输出字段说明

- `yong_shen.wang_shuai`：用神旺衰
- `yong_shen.yue_po`：用神月破
- `yong_shen.xun_kong`：用神旬空
- `yong_shen.mu_ku`：用神入墓
- `dong_yao_relations`：动爻关系

## 📖 解读：用神状态 → 应期

| 用神状态 | 应期 |
|---------|------|
| 旺相 | 逢值或逢合之年月日 |
| 休囚 | 待旺相之年月日 |
| 月破（假破/真破）| 逢合补破之年月日 |
| 旬空（假空/真空）| 出空、填实或冲空之年月日 |
| 入墓 | 冲墓、刑开或合起墓库之年月日 |
| 动爻 | 动爻逢冲逢合之年月日 |

## 📖 解读原则

- **旺相逢值逢合应**：用神旺相，逢值日或逢合日应验
- **休囚待旺相应**：用神休囚，待旺相时（逢生扶）应验
- **月破逢合补破应**：月破待逢合补破应验
- **旬空出空填实应**：旬空待出空/填实/冲空应验
- **入墓冲/刑/合开应**：入墓待冲墓、刑开墓库或合起应验

## 📖 取舍规则（旺衰 × 动静 × 合刑冲）

「逢合」是应期还是绊住，**以旺衰为纲：旺者合则起（应），衰者合则绊**。
本表系 2026-08 双卦买彩实测校准（旺相发动之财爻逢合日应验），与「动爻逢合皆论绊」的传统说法不同，本仓以实测为准：

| 用神状态 × 逢合 | 含义 |
|------|-----------|
| 旺相发动，逢值逢合 | **合为应**——即应期（动而旺者，合日应验）|
| 旺相安静，逢合 | **合起则动**——合起之日应事 |
| 休囚发动，逢合 | **合为绊**——衰而动者被绊住，待冲开合神之日 |
| 休囚安静，逢合 | 不作应期主据——本待生旺之时，合不论 |
| 变爻与日辰相合 | 变爻本身在标记应期日，按应期论 |

取舍优先级：**先定旺衰 → 再定「合」的含义 → 最后取应期**。禁止跳过旺衰直接取「逢合为绊」。

### 用神两现

卦中用神两现，依《增删卜易》取舍（逐条判，禁止凭感觉二选一）：
1. 舍空破墓，取不空不破不墓者
2. 舍休囚，取旺相者
3. 舍安静，取发动者
4. 皆同 → 取临世应者（近取）
5. 皆空或皆墓 → 应期待冲空、刑开墓库之日

（「取旺不取衰」优先于「财爻持世」——持世/临应仅作同格时的近取参考。）

### 入墓应期三路

入墓（含世爻入墓）的应期除**逢冲**（冲墓）外另有两路：
- **刑开**：墓库被三刑之支相刑（如戌墓逢丑日，丑戌刑开）
- **合起**：日辰合起墓中用神（如子辰半合起静爻用神）

三路并察，取先到之日。

### 短应期（日级）

旺相引动可在日辰层面应验（隔日级）：动而旺相之用神，逢值、逢合之日即应，不必待年月；静卦入墓逢刑开亦同。

**应期是吉凶之外的独立维度**——先断吉凶（成/难成），再断应期（何时）。

## 常见误判

- 只断"会成"不落应期（应给时间窗口）
- 应期与吉凶混淆（吉凶定方向，应期定时间）
- 旺相动爻逢合误判为「合绊」（应先看旺衰动静——动而旺者合为应）
- 用神两现时取舍凭感觉（按持世→发动→旺相不空墓逐条判）
- 静卦入墓只知待冲（忘刑开、合起两路）
