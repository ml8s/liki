# 六爻应期（定何时应验）

> 命理依据：《增删卜易》应期章。应期是根据用神状态推断的应验时间。

## 引擎输出字段说明

- `yong_shen.wang_shuai`：用神旺衰
- `yong_shen.yue_po`：用神月破
- `yong_shen.xun_kong`：用神旬空
- `yong_shen.mu_ku`：用神入墓
- `dong_yao_relations`：动爻关系

## 📖 解读：用神状态 → 应期

| 用神状态 | 应期 |
|---------|------|
| 旺相 | 逢值或逢合之年月日 |
| 休囚 | 待旺相之年月日 |
| 月破（假破/真破）| 逢合补破之年月日 |
| 旬空（假空/真空）| 出空、填实或冲空之年月日 |
| 入墓 | 冲墓、刑开或合起墓库之年月日 |
| 动爻 | 动爻逢冲逢合之年月日 |

## 📖 解读原则

- **旺相逢值逢合应**：用神旺相，逢值日或逢合日应验
- **休囚待旺相应**：用神休囚，待旺相时（逢生扶）应验
- **月破逢合补破应**：月破待逢合补破应验
- **旬空出空填实应**：旬空待出空/填实/冲空应验
- **入墓冲/刑/合开应**：入墓待冲墓、刑开墓库或合起应验

## 📖 取舍规则（旺衰 × 动静 × 合刑冲）

「逢合」是应期还是绊住，先看旺衰动静，再看合的形态：

| 情形 | 逢合的含义 |
|------|-----------|
| 用神旺相发动，逢值逢合 | **合为应**——即应期（动而旺者，合日应验）|
| 用神休囚安静，逢合 | **合为绊**——绊住不应，待冲开合神之日 |
| 变爻与日辰相合 | 变爻本身在标记应期日，按应期论 |

取舍优先级：**先定旺衰动静 → 再定「合」的含义 → 最后取应期**。禁止跳过旺衰直接取「逢合为绊」。

### 用神两现

卦中用神两现，按优先级取用（逐条判，禁止凭感觉二选一）：
1. 持世/临世应者（世爻临用神优先取）
2. 发动者
3. 旺相、不空不墓者
4. 两现皆空或皆墓 → 应期待冲空、刑开墓库之日

### 入墓应期三路

入墓（含世爻入墓）的应期除**逢冲**（冲墓）外另有两路：
- **刑开**：墓库被三刑之支相刑（如戌墓逢丑日，丑戌刑开）
- **合起**：日辰合起墓中用神（如子辰半合起静爻用神）

三路并察，取先到之日。

### 短应期（日级）

旺相引动可在日辰层面应验（隔日级）：动而旺相之用神，逢值、逢合之日即应，不必待年月；静卦入墓逢刑开亦同。

**应期是吉凶之外的独立维度**——先断吉凶（成/难成），再断应期（何时）。

## 常见误判

- 只断"会成"不落应期（应给时间窗口）
- 应期与吉凶混淆（吉凶定方向，应期定时间）
- 旺相动爻逢合误判为「合绊」（应先看旺衰动静——动而旺者合为应）
- 用神两现时取舍凭感觉（按持世→发动→旺相不空墓逐条判）
- 静卦入墓只知待冲（忘刑开、合起两路）
