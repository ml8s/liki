# 六爻旺衰与修饰（定吉凶基调 + 定时效）

> 命理依据：《增删卜易》月令日辰章、旺衰章。用神旺衰是断卦之纲（用神成败定吉凶），月破/旬空/入墓是修饰（定时效）。

## 引擎输出字段说明

- `yong_shen.wang_shuai`：用神旺衰（旺/相/休/囚/死）
- `yong_shen.yue_po`：用神月破（true=月建冲用神）
- `yong_shen.xun_kong`：用神旬空（true=用神值日柱旬空）
- `yong_shen.mu_ku`：用神入墓（true=用神地支为墓库辰戌丑未）
 - `yong_shen.chang_sheng`：用神五行在月支的十二长生
 - `lines[].mu_ku_branch` / `lines[].mu_ku_element`：按五行对应墓库展开
 - `lines[].chang_sheng_yue`：本爻五行在月支的十二长生

## 📖 解读：用神旺衰 → 吉凶基调

用神旺衰定**吉凶方向**（成败与否）：

| 旺衰 | 基调 | 说明 |
|------|------|------|
| 旺 | 事可成 | 用神得令有力，根基强 |
| 相 | 事可成 | 用神得相，根基尚可 |
| 休 | 事可成但费力 | 用神失令，事可成但费力/需待时 |
| 囚 | 事可成但费力 | 用神受制，事可成但费力 |
| 死 | 事难成 | 用神衰败，事难成 |

## 📖 解读：月破/旬空/入墓 → 时效修饰

修饰只影响**时效/程度**，不改变吉凶方向（需结合旺衰判断真假）：

| 修饰 | 旺相时（假）| 休囚死时（真）|
|------|------------|-------------|
| 月破（yue_po=true）| 假破：先挫后成 | 真破：当下无力 |
| 旬空（xun_kong=true）| 假空：迟成而非不成 | 真空：事不实 |
| 入墓（mu_ku=true）| 假墓：待冲开 | 真墓：闭塞 |

**解读原则**：
- 旺相+修饰 = 假（先挫后成/迟成/待冲开）→ 事可成，但需等待
- 休囚死+修饰 = 真（当下无力/事不实/闭塞）→ 事难成，且不实

**多个修饰同现**：按命理先后处理（先填实、后出破、再出墓）。

## 常见误判

- 见月破即断"废"（错误，旺相假破可先挫后成）
- 见旬空即断"无用"（错误，旺相假空可迟成）
- 不区分真假（旺相假破假空 vs 休囚真破真空）

## 十二长生

`chang_sheng_yue` 是“爻的五行”落在“月支”的长生状态，用于判断待时、进气、退气与墓绝：

| 状态 | 解读 |
|---|---|
| 长生 / 临官 / 帝旺 | 有力或进气 |
| 冠带 / 衰 / 病 / 养 | 过渡状态，须结合月日动爻 |
| 墓 / 绝 | 受困或气数不足，待冲开或得生扶 |

注意：土墓存在流派差异；engine 默认土墓在辰，报告如采用其他师承口径必须显式说明。

## 墓库细则

`mu_ku` 不再等于“地支见辰戌丑未”。默认按五行对应墓库：

| 五行 | 墓库 |
|---|---|
| 木 | 未 |
| 火 | 戌 |
| 金 | 丑 |
| 水 | 辰 |
| 土 | 辰（默认） |

`mu_ku_branch` 与 `mu_ku_element` 必须一起解释；不满足对应关系时不能写“入墓”。

## 歌诀条件还原

“月破必废”“旬空无用”不能直接使用。先核对：

1. 旺相还是休囚死；
2. 动爻还是静爻；
3. 有无原神救应；
4. 有无出空、填实、冲空、逢合机会；
5. 所问事项的时间范围。

snapshot 的 condition_rules 会把这类断语转为 `strong / weak / conditional` 分支；未满足条件时只能列为参考，不得写入主结论。

## 日冲细分

`day_clash_facts[].kind` 是机械分类候选，不是最终吉凶：

| kind | 初始含义 | 还须核对 |
|---|---|---|
| 暗动 | 旺相静爻逢日冲 | 是否真有暗动之用，是否被合住 |
| 日破 | 休囚静爻逢日冲 | 有无生扶救应，出月后是否恢复 |
| 冲散 | 动爻逢日冲 | 有无合救、动变是否失用 |
| 冲空 | 旬空爻逢日冲 | 区分冲实 / 冲脱，先定真假空 |
