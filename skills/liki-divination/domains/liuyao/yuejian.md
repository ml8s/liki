# 六爻旺衰与修饰（定吉凶基调 + 定时效）

> 命理依据：《增删卜易》月令日辰章、旺衰章。用神旺衰是断卦之纲（用神成败定吉凶），月破/旬空/入墓是修饰（定时效）。

## 引擎输出字段说明

- `yong_shen.wang_shuai`：用神旺衰（旺/相/休/囚/死）
- `yong_shen.yue_po`：用神月破（true=月建冲用神）
- `yong_shen.xun_kong`：用神旬空（true=用神值日柱旬空）
- `yong_shen.mu_ku`：用神入墓（true=用神地支为墓库辰戌丑未）

## 📖 解读：用神旺衰 → 吉凶基调

用神旺衰定**吉凶方向**（成败与否）：

| 旺衰 | 基调 | 说明 |
|------|------|------|
| 旺 | 事可成 | 用神得令有力，根基强 |
| 相 | 事可成 | 用神得相，根基尚可 |
| 休 | 事可成但费力 | 用神失令，事可成但费力/需待时 |
| 囚 | 事可成但费力 | 用神受制，事可成但费力 |
| 死 | 事难成 | 用神衰败，事难成 |

## 📖 解读：月破/旬空/入墓 → 时效修饰

修饰只影响**时效/程度**，不改变吉凶方向（需结合旺衰判断真假）：

| 修饰 | 旺相时（假）| 休囚死时（真）|
|------|------------|-------------|
| 月破（yue_po=true）| 假破：先挫后成 | 真破：当下无力 |
| 旬空（xun_kong=true）| 假空：迟成而非不成 | 真空：事不实 |
| 入墓（mu_ku=true）| 假墓：待冲开 | 真墓：闭塞 |

**解读原则**：
- 旺相+修饰 = 假（先挫后成/迟成/待冲开）→ 事可成，但需等待
- 休囚死+修饰 = 真（当下无力/事不实/闭塞）→ 事难成，且不实

**多个修饰同现**：按命理先后处理（先填实、后出破、再出墓）。

## 常见误判

- 见月破即断"废"（错误，旺相假破可先挫后成）
- 见旬空即断"无用"（错误，旺相假空可迟成）
- 不区分真假（旺相假破假空 vs 休囚真破真空）
