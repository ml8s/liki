# 六爻特殊格局规则

> 经典依据：《增删卜易》《卜筮正宗》——特殊格局是在基础吉凶判定之上的加权处理。

## 总原则

先用神成败，后格局加权；先主因，后附象；先当下状态，后应期触发。

---

## 旬空（真空/假空/冲空/实空）

### 识别标志
用神、世应或关键动爻落入当旬空亡（`liuyao.patterns` 返回 `type=旬空`）

### 判断步骤
1. 锁定空亡爻，标记其角色（用神/原神/忌神/世应）
2. 判断动静：动爻先按"有事待发"处理，静爻再判真空或假空
3. 判断旺衰与生扶：旺相、得日月扶、得动爻生者先记为假空
4. 判断是否到底空：若休囚、受克、无扶且出旬仍无成象，记为真空
5. 推应期：冲空日、出旬日、逢值日作为首选应点

### 引擎返回值
- `sub_type`: "假空" / "真空"
- `is_true`: true=真空（事不实），false=假空（迟成而非不成）
- `position`: 相关爻位

### 野鹤特别提示
"旺不为空，动不为空""凡遇旬空，不可即以为空"

### 常见误判
把旬空直接等于"无用"；不区分动空与静空

---

## 月破（真破/假破/出破）

### 识别标志
用神或关键爻受月建冲破（`liuyao.patterns` 返回 `type=月破`）

### 判断步骤
1. 标记月破爻，确认是否为用神链路核心爻
2. 先判动静：动破先按"待时可起"，静破先按"当下无力"
3. 判扶抑：得日辰、得动爻、得合者降级为假破
4. 判真破：休囚受制且无救应者定为真破
5. 推应期：实破日、逢合日、出月为三个关键时间窗

### 引擎返回值
- `sub_type`: "假破" / "真破"
- `is_true`: true=真破（当下无力），false=假破（先挫后成）
- `position`: 相关爻位

### 野鹤特别提示
"月破即废"是错误的，"目下虽破，出月不破，实破日不破，逢合亦可转"

---

## 飞神伏神

### 识别标志
用神不上卦，需在本宫首卦定位伏神（`liuyao.patterns` 返回 `type=飞伏`）

### 判断步骤
1. 先确认是否必须取伏神：仅在用神不现且日月不可代用时启用
2. 定位伏神并标注飞神关系（飞生伏、飞克伏、飞伏比和）
3. 判伏神旺衰及空破墓绝状态
4. 评估"冲飞起伏"条件是否成立
5. 给出双结论：当前可否成事、何时伏神可出用

### 引擎返回值
- `sub_type`: "伏藏"
- `is_true`: true=飞克伏（受压），false=飞生伏（得力）
- `position`: 伏神爻位
- `assessment`: 飞伏关系描述

### 野鹤特别提示
"伏神有用六条、无用五条"，但更强调"能再占则不泥伏神"

---

## 进神退神

### 识别标志
动爻化进神或化退神（`liuyao.patterns` 返回 `type=进退`）

### 判断步骤
1. 标记化进化退的动爻，确认其是否为用神或关键关系爻
2. 按占类判"喜进/喜退"方向
3. 结合旺衰判进退力度：旺相进退为实，休囚进退为虚
4. 叠加空破墓绝条件
5. 输出两层结论：方向判断与触发时间

### 引擎返回值
- `sub_type`: "进神" / "退神"
- `is_true`: true=进神（力量增长），false=退神（力量衰败）
- `position`: 相关爻位

### 野鹤特别提示
"喜者宜进，忌者宜退"，但空破即不进退的绝对说是错误的

---

## 六冲/六合

### 识别标志
卦体六冲/六合（`liuyao.patterns` 返回 `type=冲合`）

### 判断步骤
1. 确认冲/合的层级：卦冲、爻冲、日月冲
2. 回到占类：病、讼、忧患与婚财官宅分别定义"冲"的吉凶方向
3. 检查用神是否有根、有扶、有动
4. 判断是否为"先成后败"结构
5. 推应期：逢合可稳、逢冲再动

### 引擎返回值
- `sub_type`: "六冲" / "六合"
- `position`: 0（全卦）
- `assessment`: "六冲卦，事多反复" / "六合卦，事易成"

### 野鹤特别提示
反对"见冲即散如无"，强调"神机在动"

---

## 反吟伏吟

### 识别标志
卦变反吟/伏吟（`liuyao.patterns` 返回 `type=反吟`）

### 判断步骤
1. 判类型：内反吟、外反吟、全局反吟、伏吟
2. 判受伤：用神是否被冲克、是否化回头克
3. 判事项映射：婚、行、仕、宅的"反复"表现不同
4. 判阶段：反复后能否收敛成局

### 引擎返回值
- `sub_type`: "反吟" / "伏吟"
- `position`: 0（全卦）
- `assessment`: "反吟卦，事多反复" / "伏吟卦，事多停滞"

### 野鹤特别提示
反对把反吟伏吟独立绝对化，强调必须联看用神与回头生克

---

## 随鬼入墓

### 识别标志
世爻或用神随官鬼入墓（`liuyao.patterns` 返回 `type=随鬼入墓`）

### 判断步骤
1. 确认是否为"世/用随鬼入墓"
2. 判真假墓：旺相有扶多假墓，休囚受克多真墓
3. 查冲墓条件：日月、动爻能否冲开墓库
4. 按占类分流：疾病、功名、求财、婚姻分别给权重

### 引擎返回值
- `sub_type`: "随鬼入墓"
- `position`: 用神爻位
- `assessment`: "用神随鬼入墓，事多闭塞"

### 野鹤特别提示
只重"世爻入墓三式"等可验结构，反对"本命逢墓即凶"的泛化古法

---

## 独发独静

### 识别标志
五静一动（独发）或五动一静（独静）（`liuyao.patterns` 返回 `type=独发`/`type=独静`）

### 判断步骤
1. 先判用神成败，不得跳过
2. 标记独发/独静爻与用神关系
3. 判断该独爻是主因还是附因
4. 若仅附因，只用于细化应期，不改主结论

### 引擎返回值
- `type`: "独发" / "独静"
- `position`: 独发/独静爻位
- `assessment`: "独发爻，主事之应期" / "独静爻，主事之应期"

### 野鹤特别提示
独发独静"在事应之后如会神机"，是"校准器"而非"发动机"

---

## 用神两现

### 识别标志
同一用神（同六亲）在卦中出现两爻或三爻（`liuyao.patterns` 返回 `type=两现`）

### 判断步骤
1. 列出所有候选用神，逐一标记旺衰、动静
2. 按"取旺不取衰、取动不取静"原则
3. 特例：舍不空而用旬空、舍不破而用月破（野鹤有验例）

### 引擎返回值
- `sub_type`: "用神两现"
- `assessment`: "用神两现，取旺不取衰"

---

## 使用方法

1. 调用 `liuyao.patterns` 获取特殊格局
2. 按格局类型查阅本表
3. 结合占事类型（`liuyao-*.md`）综合判断
4. 特殊格局是加权，不改变用神成败的主结论

## 示例

```json
{
  "type": "旬空",
  "sub_type": "假空",
  "position": 3,
  "is_true": false,
  "assessment": "旺相动爻旬空，迟成而非不成"
}
```

解读：用神在第3爻，旺相且动爻旬空，属于假空，事可成但需等待出空。
