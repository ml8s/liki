# 六爻格局（定结构影响）

> 命理依据：《增删卜易》各章。格局是卦体的结构特征，对吉凶起修正/修饰作用。

## 引擎输出字段说明

- `patterns`：格局数组，每项含：
  - `type`：格局类型（六冲/六合/反吟/伏吟/进退/三刑/六神）
  - `sub_type`：子类型（如进退的进神/退神）
  - `position`：相关爻位（0=全卦）
  - `is_true`：结构是否有实质效力。空亡/月破中 true=真空/真破、false=假空/假破；其余已输出格局通常为 true。
  - `assessment`：结构影响的确定性描述

进退神只认同一五行地支的顺逆迁移：亥化子、寅化卯、巳化午、申化酉为进神；子化亥、卯化寅、午化巳、酉化申为退神。其他动爻变化不进入进退格局。

## 📖 解读：格局 → 结构影响

| 格局 | 结构影响 | 说明 |
|------|---------|------|
| 六冲 | 事多反复 | 卦体六冲，事多散、反复 |
| 六合 | 事易成 | 卦体六合，事易成、稳定 |
| 反吟 | 事多反复 | 卦变反吟，事多往返、重来 |
| 伏吟 | 事多停滞 | 卦变伏吟，事多停滞、反复 |
| 进退（进神）| 力量增长 | 动爻化进，喜者宜进 |
| 进退（退神）| 力量衰败 | 动爻化退，忌者宜退 |
| 三刑 | 需防刑冲 | 刑冲组合，需防官非/疾病 |
| 六神 | 依六神色彩 | 见 liushou.md |

## 📖 解读：格局叠加

格局是**结构修正**，叠加在旺衰×动爻的吉凶之上：
- 六冲：吉凶方向不变，但"事多反复"（好事反复，坏事也反复）
- 六合：吉凶方向不变，但"事易成/稳定"

**解读原则**：格局不改变用神成败的吉凶方向，只修饰结构影响（反复/易成/停滞）。

## 常见误判

- 见六冲即断"凶"（错误，旺相用神遇六冲是"冲而不散"）
- 见六合即断"吉"（错误，需用神有气，六合才主成）
- 见三刑即断"凶"（错误，用神旺相三刑无碍）

## 三合候选

`san_he_candidates` 只输出结构候选：

- `complete=false`：两支同组，只作半合 / 聚气候选。
- `complete=true`：三支齐，仍须看 `moving_count`、空破、月日支持和是否作用到用神 / 世应。
- 有发动不等于必然成局；无发动不等于无用，只是不应跳到"已成局"。

`san_he_candidates` 还会标注：

- `day_present` / `month_present`：日辰或月建是否补足一支；
- `void_count` / `break_count`：候选支是否有空破；
- `targets`：是否作用到用神、世爻或应爻；
- `activated=true` 仅表示卦中三支齐、有发动且未见空破，仍不是必然成局。

## 冲合格局条件还原

六合、六冲不能单独定成败：

- 六合需用神有气、世应能承接，才作“易聚 / 易稳”候选；
- 六冲需用神衰弱且无救应，才加重“散 / 难成”候选；
- 冲中逢合、合处逢冲必须说明先后状态和目标，不得只写半句吉凶。
