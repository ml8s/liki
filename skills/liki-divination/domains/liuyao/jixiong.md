# 六爻吉凶判定

> 经典依据：《增删卜易》《卜筮正宗》——断吉凶以用神旺衰为纲，动爻生克为用，月破旬空为破。
>
> **判定原则**：吉凶不是抽象评级档位，而是**符号关系的组合**——用神自身的旺衰（`wang_shuai`/`yue_po`）加上动爻对它的生克方向（`dong_sheng`/`dong_ke`）。所有输入都来自 `liuyao.chart` 每爻的确定性状态，前端把符号关系组织成断语。

## 🔧 字段契约（`liuyao.chart` 返回结构）

- `wang_shuai`：**顶层数组，按爻序 1-6（初爻→上爻）索引**，取值 `旺/相/休/囚/死`——用神旺衰 = `wang_shuai[用神爻位-1]`（如用神在 3 爻 → `wang_shuai[2]`）
- `lines[].yue_po`（月破）与 `dong_self`/`dong_sheng`/`dong_ke`/`xun_kong` 均为 **boolean 且仅在 true 时返回**（缺字段即视为 false）——判"月破/旬空/动爻生克"时按 `字段缺失 = false` 处理，不得臆断为 true
- 用神爻位取 `yong_shen.position`（1-6；0=用神不现，需看 `yong_shen.fu_shen` 飞伏）

## 动变判断体系

> 经典依据：《增删卜易》动变章。动爻是六爻断卦的核心，"动则有事"。

### A. 动爻对用神的生克路径

| 动爻类型 | 判断规则 | 经典依据 |
|---------|---------|---------|
| 明动（`dong_self=true`） | 动则有事，先看动爻对用神的作用 | "动则有事" |
| 动爻生用（`dong_sheng=true`） | 吉（用神得助） | "动爻生用，用神得力" |
| 动爻克用（`dong_ke=true`） | 凶（用神受制） | "动爻克用，用神受损" |
| 忌神动克用 | 先判不利，再看是否被制 | "忌神旺动克用，事难成" |

### B. 变爻回头生克冲合

| 变爻类型 | 判断规则 | 经典依据 |
|---------|---------|---------|
| 回头生、化长生 | 吉（力量增长） | "回头生、化长生 → 吉" |
| 回头克、化鬼、化退 | 凶（力量衰败） | "回头克、化鬼、化退 → 凶" |
| 反吟中见回头冲克 | 凶性放大 | "反吟中若见回头冲克，凶性放大" |

### C. 暗动识别与处理

> 原文："静爻旺相，日辰冲之为暗动；静爻休囚，日辰冲之为日破"。

**处理步骤**：
1. 先判该静爻旺衰
2. 旺相被日冲 → 记"暗动"
3. 休囚被日冲 → 记"日破"
4. 暗动生用可救，暗动克用增凶

### D. 动散判断

> 原文："虽则今日受制，后逢值日的时候就不散了"。

**处理步骤**：
1. 见"散"先不判终局
2. 查后续值日/逢冲/逢合是否可复聚
3. 若并见绝墓破空，再按难复处理

## 原神忌神仇神体系

> 经典依据：《增删卜易》原忌仇章。用神的支持/克制关系链。

### A. 原神生用 → 吉的条件和限制

| 条件 | 判断规则 | 经典依据 |
|------|---------|---------|
| 原神旺相生用 | 吉（用神得助） | "原神旺相生用，事可成" |
| 原神空破受制 | 名生实不生 | "原神空破受制时，名生实不生" |
| 原神发动 | 用神得力，但需看原神自身状态 | "原神发动，用神得力" |

### B. 忌神克用 → 凶的条件和例外

| 条件 | 判断规则 | 经典依据 |
|------|---------|---------|
| 忌神旺动克用 | 凶（用神受损） | "忌神旺动克用，事难成" |
| 忌神被月日动变克制 | 减凶转平 | "忌神被月日动变克制，可减凶转平" |
| 忌神空破受制 | 名克实不克 | "忌神空破受制时，名克实不克" |

### C. 仇神的间接作用链

| 仇神作用 | 判断规则 | 经典依据 |
|---------|---------|---------|
| 仇神克原 | 用神失补给 | "仇神克原，用神失补给" |
| 仇神生忌 | 忌神增力 | "仇神生忌，忌神增力" |
| 形成"断供+加害"双重凶链 | 大凶 | "仇神克原生忌，双重凶链" |

### D. 判断顺序（先看用神，再看原忌仇）

```
1. 先定用神是否有气（旺衰判断7步链）
2. 次看原神能否实生（原神旺相？空破受制？）
3. 再看忌神是否实克（忌神旺动？被制？）
4. 最后看仇神是否破坏供给链
```

## 📖 翻译表：用神状态 × 动爻关系 → 吉凶

| 用神状态 | 动爻关系 | 吉凶 |
|---------|---------|------|
| 旺相（月建或日建生扶） | 动爻生扶用神（原神发动，`dong_sheng`） | 吉（事可成） |
| 旺相（月建或日建生扶） | 静爻或无动爻克害 | 吉（顺势而发） |
| 旺相（月建或日建生扶） | 忌神动克用神（`dong_ke`） | 平/阻（旺相根基仍在，事可成但多波折，克力逊于旺相） |
| 休囚（月建日建克制） | 原神动生用神（`dong_sheng`） | 平转吉（休囚得生，事可成但费力/需待时） |
| 休囚（月建日建克制） | 动爻生扶 | 平（需待时） |
| 休囚 | 静爻 | 平（事缓/勉强） |
| 休囚 | 动爻（忌神）克用神（`dong_ke`） | 凶（事难成） |
| 月破（`yue_po`） | 无 | 凶/待时（月破失力，逢合方补） |
| 旬空（用神空亡） | 无 | 凶/虚（事不实，出空方应） |
| 用神化退神/化绝 | 无 | 凶（力量衰败） |
| 用神化进神 | 无 | 吉（力量增长） |
| 用神持世 | 得月日生扶 | 吉（近身得力） |
| 世应相冲 | 用神受克 | 凶（主体不和） |

## 边界

- 多动爻（两爻以上发动）需看组合，取最关键的一动（生克力量最直接者）
- 用神与世爻关系：用神持世/临世=事近身（`shi_ying=="世"`）；用神临应=事在外
- 变卦吉凶：本卦定事体，变卦定结果（化进=成、化退=败、化空=虚）
- 组合冲突时按「旺衰为纲、生克为用」裁决：旺相被克 → 阻而不败；休囚得生 → 待时而成；休囚被克 → 凶
