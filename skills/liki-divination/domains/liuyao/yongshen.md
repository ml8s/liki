# 六爻用神取用

> 命理依据：《增删卜易》用神章。用神是断卦的核心对象，根据用户所问之事选取对应六亲。

## 引擎输出字段说明

- `yong_shen.name`：用神六亲名（官鬼/妻财/父母/子孙/兄弟/世爻）
- `yong_shen.position`：用神所在爻位（1-6，0=用神不现）
- `yong_shen.wang_shuai`：用神旺衰（旺/相/休/囚/死）
- `yong_shen.yue_po`：用神是否月破（true/false）
- `yong_shen.xun_kong`：用神是否旬空（true/false）
- `yong_shen.mu_ku`：用神是否入墓（true/false）
- `yong_shen.liu_shou`：用神临的六神（青龙/朱雀/勾陈/螣蛇/白虎/玄武）
- `yong_shen.fu_shen`：用神不现时的伏神信息

## 📖 翻译表：占事 → 用神

| 占事 | 用神 | 说明 |
|------|------|------|
| 事业/功名/官运 | 官鬼 | 官鬼主管事业、官运 |
| 财运/求财/生意 | 妻财 | 妻财主钱财、收入 |
| 感情/婚姻（男）| 妻财 | 男占婚恋取妻财 |
| 感情/婚姻（女）| 官鬼 | 女占婚恋取官鬼 |
| 父母/长辈/文书 | 父母 | 父母主长辈、文书、房屋 |
| 学业/考试/证书 | 父母 | 父母主学业、文卷 |
| 子女/健康/创作 | 子孙 | 子孙主晚辈、健康、创作 |
| 兄弟/朋友/竞争 | 兄弟 | 兄弟主朋友、竞争 |
| 自己/身位 | 世爻 | 世爻代表自己 |
| 对方/环境 | 应爻 | 应爻代表对方/环境 |

> 引擎已根据占事类型确定 `yong_shen.name`，LLM 据此解读。

## 用神不现（position=0）

用神不上卦时，看 `yong_shen.fu_shen`（伏神）：
- 伏神临用神，需待"冲飞、出伏"之时
- 可再占一卦确认（野鹤：能再占则不泥伏神）

## 用神两现（取旺不取衰）

同一六亲出现两爻以上时，取旺相者（引擎已按旺衰选取，`yong_shen.position` 为取旺后的爻位）。
