# 六爻用神取用

> 命理依据：《增删卜易》用神章。用神是所问之事在卦中的核心对象；引擎已按占事选择 `yong_shen.name` 与 `position`。

旺衰、月破、旬空、入墓、六神与伏神字段分别在 `yuejian.md`、`liushou.md` 及引擎 schema 中解读。

| 占事 | 用神 | 说明 |
|---|---|---|
| 事业 / 官运 | 官鬼 | 官鬼主管事业、官运 |
| 求财 / 生意 | 妻财 | 妻财主钱财、收入 |
| 婚恋（男） | 妻财 | 男占婚恋取妻财 |
| 婚恋（女） | 官鬼 | 女占婚恋取官鬼 |
| 父母 / 文书 / 房屋 | 父母 | 父母主长辈、文书、房屋 |
| 学业 / 考试 / 证书 | 父母 | 父母主文卷 |
| 子女 / 健康 / 创作 | 子孙 | 子孙主晚辈、健康、创作 |
| 兄弟 / 朋友 / 竞争 | 兄弟 | 兄弟主朋友、竞争 |
| 自己 | 世爻 | 世爻代表自己 |
| 对方 / 环境 | 应爻 | 应爻代表对方与环境 |

`position=0` 时读取 `fu_shen` 伏神，待冲飞、出伏；可再占确认。用神两现时引擎取旺者，直接使用返回爻位。

主用神只在**本卦**爻位中取；变卦只用于解释动爻变化，不作为 `yong_shen.position` 的来源。`is_hidden=true` 时，旺衰、月破、旬空、入墓与长生都按伏神地支计算，不继承飞神的六神。
