# 奇门用神取用

> 命理依据：《烟波钓叟歌》用神取用章。奇门用神多维：求测人以日干/年命干，事象以门/星/神/干符号。

## 用神符号（LLM 按问事确定，引擎定位落宫取因子）

奇门事象用神 = **门/星/神/干** 的组合。LLM 读下方"事象→符号"映射，确定传什么符号给 `qimen.chart` 的 `yong_shen` 参数；引擎按符号定位落宫，聚合落宫状态。

可用符号（35 种封闭枚举）：
- **门**（8）：休门、生门、伤门、杜门、景门、死门、惊门、开门
- **星**（9）：天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英
- **神**（8）：值符、螣蛇、太阴、六合、勾陈、朱雀、九地、九天（阴遁用白虎/玄武）
- **干**（10）：甲、乙、丙、丁、戊、己、庚、辛、壬、癸

## 引擎输出字段说明（qimen.chart 传 yong_shen 符号数组时返回 yong_shen）

**求测人定位（排盘固有，顶层字段，非 yong_shen 内）**：
- `ri_gan_gong`：日干落宫（求测人"我"；日干为甲时按日支遁六仪）
- `shi_gan_gong`：时干落宫（所问之事）
- `ri_shi_sheng_ke`：日干宫-时干宫生克（我 vs 事）
- `kong_wang_affected` / `ma_xing_affected`：日干/时干宫是否空亡、马星

**用神域（yong_shen 对象）**：
- `yong_shen.nian_gan_gong`：年命干落宫（本命根基，需 birth_year；**甲年命遁六仪**：甲子遁戊/甲戌遁己/甲申遁庚/甲午遁辛/甲辰遁壬/甲寅遁癸）
- `yong_shen.symbols[]`：用神符号组合落宫状态，每项含：
  - `symbol`：符号名（开门/天辅/六合/戊）
  - `palace`：符号落宫
  - `tian_gan`：落宫天盘干（十干克应）
  - `kong_wang`：落宫是否空亡
  - `ma_xing`：落宫是否马星

## 📖 事象→用神符号映射（LLM 读此表定传什么符号）

| 问事 | 用神符号组合 | 说明 |
|------|-------------|------|
| 事业/升迁 | 开门、天心 | 开门主事业，天心主官 |
| 求财 | 生门、戊 | 生门主财，戊为财星 |
| 婚姻 | 六合、庚、乙 | 六合主婚姻，男庚女乙 |
| 健康 | 死门、天芮 | 死门主病，天芮为病星 |
| 诉讼 | 惊门 | 惊门主官非 |
| 学业 | 景门、天辅 | 景门主文书，天辅主文昌 |
| 出行 | 开门 | 开门主出行 |

> 问事复合时传多个符号（如求财看"生门、戊"两个符号）。表外问事由 LLM 依五行类象自行选门/星/神/干。

## 📖 十干克应（天盘干主事，LLM 解读用神落宫的天盘干）

| 天盘干 | 主事 |
|--------|------|
| 甲 | 首领、主事者（遁甲不露）|
| 乙 | 女人、妻妾 |
| 丙 | 男人、丈夫、文书 |
| 丁 | 玉女、文书、信息 |
| 戊 | 钱财、资本 |
| 己 | 阴私、坟墓、田土 |
| 庚 | 仇人、对手、男方 |
| 辛 | 罪人、错误、金属 |
| 壬 | 流动、水、道路 |
| 癸 | 隐藏、水、阴谋 |

## 📖 解读原则（LLM）

- **求测人**：日干落宫看"我"的当下状态；年命干落宫看本命根基（甲年命看六仪遁宫）
- **事象**：每个用神符号落宫看所问之事的一个维度（`symbols[].palace` + `tian_gan` 十干克应）
- **我 vs 事**：`ri_shi_sheng_ke` 定日干宫与时干宫的生克（求测人与事的成败关系）
- **状态**：符号落宫空亡/马星影响事之虚实、快慢
- **门/星/神吉凶**：读 `bamen.md`（八门）/ `jiuxing.md`（九星）/ `bashen.md`（八神）翻译表
