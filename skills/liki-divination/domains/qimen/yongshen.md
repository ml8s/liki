# 奇门用神取用

> 命理依据：《烟波钓叟歌》用神取用章。求测人以日干 / 年命干定位，事象以门、星、神、干组合定位。

## 符号域

事象用神由下列封闭枚举组成；甲为遁甲，不作为独立符号。

| 层 | 符号 |
|---|---|
| 门 |休、生、伤、杜、景、死、惊、开；鸣法飞盘另有中门 |
| 星 |天蓬、天芮、天冲、天辅、天禽、天心、天柱、天任、天英 |
| 神 |洛书飞盘按值符、螣蛇、太阴、六合、白虎、太常、玄武、九地、九天；转盘阴阳遁的神名以 `method.spirit_mode` 为准 |
| 干 |乙、丙、丁、戊、己、庚、辛、壬、癸 |

普通问事传 `qimen_read` 的 `matter`，Python 编排层查事象表并转为显式 `yong_shen`；engine 只接收 `yong_shen`，`matter` 不进入 `qimen.chart`。`matter` 与 `yong_shen` 互斥；高级用户可直接传 `yong_shen`。

## 事象 → 用神

| 问事 | 用神符号 | 说明 |
|---|---|---|
| 事业 / 升迁 | 开门、天心 | 事业与官星 |
| 求财 | 生门、戊 | 财门与财星 |
| 婚姻 | 六合、庚、乙 | 婚缘，男庚女乙 |
| 健康 | 死门、天芮 | 病门与病星 |
| 诉讼 | 惊门 | 官非口舌 |
| 学业 | 景门、天辅 | 文书与文昌 |
| 出行 | 开门 | 开放、通路 |
| 隐藏 | 杜门 | 闭藏、阻隔 |
| 走失人口 | 六合 | 《奇门遁甲元灵经·占走失》：时干为失主，六合为走失之物，以落宫分内外远近 |

`tools/data/qimen_matters.csv` 是事象到用神的唯一事实源；本页表格仅作展示。表外问事先映射到表内问事；无法映射时说明无封闭用神规则，不得按五行临场类象。

走失人口按表内角色读取：时干宫为失主，六合宫为走失者，再以内外宫论远近；不套用“日干为我、时干为事”的通用读法。

## 格局识别边界

`patterns` 只返回格局表已收录且满足同宫条件的格局，不承诺全量格局识别。未命中时只说明“本表未命中”，不得临场补格局名。

## 解读顺序

1. 引用 `method` 说明家法、盘式、定局与主柱。
2. 以日干宫为“我”、时干宫为“事”、年命干宫为本命根基。
3. 逐个读取 `yong_shen.symbols[]` 的落宫、天盘干、空亡与马星。
4. 用 `ri_shi_relation` 判断我与事的生克。
5. 叠加值符值使、格局、门迫门制、星宫五行与克应。
6. 门、星、神分别读 `bamen.md`、`jiuxing.md`、`bashen.md`。
