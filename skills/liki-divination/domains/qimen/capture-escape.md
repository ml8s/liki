# 奇门占捕亡

> 命理依据：《奇门遁甲元灵经·卷十八·占捕亡》。六合为逃人，伤门为捕者。

## 流程

1. 用 `qimen_snapshot` 取默认时家转盘基础盘，不传 `matter` 或 `yong_shen`。
2. 用 snapshot.special.assertions。
3. 只解释表内候选；候选并列，不排序，不做执法建议或必然结论。

## 当前边界

- 仅支持 `scope=hour` + `school=zhuanpan`。
- 已入表：逃人宫与捕者宫生克、同宫串通、天网四张 / 地罗遮蔽与五阳 / 五阴时、六癸追踪方向、太白入荧。
- 天网四张为六癸临时干宫，地罗遮蔽为六壬临时干宫；六癸高低按一二三四宫 / 五六七八九宫入表，中宫归高位。
- 中宫无方向；六癸落中宫时不输出追踪方向候选。
- 六癸追踪方向由八宫方向表投影，不得临场另算方位。
- 阳时 / 阴时按奇门五阳时 / 五阴时的时干判定：甲乙丙丁戊为阳，己庚辛壬癸为阴。
- 行人年命、官府差人等另占口径未入表，不得混用。
