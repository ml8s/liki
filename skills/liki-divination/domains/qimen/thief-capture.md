# 奇门占捕盗

> 命理依据：《奇门遁甲秘笈大全·卷九·占捕盗贼》。天蓬为大贼，玄武为小贼，勾陈为捕盗之人。

## 流程

1. 用 `qimen_snapshot` 取默认时家转盘基础盘，不传 `matter` 或 `yong_shen`。
2. 捕获关系用 snapshot.special.assertions；贼人画像用 snapshot.special.assertions。
3. 只解释工具命中的表内候选；候选并列，不排序、不合并成最终结论。

## 当前边界

- 仅支持 `scope=hour` + `school=zhuanpan`。
- 神盘消费稳定领域别名：阳遁勾陈 / 朱雀，阴遁白虎 / 玄武。捕盗的小贼只取阴遁玄武；阳遁朱雀不冒充玄武。
- 可输出制贼、难捕、串通、捕者为盗、纵盗候选。
- 画像可输出贵人 / 小人、八宫人物象、内盘亲近人或外盘外人候选。
- 庚格已入表：年格、月格、日格、时格分别给出年内 / 月内 / 日内 / 即时候选；无庚格输出难获候选；杜门落宫有庚格输出杜门捕获候选。
- 庚格候选与生克关系候选仍并列输出，不临场合并成必然结论。
- 《元灵经》以伤门为捕人的另一口径未实现，不与本法混用。
