# 金函玉镜日家奇门

> 领域依据：《奇门遁甲秘笈大全·诸葛武侯行兵遁甲金函玉镜卷一》。冬至后阳遁顺行九宫，夏至后阴遁逆行九宫；甲子日阳遁艮八起太乙、阴遁坤二起太乙。外部执行交叉源为 kentang2017/kinqimen 固定 commit。

## 引擎事实

- 输入：`scope=day`、`school=jinhan_yujing`，不传 `dingju_method`、`quarter_rule`、`yong_shen`、`birth_date`。
- 输出：`method.dun_source` 说明二至阴阳；`pan.gong_wei[].xing/men` 说明金函九星与八门；`pan.day_spirits[]` 说明十干十二神。
- 金函玉镜无常规局数、三奇六仪、天地盘干、值符值使、常规八神、格局与应期因子；这些字段不得从普通奇门盘类推。

| 太乙 | 吉 | 百事通达、见贵参谒 |
| 摄提 | 凶 | 阻滞灾危、不宜妄动 |

| 天符 | 凶 | 阴谋迟滞、防小人 |
| 青龙 | 吉 | 求财喜庆、谋事可成 |
| 咸池 | 凶 | 虚惊反复、耗损不利 |
| 太阴 | 吉 | 暗助、藏守得宜 |

八门仍读 `domains/qimen/bamen.md`。解释时先定门吉凶，再叠加本表星性；不得改用 `jiuxing.md` 的天蓬—天瑛九星表。

## 十二神

`pan.day_spirits[]` 是十干各配十二地支神的稳定领域事实。当前未建立逐神断语表，LLM 不得凭名称自行推断吉凶或用途；只能展示干支对应关系。

## 解读顺序

1. 引用 `method`：日家、金函玉镜、无定局、二至阴阳与当前节气。
2. 逐宫读取 `gong_wei[].men` 与 `xing`，按门先星后解释。
3. 中宫 `men_present=false` 时只解释星，不虚构中门。
4. 需要展示十二神时，按 `day_spirits[]` 的干支事实列出，不下吉凶断语。
