## 我们的差异化

### 与 yinyo-liuyao 对比
| 维度 | yinyo-liuyao | 我们的 liki-divination |
|------|-------------|----------------------|
| 规则数量 | 120条 | 10类特殊格局 + 9类占断 |
| 卦例库 | 412卦例 | 待补充（50-100条） |
| 排盘 | 无（用户输入） | 有（liki-engine） |
| 可视化 | 无 | 待实现 |
| 命理联动 | 无 | 可与八字/紫微交叉验证 |

### 与 fortune-liuyao-skill 对比
| 维度 | fortune-liuyao-skill | 我们的 liki-divination |
|------|---------------------|----------------------|
| 排盘 | Python 代码 | Go 引擎 |
| 占断方法 | 9类 JSON | 9类 MD 文档 |
| 可视化 | HTML 卦盘 | 待实现 |
| 命理联动 | 无 | 可与八字/紫微交叉验证 |

### 我们的核心优势
1. **多术数联动**：六爻可与八字/紫微交叉验证
2. **确定性引擎**：排盘由 Go 引擎计算，LLM 只负责断卦推理
3. **分层断卦**：L0-L5 流程标准化
4. **与命理系统集成**：共享同一引擎，数据可互通
