# 考时（出生时间存疑）

> 场景：出生时间、时辰、日界、交节或历史时制存疑；先归一候选与影响域，再用受影响体系做时敏事实交叉校准，定可用时间或说明不确定边界。

## 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- |
| 1 | 收集候选 | 与用户确认候补时辰（或“只记得上午 / 下午”）、出生地与已知人生大事；存在历史时制歧义（如夏令时）先确认口径 | 候补时间、地点事实与验证事件 |
| 2 | 时间候选归一 | 用地点坐标和时间候选归一能力展开候选；保留每个候选的原因域，不静默选择 | 候选集与影响域 |
| 3 | 影响域分类 | 按候选原因域判断影响八字、紫微还是双侧；交节通常只影响八字 / 大运 | 委派计划 |
| 4 | 受影响侧校准 | 把候选原样委派给受影响体系；各侧只做本体系时敏事实与应期验证 | 逐候选、逐侧证据 |
| 5 | 交叉裁决 | 双侧同指一时辰 → 定案；不同 → 并列候选与各自证据；交节-only 只用八字 / 大运证据 | 校时结论 |
| 6 | 输出 | 按模板给出结论、依据与不确定边界 | 校时报告 |

## 边界条件

| 异常场景 | 处理方式 |
| --- | --- |
| 无任何可验证事件 | 不给唯一时辰；给出候补区间与建议补充的事件类型 |
| 两侧结论冲突 | 并列两侧证据与适用层面，不强行合并 |
| 用户无法提供更多信息 | 按已知信息给出条件性结论，标注未校时 |
| 宝宝 / 青少年 | 跳过校验，使用用户输入时辰 |
| 用户已明确时辰 | 以用户确认为准 |
| 候补 < 2 | 请用户确认唯一时辰或补充候补 |
| 人生大事 < 3 | 考时精度不足；延后校验或接受低置信度 |
| 候补 > 5 | 先缩小时间范围，再进入结构排除 |
| 输入时间距时辰交界 ≤30 分钟 | 仍先按输入排盘；旁注提示建议校准，不得静默视为确定时辰 |

## 输出模板

```text
结论：可用时辰与置信说明（或候补区间）。
依据：两侧时辰敏感事实（列断语 id）。
置信度：高（结构排除后仅剩一盘）/ 中（吻合数明显领先）/ 低（平局后借问题方向分界）。
不确定项：未验证事件与对结论的影响。
```
