# 考时（时辰存疑）

> 场景：出生时辰存疑或不确；以两侧时辰敏感事实交叉校准，定可用时辰或说明不确定边界。

## 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- |
| 1 | 收集候选 | 与用户确认候补时辰（或“只记得上午 / 下午”）与已知人生大事；存在历史时制歧义（如夏令时）先确认口径 | 候补时辰与验证事件 |
| 2 | 双侧校准 | 八字 + 紫微：各自按本体系校准方法（时辰敏感事实）编排并交叉验证 | 两侧候选排序与依据 |
| 3 | 交叉裁决 | 两侧同指一时辰 → 定案；不同 → 并列候选与各自证据 | 校时结论 |
| 4 | 输出 | 按模板给出结论、依据与不确定边界 | 校时报告 |

## 边界条件

| 异常场景 | 处理方式 |
| --- | --- |
| 无任何可验证事件 | 不给唯一时辰；给出候补区间与建议补充的事件类型 |
| 两侧结论冲突 | 并列两侧证据与适用层面，不强行合并 |
| 用户无法提供更多信息 | 按已知信息给出条件性结论，标注未校时 |
| 宝宝 / 青少年 | 跳过校验，使用用户输入时辰 |
| 用户已明确时辰 | 以用户确认为准 |
| 候补 < 2 | 请用户确认唯一时辰或补充候补 |
| 人生大事 < 3 | 考时精度不足；延后校验或接受低置信度 |
| 候补 > 5 | 先缩小时间范围，再进入结构排除 |
| 输入时间距时辰交界 ≤30 分钟 | 仍先按输入排盘；旁注提示建议校准，不得静默视为确定时辰 |

## 输出模板

```text
结论：可用时辰与置信说明（或候补区间）。
依据：两侧时辰敏感事实（列断语 id）。
置信度：高（结构排除后仅剩一盘）/ 中（吻合数明显领先）/ 低（平局后借问题方向分界）。
不确定项：未验证事件与对结论的影响。
```
