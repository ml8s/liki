# 婚姻分析

## 流程

| 步骤 | 条件 / 目标 | 合参所需信息 |
| --- | --- | --- |
| 1 | 配偶星 | 八字 + 紫微：婚姻本命 |
| 2 | 夫妻宫 | 八字 + 紫微：婚姻本命 |
| 3 | 婚姻状态 | 八字 + 紫微：婚姻本命 |
| 4 | 应期 | 八字 + 紫微：婚姻应期 |
| 5 | 具体细节 | 八字 + 紫微：婚姻应期（目标年） |

## 📖 双盘婚姻合参

- **同域助证**：紫微流年夫妻宫化忌可作离异年份的同域助证，但不是必要条件；冲忌次数不等于婚变段数。
- **婚缘迟**：八字配偶星极弱且大运无透 叠 紫微夫妻宫落陷 / 空宫 → 先走婚缘迟路径。
- **同向加强**：八字「婚可成」与紫微夫妻宫专指象并见时，分别列十神总体象与夫妻宫专指象，再说明适用层面。
- **紫微宫位应期**：红鸾坐流年夫妻宫、流年命宫落目标领域宫并吉化，为同域主信号，与八字星宫引动并列参看。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 用户未婚但问离婚 | 先问是否已有稳定对象，有则分析当前关系，无则分析命局倾向 |
| 男命问感情但原局无财星 | 需八字补充隐性妻星信息（食伤状态） |
| 女命问婚姻但原局无官杀 | 需八字补充隐性夫星信息（财星）或大运引动 |
| 已离婚问再婚 | 需八字补充七杀清透与大运正官 / 正财信息 |
| 用户只提供了一个人的八字但想看合盘 | 提示需要双方出生信息，引导到 `references/natal-app-compatibility.md` |

## 输出模板

```text
结论：一句话婚缘状态与质量。
依据：配偶星状态、夫妻宫冲合、紫微夫妻宫（列断语 id）。
应期：首选年 / 备选年与引动层。
建议：一个现实动作。
```

### 示例

```text
结论：配偶星得地有根，夫妻宫安静，婚姻中稳。
依据：配偶星透干有根（hun_101）；夫妻宫无冲合刑害（hun_421）。
应期：大运配偶星窗口 2027-2031，流年丙午（2026）配偶星透干，首选 2026-2027。
建议：未验证时段标注置信度；确证前不写成必然。
```
