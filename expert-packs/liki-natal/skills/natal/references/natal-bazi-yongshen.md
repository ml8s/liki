# 用神方法论

## 数据流

八字用神走一条单向链：

```text
完整八字盘事实
  → 取用神阶段因子（扶抑 / 调候 / 格局 / 从格 / 中和）
  → 决策表裁决
  → 唯一用神裁决结果
  → 为用 / 为忌、流年喜忌、起名补益
```

用神只裁决一次。合参、起名、流年与断语层消费同一份裁决结果。工具能力、参数和返回字段由 MCP 自省与 schema 提供；本卡只写领域方法与解释口径。

裁决结果包含：

- 最终用神、喜神、忌神。
- 状态：已定（resolved）/ 部分确定（partial）/ 待复核（needs_review）/ 未决（unresolved）。
- 命中规则、规则版本与来源摘要。
- 冲突、证据缺口与置信度。
- 裁决所依据的扶抑、调候、格局与从格复核证据。

独立用神裁决返回决策对象与证据；因子快照另含取用神阶段的直读事实和二次因子。技能读取这份结果并解释。合参、起名、流年与断语层使用同一份裁决，保持全局一致。

## 扶抑

日主强弱是取用神的第一前提：

- 身弱：需要生扶。印星化杀生身，比劫帮身抗杀。
- 身旺：需要克泄耗。官杀制身，食伤泄秀，财星耗身。
- 中和：泄旺补缺，观察命局中偏旺或偏弱的五行。

从格从扶抑出发：日主极旺无制或极弱无援时，进入从格分支。

engine 的 `fu_yi` 给出强弱依据：日主根型、月令旺相、印比数量、日主藏干根，以及日主 / 印比 / 日支 / 日主根的关系投影。读取 `element_states` 与 `ten_god_states` 判断有效力量：得令、透干、通根、生扶、合冲刑害共同决定力量。

**数量不等于有效力量**。五行个数只是出现次数，不是力量权重。判断力度必须先读 `element_states` 与 `ten_god_states`：多个休囚无根之火不能因数量多就压过当令有根之金；少数得令通根之五行也可能为强。禁止用 `wuxing_count` 做加总评分。

## 格局

定格规则见 `references/natal-bazi-geju.md`。

格局提供月令结构与十神方向：`ge_ju / yong_fa / pattern_god / pattern_god_ten_god / pattern_god_source / structure`。格神与最终用神分开处理；格局主题用于解释命局结构，格局清透提高扶抑裁决的置信度。

格局虚格（月令本气不透干）以扶抑为主，格局作为辅助描述。格神方向可以说明约束、资源、表达、庇护等主题，最终喜忌仍由扶抑、调候与整体结构共同裁决。

## 调候

调候规则见 `references/natal-bazi-tiaohou.md`。

冬夏寒暖燥湿明显时，调候进入优先裁决；春秋温和时，调候只作修正证据，扶抑与格局为主。极端月的调候用神与扶抑忌神直接相反时，裁决进入待复核。

调候主辅神、透藏、经典条件与辅神升用条件由取用神阶段因子计算，最终结果写入用神裁决。辅神生助已定用神、经典条件满足且力量适中时，可优先作喜神；辅神克用神或旺到反制用神时，只说明调候需求，喜神仍回到裁决结果的喜神。

## 从格

从格双证：

- 证一：日主地支无根，或极旺（得令 + 比劫印绶成群）。
- 证二：原局无印比破格。从弱格无印星生身、无比劫帮身；从旺格无克泄耗强根。

`fu_yi.pattern` 给出从格标签，决策表用月令、根型、印比与十神有效力量复核。有效力量按透干，或通根且力量强计算；从弱格另查印星、比劫的藏支根，任一有根即不通过从格双证。复核通过走顺势用神，复核不足进入待复核状态。

假从格：有微根时以假从论。大运破格（根被冲合）时回归正格。

从格不按正格的扶抑 / 调候 / 格局合参处理：

- 从旺格：顺印比方向。
- 从弱格（从杀 / 从财 / 从儿）：顺官财食伤方向。
- 从格吉凶按顺势与逆势判断，岁运同看。

## 喜忌复核口径

喜忌由决策表一次给出。下列五项是表的复核口径，用于解释依据与识别冲突：

| 裁决来源 | 喜神候选 | 忌神候选 |
| --- | --- | --- |
| 扶抑 | 扶抑喜神 | 扶抑忌神 |
| 调候 | 调候辅五行，且辅神生助或护持用神、条件满足且不过旺 | 回到扶抑与整体组合，不机械反推 |
| 格局 | 按相神与救应条件复核 | 按破格条件复核 |
| 从格 | 顺势同党 | 逆势异党 |

| 检查项 | 通过条件 | 未通过时的处理 |
| --- | --- | --- |
| 生克方向 | 候选五行生用神，或与用神同气且不互克 | 若候选五行克用神，不得直接作喜神 |
| 力量反转 | 候选五行未旺到反制用神；读 `element_states` / `ten_god_states` | 候选过旺克用，降为风险因素，另取生助用神者 |
| 通关条件 | 候选克用但存在真实、有力、无破的通关神（如水→木→火） | 通关神本身优先作喜神；原候选只作条件性前导，不写成直接喜神 |
| 合冲牵制 | 候选与用神未被合绊、冲伤到失效；读用神关系事实与格局关系事实 | 被牵制者只写结构风险，不改喜神方向 |
| 调候辅证 | 调候主辅神可作为候选，但仍须通过上述生克与力量检查 | 调候神克用或过旺时，只作调候需求说明，不作喜神 |

喜神由实际作用决定：同党五行若克用或旺到反制用神，按表内「未通过时的处理」另取生助用神者。

示例：用神为火时，木生火，可为喜神；水克火，虽同属宽泛的克泄耗团队，也不能直接把水作喜神。若水生木、木生火且木真实有力无破，则木是直接喜神，水只作条件性通关前导并说明风险。

## 用神状态

取用神之后，继续判断用神状态：

- **有根无根**：用神在地支有同五行藏干为有根。有根力量持久，无根偏虚浮。
- **有力无力**：用神得月令生扶或处长生 / 帝旺为有力；被月令克制或处休囚死地为无力。
- **处境**：用神被克、被合、被冲分别记录减力、牵制、动摇。原局与大运的生克制化共同进入应期判断。

## 合化吉凶

天干五合、地支三合六合表示结构变动。合化吉凶由两部分决定：被合走的十神，以及化出的五行。（本表为解读方向，须与 `zh_206`-`zh_211` 结构候选、用喜忌裁决一致，不脱离断言）

合化成功条件：地支见化神之月日，或化神得令。盘面事实给出合化结构与条件，用神裁决提供喜忌方向。

| 场景 | 被合走之星 | 化出五行 | 结论 |
| --- | --- | --- | --- |
| 去凶化吉 | 忌神 / 凶星 | 喜神 / 用神 | 大吉：忌神被清除，喜神增强 |
| 去凶化凶 | 忌神 / 凶星 | 忌神 | 先凶后吉：过程有变动，隐患被处理 |
| 去吉化吉 | 用神 / 吉星 | 喜神 / 用神 | 吉中带变：性质变化，方向仍好 |
| 去吉化凶 | 用神 / 吉星 | 忌神 | 大凶：失去依靠，引入风险 |
| 合绊不化 | 合化条件不足 | — | 牵制：十神功能减弱，性质不变 |

输出时区分事件性质（变动）与结果走向（吉凶）。场景「去凶化吉」表示结果向好，过程仍有变动成本。

## 从格流年

- 从格流年按顺势为吉、逆势为凶：喜神同党年应吉，忌神异党年应凶。
- 从旺格以印比得势为吉，从弱格以官财食伤得势为吉。
- 判流年健康与吉凶前，先查流年地支值日支（伏吟）或冲日支，再查忌神五行攻身；任一成立即列为重点应期年。

## 用神双轨仲裁

从格标签与三得法复核方向冲突时：

1. 按正格与从格两套喜忌分别推演候选应期。
2. 两套结论事件性质相反时，比较命局结构（财官透干、格局、大运走向），取与结构更一致的一套。
3. 输出所选轨道、置信度与冲突证据；两套候选并列保留在证据中。

## 输出

解释用神时读取用神裁决结果，输出：

```text
用神：{yong}；喜神：{xi}；忌神：{ji}
依据：{source} / {rule_id} / {confidence}
证据：扶抑强弱、调候主辅、格局清透、从格复核
状态：{status}；冲突：{conflicts}
```

状态为待复核 / 未决时，输出复核原因与缺失证据；起名与流年层等待复核后再继续。
