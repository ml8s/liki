# 性格分析

## 流程

| 步骤 | 条件 / 目标 | 合参所需信息 |
| --- | --- | --- |
| 1 | 基础性格 | 八字 + 紫微：性格本命（日主、身强弱；命宫主星与辅煞） |
| 2 | 组合修正 | 八字 + 紫微：性格本命（十神组合与修正方向） |
| 3 | 紫微合参 | 八字 + 紫微：性格 / 精神本命（主星、四化、执念与消耗点）；八字 + 紫微：性格应期（目标年） |
| 4 | 外貌 / 体型 | 八字：旺衰底色 ｜ 紫微：相貌体型 |

## 📖 双盘性格合参

- **主面分层**：八字月令本气十神定结构主面；紫微命宫主星定星情表达层——通用性格题不取紫微覆盖月令主面，题目明确问气质 / 星情 / 外显风格时紫微可主导对应措辞。
- **八字验证参考**（紫微命宫主星 ↔ 十神同向）：紫微 / 天府→官杀透 + 印旺；天相→正官 + 正印；太阳→食神 + 比肩；巨门→伤官 + 七杀；天机→食伤 + 偏印；天同→食神 + 正印；太阴→正印 + 偏财；武曲→七杀 + 正财；廉贞→官杀混杂 + 伤官；七杀→七杀透 + 无印；破军→七杀 + 劫财；贪狼→偏财 + 伤官；天梁→正印 + 正官。
- **体型互证**：八字日主五行 + 旺衰定身材底色（木高瘦、土敦实、金方正、水丰腴、火中等），紫微主动星定体态（天府丰腴、天机纤细、武曲骨感）；冲突时并列证据并说明强弱。
- **空宫**：紫微命宫与对宫皆无主星时，以八字十神为主判性格。
- **取象升格**：性格 / 职业 / 身份取象须覆盖八字与紫微各至少一层证据，单星曜 / 单十神 / 单神煞不得单独定案。
- **表达层（审美 / 风格 / 偏好）**：日主五行为底色，食伤 / 偏印与命宫 / 福德宫为表达层——底色定方向、表达层定形式，不设绝对压制。

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 用户只给外貌描述（矮 / 胖 / 壮 / 瘦） | 逐诉求映射到日主五行与紫微体态，两侧并列证据 |

## 输出模板

```text
结论：一句话性格主面与表达层。
八字：日主五行、身强弱、月令主面与辅面（列断语 id）。
紫微：命宫主星与四化、身宫 / 福德宫补充。
互证：两侧同向或并列证据。
```

### 示例

```text
结论：月令正印主内向沉稳，食伤透干添表达力，外冷内热。
八字：日主戊土，月令寅木藏甲木（七杀）；食神伤官双透。
紫微：命宫天相（庙），外圆内方，稳重中带变通。
依据：月令主面为偏印（xg_m03）；食伤为辅面增表达（xg_507）。
```
