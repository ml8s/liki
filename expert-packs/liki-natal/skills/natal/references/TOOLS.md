# Natal 工具与判断

- **八字侧**（`side` = `bazi`）：排盘 + 本命判断 + 应期判断（含合盘、考时）。
- **紫微侧**（`side` = `ziwei`）：历法换算 + 排盘 + 本命判断 + 应期判断（含合盘、考时）。

用 `side` 区分两侧；卡内动作的 `八字侧` / `紫微侧` 即以对应 `side` 调用，两侧并列时各自调用后再合参。

卡内未限定 topic 的判断调用取该卡领域；结论只保留该域断语，其他域信号仅用于解释机制。

## 标准流程

1. **排盘**：出生信息 → 本命盘（八字：四柱/大运；紫微：公历 → 农历 → 十二宫/大限）。
2. **取因子**：本命盘 → 因子快照（含防篡改摘要）。
3. **本命判断**：因子快照 + 问题域 + `side` → 本命断语。
4. **应期判断**：因子快照 + 时间层 + 问题域 + `side` → 大运/大限/流年断语。

## 输出契约（断语公共字段）

`assertion_id`、`side`、`topic`、`method`、`time_scope`、`event_type`、`event`、`conclusion`、`source`、`evidence`。`side` 是 `bazi` / `ziwei`。

Topic 是受控人生问题闭集（`键`＝中文标签，卡内 `本命判断（标签）` 即取该 topic）：`marriage`＝婚姻、`family`＝家庭、`children`＝子女、`career`＝事业、`wealth`＝财运、`health`＝健康、`mental`＝精神、`study`＝学业、`personality`＝性格、`appearance`＝外貌、`origin`＝出身、`relocation`＝迁移、`social`＝人际、`property`＝房产、`adversity`＝风险、`chart_structure`＝盘面结构。

时间层由 `time_scope` 的 `type` 表达：`current_year`、`year`、`year_range`、`current_decade`、`decade`；卡内 `应期判断（十年期）` 取十年期层，无限定则按问题域取年/十年层。年份为**年号**（八字公历立春界 / 紫微农历春节界，年号级一致），不做日期换算。年份区间含端点，最多 120 年。

## 合参与裁决（八字 × 紫微）

- **分侧定案**：八字侧与紫微侧各自排盘、各自出断语，单侧断语不得混用异侧因子；需要八字 × 紫微同一条件支撑的结论走 `side=common` 合参断语。
- **证据强度**：双体系同向＝强；单侧明确＝中；仅一侧＝弱；双侧相反＝并列说明适用层面，不强行合并；输出按 八字层 / 紫微层 / 合参 三层，单侧结论标注八字侧 / 紫微侧。
- **主域优先**：先识别用户问什么，主域断语定案，其他域只作佐证、不跨域否决主域。
- **域隔离**：流年事件题只采信主域事件断语（婚姻只取婚动 / 婚变；财运只取得财 / 破财；健康只取健康 / 凶事 / 血光 / 精神；六亲只取六亲灾 / 父母 / 子女）；八字 / 紫微同域可交叉，异域一律排除。
- **同域优先**：同域具体信号成立时（六亲宫化忌、配偶星值宫、疾厄化忌），印星当旺、喜神年份等一般性异域表述不作否证；本域主信号（升学看印星 / 文昌，合伙投资看偏财比肩）不被他域杂星 / 事件否决；紫微十二宫主星庙陷断语是主信号级，与八字断语同级参看。
- **语义直指**：断语结论与用户表述直接对应时作主解释；另解同样有断语支撑时并列说明证据，不凭感觉转释。
- **主断语优先**：主断语 / 唯一断语优先于辅象——单星 / 单五行的辅象不得覆盖唯一断语（如「金旺→皮肤白皙」为主象，其他辅象不覆盖）。
- **独立证据闭环**：结构 / 星宫 / 限运 / 流年 / 事类语义分属不同层；同源重复信号不累加，不以数量门槛替代闭环。
- **问凶 / 问吉**：问凶时凶信号定调、吉信号不否决；问吉时答案年可为吉凶混杂（凶象不排除该年）；吉凶并存时按域列证，不因数量少自动失效。
- **十年层取象**：八字大运与紫微大限并列给十年窗口；八字以目标星 / 目标宫位取象，紫微以流年四化所入宫位主星取象，两侧都不替代流年取象。
- **各问题独立看盘**：禁止用其他问题的结论 + 命理修辞互斥推算。

## 裁决次序（query 输出）

- **确定性结论全部走 query 工具**（内部真值表由 analysis 断言层执行——因子条件组 + 经典依据列；跨体系结论由 common 表显式合参）。
- **断语规则统一**：query 内部真值表 + `*.md`（断法细则）都是规则，不存在「参考」弱化；细则用于理解依据与补充未入表内容。
- **直接采纳输出为最终判断**；先按领域 / 时间层分组，再按独立证据闭环整合，不因表序或术数来源默认压制任一断语。query 输出与规则卡冲突 → 以 query 为准并说明冲突。
- **排盘失败 → 提示重试，不降级查表**（真值表匹配是精度来源，降级会退精度）。
- **涉及无子、重大灾变、残疾等重结论**，须宫、星、限运、流年独立闭环；现实已发生事实可作验证，不作命理反推。
- **先决条件并入条件组**：传统断语中的前提须先因子化，再与事类信号同组 AND；同一前提可复用则先建复合因子再由断语引用。命理逻辑全部进表，agent 只解释命中断语。
