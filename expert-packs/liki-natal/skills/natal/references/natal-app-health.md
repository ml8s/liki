# 健康分析

## 流程

| 步骤 | 条件 / 目标 | 合参所需信息 |
| --- | --- | --- |
| 1 | 脏腑倾向 | 八字 + 紫微：健康本命（过旺 / 过弱五行与易病方向；疾厄宫） |
| 2 | 限运触发 | 八字 + 紫微：健康应期（十年窗口、冲入宫位与触发年份） |
| 3 | 性质与走向 | 八字：健康本命（冲合细节） |
| 4 | 具体细节 | 八字 + 紫微：健康 / 精神本命；八字 + 紫微：健康应期（目标年） |

健康输出为倾向和关注方向；重大病灾需不同层证据闭环，并先列较轻替代解释。

## 📖 双盘健康合参

- **疾病细节三层闭环**（缺一层不断细节）：① 本命疾厄宫主星定先天薄弱系统 → ② 大限疾厄宫定当限主题 → ③ 流年干支定应期（流年五行冲克薄弱五行 / 引动疾厄宫）。
- **“谁得病”判准**：紫微流年疾厄宫化忌 / 凶化 = **自己**（一级信号）；日主受忌神攻身 + 紫微疾厄宫化忌 → 断**自身病**；印星受克 + 伏吟 / 冲年柱母宫 → 断**母灾**。八字与紫微同结论才定案，冲突时并列说明。
- **好体质路径**：命宫天府 / 天相 + 迁移紫微七杀 + 疾厄宫无煞忌 → 运动健康型；童年流年冲刑只作当年小病，不作“终身暗疾”。
- **星曜不单义**：廉贞（火）主心亦主血、破军主血水、天机主肝、太阳主心/头/目——须按命局五行主次裁定，禁止星曜标签化定脏腑。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 用户问"我有什么病"而非倾向 | 说明命理只能给倾向，不能诊断；给出对应脏腑建议 |
| 原局五行平衡无明显过旺过弱 | 输出"原局五行均衡，无明显薄弱脏腑" |
| 冲刑入多个宫位 | 按柱序（年>月>日>时）说明主次 |

## 输出模板

```text
结论：一句话健康倾向与关注方向。
依据：五行失衡方向、十神为忌攻身、流年引动（列断语 id）。
时间线：关注年与检查窗口。
建议：一个现实动作。
```

### 示例

```text
结论：五行木弱金旺，肝胆与筋骨为薄弱环节。
依据：木弱（jk_113）；金旺克木（jk_107）；命局无水通关。
建议：注意肝功能与筋骨健康；四季变化时关注呼吸道（金旺应肺）。
```
