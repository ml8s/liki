# Liki 本命八字紫微 — 八字命盘 / 紫微斗数 / 合参合盘 / 考时

Liki 本命域：**八字侧与紫微侧都在本域内自举**——各自排盘、取因子、出断语，再由本域完成合参、合盘、考时与综合命书编排。能力、参数与结果以运行时自省描述和契约为准。

## 路由

执行侧按用户点名的体系选择：点名八字只跑八字侧，点名紫微只跑紫微侧，未点名时两侧都跑并合参（同向时综合，冲突时并列两侧证据）。

## 时间事实与执行

1. 用户给出出生地（城市）时，先用地点坐标归一能力获得经度与 IANA 时区——后续时间工具全部依赖它。
2. 需要当前时间上下文时，使用当前时间事实能力（依赖上一步的时区）。
3. 出生时间模糊、跨日界、跨交节或涉及历史时制时，使用时间候选归一能力（依赖经度与时区）；多候选时按考时卡（natal-app-calibration）编排：先以候选出临时盘，再基于两侧时敏事实差异出判别问题，按用户回答收敛候选或保持条件性结论。
4. 候选原因域说明影响面：交节通常只影响八字与大运；时辰、日界、时制可能影响八字与紫微。
5. 只对受影响侧执行对应的八字 / 紫微排盘与验证；候选不完整时先向用户确认，不静默选择。

## 硬边界

- 断语以工具输出为准（规则真值表）；方法论卡只用于解释依据，不自行编造。
- 跨体系合参与断语取舍见对应场景卡的「双盘合参」节。
- 部分失败降级：单体系信息不可得时，降级为单体系结论并明示缺口与置信影响；不得以单体系冒充合参。
