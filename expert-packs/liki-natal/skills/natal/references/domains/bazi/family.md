## 证据闭环与专项裁决

### 六亲取象证据闭环

- **偏印透干 ≠ 必有继母/养母**：偏印须有正印受克、偏印得地、限运引动等不同层证据闭环才可论继母/养母情境
- **财克印 ≠ 母必亡/父必灾**：六亲重大灾变须星损、宫凶、限运/流年引动形成独立闭环；一般“财克印”只断母操劳、健康波动或家计压力
- **偏财弱 ≠ 父缘淡/父早亡**：偏财弱只表父财运/父亲助力有限；"父缘"另看年柱与偏财位置、刑冲
- **桃花/天喜在六亲宫 ≠ 六亲出轨**：须叠忌神攻身/日支凶象才断婚外情；父星根空亡→聚少离多（不作出轨）
- **六亲对应星定位**：先明确用户问的是哪一亲（父=偏财、母=正印、配偶=正财/正官、子女=食伤）再查其状态；星与宫按同一亲人归位（如夫星受克归配偶线，父宫另查父星）

### 六亲优先执行细则（有限度）

「某年发生何事」类题，逐年检查六亲星受克信号（流年母星克 / 父星克 / 配偶星克 / 子女星克）：

- 六亲灾断语**结论明确**（「母亲重大变故」「配偶健康 / 关系重大受损」级）时，优先于自身一般吉象作答案——**严重程度决定优先级，不以数量比较**。
- 自身吉象结论同样明确且强度相当 → 两者并列，按命理综合裁决。
- 六亲灾**弱信号**（仅「候选」级）不得单独压过明确的自身吉象；禁止无差别六亲优先。

### 父灾应期

- **偏财入墓 = 父亲健康/关系重大变故候选**：流年/大运地支为偏财墓库且伏吟、冲刑或父星受制时，与“入库得财”并列列证；不定父亡，重大结论须年柱宫与限运闭环
- **冲偏财坐支 = 父事引动**：大运/流年冲偏财坐支，且偏财受克、合绊或入墓时，为父亲事务/健康波动候选；年柱宫凶象同参，不单独定灾

### 父母离异判据

- **独立闭环**：断父母离异须年柱宫引动、财印关系受制覆盖不同层；年柱空亡、财克印单项均不得单独定离异
- **关系变动判据**：年柱被冲或伤官克官，且财印关系受制覆盖另一层证据时，可论父母离异或分离级变动

**财坏印方向**：印星受制可同时指母灾与自身健康时，按 `wuxing-health.md` 的六亲灾 vs 自身病判据（伏吟/冲年柱母宫→母灾优先）

### 出身/子女专项裁决

#### 出身贫富判据

- 以**财星实虚**（透干有根=实 / 虚浮无根=虚）+ **年柱宫成败**（年柱得地=成 / 受冲克破败=败）定贫富档
- 出身档以财星实虚与年柱宫成败两证为准；官印相生、年柱得地只作辅助气质证据
- **年柱空亡只主祖上助力少、早年离家，不否定父母自身财力**；年月柱财星得令有根 + 偏财得令有根 → 可直接升"富贵"档（空亡不得与财星得令并列降档）

#### 无子判断闭环（结构、星宫、应期三层皆弱才可断子女缘极弱）

- ① 时柱（子女宫）逢冲/刑/害（本命或大运）
- ② 子女星（食伤/官杀）受制无根（被冲克/入墓/虚浮）
- ③ 大运/流年子女应期全空（无食伤/官杀引动年份）
- 任一层缺证 → 只断子女缘强弱或波折

**孕产分情境** — 按问法分开处理：

- **问生育应期** → 凶险 ≠ 否认定生育：难产 / 损胎信号是「生育年之象」（难产正是该年生子之象），不排除生育候选。
- **问事件且用户提到「流产 / 堕胎」** → 伏吟日柱、刑子女宫、孕产凶象等可形成流产 / 损胎候选；结论须结合孕产时间线与已知事实，不作医疗诊断，也不强行转释为剖腹产。

**流产/损胎判据**：食伤入墓 / 坐胎绝 / 被冲，叠加流年引动时柱或孕产凶象（子女星受冲刑），可作孕产损失候选；是否流产须孕产时间线、用户已知事实与医疗事实确认。流年吉神入时柱只作“生育应期/添丁”，不否定孕产风险

**子数/性别判据**：以原局食伤（女）/官杀（男）多现 + 时柱得地无冲克定子女缘强弱；**流年吉神（红鸾/天喜）只作生育应期，不作子数证据**。时柱食伤阴阳仅作传统取象参考，不作确定性性别判断；现实性别以事实为准

**冲宫 ≠ 灾亡**：六亲宫被冲只作"该亲变动/分离/健康波动"，须叠加六亲对应星入墓/受克 + 同域凶象闭环才断灾亡
