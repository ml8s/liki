# 性格分析方法

## 判断流程

```text
① 命宫主星 → 性格基调
   读取 `zhuxing.md` 星曜性格基调表
   例：命宫天府 → 保守稳重型

② 命宫辅星/煞星 → 修正
   文昌文曲+ → 文采好
   火星铃星+ → 急躁
   擎羊陀罗+ → 刚烈/拖延
   空宫 → 借对宫主星

③ 身宫 / 福德宫 → 补充
   身宫定后天取向，福德宫定精神面貌与消耗点

④ 综合输出
   举命宫主星与辅煞组合给出星情基调；不单星定论
```

## 空宫处理

借星口径见 `gong12.md`「空宫处理」；命宫与对宫皆无主星时标注「环境塑形」，按三方四正与后天环境论。

## 命宫双主星

命宫同时坐两颗主星（廉府、紫府、武贪、机月同梁等）时：

- 两条主星断语**都真实、不冲突**，按双星组合论并见（廉贞天府＝刚柔并济外柔内刚；紫微天府＝大气守成；武曲贪狼＝魄力与欲望并见）。
- 星曜亮度（庙 > 旺 > 利 > 陷）高者略主，只修正星情表达层的侧重，两条断语都不作废。
