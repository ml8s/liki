## 📖 取象升格：单星曜 / 单神煞须与组合同看

- 单星曜（贪狼=僧道、太阴=财务、空劫=极简、破军=分离、天机=聪明）、单神煞（华盖=宗教、驿马=出国、灾煞=终身病）须与组合、宫位、四化同看后才定案
- "僧道命/宗教缘/华盖"只作**倾向**（对结论的加分项），不作职业定论
- 判断顺序：先查主星庙陷与被制化 → 再查辅煞与四化组合 → 最后按组合取象表定象

### 📖 组合取象表（反标签化——同一星曜在不同组合下取不同象）

| 组合 | 取象 | 勿误取为 |
| ------ | ------ | --------- |
| 天机 + 空劫 | 古灵精怪、奇巧收藏、智谋型 | 极简/不喜摆设 |
| 太阳 + 火星 + 陀罗 + 天马 | 体能/运动/行动力职业（健身/运动/外勤） | 财务/文书 |
| 太阴化禄入官禄 | 财务/管理；但**须结合命宫主星定象**（命宫火陀天马→健身/体态管理） | 一律=会计财务 |
| 命宫天府/天相 | 保守稳重、重享受 | 闯祸/激进 |
| 紫微+武曲+天府于田宅/官禄 | 管理/资产 | 单凭田宅星=已购房 |
| 贪狼+华盖（辰戌） | 宗教/玄学**倾向**，不作职业定论 | 牧师/僧道职业 |
| 身宫主星 | 后天补充，命宫主星为第一属性 | 以身宫反断性格 |

### 📖 取象护栏：固定取象作方向提示

- **组合校验清单**：空劫看父母宫禄存/天梁、桃花与天喜叠化忌后才论、将星看是否入官禄、文曲化科看是否入官禄且被凶星夹、破军看庙地与禄存、太阴与廉贞看命宫主星组合
- **出身基础判据**：家境以父母宫主星庙陷（天梁祖荫/禄存家底）定，田宅空劫仅作"白手起家"辅助信号
- **取象顺序**：先查主星被制化与被合走 → 再按组合取象表 → 单星曜、单神煞或同源重复信号只作倾向
