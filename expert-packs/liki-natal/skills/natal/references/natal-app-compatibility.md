# 合盘分析

## 流程

| 步骤 | 条件 / 目标 | 合参所需信息 |
| --- | --- | --- |
| 1 | 双方出生信息 | 双方原始出生信息（日期、时间、城市、性别） |
| 2 | 原始对照 | 八字 + 紫微：合盘本命（双方日主、夫妻宫、配偶星、干支关系；命宫、夫妻宫、子女宫） |
| 3 | 证据整理 | 本域：汇总两侧合盘结论，分优势 / 摩擦 / 缺口 |
| 4 | 输出 | 本域：按模板输出参考结论与依据链 |

## 📖 双盘合参层级

- 紫微：看双方命宫、夫妻宫、子女宫主星（空宫借对宫只作观察）；八字：看日主、配偶星、日支与交叉关系。
- 证据层级：主配偶星 / 夫妻宫强于辅助神煞；跨体系强弱：同向加强、冲突并列说明适用层面。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 只提供了一方的八字 | 提示需要双方出生信息才能合盘 |
| 问合盘但只说"帮我看看我俩" | 提示提供双方出生信息 |
| 缺一方时辰或缺性别 | 明示对应对象无法完整评估 |
| 单一冲、合、神煞 | 只作证据，不下关系成败结论 |

## 输出模板

```text
结论：一句话关系格局与相处要点。
八字：日主关系、配偶星与夫妻宫事实（列断语 id）。
紫微：双方命宫、夫妻宫、子女宫主星。
共同点 / 差异：优势证据、摩擦证据、证据缺口。
建议：一个相处或现实确认动作。
```

结论按事实与证据层级给出；缘分分数与“良配 / 慎配”标签不出现。

### 示例

```text
结论：日主互补，合盘中等偏吉。
八字合婚：甲方戊土，乙方壬水，戊土克壬水；甲方配偶星乙木透干得地。
紫微合参：甲方夫妻宫太阳（旺），乙方夫妻宫天同（庙）；双方宫位吉星并见。
建议：互补大于冲突；日主克泄关系在磨合期需关注。
```
