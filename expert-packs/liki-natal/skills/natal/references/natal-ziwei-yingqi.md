# 紫微流年应期

用于各 app 做紫微流年验证时使用的看盘抓手。

## 📥 判定来源

下表给**看盘抓手**：每个领域查哪些宫位与关键星曜；流年吉凶断语由 counsel 应期能力返回。

## 📖 翻译表：各领域紫微看盘抓手

| 领域 | 主宫位 | 次看 | 关键星曜 |
| ------ | -------- | ------ | --------- |
| 婚姻 | 夫妻宫 | 命宫/官禄/福德 | 红鸾/天喜/咸池/天姚 |
| 事业 | 官禄宫 | 命宫/财帛 | 紫微/天府/太阳/天相/太阴 |
| 财运 | 财帛宫 | 田宅/福德 | 武曲/天府/太阴/禄存 |
| 健康 | 疾厄宫 | — | 七杀/破军/廉贞/巨门 |
| 父母 | 父母宫 | 田宅宫 | 天梁/紫微天相 |
| 子女 | 子女宫 | — | 天同/天梁/文昌文曲 |
| 学业 | 福德宫 | 命宫/父母宫 | 文昌/文曲/天魁/天钺 |
| 性格 | 命宫 | 身宫/福德宫 | 紫微/天府/太阴/七杀/破军/贪狼 |

**用法**：先读流年宫位（流年命宫落宫/四化落宫）与上述关键星曜所在，再以 counsel 应期断语能力返回的该宫位断言组织结论；缺失字段不臆造。

### 健康应期（重病 / 手术类）

- **主信号 = 疾厄大限（疾厄宫主星所主大限）内 + 流年引动疾厄宫**（化忌 / 化权入疾厄）。
- 重病信号的年限取值看疾厄宫引动本身（疾厄大限内紫微权入疾厄 = 重病年；疾厄宫武曲忌 + 流年疾厄宫流陀 = 重病信号），一般吉象只作并列说明。
- 只作关注 / 检查 / 手术时间线，不凭固定次数推断重大疾病，不作医疗诊断。

### 桃花星详解（婚姻参考）

| 星曜 | 含义 | 引动方式 |
| ------ | ------ | --------- |
| 红鸾 | 正桃花，婚缘 | 大限夫妻宫见之 |
| 天喜 | 喜庆之事，婚嫁 | 小限或流年见之 |
| 咸池 | 桃花，异性缘 | 本命或大限夫妻宫 |
| 天姚 | 偏桃花，短暂情缘 | 流年夫妻宫见之 |

### 文昌文曲详解（学业参考）

| 星曜 | 含义 |
|------|------|
| 文昌 | 正常学业文采，考试运 |
| 文曲 | 异路功名，才艺偏才 |
| 天魁 | 直接助力，长辈帮 |
| 天钺 | 间接助力，机缘好 |

> 以上星曜含义为解读参考；是否在工具返回的宫位中现身、是否被吉凶断言引用，均以工具输出为准。
