## 📖 双盘事业合参

- **职业取象**：紫微官禄宫吉化（化科 / 化禄）+ 昌曲 → 文书 / 文职类；体力星组（太阳旺 / 火星 / 天马 / 破军）并存时并列裁决（行政 vs 体力 / 技术），禁止单星独占定「文职秘书」。
- **偏门取象**：阴煞 / 丧门 / 哭星聚 + 官杀受制 → 阴质 / 入殓类；与物流 / 商贸区分看武曲 / 天马是否主运输。
- **宫位语义**：紫微官禄宫只主事业 / 职场 / 掌权，禁止用作学业 / 婚姻信号。
- **取象升格**：职业 / 身份取象须覆盖八字与紫微各至少一层证据（十神 / 格局 × 官禄 / 财帛 / 迁移宫）。
- **迁移 / 出行**：流年命宫落迁移宫、迁移宫化忌 叠 八字驿马伏吟 / 逢冲、灾煞 → 迁移 / 出行事类优先，不套婚恋 / 事业排序。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 官杀财星均不透 | 查地支藏干，或食伤/印星定方向 |
| 用户问换工作 | 结合大运流年引动判断（发送 八字侧 + 紫微侧 `应期判断` 查流年应期） |

## 输出模板

```text
结论：一句话事业方向与层次。
依据：透干组合与事业档、十神职业取象、身强弱（列断语 id）。
运势：当前大运性质与事业窗口年。
建议：一个可执行方向。
```

### 示例

```text
结论：事业中上，职业方向技术管理。
依据：官杀透干有根（shi_103），身强能任官杀；食伤生财为才华出口。
运势：当前大运食伤运（2025-2034），食伤生财，事业窗口 2026-2028。
建议：走技术管理方向；流年丁未（2027）食伤生财旺，突破概率高。
```
