## 流程

| 步骤 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- |
| 1 | 确定六亲 | 发送 八字侧 `本命判断` + 紫微侧 `本命判断`；读取 `references/domains/bazi/family.md` | 目标亲人与对应星 |
| 2 | 星宫状态 | 按目标调用父母 / 兄弟 / 子女域；读取宫位论 | 透藏、根气、冲合克与宫位 |
| 3 | 应期 | 发送 八字侧 + 紫微侧 `应期判断（十年期）`；发送 八字侧 + 紫微侧 `应期判断` | 引动层与候选年 |
| 4 | 具体细节 | 发送 八字侧 + 紫微侧 `应期判断` | 父母宫、子女宫与四化信号 |

六亲重大变动需要星损、宫凶、限运或流年引动形成独立证据闭环；单信号只作倾向或关系质感描述。

## 📖 双盘六亲合参

- **父母宫**：紫微父母宫凶象（化忌 / 煞聚）与八字年柱宫引动、财印受制覆盖不同层时，才可论父母离异或重大变故；单项不单独定论。
- **子女宫**：紫微子女宫化忌 / 流羊入子女宫 + 八字食伤受冲 / 入墓 → 孕产损失候选；流年吉化入子女宫只作生育应期。
- **出身**：紫微父母宫主星庙陷（天梁祖荫 / 禄存家底）与八字年柱宫成败、财星实虚同参定贫富档。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 偏财不现看父 | 正财有时代父 + 年柱参照 |
| 正印不现看母 | 偏印有时代母（但正印为正母，偏印为继母/养母） |
| 问子女但原局无子女星 | 大运引动时看（大运现子女星也算） |
| 时柱空亡 | 空亡≠无子女，但子女缘薄或关系疏远 |
| 年柱冲刑 | 父母关系不和或早年离家 |

## 输出模板

```text
结论：一句话六亲缘份与关注点。
父母：星宫状态与引动（列断语 id）。
兄弟 / 子女：各自星宫状态与引动。
建议：一个核查或沟通动作。
```

### 示例

```text
结论：父母缘分中等，父星偏财得地；兄弟两人；子女缘正常。
父母：偏财（父星）透干得地（fam_120），父缘较深。
兄弟：比劫不旺（liu_402），兄弟姐妹少或关系淡。
子女：八字子女星得地且无枭印夺食（zv_103），子女缘较稳。
```
