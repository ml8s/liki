# 吉日选择

用于从引擎返回的多日中筛选推荐。

> **字段契约**：只看 engine 黄历实际返回字段（`jian_chu` 建除 / `huangdao` 黄黑道 / `gan_ji`+`zhi_ji` 日忌干支 / `mansion` 二十八宿）。天德/月德/三煞/四离/四绝等日神煞**不在返回字段中，不得臆造**（见 `yiji.md`）。

## 📖 翻译表：吉日优先级

| 优先级 | 条件 | 操作 |
| ------- | ------ | ------ |
| 1 | 事项宜 + 上吉（黄道日 + 建除宜项 + 日忌干支无涉） | **首选推荐** |
| 2 | 事项宜 + 中吉（黄道日或建除宜项居其一） | **次选推荐** |
| 3 | 事项宜 + 平（无吉无凶） | **备选** |
| 4 | 事项忌（建除忌项 或 日忌干支涉该事项） | **跳过，排除** |
| 5 | 黑道日 或 建除破日 | **直接排除，不进入候选** |

## 排序规则

1. 先排除黑道日、建除破日，以及日忌干支冲犯事项的日期
2. 按优先级 1→2→3 排序
3. 同级内优先选择距用户期望日期最近的
4. 输出 1-3 个推荐日
