# Liki 六爻奇门占卜择日 — 六爻算卦 / 奇门遁甲 / 黄历择日

> 覆盖六爻结果与应期、奇门策略与方向、黄历择日。

## 工具契约

agent 经 `counsel` MCP（六爻/奇门）与 `engine` MCP（黄历）使用本域工具，参数见工具 schema；变量绑定与领域边界见 `references/TOOLS.md`。

## 路由

每个占问（六爻、奇门、黄历择日）先经 `references/app/question.md` 锁定目标并 ⛔ 确认方法，确认后按下表进入方法卡；用户明确指定六爻、奇门或黄历时，通过安全校验后优先采用该指定。

| 用户目标 | 方法 | 入口卡 |
| --- | --- | --- |
| 事件结果 / 能不能成 / 何时有结果 | 六爻 | `references/app/outcome.md` |
| 策略 / 进退 / 方向 / 行动时机 | 奇门 | `references/app/decision.md` |
| 哪天适合做事 | 黄历 | `references/app/date.md` |
| 长期命局 | — | 转本命域（natal），不临时起卦 |

## 硬边界

- 高风险主题（医疗、自伤、怀孕、重大人身或财务风险）由共享安全规则识别为 `safety_advisory`；高风险时先列支持资源再解读，工具继续返回正常盘面或择日结果。

## 输出契约

- 先给一句话判断，再列用神、盘面、动爻或择日依据等关键因子。
- 应期只解释 answer 引用且与所问对象相关的候选。
- 结论只基于工具返回的 answer、snapshot 因子或择日事实，不把条件性倾向写成确定结果。
- 竞技 / 赛事类只给态势倾向与条件候选，不预测具体比分或胜负数值。
