# Divination 工具契约

本文只约定流程产物与领域边界；工具、参数与字段以 MCP 自省和 schema 为准，流程见 app 卡。

## 流程产物

- 起卦与排盘返回不可变快照；追问基于同法快照出断语，快照对象原样传递。
- 黄历择日返回连续日期的适配事实，后续步骤直接引用该事实对象。

## 边界约束

- 起卦 / 排盘创建快照，追问基于快照出断语；追问只接受同法快照，快照对象原样传递，不裁剪或重建。
- snapshot 是 immutable 上下文：同一 snapshot 可切换用神或事项从不同角度解读；新事件、新时间、新决策必须新建 snapshot（auto 模式会重新起卦，不得伪装成同一卦）。
- 事项与用神二选一；显式用神仅在用户明确要求时传，优先于事项自动推导。
- 快照摘要只读，不修改、不伪造。

## 黄历择日

engine MCP 黄历能力：返回连续多天的黄历信息；事项给定时按建除事项规则输出适配推荐，只输出日期适配事实，不预测现实结果。

- 问事必填；事项取值以 MCP schema 枚举为准（经 `tools/list` 读取），不自行改写。
- 起始日期、查询天数与事项等参数以 schema 为准。
- 日期范围按服务端默认返回。

## 专占公共边界

奇门专占（失物 / 捕盗 / 走失 / 捕亡）共用以下口径：

- 排盘取默认时家转盘基础盘，不传事项或用神。
- 断语读取快照中的专占断言，只解释工具命中的表内候选；候选并列给出，不合并成单一必然结论。
- 方向与内外由八宫方向表、阴阳遁表投影；中宫无方向 / 内外，用神落中宫时不给对应候选。
