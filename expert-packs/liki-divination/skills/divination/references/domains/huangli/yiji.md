# 宜忌规则

用于理解 engine 黄历查日能力返回的宜忌结论。

> **字段契约**：本表只引用 engine 黄历实际返回字段（`jian_chu` 建除 / `huangdao` 黄黑道十二神 / `gan_ji`+`zhi_ji` 日忌干支 / `mansion` 二十八宿 / `xi_shen` `cai_shen` `fu_shen` / `suitability`+`reason`）。天德贵人/月德/三煞/四离/四绝/杨公忌/大耗/鸣吠日等**日神煞不在返回字段中，不得臆造**——涉及此类表述时以黄黑道/建除/日忌干支近似判定。

## 📥 结论以 engine 判定为准

事项适配由 engine 按**《协纪辨方书》通书口径**逐事项判定，返回 `suitability`（recommended / possible / unsuitable 三档）与 `reason`（命中哪些宜 / 忌规则）。LLM 只解读与渲染这两个字段，**不另行合并判定**；任何自拟的「事项宜忌表」不得覆盖引擎结论。

| `suitability` | 表达 |
| ------ | ------ |
| recommended | 宜（吉） |
| possible | 可用（平） |
| unsuitable | 忌（凶，应避开） |

## 📖 字段用途（名目、吉凶与宜忌一律以 engine 返回为准）

本页不复制黄黑道十二神、建除十二神、二十八宿的名目表与吉凶归类——这些都在 engine 数据与本工具返回里，重列只会漂移：

- `huangdao`：当日黄道 / 黑道，吉凶按返回取值为黄道（吉）或黑道（凶）。
- `jian_chu`：建除序次；当天宜忌一律读 `suitability` / `reason`，不用建除名自拟宜忌。
- `gan_ji` / `zhi_ji`：彭祖百忌文案。读当日返回文案，按关键字（开仓 / 栽植 / 修灶 / 穿井 / 问卜 / 冠带…）对号入座，优先采信 `reason` 已列出的命中项。
- `mansion`：二十八宿。吉凶归属以返回宿名为准，不确知时降级为「平」。
- 天德贵人 / 月德 / 三煞 / 四离 / 四绝 / 杨公忌 / 大耗 / 鸣吠日等不在返回字段中，不得臆造；需近似表述时以建除 / 黄黑道 / 日忌干支替代。

## 📖 组织输出

先读 `suitability` 定吉凶基调，再引用 `reason` 命中的建除/黄道/日忌/宿条目说明依据；`reason` 缺失或为空时按 `suitability` 直接输出，不自行合成等级，不臆造字段。
