# 旺衰判断

## 📋 方法论：旺衰与气势

### 📥 核心口径（引擎为准，不自行查表）

身强弱、从格与旺衰状态均由 engine `bazi_fullchart` 计算，LLM **只读字段、不重算**：

- `fu_yi.qiangruo`：身强 / 身弱 / 中和（最终定性）。
- `fu_yi.pattern`：从格标签（如从旺格 / 从弱格 / 假从格）。
- `fu_yi.wang_shuai`：五行旺相休囚死。
- `fu_yi.basis`：三得输入——`season`（月令旺相休囚死，得令）、`root_type` + `day_master_roots`（得地，强根/弱根/无根）、`yin_bi_count`（印比数量，得势）、`relation_facts`（相关关系投影）。
- `ten_god_states` / `element_states`：十神与五行显隐、通根、得令、旺弱。

三得是**概念口径**：得令（月令旺相）、得地（通根）、得势（印比帮身），三者综合定性，得令最重。数值已由引擎算好，组织断语时引用上述字段作为证据，不得用任何自建表重新推导。

十二长生（`chang_sheng` 全表 / 各柱 `day_master_trend` / `月令` 等）只作**地势修饰**读法（如审日主在地支的进退象），不作身强弱口径。

### 从格

从格标签由 engine `fu_yi.pattern` 输出，按 `data/congge_rules.json` 判势之纯度（印比满盘无克泄耗→从旺；官财食伤满盘、日主无根无助→从弱；有微根但势极偏→假从）。LLM 读字段，不自行判格。

- 从格不论正格，不适用三得旺衰判断；见 `yongshen.md`「从格处理」。
- 从格关键不是比例多少，而是有无对抗力量：有一点印比对抗官杀不成从弱，有一点官杀对抗印比不成从旺；有微根被合克仍可从，有微根得生扶不从。

### 天道、地道、人道

- **天道**：看天干之配合，天干主动，主外在表现
- **地道**：看地支之配合，地支主静，主内在根基
- **人道**：看干支之间的配合关系，判断人的行为和选择

### 气势流通

命局喜五行流通，不喜阻滞。

- 金生水、水生木、木生火，一路顺生 → 气势流畅，人生顺遂
- 某五行过旺或过弱造成堵塞 → 需通关之物。如金木相战，取水通关

### 核心口诀

- **旺极宜泄不宜克**：旺到极致反而喜欢被泄（食伤泄秀），克之则犯旺
- **衰极宜扶不宜帮**：弱到极致不能再帮扶（从弱格），帮之则激怒旺神

### 十神生克

- **相生**：木→火→土→金→水→木
- **相克**：木→土→水→火→金→木
