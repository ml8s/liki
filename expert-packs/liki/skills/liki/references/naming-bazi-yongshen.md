# 起名用神消费

## 数据流

出生信息明确时，起名先取得八字用神裁决，再进入选字：

```text
出生信息
  → 排盘
  → 用神裁决（只裁决一次）
  → 取字
  → 组名
  → 起名校验
  → 输出
```

用神裁决由 MCP 的八字用神能力给出，领域方法属于八字域。起名只消费裁决结果，不重新推盘，也不重新比较扶抑、调候、格局与从格。工具能力、参数和返回字段由 MCP 自省与 schema 提供。

裁决结果是起名唯一的用神来源，包含最终用神、喜神、忌神、状态、命中规则、冲突与来源摘要。选字与校验使用同一组喜忌。

## 消费规则

| 裁决结果 | 起名用途 |
| --- | --- |
| 用神 | 首选补益五行 |
| 喜神 | 次选补益五行；双字名在「用 + 用」不足时回退「用 + 喜」 |
| 忌神 | 候选名避忌的五行 |
| 状态 | 已定（resolved）/ 部分确定（partial）进入选字；待复核（needs_review）/ 未决（unresolved）先提示复核 |
| 冲突 | 说明证据缺口或冲突来源 |
| 来源摘要 | 传入起名校验，绑定同一份用神来源 |

## 候选冲突处理

| 候选关系 | 起名处理 |
| --- | --- |
| 用神与喜神同五行 | 合并为一个补益方向 |
| 双字名首选两字同用神 | 直接采用「用 + 用」 |
| 同用神字池不足 | 第二位回退喜神字池 |
| 喜神为空 | 第二位继续使用用神字池 |
| 忌神命中候选字 | 从候选中剔除，保留淘汰原因 |
| 待复核 / 未决 | 输出待复核用神与缺失证据，等待复核后继续 |

## 无完整出生信息

时辰缺失或用户选择期望五行时，起名进入五行策略分支：用户指定五行则按指定五行取字；用户选择「不限」则合并五个字池。输出明确标注「未评估用神」。

## 输出

起名结论输出：

```text
用神：{yong}；喜神：{xi}；忌神：{ji}
来源：{policy_id} / {rule_id}
状态：{status}
选字：用神字池、喜神回退、忌神淘汰
```

起名校验回传用神来源，候选名点评引用同一份来源与状态。
