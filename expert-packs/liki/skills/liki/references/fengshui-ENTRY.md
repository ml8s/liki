# Liki 家居风水 — 八宅命卦 / 玄空飞星 / 风水布局

> 覆盖八宅命卦、门主灶与方位吉凶，以及玄空飞星、元运和流年盘。

## 工具契约

agent 经 `engine` MCP 使用八宅排盘、八宅布局、玄空排盘与玄空流年能力；工具与参数由 MCP 自省和 schema 提供。

## 路由

所有风水 / 家宅 / 布局 / 流年飞星问题读取 `references/fengshui-app-fengshui.md`，卡内再分八宅与玄空分支，冲突在本卡「八宅 / 玄空合参与裁决」节分层裁决。

## 硬边界

- 玄空排盘能力返回带摘要的完整宅盘；流年盘使用同一宅盘时摘要必须匹配，原样传递。
- 八宅只需要出生年份和性别；玄空不需要命主出生日期，需要宅运起盘日期与房屋坐向。
- 玄空坐山与向山必须相对 180°（二十四山相隔 12 位）；同山或任意两山组合不是合法坐向。
- 二十四山 index 与山名映射以 MCP schema 为唯一事实源，本卡不复制；解读时优先复述返回的坐山名与向山名，让用户确认。
- 缺房屋坐向 / 宅运日期时先询问；缺出生年份或性别时先询问命卦所需参数。
- 阳台、大门与主要采光面朝向可能不同；排盘前必须确认以哪一项作为坐向依据。

## 输出契约

- 首句给布局判断，随后列命卦 / 飞星 / 元运依据。
- 八宅与玄空冲突按 `references/fengshui-app-fengshui.md`「八宅 / 玄空合参与裁决」分层裁决，两个体系的证据都如实呈现。
- 每个建议绑定具体方位和引擎因子；冲煞或凶方同时给可行动调整。
- 方法论卡把 `youxing` / `rating` / 飞星等工具字段翻译成含义与化解；吉凶口径以工具字段为准。
