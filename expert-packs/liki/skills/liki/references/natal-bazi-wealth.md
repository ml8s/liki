# 财运判断规则

## 📖 断语核心

财星定有无，身强定胜负，大运定起伏。

**注**：财星在地支有藏干同五行为"有根"。临官/帝旺位为"强根"，余气/墓库位为"弱根"。

### 财多身弱（以 `cai_104` / `ge_302` 断言为准）

- 身弱 + 财旺 → 财多身不任，财难存 / 富屋贫人（《三命通会》）；得财信号仍按表列证，不整体阻断
- 身弱 + 财平 → 财可担但有限，不以大财论
- 身强 + 财旺 → 正常得财判断

## 大运引动

- 财星大运 → 财务事务增多；吉凶须看身强弱与喜忌
- 比劫大运 → 争财 / 分财风险增强；是否破财须看财星根气、护财结构和命主承受力
- 官杀大运 → 压力生财（辛苦得财）
- 食伤大运 → 技术/投资得财

## 📖 翻译表：财运判断

**输入**：财星状态 + 身强弱 + 大运类型 + 比劫位置
**输出**：财运档

### ④ 比劫争财检查

`比劫争财` 是结构候选：比劫旺且财星现。它不等于必然破财。

| 状态 | 命理表达 |
| ------ | ------ |
| 财星弱 / 无根，遇比劫旺 | 弱财被劫：财来财去，难积蓄 |
| 财星得令 / 有根，遇比劫旺 | 有财被争：有赚钱机会，但分财、合伙、借贷压力增大 |
| 比劫与财星相邻 | 争财信号更直接 |
| 比劫与财星隔位 | 竞争较缓，须引动 |
| 有官杀制比劫、食伤通关得宜 | 争财风险减，须整体合参 |

### ⑤ 食伤生财检查

食伤为财之源。食伤状态直接影响财星健康度。

**判断链**：食伤生财为"因"，比劫争财为"竞争压力"。先判断财源是否成立，再判断比劫是否分夺。

- 食伤生财且无比劫争财 → 顺遂得财，财能留存
- 食伤生财但比劫争财 → 辛苦得财，财来财去；若财星有根，表现为有财难守
- 无食伤生财且弱财被劫 → 无稳定财源还被劫，财务困境

### ⑥ 财印关系检查

财和印相克（财克印为正克）。财印关系决定财富能否转化为长远根基。

**身弱时财印关系更关键**：身弱不胜财，财星透干反克印→财为压力非财富，得财即损根基。

### ⑦ 财运流年应期排队列

候选年份优先级（参考 dayun.md「应期决策表」）：

| 优先级 | 条件 |
| ------- | ------ |
| 1st | **换运年（±1年）** > 普通年份 |
| 2nd | **财星透干+食伤生财双重引动** > 单重引动 |
| 3rd | **财星合入命（六合/三合引动财星）** > 财星冲入命（冲则变动不定） |
| 4th | 财星值年（流年干支与财星相同）> 食伤生财年 > 比劫夺财年 |

**用法**：多个候选年份时从第1维开始比，第一个分出高低的维度决定应年；本排队为方向提示，最终以断言与独立证据闭环为准。

### 破财引动细分与理财判据

#### 破财按引动方式细分（断"何年/如何破财"必查）

- **驿马 + 比劫** → 外出合伙破财（合作散财）
- **偏印为忌 + 比劫争财** → 被熟人所欺/合伙受骗
- **比劫 + 偏财无迁移** → 借贷纠纷/合伙财务风险，须防欺诈信息差
- **身弱财多** → 财多身弱漏财，破财最重段 = **财星忌神旺相段**；比劫运帮身反主得财，不作破财论
- **冲刃/刑开财库**（见 `references/natal-bazi-dayun.md` 冲刃·刑开财库）→ 破财不作制刃吉论；未开库时财星入墓按 `cai_201` 蓄财之象读，两面并列

**理财/积蓄判据**：弱财被劫 / 财无根 → 无蓄财观念（钱来财去）；若财星得令有根而遇比劫，多为有财难守而非无财。断"经济状况/积蓄"看财星本身与比劫，不看其他吉神
