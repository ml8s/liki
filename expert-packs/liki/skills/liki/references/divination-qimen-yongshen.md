# 奇门用神取用

> 命理依据：《烟波钓叟歌》用神取用章。求测人以日干 / 年命干定位，事象以门、星、神、干组合定位。

## 符号域

符号取值以 MCP schema 与排盘输出为准，本页不复制枚举。只记两条边界：甲为遁甲，不作独立符号；转盘 / 洛书飞盘 / 鸣法飞盘的门、星、神名差异以方法字段为准，名目见 `references/divination-qimen-bamen.md`、`references/divination-qimen-jiuxing.md`、`references/divination-qimen-bashen.md`。

普通问事用事项用神；编排层查事象表转为显式用神，engine 只接收显式用神。事项用神与显式用神互斥；高级用户可直接传显式用神。

## 事象 → 用神

`qimen_matters` 数据表（排盘内部维护）是事象到用神的唯一事实源；本页不复制该表，只解读工具返回的 `yong_shen.symbols[]`。表外问事先映射到表内问事；无法映射时说明无封闭用神规则，不得按五行临场类象。

走失人口按表内角色读取（《奇门遁甲元灵经·占走失》：时干为失主，六合为走失之物，以落宫分内外远近）：时干宫为失主，六合宫为走失者，再以内外宫论远近；不套用“日干为我、时干为事”的通用读法。

## 格局识别边界

`patterns` 只返回格局表已收录且满足同宫条件的格局，不承诺全量格局识别。未命中时只说明“本表未命中”，不得临场补格局名。

## 解读顺序

1. 引用 `method` 说明家法、盘式、定局与主柱。
2. 以日干宫为“我”、时干宫为“事”、年命干宫为本命根基。
3. 读工具投影的门星吉凶本质（`factors.doors[].ji_xiong` / `factors.stars[].ji_xiong`），作为吉凶主据。
4. 再读 `yong_shen.symbols[]` 的落宫、天盘干、空亡与马星——空亡/马星只作力量与时点修饰，不覆盖门星吉凶本质。
5. 用 `ri_shi_relation` 判断我与事的生克。
6. 叠加值符值使、格局、门迫门制、星宫五行与克应；凶象叠加量级以 snapshot `judgments` 字段为准（`qimen_judgment_rules.json`）。
