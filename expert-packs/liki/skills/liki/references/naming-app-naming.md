# 通用起名/改名

> 场景：新生儿起名、成人改名。外国人起中文名 → `references/naming-app-foreign.md`；自选名字评估 → `references/naming-app-selfcheck.md`。

## 依赖的领域知识

[必读] - bazi: `references/naming-bazi-yongshen.md`「用神计划」+ `references/naming-bazi-calibration.md`「出生时辰判定（起名精简版）」
[必读] - qiming: `references/naming-qiming-ziku.md`「字库与选字」

## 流程

| 步骤 | 类型 | 条件 / 目标 | 动作 | 产物 |
| --- | --- | --- | --- | --- |
| 1 | 排盘 | 时辰明确 | 排八字，取 `用神裁决能力`；可用时传完整 `选定用神` | 用神计划 |
| 1 | 排盘 | 仅日期或时辰模糊 | 先问一次以确认时辰；仍无法确认时不排八字，改走期望五行分支 | 未评估八字计划 |
| 1 | 排盘 | 无出生信息 | 询问期望五行；“不限”则不传五行计划 | 无计划或用户计划 |
| 2 | 💬 参数收集 | 命名参数 | 一次确认单 / 双名、风格、必含、避讳、叠字、出处偏好；缺省为均衡风格、无必含 / 避讳、不允许叠字、出处优先但不强制 | 参数与默认值 |
| 3 | 取字 | 五行角色 | 默认 `第一用神=yong`、`第二用神=yong`；不足或音义更好时用 `yong + xi` / `xi + yong` | 角色字池 |
| 4 | 组名 | 机械组合 | 使用组名能力 | 候选名 |
| 5 | 校验 | 工具事实 | 使用起名校验能力，传同一个 `选定用神` | 字库、音韵、逐字 `五行角色` |
| 6 | 候选输出 | 按模板精选 | 推荐、优点、可商榷点、淘汰代表 | 候选清单 |
| 6a | ⛔ 阻塞确认 | 用户选定终选名 | 展示首选与编号选项；等用户回复后才能继续 | 终选名 |

### 交互模板

```text
2 💬 只输出：1.单 / 双名（默认双字名） 2.风格（默认均衡） 3.必含字（默认无） 4.避讳字（默认无） 5.叠字（默认不允许）。回复“都用默认”可直接跳过；不提前执行后续步骤。
6a ⛔ 只输出：首选推荐「{名}」({拼音})、一个优点 / 可商榷点、其他候选；选项 1.确认首选 2.看其他候选详情 3.换方向。停在这里，等用户回复后继续。
```

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 候选不足 5 个 | 放宽语义、出处或音韵过滤；仍不足则如实少给 |
| 用户不满意 | 放宽非五行约束，或改用 `yong + xi` |
| 必含字不在字池 | 说明冲突，询问保留五行角色或调整必含字 |
| 长辈同音字无法核对读音 | 请用户提供拼音；未提供时只避 exact 字 |
| 组名能力报字符错误 | 只能改用取字能力返回池中的字 |
| 起名校验标记 invalid | 丢弃该候选并保留 invalid 原因 |

## 输出模板

> 输出依据时：引用工具返回的断语 ID 和该断语的经典依据简引（`source.classic_basis`），格式为 `断语 ID —— 经典简引`。

```text
结论：首选名与逐字五行角色依据。
候选：5-8 个候选（名 + 拼音 + 五行 + 出处等级）。
推荐理由：字义、音韵、出处、逐字 `五行角色`。
淘汰代表：不推荐名与具体原因。
```

### 示例

```text
结论：推荐「陈梓梓」（zǐ zǐ，木木）为首选；两字角色均为 yong。
候选：陈梓梓（yong/yong）、陈梓林（yong/yong）、陈楚桥（yong/yong）。
推荐：字义、音韵与出处适配，且两字均命中 yong。
```
