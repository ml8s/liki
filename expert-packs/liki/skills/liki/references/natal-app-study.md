# 学业分析

## 流程

| 步骤 | 条件 / 目标 | 合参所需信息 |
| --- | --- | --- |
| 1 | 印星与学习能力 | 八字 + 紫微：学业本命（印星状态与学习特点；文昌文曲） |
| 2 | 求学阶段 | 八字 + 紫微：学业应期（关键年 / 十年窗口） |
| 3 | 学历倾向 | 八字 + 紫微：学业本命（学历档与依据） |
| 4 | 具体细节或流年 | 八字 + 紫微：学业本命；八字 + 紫微：学业应期（目标年，含文昌文曲、化科、流年命宫） |

## 📖 双盘学业合参

- **入学能力**：紫微文昌 / 文曲化科入官禄或命宫 + 八字官杀生印 / 食伤泄秀 → 入学能力在；毕业档按八字学历档护栏判。
- **流年应期**：紫微流年命宫 / 福德宫昌曲化科与八字印星引动同参，定考试有利窗口。

## 边界条件

| 异常场景 | 处理方式 |
| --------- | --------- |
| 成年人问学业（非在校） | 学历定档按原局印星终生有效；大运影响按当前运判断深造/进修可能 |
| 原局无印星 | 查食伤（技术学习能力）+ 官杀（压力中学业） |

## 输出模板

```text
结论：一句话学历层次与学习特点。
依据：印星状态与格局、文星引动（列断语 id）。
应期：考试 / 升学有利年。
建议：一个可行的学业动作。
```

### 示例

```text
结论：学历中上，考试运中等偏吉。
依据：印星得令为用，身强能任印；文昌入命（sh_302）。
应期：2026 丙午流年官杀生印，考试有利窗口。
建议：2026 年报考有优势；2027 丁未年食伤旺制印，需提前准备。
```
