# 十二宫分析要点

## 📖 决策表：十二宫解读

| 宫位 | 分析要点 |
|------|---------|
| 命宫 | 主星+辅星组合，决定性格和人生基调 |
| 兄弟宫 | 兄弟姐妹关系，母亲缘 |
| 夫妻宫 | 桃花星（贪狼/廉贞/天同）状态，配偶特征 |
| 子女宫 | 子女缘，桃花余气 |
| 财帛宫 | 财运类型，理财能力 |
| 疾厄宫 | 先天体质，易感疾病 |
| 迁移宫 | 外出运，人际关系 |
| 交友宫 | 朋友助力，社交圈 |
| 官禄宫 | 事业方向，社会地位 |
| 田宅宫 | 房产运，家庭根基 |
| 福德宫 | 精神生活，福气厚度 |
| 父母宫 | 父母关系，童年背景 |

**空宫处理**：命宫无主星时，借对宫（迁移宫）主星为断。
