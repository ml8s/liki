# 十神组合场景化
## 📖 翻译表：十神组合

十神组合不能只说"杀印相生贵格"，须说明在人生中的具体应事方向：

| 组合 | 应事场景 | 不应事场景 |
|------|---------|-----------|
| 杀印相生 | 压力大的环境中反而能学习成长；被挑战时发挥最好 | 轻松安逸的环境中难以发力；不适合自由散漫的岗位 |
| 伤官配印 | 技术/学术领域有天赋；以专业技能立足 | 纯管理岗或纯执行岗（需要创造空间） |
| 财官相生 | 资源换地位；在商业环境中攀升 | 体制内完全按资历排队的岗位（需要市场验证） |
| 食伤生财 | 才华变现；创意/内容/咨询类工作 | 固定流水线或按部就班的工作体制 |
| 比劫争财 | 适合合伙但有分配风险 | 独享型商业模式（需要分钱机制） |

## 📖 七杀强度与性格换算

七杀主胆量、冲劲、冒险精神。其性格表现取决于七杀的**强度状态**（有根与否、有无制化）。

| 七杀状态 | 性格表现 | 判断条件 |
|---------|---------|---------|
| 七杀有强根或弱根 | 胆大冒险、有冲劲、敢闯敢拼 | 地支有同五行藏干（临官/帝旺为强根，余气/墓库为弱根）|
| 七杀无根（虚浮透干） | 谨慎克制、不冒险、循规蹈矩 | 天干透但地支无同五行藏干 |
| 七杀无根被印化 | 杀被印转化，反主保守谨慎 | 七杀无根 + 印星相邻/同柱 + 印星有力（有根或得月令）|
| 七杀有根有制（食神制杀） | 有胆量但不鲁莽，能化解风险 | 七杀有根 + 食神紧邻克制 |

**用法**：先定七杀有无根，再查是否被印化或被食神制，最后对照上表。
**关键反转**：七杀无根被印化时，性格方向与七杀典型特征相反——杀越弱越谨慎。
**注**：被印化的前提是印星有力（有根或得月令）。印弱则化杀不力，不适用"反主保守谨慎"行。

## 📖 判断原则

- 性格/能力看**十神组合**，不以单一十神定论。同是正官，正官+正印与正官+七杀性格完全不同
- 十神被合走后，对应的性格/能力特征大幅减弱或消失
- **【强制】身强弱前置**：断性格/能力前，必须先按 `domains/bazi/fangfa/wangshuai.md` 判定身强弱，再取十神象——**同一十神，身强/身弱取象相反**：
  | 十神 | 身强时 | 身弱时 |
  |------|--------|--------|
  | 七杀 | 冲动、魄力、敢闯敢拼 | 胆小怕事、心气压抑、易被欺 |
  | 正官 | 自律、有领导力、责任心 | 顺从、压力大、易焦虑 |
  | 印星 | 依赖、保守、被动 | 受庇护、知书识礼（印为用时） |
  | 比劫 | 独立、竞争、好胜 | 依赖同伴、易被夺 |
  | 食伤 | 才华外露、表现欲强 | 想法多但难落实 |
  | 财星 | 能任财、理财好 | 财来财去、守不住 |
  - **反例**：七杀透干+身弱 → 断「胆小压抑」而非「冲动」；印旺+身弱 → 断「知书达理」（印为用）而非「依赖」

## 女命婚姻——官杀混杂判断

女命以正官为夫、七杀为偏夫/情人。官杀混杂（正官七杀同时出现或均暗藏）时婚姻复杂。

**取清规则**（《子平真诠》"官杀混杂取清为贵"）：
1. **有合则取清**：合杀留官（七杀被合走，只留正官）→ 婚姻由浊转清
2. **有冲则取清**：冲去多余的一颗 → 看被冲走的是正官还是七杀
3. **无合无冲** → 官杀混杂无法取清 → 婚姻复杂，至少两次婚姻或长期情感困扰

**判断流程**：
- 第一步：原局正官几位？七杀几位？
- 第二步：有合化取清吗？（合杀留官 / 合官留杀）
- 第三步：有冲克取清吗？（冲去七杀留正官）
- 第四步：混杂无法取清 → 感情多波折

## 📖 制化优先规则【强制——取象/定性格/职业前必查】

同一十神被印制/被合/被制化时，其主导特征**降级**，先列被制化十神再定权重：

- **伤官配印**：伤官双透/旺，但正印透干（印制伤官）→ 伤官的出风头/急性子/叛逆收敛，主象转技术型+涵养+印系可靠；性格选项优先取"内敛有才"，不取"外向张扬"
- **七杀有制**（食神制杀/印化杀）→ 七杀的冲动/胆大被约束，主象"有胆识但不鲁莽"
- **财被比劫合/夺** → 财的享乐/经商象降级，主象转"财务受制、钱不由己"
- **官杀被合**（合官留杀/合杀留官）→ 官杀的事业压力/婚姻主导性降级

**用法**：判断性格/职业/事件性质前，先问"该十神是否被制化？"，被制化则其特征不作为主象。

### 📖 格局病处优先【强制——性格/出身/状态类取象前必查】

**先断格局病处，再取表面吉星象**。命局有典型"病处"组合时，其对应的受压/劳碌/忍让/家道中落类象**优先于**吉星/吉神的表面象：

- **伤官见官**（伤官旺 + 官星弱被制）→ 主"受压制、敢怒不敢言、命主或对象被管束"，先于"聪明外露/技术才"取象
- **财坏印**（财星克破印星）→ 主"为财奔波、母劳/离家早、学识被财耽误"，先于"财旺能赚"取象
- **劫财夺财**（比劫旺克财）→ 主"家道中落、钱财留不住、兄弟朋友分财"，先于"财星当令"取象
- **枭神夺食**（偏印克食神）→ 主"情绪压抑、多思多虑、才华被抑"，先于"食神生财"取象
- **七杀无制**（七杀旺无食制无印化）→ 主"压力逼迫、易招是非官非"，先于"杀印相生"取象

**用法**：性格/出身/状态题定案前，先逐项排查上述病处组合；命中任一 → 该组合对应类象为主信号，吉星象降为次信号；禁止用"某星庙旺/某神煞入命"一句带过病处。
