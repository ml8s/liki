# 大运分析方法论
## 📋 方法论：大运应期

## ⚠️ 数据来源强制检查

开始大运推理前，必须先确认以下两项数据已从引擎 RPC 排盘返回中获取，而非自行推算：

1. **大运排列表**：每步大运的干支（天干+地支）和起止年龄
2. **起运年龄**：以引擎返回为准，不默认任何年龄

如不确定数据来源，回溯到 domains/bazi/SKILL.md「排八字→取全量数据」步骤确认排盘 RPC 已调用并获取完整 `dayun` 数据。

## 大运与命局的互动

每步大运须从三个维度分析：

**大运干支与命局的关系**
- 大运天干与四柱天干：生合冲克刑
- 大运地支与四柱地支：六合三合六冲六害
- 重点关注：大运冲合原局哪个柱，该柱对应的宫位和十神

**大运对用神的作用**
- 大运生扶用神 → 得运，该运有利
- 大运克制用神 → 失运，该运不利
- 大运助忌神 → 该运需谨慎

## 十年分治

每步大运不能笼统概括，须细分：

**前五年（天干主导）** — 大运天干的力量在五年中逐步增强，前五年受天干影响更大
**后五年（地支主导）** — 大运地支的力量在后五年显现，地支冲合的影响在后五年更明显
**换运年** — 前后两步大运交接之年（前后各一年），是人生节奏切换的关键节点，工作/感情/健康容易出现重大变化

## 大运与流年的配合

大运定十年基调，流年看当年应事。判断方法不是简单的"生扶=吉/克制=凶"，而是看组合后对原局用神/忌神的影响：

- 流年与大运配合后生扶用神 → 吉
- 流年与大运配合后引发忌神 → 凶
- 流年虽克大运，但克的是大运中的忌神 → 反为吉
- 流年虽生大运，但生的是大运中的忌神 → 反为凶

## 冲合关系

冲与合是两种不同性质的作用：

- **冲**：事件性质为突发/断裂/变动（性质为负），结果走向取决于冲去用神还是忌神。冲入年柱→祖辈/根基变动，冲入月柱→家庭/事业环境变动，冲入日支→婚姻/自身变动，冲入时柱→子女/晚年变动
- **合**：牵绊、聚合、持续性事件。合绊→被牵制放不开，合化→性质改变，合动→被引动为应期

**断凶事时信号权重：冲 > 合**
- 冲：事件性质为突发/断裂/变动，本身即为凶的信号
- 合：中性，需看合化结果。合化用神为吉，合化忌神为凶
- 合动不等于凶：合动只是"引动"，结果取决于引动的是什么星
- 冲与合同时出现时：先按冲定性（判断有无断裂/破坏），再看合是否有解救作用

**判断常规事时**：先看是否有冲（冲比合更直观应事），再看是否有合解救（冲被合解则力度降低）
- 天干论合先于论冲（天干合化重于冲克），地支冲与合并行分析

## 天干地支分论

- **天干**：主外显之事、上半年（1-6月）、社会层面、可见变化
- **地支**：主内隐之事、下半年（7-12月）、个人层面、内在变化
- 天干透出的十神决定事件性质，地支的冲合决定事件力度
- 流年对命局的影响：天干先作用于天干，地支先作用于地支

## 应期推断

同一方法适用于六亲、财运、事业、健康、感情等所有领域。

### 第一步：确定目标

| 目标 | 对应 |
|------|------|
| 父亲 | 偏财星 + 年柱 |
| 母亲 | 正印星 + 年柱（正印为生母，偏印不为母） |
| 配偶 | 男命正财/女命正官 + 日支 |
| 子女 | 食伤星 + 时柱 |
| 财运 | 正偏财星 + 财帛宫 |
| 事业 | 官杀星 + 官禄宫 |
| 健康 | 日主 + 忌神 + 疾厄宫 |

### 第二步：大运引动

大运给时间窗口。大运的如下行为打开应期窗口：

- **冲**：冲目标星或目标宫位 → 该运为该领域的窗口
- **合**：合住目标星 → 受牵制；合化 → 性质改变
- **克**：大运干支克制目标星 → 凶应窗口
- **生扶**：大运生扶目标星 → 吉应窗口
- **值**：大运干支与目标星/宫位完全相同 → 最强烈的引动

### 第三步：流年应事

流年定具体时间。如下情况为强应期：

- **双重引动**：大运+流年同时引动同一目标 → 强应年
- **三重引动**：大运+流年+命局自刑冲 → 极强年
- **引动强度分级**：三重>双重>单重。有多重引动的年份优先级高于单重引动
- **换运叠加**：换运年前后一年+流年引动 → 特殊窗口
- **伏吟**：流年与目标宫位相同（年柱伏吟→父母事）

### 应期精度

- 流年定年，流月定事
- 换运年（前一年交运+后一年）= 重点窗口
- 换运年叠加流年冲刑 = 重大变化概率高
- **【强制】精确到年**：断「何年发生何事」类题，必须给出**具体年份**（大运窗口 × 流年引动），禁止只断「有/无」或模糊区间。应年 = 大运引动（窗口）× 流年强引动（双重/三重）取交集

### 📖 翻译表：候选年份应期断法（传统命理，无计分）

**断法**：应期年份 = **大运为根（大运窗口）× 流年为用（流年对目标星/目标宫位的真实引动）**。多候选年份取舍时，按「应期优先级排序」逐项比较（值宫/伏吟 → 宫位引动 → 星动 → 换运加权 → 引动方式），以**引动最充分且合命理次序**者为准；次序相同者取最先发生。

**硬性要求**：
- 禁止单信号定年（只凭红鸾/流马/六合/羊刃一个信号就定年）
- **紫微四化只作佐证**——不得因"无化禄/有化忌"排除八字主信号已成立的年份（四化方向常与八字相反，冲突时以八字用神为纲）
- **凶信号≠排除**：正确年份常伴随冲/比劫/官杀攻身等凶象，只要目标星或目标宫位被引动就保留
- **健康/牢狱/手术专项**：
  - 牢狱官非 = **官杀攻身 + 印星无救**（忌神年）
  - 手术部位 = 被冲克的**五行对应脏腑**（火=心/眼/血，木=肝/胆/头，金=肺/肠/皮肤，水=肾/膀胱/骨，土=脾/胃/肉）
  - 断部位必须看**流年冲克的是哪个五行**，不是固定「日主五行=某器官」

### 📖 翻译表：应期优先级排序

**输入**：窗口内的多个候选年份 + 各年份的引动类型
**输出**：取优先级最高的（>1个同优先级时取最先发生者）

#### 按维度逐级筛选（越靠上越优先）

| 优先级 | 维度 | 规则 |
|-------|------|------|
| 1st | 值宫/伏吟 | **流年地支值目标宫位**（伏吟、值宫位）→ 一级引动，一律入候选，不得以“忌神/星未透/强度不足”否决 |
| 2nd | 宫位vs天干 | **目标宫位被合/冲/刑/害（宫位引动）** > 目标星天干透出/合（星动） |
| 3rd | 时段 | **换运年（±1年）仅在直接引动目标星或目标宫位时加权**；禁止仅因“换运+叠加”跨级压过 1st/2nd |
| 4th | 叠加效应 | 三重 > 双重 > 单重（仅在同一引动方式内比较，不得跨引动方式比较） |
| 5th | 引动方式（断凶事） | **六冲** > 三合 > 六合 > 六害 > 相刑 |

**用法**：多个候选年份时，从第1维开始比。第一个分出高低的维度决定优先级。

**铁律（禁止违反）**：
- **凶信号≠排除**：应期年常伴冲、比劫、官杀攻身等凶象，只要目标星或目标宫位同时被引动就保留候选，禁止一票否决。
- **六合合化须验条件**：合化需月令助化神等成立条件，未验证不得论“合化出某五行”并据此排除选项（合绊/合动不作合化论）。

**额外规则（应期推断必查）**：
- **三合/三会局夺根**：参与合化的用神地支视为被合走，不得当旺根救身（例：巳被巳酉丑合化 → 巳火不提供日主旺根）。
- **童限（未上运）凶应**：大运未起时仍按“流年合局 × 原局忌神”论凶，不作自动减分。
- **无六冲≠排除突发事故**：交通意外/车祸类改查驿马、迁移宫、灾煞/金舆及流年×大运组合，禁止用“全年无六冲”单项硬排除。

### 📖 附加硬信号（与候选年份评分表并列，命中即一级候选）

- **六亲入墓**：流年/大运地支为六亲星（父=偏财、母=正印）之**墓库且伏吟/引动**（如丑为癸水偏财之墓，大运丑+流年丑）＝父/母大灾**一级应期**，须与"入库得财"取象对比后裁决（六亲优先）
- **紫微宫位应期（主信号级，与①②③并列计分）**：红鸾坐流年夫妻宫；流年命宫落迁移宫（搬迁/出国）；流年命宫落目标领域宫且吉化（如太阴禄入子女宫=儿童领域）；流年命宫落田宅+太阳化禄=搬迁定居
- **迁移/出行类专用信号**：流年命宫落迁移宫、驿马伏吟/逢冲、换运叠加 → **优先于"六冲>六合"引动方式排序**（原第 5 维仅适用断凶事，迁移应期不得误用）
- **凶象优先于吉化**：驿马+羊刃+迁移化忌（出行意外）、冲刃（身强羊刃逢冲=破财/血光，不作制刃吉论）、刑开财库（受损不作得财）——此类凶象成立时，流禄/流昌/流魁等小吉星**不得反转定案**

### 📖 领域目标锁定与紫微吉化降权【强制——应期裁决护栏】

- **引动目标按领域锁定**：健康=日主+忌神+疾厄宫；婚姻=日支/夫妻宫；子女=时柱/子女宫；父/母=偏财/正印+年支。宫位引动只在本领域目标内比较，**禁止用他领域宫动判他领域事件**（如"冲夫妻宫"不得判健康"谁得病"）
- **八字凶信号 > 紫微吉化**：比劫克食伤/忌神攻身/冲刃成立时，流禄/流鸾/流钺/流昌/流魁/四化只作"应事领域提示"，**禁止作"纯吉定案"**，更不得否决八字主信号已对齐的年份
- **硬信号冲突决策表**（分属不同年份时按此优先级）：① 月柱天克地冲/反吟 → ② 冲目标宫位 → ③ 目标宫位合动/值宫 → ④ 大运流年伏吟 → ⑤ 驿马/换运年。同分取**最先发生者**
- **领域取象以流年四化所入宫位主星为准**：禁止用大限主星硬套领域（如大限天府≠必房地产；太阴禄入子女宫=儿童领域优先）
- **六亲事件优先于自身吉象【强制】**：流年事件题（该年发生何事）中，**六亲星受克合绊/六亲宫被冲（父星被合、父宫伏吟、印星受制、财星受损）优先于自身吉象**（官星合身、贵人、吉化、升职信号）——先查六亲灾，再查自身吉，禁止用"官合身+吉化"盖过"父星被合+父宫伏吟"
- **三合局/贵人修饰化【强制】**：三合局成形、天乙贵人、禄马交驰**只表该年环境有利，不作事件已发生的直接证据**——须叠加目标星或目标宫位实引动才定事；禁止"见三合局+贵人即断吉事已发生"（事业突破/得子/得财类）
- **凶象优先于吉化仅限出行/迁移专项**：不得压过同年的婚姻/事业主信号；凶象与吉象同年并存时按领域目标分别计分
