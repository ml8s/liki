# 考时校准
## 📋 方法论：出生时辰校验

时辰确认方法，用于出生时间不确定时，通过已发生的人生事实反向验证时辰。

## 适用规则

| 场景 | 操作 |
|------|------|
| 成人用户 | 建议考时确认 |
| 宝宝/青少年 | 跳过考时，走默认输入时辰 |
| 用户已明确确定时辰 | 跳过考时，以用户确认为准 |

## 前置检查（防呆）

**以下条件全部满足才能开始考时，否则阻断并说明原因：**

- □ 命主为成人（宝宝/青少年跳过此步）
- □ 排盘 RPC 已调用，候选时辰对应的 `bazi.chart` 已完成（未排盘→先去排盘）
- □ 候选时辰 ≥ 2 个（<2 → 不需要考时，直接走默认时辰）
- □ 用户已提供 ≥ 3 件人生大事及年份（<3 → 精度不足，建议延后考时或接受低置信度结果）

## 第一层：硬排除（决定性）

用用户人生已成的结构性事实做一刀切排除。**结构事实不对应的候选盘直接排除，不留入评分环节。**

| # | 结构事实 | 八字对照字段 | 排除规则 |
|---|---------|------------|---------|
| 1 | 婚姻段数 | 男命：正财+偏财个数 | 候选盘财/官数与实际婚姻数不符 → 排除 |
| | | 女命：正官+七杀个数 | |
| 2 | 有无子女、性别 | 时柱子女星（七杀=子、正官=女） | 子女数与实际不符 → 排除 |
| 3 | 是否离异 | 日支六冲、六害、相刑 | 实际已离异但日支无冲刑害 → 排除 |
| 4 | 学历层次 | 印星三关通过数（详见 `domains/bazi/duanyu/shishen.md`） | 实际学历偏高但印星全不通过 → 排除 |

**排除后只剩一盘** → 直接输出，不再评分。
**排除后无候选盘** → 告知用户数据可能有误，回到收集步骤确认。
**排除后仍有 ≥ 2 盘** → 进入第二层评分。

## 第二层：事件吻合度评分（主评分）

用户提供 3-5 件大事 + 年份，逐盘对每件事命理吻合度打分。

### 评分规则

| 吻合度 | 得分 | 说明 |
|-------|:----:|------|
| 吻合 | +1 | 流年引动方式与事件性质匹配 |
| 不吻合 | -1 | 流年引动方式与事件性质冲突 |
| 不相关 | 0 | 当年无特殊引动，或无法判断 |

### 评分表（示例格式）

| 事件 | 年份 | 候选盘 A 分析 | 得分 | 候选盘 B 分析 | 得分 |
|------|:----:|-------------|:---:|-------------|:---:|
| {事件描述} | {年份} | {流年引动分析} | +1/-1/0 | {流年引动分析} | +1/-1/0 |
| ... | ... | ... | ... | ... | ... |
| **合计** | | | **N** | | **M** |

评分应基于 `bazi.liunian` 返回的流年数据，结合 `domains/bazi/fangfa/dayun.md` 应期决策表分析。

**最高分者占优。** 领先 ≥ 2 分 → 直接输出。

## 第三层：问题方向（平局分水岭）

**仅当两张候选盘得分持平或分差 ≤ 1 时启用。**

命主当前关心的领域是否与候选盘的特征匹配：

| 关心领域 | 盘 A 特征 | 盘 B 特征 | 倾向 |
|---------|---------|---------|:---:|
| 事业 | 官杀透干有力 | 财星旺但身弱难担 | A |
| 婚姻 | 夫妻宫冲刑 | 夫妻宫合化吉 | B |
| 财运 | 比劫夺财 | 财星透干有食伤生 | B |

## 输出格式

```
考时结果：{时辰名}
依据：
  - 硬排除：{排除详情}
  - 评分结果：{评分详情}
置信度：高 / 中 / 低
  - 高：仅一盘未排除
  - 中：评分领先 ≥ 2 分
  - 低：平局后经问题方向判断决出
```

## 边界处理

| 场景 | 处理方式 |
|------|---------|
| 用户提供的事件年份不准（± ≥ 2 年） | 降低该事件权重，不作为主要评分依据 |
| 用户无法提供 ≥ 3 件大事 | 告知精度不足，建议先走默认时辰，后续有更多信息再校准 |
| 候选盘超过 5 张 | 先在硬排除阶段加大力度缩小范围；仍无法缩小则提示用户确认一个更窄的时间段 |
| 用户说"时辰肯定没错" | 跳过考时，以用户声称为准 |
