# 财运判断规则

## 核心原则

财星定有无，身强定胜负，大运定起伏。

## 📖 财星类型

| 类型 | 特征 | 财源 |
|------|------|------|
| 正财透干 | 稳定收入、工薪、实业 | 工资、做生意 |
| 偏财透干 | 投机收入、投资、偏门 | 股票、投资、副业 |
| 正偏财混杂 | 综合收入型 | 主业+副业 |
| 财星不显 | 靠技艺/印星生财 | 技术、专业服务 |

## 财星量级

| 状态 | 判断条件 | 财级 |
|------|---------|------|
| 财旺 | 财星有根 + 身强任财 + 大运生扶 | 富裕，有积蓄 |
| 财平 | 财星有根但身弱 / 身强但财无根 | 中等，略有盈余 |
| 财弱 | 财星无根 + 身弱 / 财被比劫克 | 温饱，存款少 |
| 比劫夺财 | 比劫旺 + 财星弱 + 无比劫制化 | 财来财去，负债 |

**注**：财星在地支有藏干同五行为"有根"。临官/帝旺位为"强根"，余气/墓库位为"弱根"。

## 大运引动

- 财星大运 → 财运上升期
- 比劫大运 → 破财期（合伙/争斗/开销大）
- 官杀大运 → 压力生财（辛苦得财）
- 食伤大运 → 技术/投资得财

## 📖 正财 vs 偏财

| | 正财 | 偏财 |
|--|------|------|
| 来源 | 固定收入、工资 | 投资、副业、横财 |
| 风险 | 低 | 高 |
| 持续性 | 持续稳定 | 时有时无 |
| 命局特征 | 正财透+无冲 | 偏财透+无克 |
| 大运 | 财星运 | 食伤生财运 |

## 📖 翻译表：财运判断

**输入**：财星状态 + 身强弱 + 大运类型 + 比劫位置
**输出**：财运档

### ① 财星定有无

| 财星状态 | 含义 |
|---------|------|
| 正财透干 | 固定收入，稳定财源 |
| 偏财透干 | 投资/副业，波动财源 |
| 财星暗藏 | 财运一般，需要大运引出 |
| 财星不现 | 财运较弱，靠食伤生财 |

### ② 身强定胜负

| 身强弱 | 胜财能力 | 风险 |
|--------|---------|------|
| 身旺 | 能担财，财旺则富 | 比劫夺财则破 |
| 中和 | 可担财，适合稳定财源 | — |
| 身弱 | 不胜财，财多身弱反为贫 | 财旺时更穷 |

### ③ 大运定起伏

| 大运 | 财运方向 |
|------|---------|
| 财星运 | 得财（但身弱不胜则破） |
| 食伤运 | 技术/投资得财 |
| 比劫运 | 夺财，不利 |
| 官杀运 | 压力生财，辛苦得财 |

### ④ 比劫夺财检查

| 条件 | 风险 |
|------|------|
| 比劫与财星相邻（如年干劫财克月干偏财） | **夺财风险高** |
| 比劫与财星隔位 | 有竞争但不直接 |
| 无比劫 | 无夺财之忧 |

### ⑤ 食伤生财检查

食伤为财之源。食伤状态直接影响财星健康度。

| 食伤状态 | 对财的影响 |
|---------|-----------|
| 食伤旺+生财（食伤与财星同柱或相邻） | 财源不断，技术/才华变现 |
| 食伤旺但不生财（被合/被克/隔位过远） | 有才华但变现难 |
| 食伤弱或无食伤 | 财源单一，靠正财收入 |
| 枭神夺食 | 财源中断，需警惕 |

**判断链**：食伤生财为"因"，比劫夺财为"果"。先判断食伤是否生财，再判断比劫是否夺财。
- 食伤生财且无比劫夺财 → 顺遂得财，财能留存
- 食伤生财但比劫夺财 → 辛苦得财，财来财去
- 无食伤生财且比劫夺财 → 无稳定财源还被劫，财务困境

### ⑥ 财印关系检查

财和印相克（财克印为正克）。财印关系决定财富能否转化为长远根基。

| 财印位置 | 含义 |
|---------|------|
| 财星透干克印 | 因财弃学、因财失贵、短期得财但损长远根基 |
| 印星制财 | 保守理财、因原则/家庭因素放弃财机 |
| 财印隔位（中间有其他十神） | 财印不直接交战，财富与健康/家庭可兼得 |
| 财印相邻（同柱或紧邻） | 直接冲突，得财必损某方面（健康/家庭/声誉） |
| 财星在年柱克月柱印星 | 早年家境因财问题影响学业 |

**身弱时财印关系更关键**：身弱不胜财，财星透干反克印→财为压力非财富，得财即损根基。

### ⑦ 财运流年应期排队列

候选年份优先级（参考 domains/bazi/fangfa/dayun.md「应期决策表」）：

| 优先级 | 条件 |
|-------|------|
| 1st | **换运年（±1年）** > 普通年份 |
| 2nd | **财星透干+食伤生财双重引动** > 单重引动 |
| 3rd | **财星合入命（六合/三合引动财星）** > 财星冲入命（冲则变动不定） |
| 4th | 财星值年（流年干支与财星相同）> 食伤生财年 > 比劫夺财年 |

**用法**：多个候选年份时从第1维开始比，第一个分出高低的维度决定应年。
