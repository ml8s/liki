# 学业判断决策表

用于分析学历/学业问题时逐项检查。

**核心原则**：印星为学业的第一指标，食伤为辅助。
**【强制】前置——先定身强弱 + 印星为用/为忌**：
- 身弱印为用 → 印星得力则学历高（印是「补药」）
- 身强印为忌 → 印星旺反主「食古不化」，学历看**食伤泄秀**或**官杀生印**（压力成才）
- 判断依据：按 `domains/bazi/fangfa/wangshuai.md` 定身强弱，再定印星喜忌
- **反例**：身强（水旺）印星（金）为忌，但官杀（土）制身生印 → 仍可高学历（压力成才、官杀生印）——**不能因「印为忌」直接判学历低**

## 📖 翻译表：学历判断

**输入**：印星透干/藏支 + 印星状态（得令/被财克/有根） + 食伤状态
**输出**：学历档

### ① 印星有效性三关

| 检查项 | 通过条件 | 不通过标记 |
|--------|---------|-----------|
| 得月令 | 印星在月令得生扶 | 印星在月令休囚死 |
| 不被财克 | 原局无财星透干克印 | **财星透干克印（坏印，重破）**；财星合印（如壬丁合、乙庚合印）亦记**重破** |
| 有根 | 印星在地支有藏干同五行 | 无根（虚浮） |

通过三关 → 印旺有效
通过两关 → 印星中等
通过一关或不通过 → 印弱或无效

### ② 大运辅助

| 大运类型 | 对学业影响 |
|---------|-----------|
| 印星运 | 学业上升期 |
| 官杀运 | 压力中学业 |
| 食伤运 | 轻学重技 |
| 财运 | 不利学业（财坏印） |

### ③ 组合判断

| 组合 | 效果 |
|------|------|
| 食伤配印 | 学以致用，聪明且学历高 |
| 食伤无印 | 聪明但学历不高 |
| 官杀生印 | 文凭带来地位 |
| 财星坏印 | 因钱弃学 |

### ④ 学历等级决策表

**【强制】格局主导优先于印星三关**：先断格局层次，再以印星三关作佐证——
- **官杀生印**（官杀制身生印，压力成才）→ 学历层次**上提**（如印弱三关不全亦可到大学以上，禁止按"印弱"直落专科）
- **食伤泄秀/伤官配印**（聪明秀气，学以致用）→ 学历层次正常偏上，禁止按"印星单关"压档
- **印被财克破且无格局补救**（无官杀生印、无食伤泄秀）→ 才落"学历中断/中学"档
- 三关通过数与格局冲突时，**格局定方向、三关定档位细节**，禁止互相矛盾反复横跳

| 印星状态 | 食伤/财状态 | 学历倾向 |
|---------|------------|---------|
| 印旺得令+有根+无破 + **官杀生印（压力成才）+ 紫微官禄化科 + 食伤透干技术登顶** | — | **博士**（技术/学术登顶） |
| 印旺得令+有根+无破（缺博士附加条件） | — | **硕士** |
| 印旺+微破（缺一关，且非财克破） | 食伤不克印或无食伤 | **大学** |
| **印旺但被财克破（印为用被制死）** | — | **中学/高中**（学历中断档） |
| 印弱+无破 | — | **专科/高中** |
| 印弱+被克 | — | **中小学** |
| 无印 | 食伤旺 | **技术技艺型**（非学历） |
| 印被财合（财合印） | — | **因利弃学，学历中断（中学及以下）** |

**强制修正项（查档后必检）**：
- **大运破坏修正**：求学关键期（小学-大学对应年龄段）行**食伤运/财运（财坏印）** → 至少降一档；行印星运 → 可升一档。
- **在读/未成年检查**：问学历时点若命主未成年或仍在读（如 12-18 岁），不得判“已毕业/硕士/博士”档，按在读阶段对应档输出。

### 强制修正项补充【强制】

- **无中间档禁止跳档**：查档结果若为硕士但选项无硕士档，须回验印星三关实况后**降档**判定（落高中/专科），禁止直跳最高/最低档凑选项
- **"不被财克"三关补充**：财星藏支有根（火库/余气）**暗克印**、食神合印（乙庚合）均记**破**（不得按"微破"论）

### 学历档护栏【强制】

- **"印被财合/财克破→学历中断"档优先映射"入学后中断"**（重点大学中途退学/因利弃学），不是直落"高中毕业/中小学"；先评"入学能力"（官杀生印/食伤泄秀/文昌化科存在 → 入学能力在，只断中途辍学不断没考上）
- **禁跳档只禁向下**：印星修复（大运印星透干/官杀生印转旺）可向上恢复一档
- **入学能力 ≠ 毕业档**：大运合财解印/印星转旺**只恢复"入学能力"**（能考上），**不得恢复"毕业档"**——已断"学历中断"者，大运印旺只作"补学历/进修"论，不得改判"已毕业"档
- **档位铁律不受"身强印为忌/制化优先"豁免**：决策表档位按印星三关实况执行；但"身强印为忌"时**印星受制不降档**（印忌受制反利求学，参照格局主导条款）
