# 六爻吉凶判定

> 经典依据：《增删卜易》《卜筮正宗》——断吉凶以用神旺衰为纲，动爻生克为用，月破旬空为破。

## 📖 判定表：用神状态 → 吉凶

| 用神状态 | 动爻关系 | 吉凶 |
|---------|---------|------|
| 旺相（月建或日建生扶） | 动爻生扶用神（原神发动） | 吉（事可成） |
| 旺相（月建或日建生扶） | 静爻或无动爻克害 | 吉（顺势而发） |
| 休囚（月建日建克制） | 动爻生扶 | 平（需待时） |
| 休囚 | 静爻 | 平（事缓/勉强） |
| 休囚 | 动爻（忌神）克用神 | 凶（事难成） |
| 月破（月令冲爻） | 无 | 凶/待时（月破失力，逢合方补） |
| 旬空（用神空亡） | 无 | 凶/虚（事不实，出空方应） |
| 用神化退神/化绝 | 无 | 凶（力量衰败） |
| 用神化进神 | 无 | 吉（力量增长） |
| 用神持世 | 得月日生扶 | 吉（近身得力） |
| 世应相冲 | 用神受克 | 凶（主体不和） |

## 断卦要点（顺序）

1. **取用神**：按所问事由查「用神取用表」（yongshen.md）
2. **看旺衰**：用神在月建/日建的状态（旺相/休囚/入墓/月破）——yuejian.md
3. **看动爻**：动爻与原神/忌神关系——生扶用神=吉，克害用神=凶
4. **断应期**：按用神状态查「应期判断表」（yingqi.md）

## 边界

- 多动爻（两爻以上发动）需看组合，取最关键的一动（生克力量最直接者）
- 用神与世爻关系：用神持世/临世=事近身；用神临应=事在外
- 变卦吉凶：本卦定事体，变卦定结果（化进=成、化退=败、化空=虚）
