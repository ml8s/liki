# 三才五格

## 📖 决策表：五格构成

| 格 | 计算 | 含义 |
|----|------|------|
| 天格 | 姓氏笔画 + 1（单姓）| 祖上/先天 |
| 人格 | 姓氏最后一字 + 名第一字 | 主运/自我 |
| 地格 | 名各字笔画之和 | 前运/早年 |
| 外格 | 总格 - 人格 + 1 | 副运/社交 |
| 总格 | 姓 + 名全部笔画 | 后运/一生 |

## 📖 决策表：数理吉凶

数理 1-81 各有吉凶（吉：1/3/5/6/7/8/11/13/15/16/17/18/21/23/24/25/29/31/32/33/35/37/39/41/45/47/48/52/57/61/63/65/67/68/81；凶：2/4/9/10/12/14/19/20/22/26/28/30/34/36/38/40/42/43/44/46/49/50/51/53/54/56/58/59/60/62/64/66/69-80）。

**注意**：吉笔画由 `qiming.pick` 内部计算（wuge=true 时），**不得自行推算**。

## 📖 决策表：三才配置

三才（天/人/地）五行相生为吉（木火土金水顺生），相克为凶。吉笔画对的组合由 `qiming.pick` 返回，**不手工排列**。

## 边界

- 单名：无外格计算差异（总格 = 人格 + 1）
- 复姓：天格 = 姓氏笔画之和（不加 1）
- 康熙笔画为准（非简体笔画）
