# 命盘报告

## 依赖的领域知识

- bazi: knowledge/ 全部决策表（各类）
- app: marriage.md（汇总用）
- app: health.md（汇总用）
- 其他 app（汇总用）

## 设计原则

**只陈列事实，不做深度判断。** 每条事实后指向对应 app 供深入。

```
命盘报告不是"婚姻好/不好"的结论，
而是"年干正官一位、日支无冲、大运未见正官透"的事实陈列。
```

用户看了陈列后说"我想看婚姻" → 定向到 app/marriage.md 做深度分析。

## 📖 流程卡

第1步：调用 Phase 1 命盘基础
  → bazi/SKILL.md Phase 1 已完成
  输出：□ 旺衰____ 格局____ 用神____ 合冲____

第2步：各领域快速扫描
  → 陈列各领域关键事实，不做判断
  婚姻：□ 配偶星状态____ 夫妻宫____
  学业：□ 印星三关____ 学历档____
  健康：□ 五行虚实____
  事业：□ 官财透干____
  财运：□ 财星类型____
  性格：□ 日主特征____

第3步：输出合成
  → 按模板输出简短结论，每条附 app 链接
  输出：□ 命盘报告____

📖 搜索 bazi/knowledge/ 各决策表 → 获取原始数据

## 历史事件校准

完成命盘报告后，如果用户愿意验证，可按大运流年反推已发生的 3-5 个时间段，请用户验证是否吻合实际人生变化。反馈后调整用神权重或维持原有判断。

## 报告模板引用

完整命盘报告按 `bazi/format-chart.md` 模板输出。合盘按 `bazi/format-hepan.md` 模板输出。

## 📖 输出模板

```
【命盘概览】
八字：{四柱}
日主：{身强/弱}，用神{ }，忌神{ }
关键格局：{格局名称}

【各领域速览】
婚姻：{配偶星状态}，{夫妻宫状态}  → 深入：app/marriage.md
学业：{印星状态}，{学历倾向}       → 深入：app/study.md
健康：{薄弱脏腑} → 深入：app/health.md
事业：{事业方向} → 深入：app/career.md
财运：{财源类型} → 深入：app/wealth.md
性格：{基础特征} → 深入：app/personality.md
```
