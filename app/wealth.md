## 📖 流程卡

第0步：排盘（前置）
  → 调用 bazi.chart(solar_time, gender) 排八字 → 四柱/大运
  → 调用 bazi.fullchart(chart) 取全量（十神/藏干/神煞/空亡）
  → 调用 ziwei.chart(lunar, gender) 排紫微 → 十二宫
  → 调用 ziwei.fullchart(chart) 取全量（杂曜/长生/小限）
  校验：四柱齐全、十二宫齐全，缺失则补问出生时间

第1步：财星定有无
  → 调用 domains/bazi/duanyu/caiyun.md「财星定有无」
  输出：□ 财星类型____ 透/藏____

第2步：身强定胜负
  → 调用 domains/bazi/duanyu/caiyun.md「身强定胜负」
  输出：□ 胜财能力____（能担/不能担/中和）
  → 财多身弱互斥锁：
    □ 身{强/弱/中和} + 财{旺/平/弱}
    身弱+财旺 → 强制结论"财多身弱反为贫"，阻断后续"得财"判断
    身弱+财平 → 财可担但有限，不以大财论
    身强+财旺 → 正常得财判断

第3步：大运+比劫检查
  → 换运年检测：当前年龄____ 是否在换运年±1年内？____ 若是→该年事件强度+1级
  → 调用 domains/bazi/duanyu/caiyun.md「大运定起伏」+「比劫夺财检查」
  输出：□ 当前大运____ 夺财风险____

第4步：紫微验证
  → 调用 domains/ziwei/duanyu/yingqi.md「财运」表
  输出：□ 财帛宫星曜____ 化禄/忌____ 与八字（一致/相反）____

## 📖 输出模板

### 长格式

```
【财运分析】
财星类型：{正财/偏财}，{透干/藏支}
胜财能力：{能担/不能担/中和} → {财旺则富/财多身弱/稳定财源}
大运影响：{财/食伤/比劫/官杀}运 → {得财/技术赚钱/夺财/辛苦得财}
风险提示：{比劫夺财/无}
```

### 短格式

```
财运：{正/偏}财{透/藏}，身{旺/弱/中和}。当前{大运}运{有利/不利}。
```

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 原局无财星 | 查食伤（食伤生财为隐性财源）|
| 财多身弱 | 标注为"财多身弱反为贫"，需大运帮身方可担财 |
