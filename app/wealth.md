## 📖 流程卡

⟳ 执行主干 Phase 1-2（时辰判定 + 排盘快照），此处不重复

第1步：财星定有无
  → 调用 tools/bazi/caiyun.csv（cai_101-109）
  输出：□ 财星类型____ 透/藏____

第2步：身强定胜负
  → 调用 tools/bazi/caiyun.csv
  输出：□ 胜财能力____（能担/不能担/中和）
  → 财多身弱互斥锁：
    □ 身{强/弱/中和} + 财{旺/平/弱}
    身弱+财旺 → 强制结论"财多身弱反为贫"，阻断后续"得财"判断
    身弱+财平 → 财可担但有限，不以大财论
    身强+财旺 → 正常得财判断

第3步：大运+比劫检查
  → 调用 tools/bazi/caiyun.csv+tools/bazi/caiyun.csv
  输出：□ 当前大运____ 夺财风险____

第4步：紫微验证【强制——断「具体细节」时必做，禁止只凭八字粗断】
  → 调用 domains/ziwei/fangfa/yingqi.md「财运」表
  输出：□ 财帛宫星曜____ 化禄/忌____ 与八字（一致/相反）____

## 📖 输出模板

### 长格式

```
【财运分析】
财星类型：{正财/偏财}，{透干/藏支}
胜财能力：{能担/不能担/中和} → {财旺则富/财多身弱/稳定财源}
大运影响：{财/食伤/比劫/官杀}运 → {得财/技术赚钱/夺财/辛苦得财}
风险提示：{比劫夺财/无}
```

### 短格式

```
财运：{正/偏}财{透/藏}，身{旺/弱/中和}。当前{大运}运{有利/不利}。
```

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 原局无财星 | 查食伤（食伤生财为隐性财源）|
| 财多身弱 | 标注为"财多身弱反为贫"，需大运帮身方可担财 |

- **信号冲突 → 查 SKILL.md 执行主干（Phase 6 紫微交叉裁决）**：本卡与紫微/八字互斥时，回主干按「紫微结构专断/一般冲突」裁决，禁止本卡内自决。
