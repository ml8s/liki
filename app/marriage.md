## 📖 流程卡

⟳ 执行主干 Phase 1-2（时辰判定 + 排盘快照），此处不重复

第1步：确定性别，定位配偶星（男看财星、女看官杀）
  → 调用 domains/bazi/fangfa/shishen.md「女命婚姻——官杀混杂判断」填表
  输出：□ 配偶星____ 官杀几位____ 有取清？____

第2步：夫妻宫（日支）检查
  → 调用 domains/bazi/fangfa/gongwei.md「日柱」
  输出：□ 日支冲刑____ 日支被合？____
  □ 合化类型（绊/化/动）____ 合化出什么五行____
  □ 合化结果：化出{五行} → 是{用神/忌神}
    化用神→吉应（感情顺/配偶得力），可判窗口年
    化忌神→凶应（感情纠葛/配偶拖累），大运引动亦不以吉论

第2.5步：婚姻状态锁定【强制——先锁状态再推应期；未锁定状态时禁止编造“某年结婚+某年离婚”完整叙事】
  → 判当前状态，三选一，输出：□ 状态 = 已婚 / 单身（含独身倾向）/ 离异
  已婚判据（需≥2项，且**无否决项**）：
    □ 配偶星得地（透干/有根/得月令）
    □ 夫妻宫无大破（非空亡、非双重冲克）
    □ 大运或流年已引动过配偶星且带禄/贵人
  **否决项（任一项成立 → 不得锁"已婚"，落"未婚/晚婚/恋情"路径）**：
    □ 大运从未实引动过配偶星（只有原局信号，无应期年份）
    □ 官杀（女）/财星（男）原局极弱且大运无透
    □ 孤辰/寡宿入命宫或夫妻宫、夫妻宫主星落陷/空宫
    □ 配偶星得地但带桃花贵人——仅为"异性缘/恋情"，须叠加"大运夫妻宫真动（六合/禄入）"才升格为"已婚"；**红鸾/天喜不苛求坐实流年夫妻宫**，夫宫/妻宫逢合逢冲流年 + 大运财官星交集即可断婚期
  单身/独身倾向判据（需≥2项）：
    □ 配偶星原局不现且大运无透
    □ 比劫重重（比肩+劫财≥3）+ 夫妻宫双重冲克
    □ 孤辰/寡宿入命宫或夫妻宫、命宫无桃花星
    → 判“难成婚/晚婚/独身倾向”后：有引动年份只能断“有感情经历/婚恋机会”，禁止输出“某年结婚+某年离婚”
  婚恋异常检查（强制输出一行判断，禁止写“无异常信号”式未验证否定句）：
    □ 女命官杀极弱或无 / 男命财星极弱或无 + 命宫身宫主星 + 桃花/孤寡组合 → 输出“性取向/婚恋模式倾向”判断（独身主义/同性倾向/晚婚等）
    **孤辰寡宿禁断极端**：孤辰/寡宿/华盖入命宫或夫妻宫 → **只许断“晚婚/有恋情/婚缘迟”，禁止据此断“同性恋/独身主义”**；同性恋须三证齐备：原局配偶星全无 + 夫妻宫廉贞贪狼组合 + 身宫天相类组合，且大运无配偶星实引动
  已婚状态下婚变判定【双证门槛，不再要求紫微化忌】：
    □ 伤官克官（女）/财星受克（男）年份只记“婚姻矛盾年”，先不判离异
    □ 断离异须双证齐备：① 夫妻宫被冲/刑/穿（流年或大运冲合刑穿日支）② 夫妻宫见凶格（地空/天哭/流羊/化忌入本命夫妻宫）或忌神攻身（官杀克身、伤官见官、财星受克并见）
    □ 紫微流年夫妻宫化忌只作**佐证**（助证离异之年），不作必要条件
    → 婚变段数 ≠ 冲忌次数：每段婚变须独立“成婚→离异”闭环；再婚须新财/官星重新引动

第3步：大运流年婚姻窗口
  → 调用 domains/bazi/fangfa/dayun.md「应期决策表」筛选候选年份
  → **婚变流年（经典正断）**：女命正官（夫星）受克之年 = 婚变窗口——官坐绝地/被伤官冲克/被比劫争合之年优先。男命看正财（妻星）受克同理
  → **应期排序铁律（按优先级从高到低，禁止跨级覆盖）**：
    ① 流年地支值夫妻宫/日支（伏吟、值宫位）→ 一律入候选，不得以“忌神克财/偏财非正妻/官星未透”否决
    ② 夫妻宫被合/冲/刑/害引动（宫位引动）优先于配偶星天干透出/合（星动）
    ③ **大运配偶星得地期内早期合动年优先**：禁止以换运后透干年压过早期合动年；大运财/官星透出首年（换运第一年）强制入候选
    ④ 换运年仅在直接引动配偶星或夫妻宫时加权，禁止仅因“换运+伏吟叠加”压过①/②/③
    ⑤ 凶信号≠排除：候选年常伴冲/比劫/官杀攻身，只要配偶星或夫妻宫同时被引动就保留
    ⑥ **大运与流年相冲会冲散流年合动**：合动被大运冲散者不作最高级信号
  输出：□ 窗口年份____ 引动类型____

第4步：紫微验证【强制——断「具体细节」（何年结婚/离婚/配偶情况）时必做，禁止只凭八字粗断】
  → 调用 domains/ziwei/fangfa/yingqi.md「婚姻」表
  输出：□ 夫妻宫星曜____ 四化____ 桃花星____ 与八字（一致/相反）____
  → 断「哪年结婚」：调 ziwei.liunian(chart, liu_nian) 看候选年份的**流年夫妻宫四化**（化禄/化权=吉应年，化忌=凶应）→ 与八字大运窗口取交集

第5步：综合结论
  → 整合前四步输出
  输出：□ 婚姻质量____ 建议窗口年____

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 用户未婚但问离婚 | 先问是否已有稳定对象，有则分析当前关系，无则分析命局倾向 |
| 男命问感情但原局无财星 | 食伤为财源，查食伤状态（食伤生财为隐性妻星） |
| 女命问婚姻但原局无官杀 | 查财星（财生官杀为隐性夫星），或大运引动 |
| 已离婚问再婚 | 查七杀是否清透，大运有无正官/正财出现 |
| 用户只提供了一个人的八字但想看合盘 | 提示需要双方出生信息，引导到 app/compatibility.md |

### ⚠️ 婚姻锁定补充规则【强制】

- **大运/流年透官杀（女）/财星（男）不得自动升格"已婚"**：原局配偶星极弱/不现 + 夫妻宫空宫或主星落陷 + 孤寡/华盖入日支时，必须先走"婚恋异常路径"（未婚/晚婚/同性/独身倾向）并对照选项；大运透星只允许把"未婚"修正为"晚婚/有恋情"，不得锁"已婚"
- **A/B 类证据并列时逐项打分**：同时存在支持"已婚"与支持"未婚/恋情"的证据时，逐项列出并打分（本命日支/原局配偶星权重 > 大限夫妻宫/流年桃花），≥2 项才可锁状态
- **离婚逐项证据验收表**（双证门槛逐项列证据，任一项无证据→只记"婚姻矛盾/动荡年"，状态保持已婚）：
  - ① 夫妻宫被冲/刑/穿：流年或大运冲合刑穿日支（伏吟/反吟不作冲开）
  - ② 夫妻宫凶格（地空/天哭/流羊/化忌入本命夫妻宫）或忌神攻身（官杀克身、伤官见官、财星受克并见）
  - 佐证：紫微流年夫妻宫化忌（只助证年份，不作必要条件）
- **再婚判据（新增，断二婚/三婚必查）**：离异后再见"大运配偶星重新得地（透干/有根）+ 流年夫妻宫复吉（禄入/合动）"即断第二段婚姻；无此则维持"离异后未再婚"；禁止用"同干支机制重演"逆向锁年（头婚年变更时强制重推再婚候选）

### ⚠️ 婚姻锁定护栏【强制——否决项优先级 > 升格条款】

- **否决项优先级**：孤辰/寡宿入夫妻宫、夫妻宫主星落陷/空宫、配偶星原局极弱/不现，任一成立 → **强制走婚恋异常路径**（未婚/晚婚/同性/独身倾向），红鸾/天喜/六合/大运透星**一律不得升格"已婚"**（只许修正"独身"为"晚婚/有恋情"）
- **升格条款仅适用**"配偶星得地但带桃花贵人"这一类，且必须在否决项核验之后执行
- **对向选项证据打分（定案前必做）**：婚姻状态题必须同时给出"已婚"与"未婚/独身/同性恋"两列的命理证据（原局官杀/财星有无、夫妻宫主星庙陷、孤寡/桃花、大运是否实引动）逐项对比强弱后再定；禁止"无同性信号"一句话绕过——同性倾向判据：原局官杀（女）/财星（男）全无 + 夫妻宫廉贪/主星 + 身宫天相类组合
- **结婚应期**：妻星/夫星透干降为佐证而非门槛；妻宫/夫宫逢合逢冲流年 + 大运财官星交集优先；正官/财星合日主（女命官合身/男命财合身）= 最高级婚期信号

- **信号冲突 → 查 SKILL.md 执行主干（Phase 6 紫微交叉裁决）**：本卡与紫微/八字互斥时，回主干按「一票否决类/一般冲突」裁决，禁止本卡内自决。
