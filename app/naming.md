# 起名分析

## 依赖的领域知识

- bazi: domains/bazi/yongshen.md「用神方法论」
- qiming: domains/qiming/SKILL.md「起名领域」（五格/字库/选字）

## 用户问法 → 领域信号

| 用户说 | 对应操作 |
|--------|---------|
| 起名/改名 | 排八字定用神 → 取字库 → 排三才五格 → 推荐 |
| 外国人起中文名 | 英文姓→音近中国姓推荐 → 按中文起名流程 |
| 自选名字让我看看 | 跳过流程，直接评估名字 |

## 📖 流程卡

第1步：排盘（前置）
  调用 bazi.chart(solar_time, gender) → 返回四柱/十神/旺衰
  校验四柱齐全（年/月/日/时干支持），缺失则补问出生时间

第2步：定用神/喜神
  调用 bazi.yongshen（用上一步 chart）→ 返回三派用神（扶抑/调候/格局，各含 yong/xi/ji）
  按 domains/bazi/yongshen.md 定夺——用神按决策表定（扶抑定基础/格局定方向/调候做修正），**喜神/忌神取用神所在派的 xi/ji**（同派配套，详见 domains/bazi/yongshen.md「喜神/忌神定夺」）
  **特别注意调候**：冬夏极端月份调候优先于扶抑和格局
  输出：□ 用神____ 喜神____ 忌神____

第3步：定命名参数
  输出：□ 单/双字名____ 考虑三才五格？____

第4步：定字库策略
  默认「用+用」：双字都取用神五行 → pick 一次（wuxing1=wuxing2=用神）
  候选不足回退「用+喜」：一用神一喜神 → **pick 调两次**（双向都要）：
    pick(陈, 用神, 喜神) → 用+喜方向（第1字用神、第2字喜神）
    pick(陈, 喜神, 用神) → 喜+用方向（第1字喜神、第2字用神）
  两个方向的 combos 都收集，LLM 合并筛选
  输出：□ 第1字五行____ 第2字五行____

第5步：取字
  调用 qiming.pick(surname, 第1字五行, 第2字五行?, count, wuge)
    count: 1=单名 2=双名（恒生效，决定单/双字池）
    wuge: true=按吉笔画取字（默认，surname 必填）/ false=按笔画取字（surname 不需要）
    wuxing2: 第2字五行；用+用=同 wuxing1，用+喜=喜神（双向需互换 wuxing1/wuxing2 调两次）
  返回 combos 数组，每组合 {id, first, second?}（first/second 纯字数组）
  LLM 过滤每组字（机械删→语义删，按「domains/qiming/ziku.md 字库过滤细则」）→ 保留好字
  **只允许在同一 combo 的 first/second 内选字**——跨组组合笔画对会错，五格不保（check 也救不回）
  **字池太差的组直接跳过**：某组 first/second 全是生僻字或无一可用 → 整组丢弃，不硬选
  **候选不足时逐级回退**：放宽语义过滤→放宽机械过滤→用+用→用+喜→调整用神策略
  输出：□ 过滤后 combos____

第6步：组名（仅双名）
  单名：LLM 直接从 combos 的 first 选 1 个字 → 即 given name，跳过 build
  双名：调用 qiming.build({combos: 过滤后的 first/second})
    → 引擎 first×second 笛卡尔积 → given name 数组（不含姓）
  LLM 过滤候选名（不吉/拗口/歧义删）
  **谐音审查**：读一遍，删除谐音不雅者（如"梦嘉"→"梦假"、"梓默"→"沉默"）
  **重字检查**：删除两字相同或与姓重复者
  输出：□ 候选名（given name）____

第7步：评估
  调用 qiming.check(surname, names=[given name 数组]) → 五格三才音调评估
  LLM 按评估结果 + 语义，终选推荐
  输出：□ 推荐名____ 寓意____ 五行____

## 红线（强制）

- **不得自行推算五格数理**，吉笔画由 qiming.pick 内部计算（wuge 已并入 pick）
- **build 的 combos 必须来自 qiming.pick 输出**，不得凭空编造字
- **不得跳步**：未完成第4步取字过滤，不得进入第5步组名
- **单名不走 build**（直接从 first 选字），双名才 build
- **check 的 names 只传名（given name 不含姓）**，surname 单独传
- **组合只在同一 combo 内**（first 配本组 second），严禁跨组搭配
- **生僻字宁可放弃整组**，不得为了凑数选自己不认识的字

## 边界条件

| 异常场景 | 处理方式 |
|---------|---------|
| 候选不足 8 个 | 逐级回退：①放宽语义过滤→②放宽机械过滤→③用+用→用+喜→④调整用神策略 |
| 用户不满意 | 放宽过滤，或回退命理决策尝试另一策略（用+用 ↔ 用+喜） |
| 用户自选名字 | 跳过全部流程，直接评估名字 |
| 名字评估字段缺失 | 跳过该维度，不臆测 |
| 外国人起名 | 英文姓→推荐 3-5 个音近中国姓供确认→按中文流程 |

## 📖 输出模板

### 一、用神
一句话：日主强弱、身强身弱、用神喜忌 → 起名宜补五行方向。

### 二、候选名字

| 名字 | 五行 | 寓意/出处 | 三才五格 |
|------|------|----------|---------|
| [名字] | [单/两字五行] | [寓意和出处] | [吉·吉；不考虑三才时留空] |

名字行数不限，能出几个写几个。单字名五行写一字属性，双字名五行列显示两字各自的五行。有生僻字时在寓意列加注拼音。候选不足时不强求 8 个。

### 三、推荐
一句话给出综合推荐。
